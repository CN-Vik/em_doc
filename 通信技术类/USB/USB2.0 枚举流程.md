USB2.0 枚举（Enumeration）是指 USB 设备连接到主机（Host）后，主机识别设备并为其分配资源（地址、驱动、配置）的过程。这个过程是 USB 协议栈中的核心步骤，确保设备可以被系统正确识别和使用。

我们可以从主机角度来详细描述 USB2.0 的 **完整枚举流程**：

---

## 🧩 一、基本流程概览

1. **物理连接**
2. **设备检测**
3. **总线复位（Reset）**
4. **获取设备描述符（Device Descriptor）**
5. **分配地址**
6. **获取更多描述符（配置、接口、端点）**
7. **设置配置**
8. **驱动加载并完成枚举**

---

## 🧵 二、详细过程

### 1. 🔌 物理连接

* 当 USB 设备插入主机端口时，USB 数据线上的 **D+ 或 D- 被拉高**。

  * USB2.0 全速（Full-Speed）：D+ 上拉
  * USB2.0 低速（Low-Speed）：D- 上拉

主机检测到此状态变化，说明有新设备插入。

---

### 2. 🔍 主机检测设备并供电

* 主机向设备提供 **5V 电源**。
* 检测到设备上拉后，开始启动 USB 状态机流程。

---

### 3. 🔄 端口复位与速度检测

* 主机对该端口进行 **Reset（10ms以上）**，让设备进入默认状态，清除之前状态。
* 同时，主机通过电平识别设备是：

  * 低速（1.5 Mbps）
  * 全速（12 Mbps）
  * 高速（480 Mbps，USB2.0 High-Speed）

> ⚠️ 高速设备必须通过 Chirp 信号确认。

---

### 4. 📦 获取设备描述符（Device Descriptor）

* 此时设备默认地址为 **0**。
* 主机发送 `GET_DESCRIPTOR` 请求，读取 **前8字节** 的 Device Descriptor。

主要信息包括：

* USB 版本（bcdUSB）
* 类别（bDeviceClass）
* 最大包长（bMaxPacketSize0）
* 供应商 ID（VID）
* 产品 ID（PID）

---

### 5. 🏷️ 分配 USB 地址

* 主机使用 `SET_ADDRESS` 命令为设备分配一个唯一地址（1\~127），然后通信地址就变为新地址。

---

### 6. 📑 获取完整描述符信息

* 使用新地址与设备通信。
* 主机读取：

  * **Device Descriptor（完整）**
  * **Configuration Descriptor**
  * **Interface Descriptor**
  * **Endpoint Descriptor**
  * **String Descriptor（可选）**

---

### 7. ✅ 设置配置

* 主机发送 `SET_CONFIGURATION` 命令，设备将进入工作状态。

配置描述符中会指定设备使用的接口、端点数量、端点类型（中断、批量、等时、控制）、功耗等。

---

### 8. ⚙️ 驱动加载与使用

* 主机根据 VID/PID、Class/SubClass/Protocol 匹配对应的驱动程序（如 UVC、HID、MSC 等）。
* 驱动加载完成后，设备可用，枚举完成。

---

## 📊 三、关键传输内容总结

| 描述符                      | 描述                       |
| ------------------------ | ------------------------ |
| Device Descriptor        | 提供设备基本信息（VID/PID、USB版本等） |
| Configuration Descriptor | 提供一个或多个设备配置方案            |
| Interface Descriptor     | 每个配置包含多个接口信息             |
| Endpoint Descriptor      | 每个接口包含多个端点（输入/输出）        |
| String Descriptor        | 提供字符串信息，如厂商名、产品名等        |

---

## 🧠 四、USB 枚举时的典型控制请求

| 请求                  | 方向            | 说明        |
| ------------------- | ------------- | --------- |
| `GET_DESCRIPTOR`    | Host → Device | 获取各种描述符   |
| `SET_ADDRESS`       | Host → Device | 分配 USB 地址 |
| `SET_CONFIGURATION` | Host → Device | 设置工作配置    |
| `GET_CONFIGURATION` | Host ← Device | 获取当前配置    |

---

## 🛠️ 五、分析工具推荐

* **USBlyzer** / **USBView**（Windows）
* **Wireshark + usbmon**（Linux）
* **逻辑分析仪**：抓取 D+/D- 总线数据

---

## 🧭 六、USB2.0 vs USB3.0 枚举差异

| 项目    | USB2.0       | USB3.0                         |
| ----- | ------------ | ------------------------------ |
| 传输速度  | 最高 480 Mbps  | 最高 5 Gbps                      |
| 电气接口  | D+/D-        | 增加了 SuperSpeed TX/RX 对         |
| 枚举流程  | 较简单          | 增加 Link Training、LPM 状态等       |
| 设备描述符 | 只有 USB2.0 格式 | 增加 BOS（Binary Object Store）描述符 |

* **设置地址**：分配唯一的 USB 地址，后续通信都用此地址。

* **设置配置**：激活设备配置，设备进入工作状态。
* **驱动加载**：操作系统匹配驱动程序，完成设备识别。
