
你主要搞 **FOC + 平衡车**，示波器最重要的注意事项不是“会不会按按钮”，而是：

> **别把示波器地夹乱夹，否则轻则波形不对，重则短路炸板、烧 MOS、烧示波器。**

尤其是你测三相 BLDC 半桥、电机相线、电池母线、MOS 管驱动时，这个非常关键。

---

# 1. 第一大坑：示波器地夹不是“随便夹的地”

普通台式示波器的探头一般是这样：

```text
探头尖端：测量信号
地夹：示波器公共地
```

但注意：

```text
所有探头的地夹在示波器内部是连在一起的
而且通常还和插座保护地 PE 相连
```

也就是说，CH1 地夹、CH2 地夹、CH3 地夹、CH4 地夹，本质上都是同一个点。

## 错误操作

比如你测三相逆变桥：

```text
U 相
V 相
W 相
电池负极 GND
```

你如果这样夹：

```text
CH1 地夹夹 U 相
CH2 地夹夹 V 相
```

那等于你把：

```text
U 相 和 V 相 通过示波器地线短接了
```

这可能直接炸 MOS。

---

# 2. 你测 FOC 时，哪些点可以直接测？

如果你的平衡车是电池供电，板子没有接市电，通常可以把示波器地夹接到：

```text
电池负极
功率地 PGND
控制板 GND
电流采样地
驱动芯片 GND
```

然后探头尖端去测：

```text
低边 MOS 栅极信号
PWM 输入信号
电流采样放大器输出
母线电压分压输出
霍尔信号
编码器 A/B 相
IMU I2C/SPI 信号
MCU GPIO
```

这些一般是安全的。

---

# 3. FOC 最危险的测量点：电机三相相线

电机三相线：

```text
U / V / W
```

都不是固定地，它们是高速开关节点。

比如 U 相电压会在：

```text
0V 和 电池电压之间高速跳变
```

假设你的电池是 24V：

```text
U 相：0V ~ 24V PWM 跳变
V 相：0V ~ 24V PWM 跳变
W 相：0V ~ 24V PWM 跳变
```

你不能把示波器地夹夹到 U 相，然后探头尖端测 V 相。

因为这会让 U 相被强行接到示波器地。

---

# 4. 想测相电压，应该怎么测？

## 方法 1：测相对电池负极的波形

这个最简单。

```text
示波器地夹 -> 电池负极 / 功率地
探头尖端 -> U 相
```

可以看到：

```text
U 相对 GND 的 PWM 波形
```

同理：

```text
CH1 -> U 相
CH2 -> V 相
CH3 -> W 相
所有地夹都夹电池负极
```

这样可以观察三相 PWM。

但是注意，这测的是：

```text
U-GND
V-GND
W-GND
```

不是电机真正两端的：

```text
U-V
V-W
W-U
```

---

## 方法 2：用 Math 做差分

如果你想看：

```text
U - V
```

可以这样：

```text
CH1 探头尖端 -> U 相
CH2 探头尖端 -> V 相
CH1/CH2 地夹 -> 都夹电池负极
示波器 Math -> CH1 - CH2
```

这样可以得到近似的线电压：

```text
U - V
```

这种方法适合低压 BLDC，比如 12V、24V、36V 平衡车调试。

---

## 方法 3：用差分探头

最专业、安全的方式：

```text
差分探头 + 输入端 -> U 相
差分探头 - 输入端 -> V 相
```

这样直接测：

```text
U - V
```

优点：

```text
安全
不会短路
抗共模能力强
适合高压、大电流、高 dv/dt 场景
```

如果你长期搞 FOC，我建议以后配一个差分探头。

---

# 5. 千万不要这样测

## 错误 1：地夹夹到电机相线

```text
地夹 -> U 相
探头 -> V 相
```

危险。

---

## 错误 2：两个通道地夹夹不同地方

```text
CH1 地夹 -> U 相
CH2 地夹 -> V 相
```

危险。

因为 CH1 和 CH2 的地夹在示波器内部是短接的。

---

## 错误 3：拆掉示波器三脚插头地线

有人会说：

```text
把示波器电源地线剪掉，就浮地了
```

不要这么干。

这很危险，可能让整个示波器外壳带电。正确方法是：

```text
用差分探头
用隔离探头
用电池供电手持示波器
```

---

# 6. FOC 调试建议测哪些波形？

## 6.1 三相 PWM

测：

```text
U 相 PWM
V 相 PWM
W 相 PWM
```

接法：

```text
地夹 -> 电池负极
CH1 -> U 相
CH2 -> V 相
CH3 -> W 相
```

你会看到的不是标准正弦波，而是高频 PWM。

FOC 里真正像正弦的是：

```text
三相占空比包络
```

也就是说，PWM 是一串高低电平，但它的平均值在按正弦变化。

---

## 6.2 低边 MOS 栅极

测：

```text
低边 MOS gate
```

接法：

```text
地夹 -> 驱动地 / 功率地
探头 -> 低边 gate
```

你能看：

```text
PWM 是否正常
死区是否合理
栅极上升沿/下降沿是否太慢
是否有振铃
是否误导通
```

常见低边 gate 电压：

```text
0V / 10V
0V / 12V
0V / 5V
```

具体看你的 MOS 驱动芯片。

---

## 6.3 高边 MOS 栅极不要直接乱测

高边 MOS 的 gate 是浮动的。

你真正想看的不是：

```text
Gate 对 GND
```

而是：

```text
Gate 对 Source
也就是 Vgs
```

高边 MOS 的 Source 是相线，会跟着 PWM 上下跳。

所以测高边 Vgs 推荐：

```text
差分探头测 Gate - Source
```

不要简单地：

```text
地夹夹 Source
探头尖端测 Gate
```

因为 Source 是开关节点，可能直接出事故。

---

## 6.4 电流采样波形

FOC 很关键的是电流。

常见测法：

```text
相电流采样电阻
母线电流采样电阻
电流采样放大器输出
MCU ADC 输入
```

推荐优先测：

```text
电流采样放大器输出
MCU ADC 输入脚
```

因为这是低压信号，安全很多。

比如：

```text
地夹 -> 模拟地 AGND
探头 -> ADC 输入
```

你能检查：

```text
ADC 输入有没有超范围
采样波形是否有毛刺
PWM 开关瞬间是否干扰太大
采样点是否落在干净区域
```

---

## 6.5 母线电压

比如电池是：

```text
12V / 24V / 36V / 48V
```

可以测：

```text
电池正极
DC bus
母线电容两端
```

接法：

```text
地夹 -> 电池负极
探头 -> 电池正极 / DC bus+
```

主要看：

```text
启动瞬间是否掉压
刹车/回灌时是否升压
电机堵转时纹波是否很大
母线电容够不够
```

平衡车特别要看：

```text
电机突然加速时，电池电压有没有塌陷
刹车时，母线电压有没有飙高
```

---

# 7. 平衡车建议测哪些波形？

平衡车除了电机，还要关注控制系统。

## 7.1 IMU 通信

如果你的 IMU 是 I2C：

```text
SCL
SDA
```

接法：

```text
地夹 -> MCU GND
CH1 -> SCL
CH2 -> SDA
```

看：

```text
有没有 ACK
电平是否正确
上拉是否太弱
波形上升沿是否太慢
有没有干扰毛刺
```

如果是 SPI：

```text
SCLK
MOSI
MISO
CS
```

看：

```text
时钟频率
CS 时序
MISO 是否有数据
边沿是否干净
```

---

## 7.2 编码器信号

如果你用霍尔/编码器测速：

```text
A 相
B 相
Z 相
```

接法：

```text
地夹 -> MCU GND
CH1 -> A
CH2 -> B
```

重点看：

```text
A/B 相是否相差 90°
有没有抖动
有没有丢脉冲
速度高时边沿是否还干净
```

---

## 7.3 控制周期 GPIO 打点

这个非常推荐。

你可以在控制任务里加一个 GPIO 翻转：

```c
gpio_set_level(DEBUG_PIN, 1);

// 姿态解算
// PID
// FOC 计算
// PWM 更新

gpio_set_level(DEBUG_PIN, 0);
```

然后用示波器测这个 DEBUG_PIN。

你可以直接看到：

```text
控制周期多久执行一次
一次控制计算耗时多久
有没有周期抖动
有没有被 Wi-Fi / Flash / LVGL / 日志打印打断
```

比如你平衡车控制周期是 1ms，那你应该看到：

```text
每 1ms 出现一次脉冲
脉冲宽度 = 你的控制算法耗时
```

这个对调平衡车非常有用。

# 8. 探头设置注意事项

## 8.1 优先用 10X 档

探头上通常有：

```text
1X / 10X
```

建议默认用：

```text
10X
```

原因：

```text
输入阻抗更高
对电路影响更小
带宽更高
更适合测 PWM、SPI、MOS gate
```

但是你要在示波器菜单里也设置成：

```text
Probe: 10X
```

否则电压显示会差 10 倍。

---

## 8.2 使用前做探头补偿

示波器一般有一个校准输出：

```text
1kHz 方波
```

你把探头接上去，看方波。

正确补偿：

```text
方波边沿平直
顶部平直
```

补偿不对会出现：

```text
过冲
圆角
顶部倾斜
```

测 PWM、MOS gate 前建议先补偿。

---

## 8.3 地线越短越好

普通地夹线很长，测高速 PWM 时容易引入振铃。

测 MOS gate、开关节点、SPI 时，尽量用：

```text
短地弹簧
短地线
靠近测量点的地
```

否则你看到的振铃可能一部分是探头地线带来的假振铃。

---

# 9. 示波器设置建议

## 9.1 测 PWM

比如 PWM 频率是 20kHz。

周期：

```text
T = 1 / 20000 = 50us
```

时基可以先设：

```text
10us/div
或者 20us/div
```

电压档：

```text
5V/div
10V/div
20V/div
```

触发：

```text
Edge Trigger
Rising Edge
触发源选 CH1
```

---

## 9.2 测控制周期

比如控制周期是 1ms。

时基：

```text
200us/div
或者 500us/div
```

如果你想看长时间抖动：

```text
1ms/div
5ms/div
10ms/div
```

---

## 9.3 测启动过程

比如你想看平衡车电机启动瞬间：

```text
Single 单次触发
Normal Trigger
触发条件：PWM 出现 / 母线电压跌落 / 电流超过某值
```

很有用。

比如：

```text
按下启动
示波器捕获第一次 PWM 输出
看电流、母线电压、相电压
```

---

## 9.4 测噪声和纹波

比如测电源纹波：

```text
AC Coupling
Bandwidth Limit 20MHz
小电压档位
短地线
```

注意：

```text
AC 耦合只看交流纹波
DC 耦合看完整电压
```

测电池母线掉压，要用 DC 耦合。

测电源纹波，可以用 AC 耦合。

---

# 10. FOC 典型测量组合

## 组合 1：看三相 PWM

```text
CH1 -> U 相
CH2 -> V 相
CH3 -> W 相
地夹 -> 电池负极
```

看：

```text
三相 PWM 是否都有
占空比是否变化
是否有某一相异常
是否有互补误导通
```

---

## 组合 2：看电流采样和 PWM 采样点

```text
CH1 -> PWM 定时器触发点 GPIO
CH2 -> 电流采样 ADC 输入
CH3 -> U 相 PWM
```

看：

```text
ADC 采样点是否避开开关毛刺
电流波形是否饱和
采样值是否被 PWM 噪声污染
```

---

## 组合 3：看平衡车控制耗时

```text
CH1 -> 控制循环 GPIO 打点
CH2 -> PWM 更新 GPIO 打点
CH3 -> IMU INT 引脚
```

看：

```text
IMU 数据来了多久后开始控制
控制计算耗时多久
PWM 更新是否稳定
周期有没有抖动
```

---

## 组合 4：看电池母线

```text
CH1 -> 电池电压
CH2 -> 电机相线 U
CH3 -> 电流采样输出
```

看：

```text
加速瞬间电池是否掉压
堵转电流是否过大
刹车时母线是否升压
```

---

# 11. 平衡车调试时特别注意

平衡车上电调试非常容易失控，建议：

```text
1. 车轮悬空调试
2. 限制最大 PWM / 最大电流
3. 先低压供电测试
4. 串联保险丝或限流电源
5. 人不要站上去直接调第一版参数
6. 代码里加急停逻辑
7. 倾角超过阈值立刻关 PWM
```

比如：

```c
if (fabs(angle) > 45.0f) {
    motor_pwm_disable();
}
```

否则 PID 参数不对，车轮可能突然高速转。

---

# 12. 你最应该买/配的附件

如果你主要搞 FOC 和平衡车，建议以后配：

```text
1. 差分探头
   测相间电压、高边 Vgs、半桥开关节点更安全。

2. 电流探头
   看相电流、母线电流很方便。

3. 短地弹簧
   测 MOS gate、PWM、SPI 波形更真实。

4. 逻辑分析仪
   看 I2C/SPI/UART/CAN/编码器比示波器更方便。

5. 隔离 USB 转串口
   减少电脑、示波器、开发板之间的地环路问题。
```

# 13. 最后给你一个操作检查表

每次测 FOC 板子前，先问自己：

```text
1. 示波器地夹夹在哪里？
2. 这个地是不是电池负极 / 控制板 GND？
3. 有没有把两个不同相线通过地夹短接？
4. 探头是不是 10X？
5. 示波器通道设置是不是 10X？
6. 电压量程够不够？
7. 探头耐压够不够？
8. 需不需要差分探头？
9. 测的是低边还是高边？
10. 电机是否悬空？
11. 程序有没有限流 / 急停？
12. 人和手有没有远离电机和轮子？
```

最重要的三条：

```text
第一：示波器地夹不要乱夹到电机相线。
第二：测高边 MOS、相间电压，最好用差分探头。
第三：调平衡车时先让轮子悬空，并限制最大 PWM / 电流。
```

一句话总结：**你搞 FOC 和平衡车，示波器最核心的注意事项就是“地夹安全 + 差分测量 + 低频保存 + 控制周期打点”。其中地夹安全排第一。**
