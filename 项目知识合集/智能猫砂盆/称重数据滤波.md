你说得对，前面讲的是**方案层面**，但是你现在要的是**直接能塞进 ESP32/STM32 工程里的代码**。我们直接做一个**一维卡尔曼滤波**，你的 CS1237 称重正好就是这个模型。

你的场景：

```
CS1237 ADC
    |
    |
ADC重量值(g)
    |
    |
Kalman
    |
    |
最终重量(g)
```

---

## 1. 先建立一个Kalman结构体

新建：

```c
typedef struct
{
    float x;   // 当前估计重量

    float p;   // 估计误差协方差

    float q;   // 过程噪声
    float r;   // 测量噪声

    float k;   // Kalman增益

}kalman_filter_t;
```

---

## 2. 初始化

比如你的猫秤：

```c
kalman_filter_t weight_kf;


void kalman_init(kalman_filter_t *kf)
{
    kf->x = 0;      // 初始重量

    kf->p = 1;

    kf->q = 0.05f;  // 响应速度
    kf->r = 100;    // ADC噪声

    kf->k = 0;
}
```

启动的时候调用一次：

```c
kalman_init(&weight_kf);
```

---

## 3. 核心函数（重点）

这个就是卡尔曼。

每读取一次 CS1237 数据调用一次。

```c
float kalman_update(
        kalman_filter_t *kf,
        float measure)
{

    /*
     * 1. 预测
     *
     * 假设重量没有变化
     *
     */

    kf->p = kf->p + kf->q;



    /*
     * 2. 计算Kalman增益
     *
     */

    kf->k = kf->p /
            (kf->p + kf->r);



    /*
     * 3. 修正预测值
     *
     */

    kf->x =
        kf->x +
        kf->k *
        (measure - kf->x);



    /*
     * 4. 更新误差
     *
     */

    kf->p =
        (1-kf->k) *
        kf->p;



    return kf->x;

}
```

---

## 4. 你的CS1237里面怎么用？

比如你现在：

```c
float weight;

weight = cs1237_get_weight();
```

改成：

```c
float raw_weight;

float filter_weight;


raw_weight = cs1237_get_weight();


filter_weight =
    kalman_update(
        &weight_kf,
        raw_weight
    );
```

之后：

不要使用：

```c
raw_weight
```

用：

```c
filter_weight
```

# 6. 参数怎么调？

你现在最关心这个。

## R 调噪声

你的CS1237空载：

读取：

```
0.2
-0.5
0.8
-0.1
0.4
```

噪声大概：

1g以内。

那么：

```c
r = 50~200
```

开始：

```c
kf.r=100;
```

---

## Q 调响应速度

Q越大：

响应越快，但是抖。

Q越小：

越稳，但是慢。

猫砂盆：

推荐：

```c
q=0.05
```

---

## 7. 你可以直接打印调试

加：

```c
printf(

raw_weight,

);
```

例如：

```

raw=4490 filter=4500 k=0.05
```

说明：

滤波很强。

如果：

```
raw=5000
filter=4600
```

说明：

响应慢。

增加：

```c
q
```

# 8. 产品级建议

你的猫砂盆不要固定：

```c
q=0.05
```

可以动态：

```c
float diff;


diff=fabs(raw_weight-filter_weight);


if(diff>200)
{
    // 猫跳上来了
    weight_kf.q=1.0f;
}
else
{
    // 稳定称重
    weight_kf.q=0.05f;
}
```

效果：

猫跳：

```
0
1000
3000
4500
```

快速。

猫不动：

```
4500
4500
4499
4500
```

稳定。
