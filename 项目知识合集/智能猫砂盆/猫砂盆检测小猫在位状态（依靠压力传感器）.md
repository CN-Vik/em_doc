明白了，你的需求其实可以拆成三个问题：**小猫上猫砂盆的检测、实时体重测量、稳定体重记录**。我帮你梳理一下思路，尽量结合你用的 **CS1237 ADC + 压力传感器** 硬件实现。

---

### 1️⃣ 硬件原理

* **压力传感器**：输出随重量变化的微弱电压信号。
* **CS1237 ADC**：高精度 24 位 ADC，把压力传感器信号转成数字量。
* **问题**：小猫会动，导致重量测量抖动（噪声、瞬时变化）。

---

### 2️⃣ 基本测量策略

1. **去皮重（tare）**

   * 上电或每次猫砂盆空闲时，记录当前传感器的零点（猫砂盆+猫砂重量），作为基础重量。
   * 记作 `tareWeight`。

2. **实时采样与滤波**

   * 高频率采样（例如 50–100 Hz），得到 `rawWeight`。
   * 对数据进行滤波，常用方法：

     * **滑动平均（Moving Average）**：平均最近 N 个采样点。
     * **低通滤波（LPF）**：减少快速抖动。
   * 滤波后的重量记作 `smoothedWeight`。

---

### 3️⃣ 判断小猫是否上来 / 下去

* 定义 **重量阈值** `weightThreshold`，例如：猫砂盆重量 + 50g。
* **小猫上来判断逻辑**：

  ```c
  if(smoothedWeight - tareWeight > weightThreshold)
      cat_on_box = true;
  else
      cat_on_box = false;
  ```
* **避免误触发**：小猫偶尔踏盆边或跳跃会导致短暂变化
  → 可用 **时间窗口**，例如重量持续超过阈值 0.5–1 秒才判定为“上来”。

---

### 4️⃣ 测量小猫体重

* **实时体重**：

  ```c
  catWeight = smoothedWeight - tareWeight;
  ```
* **稳定体重判断**：

  * 小猫上来后，重量波动很大，无法直接记录。
  * 需要检测重量稳定：

    1. 小猫上来后，记录连续 N 个采样点。
    2. 如果波动在 ±x 克（例如 ±5–10g）以内，认为体重稳定。
  * **记录一次**：

    ```c
    if(cat_on_box && weight_stable)
        record(catWeight, timestamp);
    ```

---

### 5️⃣ 流程示意

```
[ADC采样] --> [滤波] --> [是否超过阈值？] --> [是 -> 小猫上] 
                                   --> [稳定判断] -> [稳定 -> 记录体重]
                                   --> [否 -> 小猫下]
```

---

### 6️⃣ 防止猫动导致的数据漂移

* 使用 **短时平均 + 低通滤波**。
* 或者使用 **滑动窗口最频繁值（Mode Filter）**，小猫抖动导致的瞬时峰值不会计入体重。

---

### 7️⃣ 实际建议

* **采样率**：50~100Hz，足够捕捉猫的动作。
* **滤波参数**：滑动平均 10–20 个点，或者 LPF α=0.2~0.3。
* **阈值选择**：根据猫砂盆重量 + 猫最小体重（一般 1kg 左右） + 安全裕量。
* **记录策略**：

  * 只记录稳定后的体重。
  * 可以记录上来时间、下去时间、体重。

可以。这个问题不能只靠“滤波”，要做成一个**称重状态机**。

核心思路是：

> **先判断猫是否在盆上，再判断猫是否稳定，再从稳定片段里取本次体重。猫动的时候不相信重量，只用它来判断“猫还在”。**

# 1. 整体测量链路

CS1237 读出来的是 ADC 原始值：

```c
raw_adc
```

经过零点和校准系数转换成重量：

```c
weight_g = (raw_adc - zero_adc) * weight_cal;
```

其中：

```c
zero_adc    // 空盆时 ADC 零点
weight_cal // 每个 ADC 码值对应多少克
```

比如空盆时：

```c
zero_adc = 8380000;
```

放 1000g 砝码后：

```c
raw_adc = 8480000;
```

那么：

```c
weight_cal = 1000.0f / (8480000 - 8380000);
```

以后实时重量就是：

```c
weight_g = (raw_adc - zero_adc) * weight_cal;
```

但是实际猫砂盆里不能直接用这个 `weight_g`，因为会有：

* 猫走动；
* 猫跳上来；
* 猫跳下去；
* 猫挠沙子；
* 猫砂本身移动；
* 电机震动；
* 地毯软地面变形；
* 温漂和零点漂移。

所以要分成几个重量：

```c
raw_weight      // 原始换算重量，噪声大
fast_weight     // 快速滤波重量，用来判断上来/下去
slow_weight     // 慢速滤波重量，用来估算体重
baseline_weight // 当前空盆基准重量
cat_net_weight  // 当前相对空盆增加的重量
```

其中：

```c
cat_net_weight = slow_weight - baseline_weight;
```

# 2. 不要直接判断 raw_weight

错误做法：

```c
if (weight > 1000)
{
    cat_in = 1;
}
else
{
    cat_in = 0;
}
```

这个肯定会出问题。

因为猫一动，重量可能变成：

```text
0g → 500g → 2800g → 4700g → 3200g → 6100g → 4000g
```

如果直接判断，状态会疯狂跳变。

正确做法是：

```text
原始 ADC
   ↓
中值滤波，去掉尖峰
   ↓
一阶低通滤波
   ↓
计算最近一段时间的波动程度
   ↓
状态机判断
```

---

# 3. 推荐滤波结构

## 3.1 第一级：中值滤波

中值滤波主要干掉瞬间尖峰。

比如最近 5 个采样值：

```text
4010, 4020, 3980, 9000, 4005
```

排序后：

```text
3980, 4005, 4010, 4020, 9000
```

取中间值：

```text
4010
```

这样 `9000` 这个瞬间毛刺就被去掉了。

---

## 3.2 第二级：快慢两个低通滤波

建议做两个滤波值。

### 快速滤波

用来判断猫是否上来、是否下去。

```c
fast_weight = fast_weight * 0.7f + new_weight * 0.3f;
```

它响应快。

### 慢速滤波

用来估算体重。

```c
slow_weight = slow_weight * 0.95f + new_weight * 0.05f;
```

它比较稳。

---

# 4. 判断猫动不动：看“波动程度”

不能只看重量值，还要看最近一段时间是否稳定。

比如最近 1 秒内采了 20 个点：

```text
3980, 3990, 4010, 4005, 3995...
```

最大值减最小值只有几十克，说明稳定。

如果是：

```text
3200, 4500, 2800, 5100, 3900...
```

波动几千克，说明猫在动。

可以计算：

```c
weight_range = max_weight_in_window - min_weight_in_window;
```

判断稳定：

```c
if (weight_range < 80)
{
    stable = 1;
}
else
{
    stable = 0;
}
```

对于猫砂盆，可以先用这些经验值：

```c
#define STABLE_RANGE_G       80      // 1秒内波动小于80g，认为稳定
#define ENTER_THRESHOLD_G    500     // 超过500g，认为可能有猫上来
#define LEAVE_THRESHOLD_G    300     // 低于300g，认为猫可能下去了
#define VALID_CAT_MIN_G      800     // 小于800g一般不认为是有效猫体重
#define VALID_CAT_MAX_G      12000   // 大于12kg认为异常
```

后面根据你的产品再调。

# 5. 猫上来、猫下去、本次体重：用状态机做

推荐状态机：

```text
IDLE              空盆状态
  ↓
ENTER_CONFIRM     疑似猫上来
  ↓
CAT_ON_UNSTABLE   猫在盆上，但在动
  ↓
CAT_ON_STABLE     猫在盆上，并且比较稳定
  ↓
LEAVE_CONFIRM     疑似猫下去
  ↓
IDLE              确认离开，结算本次体重
```

---

# 6. 每个状态的意义

## 6.1 IDLE：空盆状态

此时认为猫不在。

这个阶段可以慢慢更新空盆基准重量：

```c
baseline_weight = baseline_weight * 0.999f + slow_weight * 0.001f;
```

注意：
**只有确定猫不在、并且电机不动、重量稳定时，才允许更新 baseline。**

不能猫在里面的时候更新零点，否则猫体重会被慢慢吃掉。

---

## 6.2 ENTER_CONFIRM：疑似猫上来

如果检测到：

```c
cat_net_weight > ENTER_THRESHOLD_G
```

不要马上认为猫上来了。

因为可能是：

* 人碰了一下；
* 猫踩了一脚又走了；
* 沙子晃动；
* 设备震动。

要持续一段时间，比如 800ms：

```c
if (cat_net_weight > ENTER_THRESHOLD_G 持续 800ms)
{
    确认猫上来了;
}
```

---

## 6.3 CAT_ON_UNSTABLE：猫在，但在动

猫刚进去一般会：

* 转身；
* 挠沙子；
* 调整姿势；
* 上厕所；
* 踩边缘。

这个阶段重量不可信。

你只做两件事：

1. 继续判断猫还在不在；
2. 等待稳定片段出现。

---

## 6.4 CAT_ON_STABLE：猫在，并且稳定

如果最近 1 秒重量波动小于 80g，并且重量在合理范围：

```c
800g < cat_net_weight < 12000g
```

说明当前可以采集一次有效体重片段。

比如连续稳定 1 秒，得到平均重量：

```text
4010g, 3990g, 4005g, 3988g, 4015g
```

本次稳定片段重量大概：

```text
4002g
```

把它保存起来：

```c
session_weight_list[session_count++] = stable_avg_weight;
```

一次上厕所过程中，可能会保存多个稳定片段：

```text
第1次稳定：3980g
第2次稳定：4020g
第3次稳定：3995g
```

最终体重取中位数或者平均值：

```text
本次体重 = 3995g 或 4000g 左右
```

---

## 6.5 LEAVE_CONFIRM：疑似猫下去

如果：

```c
cat_net_weight < LEAVE_THRESHOLD_G
```

也不要马上认为猫下去了。

因为猫可能只是身体靠边、重量传递异常、或者设备震了一下。

要持续一段时间，比如 2 秒：

```c
if (cat_net_weight < LEAVE_THRESHOLD_G 持续 2秒)
{
    确认猫离开;
}
```

然后结算本次体重。

# 7. 关键点：猫排泄后，基准重量会变

这点很重要。

猫进去前：

```text
空盆 + 猫砂 = baseline_before
```

猫在里面：

```text
总重量 = baseline_before + 猫体重
```

猫尿尿/拉屎后：

```text
总重量 = baseline_before + 猫体重 + 排泄物重量
```

猫离开后：

```text
总重量 = baseline_before + 排泄物重量
```

所以如果你在猫排泄之后采集重量，直接用：

```c
当前总重量 - 进盆前baseline
```

会把排泄物也算进去。

因此本次体重最好有两个估算方式。

---

## 方法一：进盆早期稳定重量

猫刚进去，还没排泄前，如果有稳定片段：

```text
猫体重 = 猫在盆内稳定重量 - 进盆前baseline
```

这个最直接。

---

## 方法二：离开前稳定重量 - 离开后新基准

如果猫离开前稳定过，并且猫离开后排泄物还留在盆里：

```text
猫体重 = 离开前稳定总重量 - 离开后空盆重量
```

这个也能抵消排泄物重量。

举例：

```text
进盆前空盆重量 = 10000g
猫体重 = 4000g
排泄物 = 150g
```

猫离开前总重量：

```text
10000 + 4000 + 150 = 14150g
```

猫离开后总重量：

```text
10000 + 150 = 10150g
```

那么：

```text
猫体重 = 14150 - 10150 = 4000g
```

所以最终可以综合：

```c
weight_entry = 进盆早期稳定重量 - 进盆前baseline;
weight_exit  = 离开前稳定重量 - 离开后baseline;
```

如果两个都有，而且差不多，就取平均：

```c
final_weight = (weight_entry + weight_exit) / 2;
```

如果只有一个有效，就用那个。

# 8. 推荐完整判断逻辑

## 本次体重计算策略

优先级建议：

```text
1. 有进盆早期稳定体重：优先用
2. 有离开前稳定体重 + 离开后基准：也可用
3. 全程都没有稳定片段：不直接上报精确体重，只上报低置信度体重
```

产品上可以这样设计：

```c
typedef enum {
    WEIGHT_CONF_HIGH,
    WEIGHT_CONF_MEDIUM,
    WEIGHT_CONF_LOW,
    WEIGHT_CONF_INVALID
} weight_confidence_t;
```

不要所有数据都当真。

猫一直动的情况下，强行给出一个体重，容易误报。

# 9. C伪代码框架

下面这个结构比较适合你的猫砂盆项目。

```c
typedef enum
{
    CAT_STATE_IDLE = 0,          // 空盆状态
    CAT_STATE_ENTER_CONFIRM,     // 疑似猫上来
    CAT_STATE_ON_UNSTABLE,       // 猫在盆上，但重量不稳定
    CAT_STATE_ON_STABLE,         // 猫在盆上，重量稳定
    CAT_STATE_LEAVE_CONFIRM      // 疑似猫离开
} cat_state_t;
```

---

## 会话结构体

```c
typedef struct
{
    cat_state_t state;

    float baseline_before;       // 猫进来前的空盆基准
    float baseline_after;        // 猫离开后的空盆基准

    float fast_weight;           // 快速滤波重量
    float slow_weight;           // 慢速滤波重量
    float net_weight;            // 相对空盆增加重量

    float stable_weights[16];    // 本次如厕过程中的稳定体重片段
    uint8_t stable_count;

    uint32_t enter_timer_ms;     // 上盆确认计时
    uint32_t leave_timer_ms;     // 下盆确认计时
    uint32_t stable_timer_ms;    // 稳定计时
    uint32_t session_time_ms;    // 本次会话持续时间

    uint8_t cat_present;         // 猫是否在盆上
    uint8_t report_ready;        // 是否可以上报本次体重

    float final_cat_weight;      // 本次猫体重
} cat_weight_ctx_t;
```

---

## 参数建议

```c
#define SAMPLE_PERIOD_MS        50      // 50ms处理一次，20Hz

#define ENTER_THRESHOLD_G       500.0f  // 疑似猫上来阈值
#define LEAVE_THRESHOLD_G       300.0f  // 疑似猫离开阈值

#define ENTER_CONFIRM_MS        800     // 超过阈值持续800ms，确认上来
#define LEAVE_CONFIRM_MS        2000    // 低于阈值持续2秒，确认离开

#define STABLE_RANGE_G          80.0f   // 最近窗口波动小于80g，认为稳定
#define STABLE_CONFIRM_MS       1000    // 稳定持续1秒，记录一次有效体重

#define VALID_CAT_MIN_G         800.0f
#define VALID_CAT_MAX_G         12000.0f

#define MAX_STABLE_RECORDS      16
```

# 10. 状态机伪代码

```c
void cat_weight_process(cat_weight_ctx_t *ctx, float new_weight_g)
{
    /*
     * 第一步：更新滤波重量
     * fast_weight 响应快，用来判断猫上来/下去
     * slow_weight 响应慢，用来计算体重
     */
    ctx->fast_weight = ctx->fast_weight * 0.7f + new_weight_g * 0.3f;
    ctx->slow_weight = ctx->slow_weight * 0.95f + new_weight_g * 0.05f;

    /*
     * 第二步：计算相对空盆增加重量
     */
    ctx->net_weight = ctx->slow_weight - ctx->baseline_before;

    /*
     * 第三步：判断最近一段时间是否稳定
     * 这里假设 is_weight_stable() 内部会计算最近1秒的最大值和最小值
     */
    uint8_t stable = is_weight_stable(STABLE_RANGE_G);

    switch (ctx->state)
    {
        case CAT_STATE_IDLE:
        {
            ctx->cat_present = 0;
            ctx->report_ready = 0;
            ctx->stable_count = 0;
            ctx->session_time_ms = 0;

            /*
             * 空盆状态下，如果重量稳定，可以慢慢更新空盆基准
             * 注意：电机运行时不要更新，清理过程中也不要更新
             */
            if (stable && motor_is_idle())
            {
                ctx->baseline_before =
                    ctx->baseline_before * 0.999f + ctx->slow_weight * 0.001f;
            }

            /*
             * 检测疑似猫上来
             */
            if (ctx->net_weight > ENTER_THRESHOLD_G)
            {
                ctx->enter_timer_ms += SAMPLE_PERIOD_MS;

                if (ctx->enter_timer_ms >= ENTER_CONFIRM_MS)
                {
                    ctx->state = CAT_STATE_ON_UNSTABLE;
                    ctx->cat_present = 1;

                    /*
                     * 锁定猫进来前的基准
                     * 本次会话期间不要再改这个值
                     */
                    ctx->baseline_before = ctx->slow_weight - ctx->net_weight;

                    ctx->session_time_ms = 0;
                    ctx->stable_count = 0;
                    ctx->stable_timer_ms = 0;
                }
            }
            else
            {
                ctx->enter_timer_ms = 0;
            }

            break;
        }

        case CAT_STATE_ON_UNSTABLE:
        {
            ctx->cat_present = 1;
            ctx->session_time_ms += SAMPLE_PERIOD_MS;

            /*
             * 如果重量低于离开阈值，进入疑似离开状态
             */
            if (ctx->net_weight < LEAVE_THRESHOLD_G)
            {
                ctx->leave_timer_ms = 0;
                ctx->state = CAT_STATE_LEAVE_CONFIRM;
                break;
            }

            /*
             * 如果猫在盆上，并且当前重量稳定，开始稳定计时
             */
            if (stable &&
                ctx->net_weight > VALID_CAT_MIN_G &&
                ctx->net_weight < VALID_CAT_MAX_G)
            {
                ctx->stable_timer_ms += SAMPLE_PERIOD_MS;

                if (ctx->stable_timer_ms >= STABLE_CONFIRM_MS)
                {
                    ctx->state = CAT_STATE_ON_STABLE;
                }
            }
            else
            {
                ctx->stable_timer_ms = 0;
            }

            break;
        }

        case CAT_STATE_ON_STABLE:
        {
            ctx->cat_present = 1;
            ctx->session_time_ms += SAMPLE_PERIOD_MS;

            /*
             * 稳定状态下，如果重量有效，就记录一个稳定体重片段
             */
            if (stable &&
                ctx->net_weight > VALID_CAT_MIN_G &&
                ctx->net_weight < VALID_CAT_MAX_G)
            {
                if (ctx->stable_count < MAX_STABLE_RECORDS)
                {
                    ctx->stable_weights[ctx->stable_count] = ctx->net_weight;
                    ctx->stable_count++;
                }
            }
            else
            {
                /*
                 * 稳定被打破，猫又动了
                 */
                ctx->stable_timer_ms = 0;
                ctx->state = CAT_STATE_ON_UNSTABLE;
            }

            /*
             * 检测疑似离开
             */
            if (ctx->net_weight < LEAVE_THRESHOLD_G)
            {
                ctx->leave_timer_ms = 0;
                ctx->state = CAT_STATE_LEAVE_CONFIRM;
            }

            break;
        }

        case CAT_STATE_LEAVE_CONFIRM:
        {
            ctx->session_time_ms += SAMPLE_PERIOD_MS;

            /*
             * 如果重量重新变大，说明猫可能还没走，只是短暂跳动
             */
            if (ctx->net_weight > ENTER_THRESHOLD_G)
            {
                ctx->state = CAT_STATE_ON_UNSTABLE;
                ctx->leave_timer_ms = 0;
                break;
            }

            /*
             * 重量持续低于离开阈值，确认离开
             */
            if (ctx->net_weight < LEAVE_THRESHOLD_G)
            {
                ctx->leave_timer_ms += SAMPLE_PERIOD_MS;

                if (ctx->leave_timer_ms >= LEAVE_CONFIRM_MS)
                {
                    ctx->cat_present = 0;

                    /*
                     * 猫离开后的重量作为新的空盆重量
                     * 这里面可能包含排泄物重量
                     */
                    ctx->baseline_after = ctx->slow_weight;

                    /*
                     * 计算本次体重
                     */
                    ctx->final_cat_weight = calc_final_cat_weight(ctx);

                    ctx->report_ready = 1;

                    /*
                     * 更新基准，进入空盆状态
                     */
                    ctx->baseline_before = ctx->baseline_after;
                    ctx->state = CAT_STATE_IDLE;
                }
            }
            else
            {
                ctx->leave_timer_ms = 0;
            }

            break;
        }

        default:
        {
            ctx->state = CAT_STATE_IDLE;
            break;
        }
    }
}
```

# 11. 本次体重计算函数

简单版可以这样：

```c
float calc_final_cat_weight(cat_weight_ctx_t *ctx)
{
    if (ctx->stable_count == 0)
    {
        return -1.0f;   // 无有效体重
    }

    /*
     * 对稳定片段排序，取中位数
     * 中位数比平均值抗异常能力更强
     */
    sort_float_array(ctx->stable_weights, ctx->stable_count);

    return ctx->stable_weights[ctx->stable_count / 2];
}
```

比如稳定片段是：

```text
3980g, 4050g, 3995g, 7000g, 4010g
```

其中 `7000g` 是异常值。

排序后：

```text
3980g, 3995g, 4010g, 4050g, 7000g
```

取中位数：

```text
4010g
```

比直接平均靠谱。

# 12. 更高级的体重计算方式

可以把稳定片段分成两类：

```text
前期稳定片段：猫刚进来时
后期稳定片段：猫快离开前
```

前期体重：

```c
weight_entry = early_stable_total_weight - baseline_before;
```

后期体重：

```c
weight_exit = late_stable_total_weight - baseline_after;
```

最终：

```c
if (entry_valid && exit_valid)
{
    if (fabs(weight_entry - weight_exit) < 300)
    {
        final_weight = (weight_entry + weight_exit) * 0.5f;
    }
    else
    {
        final_weight = weight_entry;  // 优先相信进盆早期体重
    }
}
else if (entry_valid)
{
    final_weight = weight_entry;
}
else if (exit_valid)
{
    final_weight = weight_exit;
}
else
{
    final_weight = invalid;
}
```

这样可以避免把猫的尿尿、便便重量算进猫体重里。

# 13. 检测猫上来没上来

不要只看一个阈值，建议分成三档：

```text
0 ~ 100g      空盆噪声
100 ~ 500g    疑似触碰、踩边、猫爪、沙子扰动
500g 以上     疑似猫上来
800g 以上     高概率猫上来
```

推荐逻辑：

```c
if (net_weight > 500g 持续 800ms)
{
    猫上来了;
}
```

如果你家猫比较小，可以改成：

```c
ENTER_THRESHOLD_G = 300g;
VALID_CAT_MIN_G   = 500g;
```

但阈值越低，越容易误判。

# 14. 检测猫下去了没下去

猫离开后，重量不一定回到 0，因为留下了排泄物。

所以不要用：

```c
net_weight < 20g
```

这种判断。

应该用：

```c
net_weight < 300g 持续 2秒
```

或者：

```c
当前重量明显小于本次猫体重的一部分
```

例如：

```c
if (net_weight < final_estimate_weight * 0.25f)
{
    疑似离开;
}
```

更稳的离开判断：

```c
if (net_weight < 300g 持续2秒)
{
    猫离开;
}
else if (已估算猫体重 && net_weight < 猫体重 * 0.25f 持续2秒)
{
    猫离开;
}
```

这样大猫、小猫都能兼容。

# 15. 实际产品里还要加几个保护条件

## 15.1 电机运行时不要称体重

清理电机、翻桶电机运行时，称重数据会乱。

```c
if (!motor_is_idle())
{
    不判断猫体重;
    不更新baseline;
}
```

---

## 15.2 刚上电不要马上判断

上电后 ADC、传感器、机械结构可能还没稳定。

```c
上电前3~5秒只做零点稳定，不判断猫;
```

---

## 15.3 猫砂盆放在软地毯上会影响很大

软地毯会导致：

* 重量传递慢；
* 底壳变形；
* 猫走动时重量回弹；
* 四角受力不均。

机械上要尽量做到：

```text
外壳底部 → 称重传感器 → 地面
```

不要让外壳其它地方碰地。

最好是：

```text
四角称重传感器 + 刚性底板
```

而不是一个点称重。

# 16. 推荐最终上报内容

不要只上报一个体重，建议带状态和可信度：

```c
typedef struct
{
    uint8_t cat_enter;       // 猫是否上来过
    uint8_t cat_leave;       // 猫是否已经离开
    float cat_weight;        // 本次体重
    float excretion_weight;  // 本次排泄物重量
    uint8_t confidence;      // 体重可信度
} cat_report_t;
```

排泄物重量可以这样估算：

```c
excretion_weight = baseline_after - baseline_before;
```

例如：

```text
猫进来前空盆重量：10000g
猫离开后空盆重量：10180g
```

那么：

```text
本次排泄物重量 = 180g
```

# 17. 最推荐的核心方案

你这个项目我建议这样做：

```text
1. CS1237 连续采样
2. 原始值转重量
3. 中值滤波去尖峰
4. 快速低通判断猫上来/下去
5. 慢速低通用于体重估算
6. 最近1秒窗口判断重量是否稳定
7. 状态机管理：
   空盆 → 疑似上来 → 猫在动 → 猫稳定 → 疑似离开 → 结算
8. 只在猫稳定时记录体重片段
9. 最终取稳定片段中位数
10. 离开后更新空盆基准
```

一句话总结：

> **猫动的时候，只判断“猫还在不在”；猫不动的时候，才记录体重；猫离开后，才结算本次体重。**
