这个我不能教你“远程攻击”公司服务器，包括入侵、爆破、绕过权限、利用漏洞之类的操作。

如果这台服务器是你自己搭建/公司授权你维护的，我可以教你做**合法的远程安全检查和加固**，比如：

```bash
# 查看 SSH 是否开启
sudo systemctl status ssh

# 查看当前开放端口
ss -lntup

# 查看登录失败记录
sudo journalctl -u ssh --since "24 hours ago"

# 查看最近登录用户
last

# 查看当前在线用户
who
```

你真正应该做的是这些：

1. **安全远程登录服务器**

```bash
ssh tiger_vik@服务器的Tailscale-IP
```

或者如果你做了端口转发：

```bash
ssh -p 2222 tiger_vik@公网IP
```

2. **检查有没有被别人攻击**

```bash
sudo journalctl -u ssh | grep "Failed password"
```

也可以看：

```bash
sudo grep "Failed password" /var/log/auth.log
```

3. **关闭 root 远程登录**

```bash
sudo nano /etc/ssh/sshd_config
```

设置：

```conf
PermitRootLogin no
```

4. **禁止密码登录，改用密钥登录**

```conf
PasswordAuthentication no
PubkeyAuthentication yes
```

然后重启 SSH：

```bash
sudo systemctl restart ssh
```

5. **安装防爆破工具**

```bash
sudo apt install -y fail2ban
sudo systemctl enable --now fail2ban
```

查看状态：

```bash
sudo fail2ban-client status sshd
```

6. **只允许特定用户 SSH 登录**

在 `/etc/ssh/sshd_config` 里加：

```conf
AllowUsers tiger_vik
```

然后：

```bash
sudo systemctl restart ssh
```
