# 整句命令是什么意思？
```bash
cat arch/mips/configs/x2000_module_base_linux_sfc_nand_defconfig | grep dts
```

**翻译成人话：**
> 打开一个 Linux 内核配置文件，**只把里面包含“dts”这三个字母的行筛选出来显示**。

---

# 关键部分拆解

## 1. `cat`
作用：**把文件内容全部输出到屏幕**
这里就是读取这个内核配置文件：
```
arch/mips/configs/x2000_module_base_linux_sfc_nand_defconfig
```

## 2. `|` 管道符
作用：**把左边命令的输出，传给右边命令当输入**

## 3. `grep`（你最关心的）
### 官方作用：
**在文本里搜索你指定的字符串，只把匹配到的行显示出来**

### 通俗理解：
grep = **过滤器 / 查找器**

你给它一段文本，它只留下**包含你要找的关键词**的行，其他全部扔掉。

---

# 这个命令里 `grep dts` 到底在干嘛？
`dts` 是 Linux 里的 **设备树源文件（Device Tree Source）** 的缩写。

所以：
```
grep dts
```
意思就是：
> **只显示文件里包含“dts”的行**

比如文件里可能有这些内容：
```
CONFIG_USE_OF=y
CONFIG_DTS=y
CONFIG_BUILD_DTS_FILE="x2000.dts"
CONFIG_DEBUG=n
```
经过 `grep dts` 过滤后，只会输出：
```
CONFIG_DTS=y
CONFIG_BUILD_DTS_FILE="x2000.dts"
```

---

# 整句命令的完整流程（超清晰）
1. `cat` 读取整个配置文件
2. 通过 `|` 把内容传给 `grep`
3. `grep dts` 筛选出**所有带 dts 的行**
4. 最终只显示这些行，其他内容不显示

---

# 小总结
* **cat**：查看文件
* **|**：传递数据
* **grep 关键词**：**搜索并只显示包含关键词的行**

你这条命令就是：**快速查看内核配置里和设备树（dts）相关的配置项**。

# * grep 常用技巧
# grep 极简常用技巧
1. **基础搜**
`grep 关键字 文件名`
搜文件里含关键字的行

2. **忽略大小写**
`grep -i 关键词`
大小写一起匹配

3. **反向过滤（排除）**
`grep -v 关键词`
**不含这个词**的行才显示

4. **显示行号**
`grep -n 关键词`
查出在哪一行

5. **递归搜整个文件夹**
`grep -r 关键词 ./`
遍历所有文件查找

6. **只显示匹配内容，不整行**
`grep -o 关键词`

7. **多关键词或搜索**
`grep -E "词1|词2"`

8. **搭配管道最常用**
`xxx命令 | grep 关键词`
过滤命令输出

### 嵌入式开发最常用两条
```bash
# 查内核配置含dts
cat xxx_defconfig | grep dts
# 排除注释空行
grep -v ^# 文件名
```

完美！**只在当前目录找，不进子目录、不递归**，用这条 `find` 命令：

```bash
find . -maxdepth 1 -name ".git" -type d
```

### 解释
- `-maxdepth 1` → **只搜当前这一层，不往下递归**
- `-type d` → 只找文件夹
- `-name ".git"` → 名字匹配 `.git`

### 结果
- 输出 `./.git` → **有**
- 啥也不输出 → **没有**

这就是你想要的效果！
