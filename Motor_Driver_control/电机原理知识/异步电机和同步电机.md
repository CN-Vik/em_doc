这个问题其实是**电机原理里面最核心的概念之一**。

很多人刚开始学的时候都会以为：

> 同步电机 = 转得很同步
> 异步电机 = 转得不同步

其实**同步、异步，指的是转子和定子旋转磁场之间的关系**。

---

# 先理解一个东西——旋转磁场

交流电机的定子（三相绕组）通入三相交流电后，会产生一个不断旋转的磁场。

例如：

```
三相AC

A
B
C

↓

形成旋转磁场

↻↻↻↻↻
```

这个磁场不是静止的，而是在不停旋转。

它有一个速度，叫

> **同步转速（Synchronous Speed）**

计算公式：

[
n_s=\frac{120f}{P}
]

其中

* f = 电源频率（50Hz）
* P = 极数

例如：

50Hz

2极：

```
n = 120×50/2
  =3000rpm
```

4极：

```
1500rpm
```

6极：

```
1000rpm
```

这个速度就是：

**定子磁场的旋转速度。**

---

# 什么叫同步？

同步就是：

> **转子转速 = 定子磁场速度**

例如

磁场：

```
3000rpm
```

转子：

```
3000rpm
```

二者完全一致。

所以叫：

**同步电机。**

可以画成

```
磁场

↻↻↻↻

3000rpm

↓↓↓↓

转子

↻↻↻↻

3000rpm
```

永远保持一致。

---

# 什么叫异步？

异步就是：

**转子速度永远比磁场慢一点。**

例如：

磁场

```
3000rpm
```

转子

```
2950rpm
```

或者

```
2980rpm
```

总之：

```
转子 < 磁场
```

所以叫：

异步电机。

---

# 为什么必须慢？

这是异步电机最关键的地方。

异步电机转子里面**没有磁铁。**

里面通常只有：

```
铜条

或者

铝条
```

组成鼠笼。

例如：

```
=========
| | | | |
| | | | |
=========
```

（鼠笼转子）

它不能自己产生磁场。

怎么办？

利用：

**电磁感应。**

---

# 电磁感应怎么来的？

还记得高中物理：

```
导体切割磁感线

↓

产生电流
```

异步电机就是利用这个。

如果：

磁场3000rpm

转子也3000rpm

那么：

```
二者没有相对运动
```

没有切割磁感线。

于是：

```
没有感应电流

↓

没有磁场

↓

没有转矩
```

电机根本带不动。

所以：

**异步电机必须有速度差。**

---

# 举个例子

磁场：

```
3000rpm
```

转子：

```
2950rpm
```

相差：

```
50rpm
```

这50rpm就是：

相对运动。

于是：

```
磁场

↓

切割鼠笼

↓

产生感应电流

↓

产生磁场

↓

产生转矩
```

所以：

异步电机永远差一点点。

---

# 这个差值叫什么？

叫：

**转差（Slip）**

定义：

[
S=\frac{n_s-n}{n_s}
]

例如：

同步速度：

3000rpm

实际：

2940rpm

那么：

```
(3000-2940)/3000

=0.02

=2%
```

所以：

异步电机一般：

```
1%

2%

3%

5%
```

都有可能。

负载越重：

```
转速越低

↓

转差越大

↓

感应电流越大

↓

转矩越大
```

所以：

异步电机是靠转差来输出转矩。

---

# 同步电机为什么不用慢？

同步电机里面：

有磁铁。

例如：

```
N

S
```

或者：

励磁绕组。

转子本身就有磁场。

于是：

```
定子磁场

吸引

转子磁场
```

两者像齿轮一样：

```
↻ ↻ ↻ ↻

一起转
```

所以：

即使

```
3000rpm

=

3000rpm
```

依然可以输出转矩。

因为：

不是靠感应。

而是：

磁场之间直接吸引。

---

# 举个生活例子

## 异步电机

像人在跑步机上。

跑步机：

```
10km/h
```

你：

```
9.8km/h
```

只有慢一点，

脚才能向后蹬。

否则：

完全同步，

脚就不会摩擦，

没有力。

---

## 同步电机

更像两块磁铁吸在一起。

```
🧲🧲
```

前面磁铁转：

后面一定跟着一起转。

速度完全一样。

---

# 为什么现在新能源汽车都是同步电机？

因为：

同步电机（尤其是永磁同步电机，PMSM）具有以下优势：

* 效率高
* 功率密度高
* 转矩响应快
* 控制精度高
* 非常适合采用FOC（磁场定向控制）

这也是你最近一直研究FOC控制的原因——**FOC最经典的控制对象就是永磁同步电机**。

而异步电机虽然结构简单、成本低、耐用，但控制相对复杂，在轻载时效率通常不如永磁同步电机。不过它没有永磁体，不依赖稀土材料，在一些工业场景和部分电动车（例如早期车型）仍然广泛使用。

---

## 一张表总结

| 特性       | 同步电机            | 异步电机                     |
| -------- | --------------- | ------------------------ |
| 转子速度     | 始终等于旋转磁场速度      | 始终略低于旋转磁场速度              |
| 转差       | 0               | 大于0                      |
| 转矩来源     | 转子磁场与定子磁场相互作用   | 定子磁场在转子中感应电流，再产生转矩       |
| 转子结构     | 永磁体或励磁绕组        | 鼠笼导条或绕线转子                |
| 是否必须有速度差 | 否               | 是，否则无法产生感应电流和转矩          |
| 是否适合FOC  | 非常适合（PMSM是典型对象） | 也可以，但需要建立和估计转子磁链，控制复杂度更高 |

**一句话记住：**

* **同步电机**：转子自带磁场，**跟着定子旋转磁场一起转**，两者转速相同。
* **异步电机**：转子没有自带磁场，必须依靠**转子与定子旋转磁场之间的速度差（转差）**产生感应电流，从而建立磁场并输出转矩，因此转子速度始终略低于同步转速。
