基于 **TMS320F2800137**（LQFP-32 或 LQFP-48 封装）设计一套支持 **5V–48V 宽电压输入** 的低成本 FOC（磁场定向控制）驱动器硬件方案，核心在于**极致的性价比**、**硬件级过流保护**以及**宽输入电压适配**。

---

### 系统整体架构图

```text
 [ 5V - 48V 电压输入 ]
      │
      ├──> [ 宽压 DCDC (MP4560/LM5164) ] ──> 5V ──> [ LDO (AMS1117-3.3) ] ──> 3.3V (DSP/模拟源)
      │                                    │
      │                                    └──> 驱动芯片 VCC (5V-12V)
      │
      ├──> [ 3相半桥功率 MOS 阵列 ] <─── [ 3相栅极驱动器 (DRV8300 / FD6288) ] <── [ PWM (DSP) ]
      │          │
      │          ├──> 电机 (U, V, W)
      │          │
      │          └──> [ 下桥运放采样 (U/V) ] ───────────> [ ADC0 / ADC1 (DSP) ]
      │                    │
      └────────────────────┴───────────────────────────> [ CMPSS 内部比较器 ] ──> [ ePWM 硬件封栅 (TZ) ]

```

### 1. 电源与管理系统电路（宽压 5–48V）

宽电压 5-48V 输入（需预留极限 60V 耐压）是电源设计的难点。当 $V_{IN}=5\text{V}$ 时降压芯片需进入近乎 100% 占空比直通模式；当 $V_{IN}=48\text{V}$ 时需具备高降压比。

* **一级 DCDC 主降压（降至 5V）**：
* **芯片选型**：MP4560 / LM5164 / SY8501（均支持高压输入，性价比极高）。
* **关键配置**：输出固定 5V，提供 500mA–1A 电流，给栅极驱动器供电及二级 LDO。


* **二级 LDO 降压（降至 3.3V）**：
* **芯片选型**：AMS1117-3.3 或 ME6211C33（低噪音）。
* **作用**：专门给 F2800137 VDD、模拟基准电平（VREFA/B）和外置编码器供电。


* **输入退耦与防浪涌（TVS）**：
* **母线电容**：2个 100µF/63V 铝电解电容 + 4个 10µF/100V X7R 贴片电容并联，降低 ESR。
* **防浪涌**：加装 58V/60V 贴片 TVS 管（如 SMAJ58A），防止电机刹车反电势拉高母线烧毁 MOSFET。



---

### 2. DSP 最小系统电路 (TMS320F2800137)

* **时钟方案**：利用 F2800137 内部集成的高精度 10MHz 晶振（INTOSC2），**无需外挂无源晶体**，直接省去晶振和负载电容成本。
* **复位与 BOOT 引脚配置**：
* `xRS` 引脚接 10kΩ 上拉电阻到 3.3V，并并联一个 100nF 电容到地。
* BOOT 引脚配置：通过 GPIO24 / GPIO32 配合上拉/下拉电阻固定为 Flash 启动模式。


* **模拟电源滤波**：VDDA/VSSA 需通过磁珠（100Ω@100MHz）与数字地隔离，VDDA 旁路电容配置 10µF + 100nF。

---

### 3. 驱动与 3 相逆变桥电路 (Inverter)

#### (1) 栅极驱动芯片 (Gate Driver)

为了保证 5V 输入时驱动依然有效，建议选用支持 5–20V 宽 $V_{CC}$ 供电的驱动器：

* **推荐选型**：**DRV8300D**（TI 低成本 60V 三相半桥驱动）或 **FD6288Q / EG2133**（国产极低成本三相驱动）。
* **自举电路**：每相上桥须配置自举二极管（选用快恢复二极管如 US1M/ES1D）和自举电容（1µF/16V X7R 贴片电容）。

#### (2) 功率 MOSFET 选型

* **耐压与电流**：60V / 80A，导通内阻 $R_{DS(on)} < 5\text{m}\Omega$。
* **推荐型号**：NCE6080（新洁能）/ HY1908 / BSC035N10NS。
* **栅极电阻**：每管栅极串联 10Ω 驱动电阻，并联 1N4148（下拉加速关断），防止开关谐振。

---

### 4. 电流与电压采样电路（FOC 核心）

为了达到极致性价比，采用 **双采样电阻下桥采样（Low-side Dual-Shunt）** 方案，U、V 两相进行电流采样，W 相电流通过公式 $I_w = -I_u - I_v$ 算得。

#### (1) 运放放大与偏置电路

F2800137 的 ADC 采样范围为 0–3.3V。双向交流电流采样必须将 0A 电流偏置到 1.65V。

```text
                      3.3V
                       │
                     [R_bias1 10k]
                       │
Phase_Shunt ──[R_in 1k]───(+) 运放 ───[R_f 10k]───> To F2800137 ADC
                       │       │
                     [R_bias2 10k] [R_g 1k]
                       │       │
                      GND     GND

```

* **采样电阻**：2512 封装，5mΩ 1% 2W 合金电阻。
* **运放选型**：低成本双运放 **SGM8632** / **TP181** / **TLV9062**（压摆率 $> 8\text{V/\mu s}$，带宽 $> 10\text{MHz}$）。
* **计算公式**：
假设放大倍数为 10 倍，采样电阻为 $5\text{m}\Omega$：

$$V_{out} = (I_{phase} \times 0.005\Omega \times 10) + 1.65\text{V}$$



采样电流范围为 $\pm 33\text{A}$，完全满足大部分电机需求。

#### (2) 母线电压与分压采样

* 母线电压分压比设计：使用 100kΩ 与 4.7kΩ 精密电阻（0.1%）分压，将 48V 降至 2.15V 送入 DSP ADC 引脚，并加 100nF 电容滤波。

---

### 5. 硬件级过流保护电路（基于 C2000 CMPSS）

这是 TI C2000 的核心优势，**无需外置比较器**即可实现 $50\text{ns}$ 级过流硬件保护：

1. 将运放输出端的电流信号直接引入 F2800137 的 **CMPSS（比较器子系统）引脚**（如 `CMPIN1P`）。
2. 内部 DAC 设定过流阈值（例如偏置 1.65V + 1.0V = 2.65V，对应偏置过流电流）。
3. 当运放电压超过 2.65V，CMPSS 触发 Trip Zone（TZ）信号，**从硬件层面直接封锁 ePWM 栅极输出**，无需 CPU 执行代码，能有效防止 MOS 爆管。

### 8. PCB Layout 布局关键准则

1. **功率回路与小信号隔离**：
* DC 母线电容必须**紧靠** 3 相 MOS 桥，最小化高频开关回路（Loop Area）。
* 采样电阻地（Power GND）与 DSP 模拟地（AGND）采用**单点接地**（Net Tie 或通过 0Ω 电阻连接）。


2. **运放采样走线**：
* 采样电阻到运放输入端采用 **差分走线（Differential Trace）**，避免大电流开关噪声干扰。


3. **散热设计**：
* MOSFET 漏极（Drain）铺大面积铜箔，并打密集过孔（Via Matrix）到背层进行散热。
