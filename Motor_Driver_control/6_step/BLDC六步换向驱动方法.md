BLDC 六步换向法，你可以先记住一句话：

**同一时刻只驱动两相：一相接电源正极，一相接地，剩下一相悬空；每隔 60° 电角度换一次组合，一圈电角度一共 6 步。**

---

## 1. 三相桥是基础

BLDC 三相电机一般接在三相半桥上：

```text
             电池/母线正极 VM+
                  |
          UH      VH      WH       ← 上桥臂 MOS
          |       |       |
          U       V       W        ← 电机三相
          |       |       |
          UL      VL      WL       ← 下桥臂 MOS
                  |
                 GND
```

每一相都有两个 MOS：

```text
U相：UH / UL
V相：VH / VL
W相：WH / WL
```

每一相可以有 3 种状态：

```text
上管开，下管关：这一相接 VM+，记为 +
上管关，下管开：这一相接 GND，记为 -
上下管都关：这一相悬空，记为 Z
```

重点：**同一相的上管和下管绝对不能同时开**，否则就是电源直通，可能直接炸 MOS。

---

## 2. 六步换向表

正转时，一个常见换向顺序是：

| 步骤 | U相 | V相 | W相 | 导通状态      |
| -- | -- | -- | -- | --------- |
| 1  | +  | -  | Z  | UH 开，VL 开 |
| 2  | +  | Z  | -  | UH 开，WL 开 |
| 3  | Z  | +  | -  | VH 开，WL 开 |
| 4  | -  | +  | Z  | UL 开，VH 开 |
| 5  | -  | Z  | +  | UL 开，WH 开 |
| 6  | Z  | -  | +  | VL 开，WH 开 |

然后再回到第 1 步。

用更直观的方式看：

```text
第1步：U → V
第2步：U → W
第3步：V → W
第4步：V → U
第5步：W → U
第6步：W → V
```

电流方向大概是：

```text
电池正极 → 上桥臂 → 某一相绕组 → 另一相绕组 → 下桥臂 → GND
```

比如第 1 步：

```text
VM+ → UH → U相 → 电机内部绕组 → V相 → VL → GND
```

W 相不主动驱动，悬空。

---

## 3. 为什么叫“六步”？

因为一个电角周期分成 6 个区间：

```text
0° ~ 60°
60° ~ 120°
120° ~ 180°
180° ~ 240°
240° ~ 300°
300° ~ 360°
```

每 60° 电角度换一次状态。

```text
一圈电角度 = 6 次换向
```

注意这里是**电角度**，不是机械角度。

如果电机有 `p` 对极，那么：

```text
电角度 = 机械角度 × 极对数
```

比如电机是 7 对极：

```text
电机机械转一圈，电角度转 7 圈
也就是六步换向会执行 7 × 6 = 42 次
```

---

## 4. PWM 加在哪里？

六步换向不是简单地让 MOS 全开全关，一般会在导通相上加 PWM，用占空比控制电压、电流、转矩和速度。

以第 1 步为例：

```text
U相 = +
V相 = -
W相 = Z
```

可以这样做：

### 方式 A：上桥臂 PWM，下桥臂常开

```text
UH：PWM
VL：常开
其他 MOS：关闭
```

电流路径：

```text
UH PWM 导通时：
VM+ → UH → U相 → 电机 → V相 → VL → GND
```

### 方式 B：下桥臂 PWM，上桥臂常开

```text
UH：常开
VL：PWM
其他 MOS：关闭
```

也可以。

### 方式 C：互补 PWM

上管和下管互补导通，并加入死区时间。这种效率高，但控制复杂一些，必须保证死区正确。

对于你初学调试，建议先理解成：

```text
一个 MOS 给 PWM
另一个 MOS 常开
第三相悬空
```

这样最容易理解。

## 5. 六步换向怎么知道什么时候换下一步？

有三种常见方式。

---

# 方法一：开环定时换向

这是最简单的。

你用一个定时器，每隔一段时间切换到下一步：

```text
1 → 2 → 3 → 4 → 5 → 6 → 1 → ...
```

伪代码：

```c
uint8_t step = 0;

void motor_commutate_open_loop(void)
{
    step++;
    if (step >= 6)
    {
        step = 0;
    }

    set_six_step_pwm(step, duty);
}
```

然后启动时慢慢加快换向速度：

```text
刚开始：每 20ms 换一步
然后：每 15ms 换一步
然后：每 10ms 换一步
然后：每 5ms 换一步
```

这叫开环强拖。

缺点是：**你不知道转子是否真的跟上了**。

如果负载大，转子跟不上，会：

```text
抖动
失步
堵转
电流很大
电机发热
```

所以开环六步一般只适合启动阶段或者简单风扇类负载。

---

# 方法二：霍尔传感器换向

很多 BLDC 电机内部有 3 个霍尔传感器，输出 3 路信号：

```text
Hall_A
Hall_B
Hall_C
```

组合起来是一个 3bit 状态：

```c
hall = (Hall_A << 2) | (Hall_B << 1) | Hall_C;
```

理论上会出现 6 个有效状态：

```text
001
101
100
110
010
011
```

每个状态对应一个换向步骤。

比如一种常见表：

| Hall值 | 换向步骤   | U相 | V相 | W相 |
| ----- | ------ | -- | -- | -- |
| 001   | Step 1 | +  | -  | Z  |
| 101   | Step 2 | +  | Z  | -  |
| 100   | Step 3 | Z  | +  | -  |
| 110   | Step 4 | -  | +  | Z  |
| 010   | Step 5 | -  | Z  | +  |
| 011   | Step 6 | Z  | -  | +  |

代码大概这样：

```c
void motor_hall_commutate(uint8_t hall, uint16_t duty)
{
    switch (hall)
    {
        case 0x01:  // 001
            set_phase(U_PLUS, V_MINUS, W_FLOAT, duty);
            break;

        case 0x05:  // 101
            set_phase(U_PLUS, W_MINUS, V_FLOAT, duty);
            break;

        case 0x04:  // 100
            set_phase(V_PLUS, W_MINUS, U_FLOAT, duty);
            break;

        case 0x06:  // 110
            set_phase(V_PLUS, U_MINUS, W_FLOAT, duty);
            break;

        case 0x02:  // 010
            set_phase(W_PLUS, U_MINUS, V_FLOAT, duty);
            break;

        case 0x03:  // 011
            set_phase(W_PLUS, V_MINUS, U_FLOAT, duty);
            break;

        default:
            // 000 和 111 通常是异常状态
            motor_disable_all_pwm();
            break;
    }
}
```

但是注意：**这个表不是所有电机都一样**。

因为霍尔线序、电机相线线序可能不同，所以实际调试时经常要改表。

如果表错了，现象是：

```text
电机抖
反转
启动不了
电流很大
转起来声音很怪
```

# 方法三：无感反电动势换向

无感 BLDC 六步换向一般用“悬空相反电动势过零点”来判断转子位置。

因为六步里面总有一相是悬空的：

```text
第1步：U+ V- W悬空
第2步：U+ W- V悬空
第3步：V+ W- U悬空
...
```

悬空相没有被主动拉高或拉低，可以用 ADC 或比较器测它的电压。

当悬空相的反电动势穿过母线电压的一半时，称为过零点：

```text
悬空相电压 ≈ VBUS / 2
```

检测到过零点以后，再延迟 30° 电角度，然后进行下一次换向。

原因是：

```text
反电动势过零点通常发生在两个换向点的中间
换向点相差 60° 电角度
所以过零点后再等 30° 电角度换向
```

流程大概是：

```text
1. 先开环强拖，让电机转起来
2. 转起来后开始检测悬空相反电动势
3. 检测到过零点
4. 延迟 30° 电角度
5. 切换到下一步
6. 循环
```

无感六步的问题是：**低速和静止时反电动势很小，不好检测**。
所以无感 BLDC 通常启动阶段必须开环强拖。

## 6. 真正写代码时，可以这样分层

建议你不要把所有东西写在一个函数里面，可以分成 4 层。

### 第一层：关闭所有 MOS

```c
void motor_all_off(void)
{
    UH_OFF();
    UL_OFF();

    VH_OFF();
    VL_OFF();

    WH_OFF();
    WL_OFF();
}
```

---

### 第二层：设置某一个六步状态

比如：

```c
void motor_set_step(uint8_t step, uint16_t duty)
{
    motor_all_off();

    switch (step)
    {
        case 0:
            // U+ V- W悬空
            UH_PWM(duty);
            VL_ON();
            break;

        case 1:
            // U+ W- V悬空
            UH_PWM(duty);
            WL_ON();
            break;

        case 2:
            // V+ W- U悬空
            VH_PWM(duty);
            WL_ON();
            break;

        case 3:
            // V+ U- W悬空
            VH_PWM(duty);
            UL_ON();
            break;

        case 4:
            // W+ U- V悬空
            WH_PWM(duty);
            UL_ON();
            break;

        case 5:
            // W+ V- U悬空
            WH_PWM(duty);
            VL_ON();
            break;

        default:
            motor_all_off();
            break;
    }
}
```

这里 `UH_PWM(duty)` 表示 U 相上桥臂输出 PWM，`VL_ON()` 表示 V 相下桥臂常开。

---

### 第三层：根据方向决定步进顺序

正转：

```text
0 → 1 → 2 → 3 → 4 → 5 → 0
```

反转：

```text
0 → 5 → 4 → 3 → 2 → 1 → 0
```

代码：

```c
void motor_next_step(uint8_t dir)
{
    if (dir == MOTOR_FORWARD)
    {
        step++;
        if (step >= 6)
        {
            step = 0;
        }
    }
    else
    {
        if (step == 0)
        {
            step = 5;
        }
        else
        {
            step--;
        }
    }

    motor_set_step(step, duty);
}
```

---

### 第四层：速度控制

最简单的速度控制就是调换向周期：

```text
换向越快，目标转速越高
占空比越大，输出电压越高，带载能力越强
```

但是要注意：

```text
换向速度 ≠ 电机实际速度
```

开环时你只是“命令磁场转这么快”，电机能不能跟上不一定。

比较靠谱的做法是：

```text
霍尔/无感检测实际转速
然后用 PI 调 duty
```

也就是：

```c
speed_error = target_speed - actual_speed;
duty += Kp * speed_error + Ki * integral;
```

六步控制里面，速度闭环通常是：

```text
霍尔/反电动势 → 测实际转速
实际转速和目标转速比较
PI 调节 PWM 占空比
换向时刻由霍尔/反电动势决定
```

## 7. 六步换向和 FOC 的核心区别

六步换向：

```text
一次只驱动两相，一相悬空
每 60° 电角度硬切换一次
相电流更接近梯形/方波
控制简单
噪声和转矩脉动比较大
```

FOC：

```text
三相通常都参与调制
电流尽量控制成正弦
根据转子角度连续调节电压矢量
转矩更平滑
低速性能更好
更适合平衡车、伺服、低速大扭矩场景
```

---

## 8. 对你现在做电机调试的建议

你可以按这个顺序学：

```text
第一步：先实现六步开环，让电机能慢慢转
第二步：加霍尔换向，做到稳定启动和稳定转动
第三步：加速度闭环，用 PI 调 duty
第四步：看三相电流波形、电流限制、堵转保护
第五步：再上 FOC
```

但是如果你最终目标是**平衡车双电机**，六步法可以用来学习电机驱动原理，但最终更建议上：

```text
有感 FOC：编码器 / 霍尔 / 磁编码器
电流采样
速度环
姿态环
```

因为平衡车对低速、堵转、快速响应、转矩平滑要求很高，六步法会比较粗糙。

## 1. 六步换向三相状态长什么样？

以正转为例：

| 电角度区间     | U 相 | V 相 | W 相 | 导通 MOS  |
| --------- | --- | --- | --- | ------- |
| 0°~60°    | +   | -   | Z   | UH + VL |
| 60°~120°  | +   | Z   | -   | UH + WL |
| 120°~180° | Z   | +   | -   | VH + WL |
| 180°~240° | -   | +   | Z   | UL + VH |
| 240°~300° | -   | Z   | +   | UL + WH |
| 300°~360° | Z   | -   | +   | VL + WH |

其中：

```text
+ ：这相接电源正极，通常上桥臂导通或者 PWM
- ：这相接 GND，通常下桥臂导通
Z ：这相悬空，不主动驱动
```

---

## 2. 三相“相状态”波形大概这样

如果先不看 PWM 细节，只看六步换向的相状态，大概是这样：

```text
电角度： 0     60    120   180   240   300   360
        |-----|-----|-----|-----|-----|-----|

U相：    +     +     Z     -     -     Z
V相：    -     Z     +     +     Z     -
W相：    Z     -     -     Z     +     +
```

换成波形感觉就是：

```text
U相：  ++++++++  ZZZZ  --------  ZZZZ
V相：  ----  ZZZZ  ++++++++  ZZZZ  ----
W相：  ZZZZ  --------  ZZZZ  ++++++++
```

注意这里的 `+`、`-`、`Z` 不是正弦波，而是**一段一段的方波状态**。

---

## 3. 如果你看 MCU 的 6 路 PWM 控制信号

三相桥一般有 6 个 MOS：

```text
UH  VH  WH   上桥臂
UL  VL  WL   下桥臂
```

假设你采用“上桥臂 PWM，下桥臂常开”的方式，那么 6 步信号大概是：

| 步骤      | UH  | UL  | VH  | VL  | WH  | WL  |
| ------- | --- | --- | --- | --- | --- | --- |
| 1：U+ V- | PWM | OFF | OFF | ON  | OFF | OFF |
| 2：U+ W- | PWM | OFF | OFF | OFF | OFF | ON  |
| 3：V+ W- | OFF | OFF | PWM | OFF | OFF | ON  |
| 4：V+ U- | OFF | ON  | PWM | OFF | OFF | OFF |
| 5：W+ U- | OFF | ON  | OFF | OFF | PWM | OFF |
| 6：W+ V- | OFF | OFF | OFF | ON  | PWM | OFF |

也就是说，示波器如果测 6 路门极信号，你会看到：

```text
某一步里：
一根是 PWM
一根是常高
其他四根是低

下一步：
PWM 换到另一根
常高也换到另一根
```

例如第 1 步：

```text
UH：PWM PWM PWM PWM
VL：一直高
其他：一直低
```

第 2 步：

```text
UH：PWM PWM PWM PWM
WL：一直高
其他：一直低
```

第 3 步：

```text
VH：PWM PWM PWM PWM
WL：一直高
其他：一直低
```

---

## 4. 如果你只看 U/V/W 三相桥臂输出点

也就是测电机三根相线对电源 GND 的电压。

假设母线电压是 12V，第 1 步是：

```text
U+，V-，W悬空
```

那么大概是：

```text
U相：PWM，在 0V 和 12V 之间跳
V相：接 GND，约 0V
W相：悬空，可能是反电动势波形，也可能漂浮、毛刺、噪声
```

第 2 步：

```text
U相：PWM
W相：0V
V相：悬空
```

第 3 步：

```text
V相：PWM
W相：0V
U相：悬空
```

所以你用示波器看 U/V/W 相线，对地测的时候，它不是三路漂亮的正弦，也不是三路固定相差 120° 的 PWM。

它更像这种状态切换：

```text
步骤：  1        2        3        4        5        6

U相：  PWM      PWM      Z        0V       0V       Z
V相：  0V       Z        PWM      PWM      Z        0V
W相：  Z        0V       0V       Z        PWM      PWM
```

这就是六步换向的典型三相波形。

---

## 5. 如果你看线电压 U-V、V-W、W-U

这个更能看出六步换向的味道。

比如测 `U相 - V相`，理想情况下会看到类似：

```text
U-V线电压：

+Vbus  +Vbus   0    -Vbus  -Vbus   0
  |------|------|------|------|------|------|
   0°    60°   120°   180°   240°   300°  360°
```

但是因为有 PWM，所以不是平滑的 `+12V` 或 `-12V`，而是被 PWM 切碎的：

```text
+Vbus区间：  |‾|_|‾|_|‾|_|‾|_
0区间：      __________________
-Vbus区间： _|‾|_|‾|_|‾|_|‾|    方向相反
```

所以线电压大概是这种“带 PWM 斩波的六阶梯波”。

---

## 6. 六步换向和 FOC 波形最大的区别

FOC / 正弦控制希望三相等效电压是：

```text
U相：正弦
V相：比 U 相差 120°
W相：比 U 相差 240°
```

六步换向则是：

```text
U相：+、+、Z、-、-、Z
V相：-、Z、+、+、Z、-
W相：Z、-、-、Z、+、+
```

所以六步换向的电流一般更接近梯形波/方波，转矩脉动会比 FOC 大。

## 7. 用示波器看时要注意两个时间尺度

你现在 PWM 频率大概是 30kHz，周期约 33.3us。

六步换向还有一个更慢的换向频率，比如几百 Hz、几 kHz，取决于电机转速。

所以示波器上会出现两种观察方式：

### 放大看

时间档调到：

```text
10us/div
20us/div
50us/div
```

你看到的是 PWM 细节：

```text
|‾‾‾|___|‾‾‾|___|‾‾‾|___
```

### 拉远看

时间档调到：

```text
1ms/div
2ms/div
5ms/div
10ms/div
```

你才能看到六步换向的区间切换：

```text
U相：PWM PWM 悬空 低电平 低电平 悬空
V相：低电平 悬空 PWM PWM 悬空 低电平
W相：悬空 低电平 低电平 悬空 PWM PWM
```

## 8. 你实际测量时应该看到什么？

如果你测 MCU 输出给驱动芯片的 PWM 信号，可能看到：

```text
CH1：U相 PWM
CH2：V相 PWM
CH3：W相 PWM
```

在六步里面，某个时间段可能是：

```text
CH1 有 PWM
CH2 常低或者常高
CH3 关闭
```

过一会换成：

```text
CH1 关闭
CH2 有 PWM
CH3 常低或者常高
```

这就对了。

如果你看到三相一直都是类似 FOC 那种连续 PWM，而且三个占空比一直都在变化，那它更像是正弦 PWM / SVPWM，而不是传统六步换向。

## 9. 一句话总结

六步换向的三相 PWM 不是三路正弦调制 PWM，而是：

```text
每一时刻只驱动两相：
一相 PWM 接正极
一相接地
一相悬空

每 60° 电角度换一次组合
6 个组合循环一次
```

所以示波器上看到的三相相线状态大概是：

```text
U相：PWM  PWM  Z    0    0    Z
V相：0    Z    PWM  PWM  Z    0
W相：Z    0    0    Z    PWM  PWM
```

这就是典型的 BLDC 六步换向 PWM 波形。

----
# 注意事项！
----
六步换向最需要注意的不是“能不能转”，而是：

**别炸 MOS、别过流、别换向错、别让电机失步。**

---

## 1. 上下桥绝对不能直通

这是最重要的。

三相桥每一相都有上管和下管：

```text
U相：UH / UL
V相：VH / VL
W相：WH / WL
```

同一相的上管和下管不能同时开。

比如：

```text
UH = 1
UL = 1
```

这就相当于：

```text
电池正极 → UH → UL → GND
```

中间几乎没有负载，瞬间大电流，轻则 MOS 发热，重则炸 MOS、炸驱动、电源保护。

所以必须有：

```text
1. 死区时间 dead time
2. 换向前先关断旧状态
3. 延时一小段时间
4. 再打开新状态
```

比如换向时不要直接：

```c
关 A，开 B，全部同时改
```

而应该类似：

```c
motor_all_off();
delay_deadtime();
motor_set_new_step();
```

实际产品里一般靠高级定时器自动插入死区，比如 STM32 TIM1/TIM8、GD32 高级 TIMER。

---

## 2. 六步换向表一定要和电机相序匹配

理论换向表是：

```text
1：U+ V- W悬空
2：U+ W- V悬空
3：V+ W- U悬空
4：V+ U- W悬空
5：W+ U- V悬空
6：W+ V- U悬空
```

但是实际中，电机三根相线、霍尔三根线、驱动板 U/V/W 标号，可能都不一致。

如果换向表不匹配，现象会是：

```text
电机抖动
启动不了
转一下停一下
声音很大
电流很大
反转
空载能转，带载不行
```

所以调试时要先低电压、限流、低占空比慢慢试。

尤其有霍尔传感器时，不能死记网上的表。要根据实际 Hall 状态和相线对应关系重新匹配。

---

## 3. 启动不能一上来就高速换向

六步开环启动最容易出问题。

刚开始转子静止，你不知道转子在哪。如果你直接快速切换：

```text
1 → 2 → 3 → 4 → 5 → 6
```

磁场跑得太快，转子跟不上，就会失步。

正确启动一般是：

```text
1. 预定位：先固定一个换向状态，让转子吸到一个已知位置
2. 低占空比启动
3. 慢慢加快换向频率
4. 同时慢慢增加 duty
5. 转起来后再切到霍尔换向或者反电动势换向
```

比如开环启动过程：

```text
先 10% duty，20ms 换一步
再 12% duty，15ms 换一步
再 15% duty，10ms 换一步
再 18% duty，5ms 换一步
```

不要一开始就：

```text
30kHz PWM，80% duty，快速六步切换
```

这样很容易堵转大电流。

---

## 4. 一定要有限流保护

电机堵转时，绕组基本就是低阻电感。尤其低速时反电动势很小，电流会非常大。

所以六步控制必须考虑：

```text
母线电流采样
相电流采样
过流比较器
ADC 采样保护
软件限流
硬件关断保护
```

最少也要有：

```text
1. 电源限流
2. 保险丝 / 电子保险
3. 驱动芯片过流保护
4. 软件 duty 限制
```

调试时建议：

```text
低压电源启动，比如 6V / 8V
电源电流限流，比如 0.5A~2A
小 duty 开始，比如 5%~10%
```

不要一开始就接大电池直接怼。

---

## 5. PWM 频率要选合适

常见 BLDC 六步 PWM 频率：

```text
16kHz ~ 30kHz
```

你现在看到的 30kHz 是可以的。

频率太低：

```text
电机会有明显啸叫
电流纹波大
噪声大
```

频率太高：

```text
MOS 开关损耗增加
驱动芯片更热
定时器分辨率下降
死区占比变大
```

所以一般：

```text
小功率电机：20kHz ~ 30kHz 常见
大功率电机：10kHz ~ 20kHz 也常见
```

---

## 6. 高边驱动要注意自举电容

很多三相栅极驱动芯片的高边 MOS 是 bootstrap 自举供电。

这意味着高边不能长期 100% 导通，否则自举电容没机会充电。

所以如果你用高边 PWM，要注意：

```text
duty 不要长期 100%
最好限制到 95% 或 98% 以下
低速/堵转时高边驱动可能异常
```

有些驱动芯片支持 100% duty，有些不支持，要看具体驱动芯片手册。

---

## 7. 换向瞬间会有尖峰和噪声

六步换向是硬切换，每 60° 电角度切一次。换向瞬间电流路径变化，会产生：

```text
电压尖峰
电流尖峰
EMI 噪声
反电动势干扰
MOS 发热
驱动误触发
```

所以硬件上要注意：

```text
母线电容靠近 MOS
驱动芯片去耦电容靠近芯片
MOS 栅极电阻合适
必要时加 RC snubber
功率地和信号地布局要小心
电流采样走线要干净
```

布局不好时，软件再好也会出现奇怪问题。

---

## 8. 悬空相不要真的乱接

六步里总有一相是悬空相，比如：

```text
U+ V- W悬空
```

这个“悬空”意思是：这一相的上下 MOS 都关掉。

不能把悬空相又拉高或者拉低。

如果你做无感反电动势检测，悬空相还要接到 ADC 或比较器，用来检测过零点。

但是要注意：悬空相电压有很多毛刺，不能直接粗暴判断。一般要：

```text
换向后加 blanking time 消隐时间
滤波
比较 Vphase 和 VBUS/2
检测过零点
过零后延迟 30° 电角度再换向
```

低速时反电动势很小，无感检测不可靠，所以无感六步通常要先开环强拖启动。

---

## 9. 霍尔信号要滤波和判错

如果你用霍尔传感器换向，要注意：

有效 Hall 状态一般只有 6 个：

```text
001
101
100
110
010
011
```

异常状态：

```text
000
111
```

如果读到 `000` 或 `111`，不要继续强行换向，应该保护或者报错。

霍尔线也可能被电机大电流干扰，所以要：

```text
上拉电阻合适
线不要离相线太近
软件消抖/滤波
状态跳变顺序检查
异常跳变保护
```

正常情况下 Hall 状态应该按固定顺序变化。比如正转：

```text
001 → 101 → 100 → 110 → 010 → 011 → 001
```

如果突然跳到不相邻状态，可能是干扰或者线序问题。

---

## 10. 方向切换不能直接反打

电机正转时，不要直接把换向顺序反过来。

比如正在：

```text
1 → 2 → 3 → 4 → 5 → 6
```

突然切成：

```text
6 → 5 → 4 → 3 → 2 → 1
```

这等于强行反向制动，电流可能非常大。

正确做法：

```text
1. 先降 duty
2. 等速度降下来
3. 进入刹车或滑行
4. 接近停止后再反向启动
```

平衡车这种需要快速正反转的场景，六步法会比较粗糙，FOC 更合适。

---

## 11. 刹车方式要分清楚

常见几种状态：

### 滑行

所有 MOS 关闭：

```text
UH UL VH VL WH WL 全关
```

电机自由转，慢慢停。

### 短刹

三个下桥臂打开，或者三个上桥臂打开：

```text
UL VL WL 打开
```

电机绕组被短接，刹车更快，但电流可能比较大。

### 反拖刹车

直接反向换向，这个最猛，也最危险。

初期调试不建议用反拖刹车。

---

## 12. 示波器测量要特别小心

如果你测 MCU PWM 引脚，普通示波器可以直接测。

但是如果你测三相桥输出，也就是 U/V/W 相线，要非常小心。

普通台式示波器地夹通常接大地 PE，不能随便夹到电机相线上。

错误接法可能导致：

```text
示波器地夹把半桥输出短到地
炸 MOS
炸驱动
炸示波器地线
电源保护
```

安全测法：

```text
1. 用差分探头测 U-V、V-W、W-U
2. 或用隔离示波器
3. 或只测低压侧的 MCU PWM 信号
4. 或用电池供电的小型隔离示波器，但仍要小心
```

不要用普通示波器地夹直接夹半桥输出点。

---

## 13. 软件状态机要写清楚

不要让电机控制散落在各种函数里。建议有明确状态：

```c
typedef enum
{
    MOTOR_IDLE = 0,
    MOTOR_ALIGN,
    MOTOR_OPEN_LOOP_START,
    MOTOR_RUN_HALL,
    MOTOR_RUN_SENSORLESS,
    MOTOR_BRAKE,
    MOTOR_FAULT
} motor_state_t;
```

任何异常都进入：

```text
MOTOR_FAULT
```

然后关闭 PWM。

异常包括：

```text
过流
欠压
过压
霍尔异常
堵转
驱动芯片故障
温度过高
启动失败
```

---

## 14. 最小调试顺序建议

你可以按这个顺序来：

```text
1. 不接电机，只看 6 路 PWM 是否符合换向表
2. 接低压限流电源
3. duty 设很小，比如 5%~10%
4. 单步输出六个状态，看电机是否有吸合感
5. 慢速开环六步，看能否平滑转
6. 加霍尔换向或反电动势换向
7. 加速度闭环
8. 加过流、堵转、欠压保护
9. 最后再提高电压和负载
```

---

最关键的几个点你先记住：

```text
1. 上下桥不能直通，必须有死区
2. 开始必须低压限流小 duty
3. 换向表必须和电机相序匹配
4. 启动要慢慢加速，不能直接高速换向
5. 必须有过流/堵转保护
6. 普通示波器地夹不要乱夹三相输出
```

六步换向看起来比 FOC 简单，但功率级一样危险。软件一个状态写错，MOS 可能瞬间就没了。
