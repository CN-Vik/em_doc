“检测各相绕组的反电动势过零点”是**无感六步换相（Sensorless BLDC）最经典的方法**。

简单理解：

> **不用霍尔、不用编码器，而是看电机自己发出来的反电动势波形，判断转子转到哪里，然后决定什么时候换相。**

---

## 1. 先理解反电动势是什么

BLDC 电机转起来以后，本身就是一个“小发电机”。

比如：

```
电机旋转

磁钢运动
 ↓
切割绕组磁场
 ↓
线圈产生电压

这个电压 = 反电动势 BEMF
```

三相绕组会产生：

```
U相 BEMF:

      /\
     /  \
----/    \----
    
V相:

  /\      
 /  \     
/    \----

W相:

    /\
   /  \
--/    \--
```

它和转子位置强相关。

---

## 2. 六步控制为什么能靠它换相？

BLDC六步控制：

每60°电角度换一次相。

例如：

| 状态 | 导通    |
| -- | ----- |
| 1  | U+ V- |
| 2  | U+ W- |
| 3  | V+ W- |
| 4  | V+ U- |
| 5  | W+ U- |
| 6  | W+ V- |

其中：

两相通电：

```
U ---- MOS ----+
               |
              电机
               |
V ---- MOS ----+
```

剩下一相：

```
W相悬空
```

这个悬空相就是用来检测BEMF的。

---

## 3. 什么叫“过零点”？

假设W相悬空：

它的反电动势：

```
W相电压

       +
       |
       |
-------0--------- 时间
       |
       |
       -

```

当它从正变负：

或者：

负变正：

经过：

```
0V
```

这个瞬间：

叫：

> **反电动势过零点**

英文：

> BEMF Zero Crossing

---

## 4. 为什么过零点能知道转子位置？

因为BLDC梯形反电动势：

```
电角度


0°       60°      120°


U:
 /\____________

V:
____/\_________

W:
______/\_______

```

每个相的过零点固定对应转子位置。

例如：

W相下降过零：

```
W BEMF

+
|
|
0 ---------  ← 这里
|
|
-

```

代表：

```
距离下一次换相约30°电角度
```

所以：

检测到：

```
W相过零
        |
        ↓

延迟30°电角度

        |
        ↓

换下一步
```

---

## 5. 实际电路怎么检测？

通常：

三相：

```
U相
 |
分压
 |
ADC


V相
 |
分压
 |
ADC


W相
 |
分压
 |
ADC

```

MCU采样：

```
U_adc
V_adc
W_adc
```

然后计算：

```
中性点电压:

Vmid=(U+V+W)/3
```

比较：

```
W相电压 - Vmid
```

如果：

```
W-Vmid

正

↓

负

```

说明：

过零。

---

## 6. 波形大概这样

假设检测W相：

```
W相BEMF


  +5V
    |
    |
    |      /
    |     /
0V--|----*--------- 
    |   过零点
    |
    |
 -5V


```

MCU：

ADC采样：

```
if(W_adc > Vmid)
{
    positive
}

if(W_adc < Vmid)
{
    negative
}
```

检测翻转。

---

## 7. 为什么低速不能用？

因为：

BEMF大小：

$$
E = K_e \omega
$$

转速越低：

反电动势越小。

比如：

高速：

```
BEMF = 10V

很好测
```

低速：

```
BEMF = 0.1V

噪声都比它大
```

所以：

无感六步：

启动必须：

```
强拖启动
↓
升速
↓
BEMF足够大
↓
切无感
```

---

## 8. 和你现在研究的无感FOC有什么区别？

你现在研究：

```
SMO
PLL
HFI
```

属于：

### 无感FOC

检测：

```
连续反电动势
```

估计：

```
磁链角度 θ
```

然后：

```
Park变换
↓
Id/Iq控制
↓
SVPWM
```

而无感六步：

只需要：

```
BEMF过零
↓
判断60°位置
↓
换相
```

精度低很多。

---

简单总结：

```
无感六步：

三相电机转动
       |
       ↓
产生BEMF
       |
       ↓
检测悬空相电压
       |
       ↓
找到BEMF穿过0V瞬间
       |
       ↓
延迟30°电角度
       |
       ↓
换下一步
```

所以“反电动势过零检测”本质就是：

> **把电机自己产生的电压波形当成一个免费的霍尔传感器，用它判断转子位置。**

对于你那个 **2208-80T、7对极、12V、低KV电机**，这个方法其实不太适合，因为KV低、转速低，BEMF很弱；你的电机更适合研究 **SMO/HFI无感FOC**。

这个“每60°电角度换一次相”是 **BLDC六步控制的核心**。你不理解很正常，因为这里混合了 **电角度、机械角度、三相磁场旋转**。

我们一步一步看。

---

## 1. BLDC为什么要换相？

BLDC电机里面：

* 转子：永磁磁钢（N/S极）
* 定子：三相绕组

三相绕组通电后产生磁场：

比如：

```
U+ V-

        N
        ↑
        |
        |
S ------+------ N   转子

```

定子磁场会吸引/排斥转子，让转子跟着转。

但是：

如果一直：

```
U+ V-
```

不变：

定子磁场方向固定：

```
        ↑
        ↑
        ↑

```

转子转到对应位置以后：

```
转子
 N
 |
 |
 S

```

磁场对齐。

这时候：

> 没有继续旋转的力了。

所以必须不断改变定子磁场方向。

---

# 2. 三相绕组可以产生6个磁场方向

BLDC六步：

实际上就是：

让定子磁场每次跳60°。

例如：

### 第一步

```
U+ V-

磁场方向：

0°
```

---

### 第二步

```
U+ W-

磁场方向：

60°
```

---

### 第三步

```
V+ W-

磁场：

120°
```

---

### 第四步

```
V+ U-

磁场：

180°
```

---

### 第五步

```
W+ U-

磁场：

240°
```

---

### 第六步

```
W+ V-

磁场：

300°
```

然后回到：

```
0°
```

形成旋转磁场。

所以：

```
0
 |
60
 |
120
 |
180
 |
240
 |
300
 |
0
```

每跳一次：

就是：

60°电角度。

---

# 3. 为什么不是30°？为什么不是90°？

因为三相绕组天然相差：

$$
120^\circ
$$

比如：

```
U相

0°


V相

120°


W相

240°

```

三相组合：

两个通电，一个断开。

能够形成：

6个稳定磁场方向。

数学上：

$$
360^\circ / 6 =60^\circ
$$

所以六步换相：

天然就是：

$$
60^\circ_e
$$

---

# 4. 注意：这是电角度，不是机械角度！

这个非常重要。

你的2208：

```
12槽14极
```

磁极：

14个

所以：

极对数：

$$
p=7
$$

关系：

$$
\theta_e=p\theta_m
$$

也就是：

7倍。

例如：

电角度60°：

对应机械角度：

$$
60/7=8.57^\circ
$$

所以你的电机：

六步一次换相：

转子机械只转：

约8.6°。

---

# 5. 为什么过零点后延迟30°？

因为：

反电动势过零点：

刚好在两个换相点中间。

例如：

六步：

```
换相点：

0° --------60°---------120°

        ↑
       BEMF过零

```

过零在中间：

所以：

距离下一次换相：

30°电角度。

因此：

检测：

```
BEMF过零
```

然后：

等待：

```
30°电角度
```

换相。

---

# 6. 和FOC有什么关系？

六步：

```
磁场：

0
60
120
180
240
300

跳着走
```

所以：

转矩波动大。

FOC：

```
磁场：

0
1°
2°
3°
4°
5°
...

连续旋转
```

所以：

声音小，效率高。

---

你可以把它理解成：

**六步BLDC = 用6个“台阶”逼近一个旋转磁场。**

每走一级：

定子磁场转60°电角度。

而FOC：

就是把这6级台阶变成无限细的连续旋转。你现在研究的SVPWM，本质就是干这个。

# 无感六步如何强拖起步

对，这个就是**无感六步最关键的问题之一**：

> **电机刚开始是静止的，没有反电动势，所以你根本检测不到过零点。**

因此启动阶段不能靠 BEMF，而是先**人为给定换相顺序，把转子“拖起来”**。等转速起来、BEMF 足够大以后，再切换到 BEMF 过零检测。

---

# 1. 刚上电的时候为什么不能直接检测过零？

电机静止：

$$
\omega=0
$$

反电动势：

$$
E=K_e\omega=0
$$

所以：

```text
电机静止
   ↓
没有反电动势
   ↓
没有过零点
   ↓
无法判断转子位置
   ↓
无法知道应该给哪组相
```

这就是无感六步的“启动死结”。

---

# 2. 所以第一步：先“强拖”

假设你的三相：

```text
U
V
W
```

刚开始不知道转子在哪。

你可以直接强制：

```text
U+ V-
W悬空
```

维持一段时间。

比如：

```text
U+ V-

      ↓

保持 50~200ms
```

这时候产生一个固定的定子磁场：

```text
定子磁场
    ↓
    ↓
    ↓

      N
      |
      |
      S

     转子
```

转子会被吸到这个固定位置。

这一步叫：

> **转子预定位 / Alignment**

---

# 3. 然后开始“拖着转子走”

比如已经预定位以后：

```text
Step 1
U+ V-
```

然后不要马上依赖BEMF。

而是**自己按照固定时间换相**：

```text
U+ V-
   ↓
U+ W-
   ↓
V+ W-
   ↓
V+ U-
   ↓
W+ U-
   ↓
W+ V-
```

也就是：

```text
1 → 2 → 3 → 4 → 5 → 6
```

这时候：

> **MCU根本不需要知道转子在哪里。**

它就是“硬拖”。

---

# 4. 但是不能一开始就换得特别快

例如：

```text
Step1
↓ 100ms
Step2
↓ 100ms
Step3
↓ 100ms
...
```

电机可能根本转不起来。

因为转子有：

* 转动惯量
* 负载
* 摩擦
* 磁阻
* 转矩限制

所以一般要做：

> **加速换相**

例如：

```text
换相间隔

100ms
 ↓
80ms
 ↓
60ms
 ↓
40ms
 ↓
25ms
 ↓
15ms
 ↓
10ms
 ↓
8ms
```

相当于：

```text
低速
 ↓
越来越快
 ↓
越来越快
 ↓
BEMF越来越大
```

---

# 5. 到某个速度之后，就可以“甩锅给BEMF”

这个过程非常重要：

```text
             启动
              ↓
        转子预定位
              ↓
          强制换相
              ↓
          加速拖动
              ↓
       BEMF逐渐变大
              ↓
      能可靠检测过零点
              ↓
        切换无感运行
              ↓
       BEMF闭环换相
```

也就是说：

### 启动阶段

```text
MCU说了算

Step1
Step2
Step3
Step4
...
```

### 正常运行

```text
电机说了算

BEMF过零
   ↓
延迟30°
   ↓
换相
   ↓
BEMF过零
   ↓
延迟30°
   ↓
换相
```

---

# 6. 给你一个非常直观的例子

假设你用ESP32做六步。

### 阶段1：预定位

```c
set_phase(U_HIGH, V_LOW);

delay_ms(100);
```

此时：

```text
转子
 ↓
被吸到固定位置
```

---

### 阶段2：强拖

然后：

```text
U+ V-
↓
U+ W-
↓
V+ W-
↓
V+ U-
↓
W+ U-
↓
W+ V-
```

换相间隔逐渐缩短：

```text
50ms
40ms
30ms
20ms
15ms
12ms
10ms
8ms
```

电机越来越快。

# 7. 什么时候切BEMF？

例如：

```text
强拖到：

500 RPM

↓

BEMF已经比较明显

↓

开始检测悬空相

↓

检测到过零

↓

切换BEMF换相
```

但是这个 **500 RPM不是固定值**。

实际上取决于：

* 电机KV
* 母线电压
* 负载
* BEMF检测电路
* ADC精度
* 噪声
* 电机反电动势常数

所以应该理解成：

> **当BEMF信号已经明显高于噪声，并且连续检测可靠时，再切换。**

---

# 8. 这里还有一个非常关键的问题

你可能马上会想到：

> “我一开始根本不知道转子位置，直接U+V-，不会转反吗？”

**会有这个风险。**

所以启动算法通常会：

### ① 先预定位

```text
U+ V-
保持100ms
```

把转子强制拉到已知位置。

### ② 再按照固定方向六步拖动

```text
1 → 2 → 3 → 4 → 5 → 6
```

这样就知道：

```text
我正在让磁场向这个方向旋转
```

转子跟着跑。

---

# 9. 如果负载很大怎么办？

这时候单纯：

```text
预定位
+
固定换相加速
```

可能会：

```text
磁场跑太快
      ↓
转子跟不上
      ↓
失步
      ↓
电机抖动/堵转
```

所以真正好一点的无感六步启动，会设计：

```text
Alignment
    ↓
Open-loop ramp
    ↓
逐渐提高换相频率
    ↓
检测BEMF
    ↓
判断BEMF可靠
    ↓
Closed-loop BEMF commutation
```

---

# 10. 你可以把整个无感六步理解成两个控制器

```text
                无感六步
                   │
          ┌────────┴────────┐
          ↓                 ↓
       启动阶段            运行阶段
          │                 │
       开环强拖             BEMF闭环
          │                 │
   MCU自己决定换相        BEMF决定换相
          │                 │
   1→2→3→4→5→6            过零检测
          │                 │
       加速                 延迟30°
          │                 │
          └──────→ 切换 ←───┘
```

**所以“无感”并不意味着从0 RPM开始就完全无传感器闭环。**

它实际上是：

> **0速附近：开环强拖；达到一定速度：利用BEMF闭环。**

这和你现在研究的 **SMO 无感FOC**其实是一个非常类似的思想：**SMO在低速/零速也很难仅靠反电动势准确估角，所以才会出现开环启动、HFI、初始位置检测等方案。**
