你这个疑惑非常正常。网上很多文章都是：
 三相电流 → Clarke 变换 → Park 变换 → PI 控制 → 反 Park → SVPWM
但它们往往只告诉你“流程”，没有讲清楚：
为什么非要这么变？不变行不行？变换背后的物理意义是什么？
我们从“电机到底想控制什么”开始讲。
1. FOC 的本质：不是控制三相电流，而是控制“磁场方向”
无刷电机 / PMSM / BLDC 里面，真正让电机转起来的不是某一根线里的电流，而是：
定子电流产生的旋转磁场，去拉着转子永磁体旋转。
你可以把电机想象成：
定子：你手里拿着一个电磁铁，可以改变磁场方向
转子：里面有一个永磁铁，会被定子磁场吸引/排斥
FOC 的目标是：
 让定子磁场始终以最合适的角度“拉着”转子磁场。
最理想的情况是：
转子磁场方向：d 轴
产生转矩的方向：q 轴
也就是：
d轴：和转子磁铁同方向
q轴：和转子磁铁垂直，真正产生力矩
简单理解：
Id：控制磁场强弱/励磁
Iq：控制转矩大小
对常见表贴式永磁同步电机来说，通常希望：
Id = 0;
Iq = 你想要的转矩电流;
这就是 FOC 最核心的思想：
把复杂的三相交流电流控制，变成类似直流电机那样的“励磁电流 Id + 转矩电流 Iq”控制。
2. 如果不做变换，会遇到什么问题？
假设你直接控制三相电流：
Ia
Ib
Ic
这三个电流是正弦变化的，而且随着电机转动一直在变。
例如：
Ia = 正弦波
Ib = 相差 -120°
Ic = 相差 +120°
你要控制它们，就会发现一个麻烦：
目标电流本身一直在变化。
比如电机转得越快，三相电流变化越快。
这就像你要追一个不断变化的目标：
Ia_ref 是正弦波
Ib_ref 是正弦波
Ic_ref 是正弦波
PI 控制器最喜欢控制什么？
一个稳定的直流量。
比如：
目标 = 3A
实际 = 2.8A
误差 = 0.2A
PI 输出补偿
但是三相电流是交流量：
目标这一瞬间是 3A
下一瞬间是 2.5A
再下一瞬间是 1A
再下一瞬间是 -1A
PI 控制器会很难受。
所以 FOC 要干一件事：
把正在旋转的交流量，转换到跟着转子一起旋转的坐标系里。
这样一来，原本变化的正弦波，在旋转坐标系里就变成了“几乎不变的直流量”。
这就是 Clarke 和 Park 变换的根本原因。
3. Clarke 变换：把三相世界，压缩成二维平面
三相电流是：
Ia
Ib
Ic
但是三相电机通常满足：
Ia + Ib + Ic = 0
也就是说，只要知道其中两个，第三个就能算出来。
例如：
Ic = -Ia - Ib
所以三相电流虽然看起来是 3 个变量，本质上只有 2 个自由度。
这就是 Clarke 变换的意义：
把三相 abc 坐标，变成二维静止坐标 αβ。
可以理解为：
abc 三相电流
    ↓ Clarke
αβ 平面上的一个电流矢量
也就是把三相电流合成为一个“等效磁场箭头”。
你可以这样理解 Clarke 变换
三相绕组空间上差 120°：
A相：0°
B相：-120°
C相：+120°
每一相通电都会产生一个方向固定、大小变化的磁场。
三个磁场叠加以后，得到一个总磁场。
这个总磁场可以用一个二维箭头表示：
Iα：这个箭头在 α 轴上的分量
Iβ：这个箭头在 β 轴上的分量
所以 Clarke 变换不是魔法，它只是做了这件事：
把三相绕组产生的合成磁场，用二维坐标表示出来。
就像一个力可以分解成 X/Y 分量一样。
三相电流  →  一个空间电流矢量
Ia Ib Ic     Iα Iβ
4. 但是 Clarke 之后还不够，因为 αβ 坐标系是“静止的”
Clarke 变换后，我们得到了：
Iα
Iβ
它表示定子电流产生的磁场矢量。
但是 αβ 坐标系是固定在定子上的，也就是：
α轴固定不动
β轴固定不动
而转子在旋转。
所以你看到的电流矢量还是在转。
比如电机稳定运行时，定子磁场也在旋转：
Iα = 正弦变化
Iβ = 余弦变化
这时候 PI 控制器还是不好控制，因为它看到的目标还是交流的。
所以还需要 Park 变换。
5. Park 变换：站到转子身上看世界
Park 变换的本质是：
把静止坐标系 αβ，旋转到跟转子一起转的 dq 坐标系。
也就是说：
αβ：站在电机外壳上看磁场
dq：站在转子磁铁上看磁场
这是最关键的理解。
举个非常直观的例子
假设有一个人在操场跑圈。
你站在操场边看他：
他的位置一直在变
一会儿东边
一会儿北边
一会儿西边
一会儿南边
这就像 αβ 坐标系。
但是如果你坐在他旁边一起跑：
你看他的位置几乎不变
这就是 dq 坐标系。
所以 Park 变换做的事情就是：
让坐标系跟着转子一起旋转。
这样原本旋转的电流矢量，在 dq 坐标系里就变成了稳定的直流分量。
6. dq 坐标系为什么有用？
dq 坐标系有两个轴：
d轴：direct axis，直轴，和转子磁链方向对齐
q轴：quadrature axis，交轴，和转子磁链垂直
可以画成这样：
q轴
             ↑
             |
             |
转子磁链 →   +----------→ d轴
如果转子永磁体的磁场方向是 d 轴，那么：
Id：沿着转子磁场方向的电流分量
Iq：垂直于转子磁场方向的电流分量
Id 是干什么的？
Id 和转子磁场同方向或反方向。
它主要影响磁链。
对于表贴式 PMSM，一般不希望它产生太多 Id：
Id_ref = 0
因为永磁体已经提供磁场了，你再加 Id 没啥必要，反而会增加铜耗。
Iq 是干什么的？
Iq 和转子磁场垂直。
它主要产生转矩。
所以：
Iq 越大，电机输出力矩越大
Iq 改变正负，电机力矩方向改变
这就非常像直流电机：
直流电机：
励磁电流控制磁场
电枢电流控制转矩

FOC：
Id 控制磁链
Iq 控制转矩
所以 FOC 的目的就是把交流电机“控制成直流电机的感觉”。
7. 一句话理解 Clarke 和 Park
你可以这样记：
Clarke 变换：
把三相电流合成为一个二维磁场矢量。

Park 变换：
把这个二维磁场矢量，转到转子坐标系里，拆成 Id 和 Iq。
更通俗地说：
Clarke：把三相线圈产生的磁场“合成一个箭头”
Park：站到转子身上，看这个箭头相对转子是往哪拉
8. 为什么 FOC 必须知道电角度？
Park 变换需要知道：
转子现在转到哪里了
也就是电角度 θ。
因为你要把 αβ 坐标系旋转到 dq 坐标系，必须知道旋转多少度。
Iα/Iβ 通过角度 θ 旋转 → Id/Iq
如果角度错了，后果很严重。
比如你以为 d 轴在这里：
你以为：
d轴 →
q轴 ↑
实际转子磁场在别的地方：
实际 d轴 ↗
那你算出来的 Id/Iq 就不准。
本来想控制 Iq 产生转矩，结果一部分电流跑到 Id 上去了。
结果就是：
力矩变小
发热变大
抖动
噪声
效率下降
甚至失步
所以 FOC 的核心之一就是：
准确知道转子电角度
有感 FOC 用编码器、霍尔、磁编码器。
无感 FOC 用反电动势、观测器、PLL、滑模观测器等算法估计角度。
9. 用一个具体例子说明 Park 变换为什么能把交流变直流
假设定子电流矢量在 αβ 平面里面旋转：
Iα = I * cosθ
Iβ = I * sinθ
这时候在静止坐标系看，它一直变。
但是如果 dq 坐标系也跟着 θ 旋转，Park 变换后：
Id = Iα * cosθ + Iβ * sinθ
Iq = -Iα * sinθ + Iβ * cosθ
代进去：
Id = I * cosθ * cosθ + I * sinθ * sinθ
Id = I * (cos²θ + sin²θ)
Id = I
而：
Iq = -I * cosθ * sinθ + I * sinθ * cosθ
Iq = 0
你看，原来 αβ 里面一直旋转的量，到了 dq 里面变成了：
Id = 常数
Iq = 0
这就是重点：
Park 变换把“旋转的交流量”变成了“静止的直流量”。
当然实际 FOC 里通常希望电流主要在 q 轴上，所以也可以得到：
Id ≈ 0
Iq ≈ 常数
这样 PI 控制器就非常好控制。
10. 为什么不直接控制三相正弦波？
理论上可以。
比如六步换相、正弦波控制、SPWM 控制，都可以让电机转。
但是问题是：
它们不直接关心转子磁场和定子磁场之间的精确角度关系。
FOC 更高级的地方在于：
它实时知道转子角度
实时把电流拆成 Id/Iq
精确控制产生转矩的那部分电流
所以 FOC 的优势是：
低速力矩更好
效率更高
噪声更低
响应更快
转矩控制更准
动态性能更好
尤其对于平衡车这种场景，电机需要频繁正反转、快速调节转矩，FOC 非常适合。
11. 用平衡车来理解 FOC
平衡车最关心的不是“电机转速”，而是：
我现在需要多大的力矩，把车身扶起来？
姿态环算出来一个目标力矩。
这个目标力矩最终就变成：
Iq_ref
然后 FOC 电流环负责：
让实际 Iq 快速跟上 Iq_ref
而 Id 通常保持：
Id_ref = 0
整个思路就是：
车身倾倒
    ↓
姿态控制器算出需要的力矩
    ↓
转换成 Iq_ref
    ↓
FOC 控制 Iq
    ↓
电机输出对应力矩
    ↓
车身被扶起来
所以在平衡车里面，FOC 的核心价值是：
你可以把电机当成一个“可快速控制力矩的执行器”。
12. Clarke、Park、反 Park、SVPWM 之间的关系
完整流程是：
采样三相电流
Ia, Ib, Ic
    ↓
Clarke 变换
Iα, Iβ
    ↓
Park 变换，需要转子电角度 θ
Id, Iq
    ↓
和目标比较
Id_ref - Id
Iq_ref - Iq
    ↓
PI 控制器
Vd, Vq
    ↓
反 Park 变换
Vα, Vβ
    ↓
SVPWM
三相 PWM 占空比
    ↓
驱动逆变器
    ↓
控制电机三相电流
你会发现：
Clarke/Park 是为了“测量并理解当前电流”
反 Park/SVPWM 是为了“把控制结果重新变回三相电压去驱动电机”
13. 为什么电流环不用 PI 直接控制 Ia/Ib/Ic？
因为 Ia/Ib/Ic 是高速变化的交流量。
而 Id/Iq 在转子坐标系下接近直流量。
PI 控制器控制直流量很舒服：
Id_ref = 0
Iq_ref = 3A
实际：
Id = 0.1A
Iq = 2.7A
误差：
Id_error = -0.1A
Iq_error = 0.3A
然后 PI 输出：
Vd
Vq
非常清晰。
如果直接控制三相：
Ia_ref = 正弦波
Ib_ref = 正弦波
Ic_ref = 正弦波
控制器就要不断追随变化目标，控制难度高，动态效果差。
14. 最重要的一张脑图
你可以把 FOC 理解为：
真实电机世界：
三相交流、旋转磁场、耦合严重、难控制

Clarke：
把三相电流合成为二维电流矢量

Park：
站到转子视角，把电流分成：
    Id：磁链方向
    Iq：转矩方向

控制器：
直接控制 Id/Iq，就像控制直流电机一样

反变换：
把控制器输出重新变回三相 PWM
15. 最后用一句很直白的话总结
FOC 里面为什么要做 Clarke 和 Park 变换？
因为：
电机本质上是靠“定子磁场矢量”拉着“转子磁场”转。三相电流只是产生这个磁场的手段。Clarke 变换把三相电流合成一个磁场矢量，Park 变换把这个磁场矢量放到转子坐标系下，拆成控制磁链的 Id 和控制转矩的 Iq。这样原本复杂的三相交流电机，就变成了类似直流电机一样好控制的系统。
再压缩一点：
Clarke：三相 → 一个磁场箭头
Park：静止视角 → 转子视角
Id：磁链
Iq：转矩
FOC：精准控制 Iq，让电机精准输出力矩
你真正要抓住的不是公式，而是这个思想：
FOC 不是为了变换而变换，而是为了把“不好控制的三相交流量”，变成“好控制的转矩电流和磁链电流”。

d轴：direct axis，直轴，和转子磁链方向对齐
q轴：quadrature axis，交轴，和转子磁链垂直
可以画成这样：
q轴
             ↑
             |
             |
转子磁链 →   +----------→ d轴
如果转子永磁体的磁场方向是 d 轴，那么：
Id：沿着转子磁场方向的电流分量
Iq：垂直于转子磁场方向的电流分量
Id 是干什么的？
Id 和转子磁场同方向或反方向。
它主要影响磁链。
对于表贴式 PMSM，一般不希望它产生太多 Id：
Id_ref = 0
因为永磁体已经提供磁场了，你再加 Id 没啥必要，反而会增加铜耗。
Iq 是干什么的？
Iq 和转子磁场垂直。
它主要产生转矩。
所以：
Iq 越大，电机输出力矩越大
Iq 改变正负，电机力矩方向改变
这就非常像直流电机：
直流电机：
励磁电流控制磁场
电枢电流控制转矩

FOC：
Id 控制磁链
Iq 控制转矩
所以 FOC 的目的就是把交流电机“控制成直流电机的感觉”。
7. 一句话理解 Clarke 和 Park
你可以这样记：
Clarke 变换：
把三相电流合成为一个二维磁场矢量。

Park 变换：
把这个二维磁场矢量，转到转子坐标系里，拆成 Id 和 Iq。
更通俗地说：
Clarke：把三相线圈产生的磁场“合成一个箭头”
Park：站到转子身上，看这个箭头相对转子是往哪拉
8. 为什么 FOC 必须知道电角度？
Park 变换需要知道：
转子现在转到哪里了
也就是电角度 θ。
因为你要把 αβ 坐标系旋转到 dq 坐标系，必须知道旋转多少度。
Iα/Iβ 通过角度 θ 旋转 → Id/Iq
如果角度错了，后果很严重。
比如你以为 d 轴在这里：
你以为：
d轴 →
q轴 ↑
实际转子磁场在别的地方：
实际 d轴 ↗
那你算出来的 Id/Iq 就不准。
本来想控制 Iq 产生转矩，结果一部分电流跑到 Id 上去了。
结果就是：
力矩变小
发热变大
抖动
噪声
效率下降
甚至失步
所以 FOC 的核心之一就是：
准确知道转子电角度
有感 FOC 用编码器、霍尔、磁编码器。
无感 FOC 用反电动势、观测器、PLL、滑模观测器等算法估计角度。
9. 用一个具体例子说明 Park 变换为什么能把交流变直流
假设定子电流矢量在 αβ 平面里面旋转：
Iα = I * cosθ
Iβ = I * sinθ
这时候在静止坐标系看，它一直变。
但是如果 dq 坐标系也跟着 θ 旋转，Park 变换后：
Id = Iα * cosθ + Iβ * sinθ
Iq = -Iα * sinθ + Iβ * cosθ
代进去：
Id = I * cosθ * cosθ + I * sinθ * sinθ
Id = I * (cos²θ + sin²θ)
Id = I
而：
Iq = -I * cosθ * sinθ + I * sinθ * cosθ
Iq = 0
你看，原来 αβ 里面一直旋转的量，到了 dq 里面变成了：
Id = 常数
Iq = 0
这就是重点：
Park 变换把“旋转的交流量”变成了“静止的直流量”。
当然实际 FOC 里通常希望电流主要在 q 轴上，所以也可以得到：
Id ≈ 0
Iq ≈ 常数
这样 PI 控制器就非常好控制。
10. 为什么不直接控制三相正弦波？
理论上可以。
比如六步换相、正弦波控制、SPWM 控制，都可以让电机转。
但是问题是：
它们不直接关心转子磁场和定子磁场之间的精确角度关系。
FOC 更高级的地方在于：
它实时知道转子角度
实时把电流拆成 Id/Iq
精确控制产生转矩的那部分电流
所以 FOC 的优势是：
低速力矩更好
效率更高
噪声更低
响应更快
转矩控制更准
动态性能更好
尤其对于平衡车这种场景，电机需要频繁正反转、快速调节转矩，FOC 非常适合。
11. 用平衡车来理解 FOC
平衡车最关心的不是“电机转速”，而是：
我现在需要多大的力矩，把车身扶起来？
姿态环算出来一个目标力矩。
这个目标力矩最终就变成：
Iq_ref
然后 FOC 电流环负责：
让实际 Iq 快速跟上 Iq_ref
而 Id 通常保持：
Id_ref = 0
整个思路就是：
车身倾倒
    ↓
姿态控制器算出需要的力矩
    ↓
转换成 Iq_ref
    ↓
FOC 控制 Iq
    ↓
电机输出对应力矩
    ↓
车身被扶起来
所以在平衡车里面，FOC 的核心价值是：
你可以把电机当成一个“可快速控制力矩的执行器”。
12. Clarke、Park、反 Park、SVPWM 之间的关系
完整流程是：
采样三相电流
Ia, Ib, Ic
    ↓
Clarke 变换
Iα, Iβ
    ↓
Park 变换，需要转子电角度 θ
Id, Iq
    ↓
和目标比较
Id_ref - Id
Iq_ref - Iq
    ↓
PI 控制器
Vd, Vq
    ↓
反 Park 变换
Vα, Vβ
    ↓
SVPWM
三相 PWM 占空比
    ↓
驱动逆变器
    ↓
控制电机三相电流
你会发现：
Clarke/Park 是为了“测量并理解当前电流”
反 Park/SVPWM 是为了“把控制结果重新变回三相电压去驱动电机”
13. 为什么电流环不用 PI 直接控制 Ia/Ib/Ic？
因为 Ia/Ib/Ic 是高速变化的交流量。
而 Id/Iq 在转子坐标系下接近直流量。
PI 控制器控制直流量很舒服：
Id_ref = 0
Iq_ref = 3A
实际：
Id = 0.1A
Iq = 2.7A
误差：
Id_error = -0.1A
Iq_error = 0.3A
然后 PI 输出：
Vd
Vq
非常清晰。
如果直接控制三相：
Ia_ref = 正弦波
Ib_ref = 正弦波
Ic_ref = 正弦波
控制器就要不断追随变化目标，控制难度高，动态效果差。
14. 最重要的一张脑图
你可以把 FOC 理解为：
真实电机世界：
三相交流、旋转磁场、耦合严重、难控制

Clarke：
把三相电流合成为二维电流矢量

Park：
站到转子视角，把电流分成：
    Id：磁链方向
    Iq：转矩方向

控制器：
直接控制 Id/Iq，就像控制直流电机一样

反变换：
把控制器输出重新变回三相 PWM
15. 最后用一句很直白的话总结
FOC 里面为什么要做 Clarke 和 Park 变换？
因为：
电机本质上是靠“定子磁场矢量”拉着“转子磁场”转。三相电流只是产生这个磁场的手段。Clarke 变换把三相电流合成一个磁场矢量，Park 变换把这个磁场矢量放到转子坐标系下，拆成控制磁链的 Id 和控制转矩的 Iq。这样原本复杂的三相交流电机，就变成了类似直流电机一样好控制的系统。
再压缩一点：
Clarke：三相 → 一个磁场箭头
Park：静止视角 → 转子视角
Id：磁链
Iq：转矩
FOC：精准控制 Iq，让电机精准输出力矩
你真正要抓住的不是公式，而是这个思想：
FOC 不是为了变换而变换，而是为了把“不好控制的三相交流量”，变成“好控制的转矩电流和磁链电流”。
好，电角度是 FOC 里非常关键的概念。你可以先记一句话：
机械角度是“转子物理上转了多少度”；电角度是“转子磁场对定子三相绕组来说转了多少度”。
FOC 里的 Park 变换用的不是普通机械角度，而是电角度。
1. 机械角度是什么？
机械角度很好理解，就是电机转子实际转过的物理角度。
比如电机轴转了一圈：
机械角度 = 360°
转了半圈：
机械角度 = 180°
这个角度就是你肉眼看到电机轴真实转了多少。
2. 电角度是什么？
电角度不是看轴物理转了多少，而是看：
转子磁场相对于定子三相绕组的电磁周期位置。
三相电机不是转一圈就一定只有一个磁场周期。
关键取决于电机有多少对磁极，也就是：
极对数 pole pairs
3. 极对数是什么？
比如一个转子永磁体有：
1 个 N 极 + 1 个 S 极
这叫：
2 极电机
1 对极
极对数 = 1
如果有：
2 个 N 极 + 2 个 S 极
这叫：
4 极电机
2 对极
极对数 = 2
如果有：
7 个 N 极 + 7 个 S 极
这叫：
14 极电机
7 对极
极对数 = 7
很多航模无刷电机、轮毂电机、平衡车电机，极对数通常不小。
4. 电角度和机械角度的关系
公式非常重要：
电角度 = 机械角度 × 极对数
也就是：
electrical_angle = mechanical_angle * pole_pairs;
如果超过 360°，就取模：
electrical_angle = fmod(mechanical_angle * pole_pairs, 360.0f);
如果用弧度：
theta_e = theta_m * pole_pairs;
theta_e = normalize_0_to_2pi(theta_e);
5. 举几个例子
例子 1：1 对极电机
极对数 = 1
机械转一圈 = 360°
电角度也转一圈 = 360°
这种情况下：
电角度 = 机械角度
例子 2：2 对极电机
极对数 = 2
机械转一圈 = 360°
电角度转两圈 = 720°
也就是说：
机械角度 0°   → 电角度 0°
机械角度 90°  → 电角度 180°
机械角度 180° → 电角度 360°
机械角度 270° → 电角度 540°
机械角度 360° → 电角度 720°
取模到 0~360° 后：
机械 0°   → 电角 0°
机械 90°  → 电角 180°
机械 180° → 电角 0°
机械 270° → 电角 180°
机械 360° → 电角 0°
你会发现：
机械转一圈，电磁关系重复了 2 次。
例子 3：7 对极电机
极对数 = 7
机械转一圈 = 360°
电角度转 7 圈 = 2520°
所以：
机械转 360°
电角度转 2520°
也就是电磁周期重复 7 次。
6. 为什么会有电角度？
因为定子三相绕组产生的是一个旋转磁场。
转子上不是只有一个 N/S，而是可能有很多 N/S 极对。
比如 7 对极电机，转子机械转一圈时，每一个定子线圈位置会依次经历：
N S N S N S N S ...
对定子绕组来说，它感受到的磁场变化不是 1 次，而是 7 次。
所以：
机械角度描述的是轴的位置
电角度描述的是磁场周期的位置
FOC 控制的是磁场关系，所以必须用电角度。
7. FOC 为什么必须用电角度？
因为 Park 变换要做的是：
把 αβ 静止坐标系旋转到转子磁场坐标系 dq。
这个 dq 坐标系的 d 轴要对准什么？
转子永磁体磁链方向
也就是转子磁场方向。
而转子磁场方向对定子三相绕组来说，是按照电角度变化的。
所以 Park 变换里面的 θ 必须是：
转子电角度
不是普通机械角度。
8. 如果角度用错了会怎样？
比如一个 7 对极电机，你误把机械角度直接当成电角度。
那实际应该是：
theta_e = theta_m × 7
但你用了：
theta_e = theta_m
结果就是 dq 坐标系根本没有对准转子磁场。
后果很明显：
Id/Iq 计算错误
转矩变小
电流变大
发热严重
电机抖动
启动困难
速度上不去
甚至反转、啸叫、失步
因为你以为自己在控制 Iq，实际上电流可能跑到 Id 上去了。
本来想产生转矩，结果变成了乱加磁场。
9. 电角度可以怎么理解？
你可以把它理解成：
电机磁场世界里的角度。
机械角度是现实空间的角度：
轴真的转了多少
电角度是电磁关系的角度：
当前转子磁场相对于 A 相绕组处在什么位置
FOC 不是关心轴表面位置，而是关心：
定子磁场和转子磁场之间差多少角度
所以它用电角度。
10. 电角度和三相正弦波的关系
三相电流通常是这样的：
Ia = I * sin(theta_e)
Ib = I * sin(theta_e - 120°)
Ic = I * sin(theta_e + 120°)
注意这里用的是：
theta_e
也就是电角度。
为什么？
因为三相电流控制的是电磁周期，而不是机械周期。
如果电机是 7 对极，那么转子机械转一圈，三相电流正弦波要走 7 个周期。
机械转一圈：
theta_m = 0° ~ 360°

电角度：
theta_e = 0° ~ 2520°

三相电流：
完成 7 个正弦周期
所以电机极对数越多，同样机械转速下，电频率越高。
11. 电角度、电频率、机械转速的关系
还有一个很重要的关系：
电频率 = 机械转速频率 × 极对数
如果机械转速是 RPM：
机械频率 Hz = RPM / 60
那么：
电频率 Hz = RPM / 60 × 极对数
举个例子：
电机转速 = 3000 RPM
极对数 = 7
机械频率：
3000 / 60 = 50 Hz
电频率：
50 × 7 = 350 Hz
也就是说，电机轴每秒转 50 圈，但电磁正弦周期每秒变化 350 次。
12. 编码器读到的是机械角度还是电角度？
大多数编码器、磁编码器读到的是：
机械角度
比如 AS5600、MT6701、TLE5012、ABI 编码器等，它们测的是轴的实际位置。
FOC 里面要把它转换成电角度：
theta_e = theta_m * pole_pairs + offset;
theta_e = normalize(theta_e);
这里还有一个很关键的东西：
offset 零点偏移
13. 为什么还要加 offset？
因为编码器的 0° 不一定等于电机 d 轴 0°。
比如编码器上电读到：
机械角度 = 0°
但此时转子磁场不一定正好对准 A 相定义的 d 轴。
所以必须做一次对齐。
通常叫：
电角度零点校准
encoder alignment
electrical zero offset calibration
最终得到：
theta_e = theta_m * pole_pairs + theta_offset;
也可能是：
theta_e = theta_m * pole_pairs - theta_offset;
具体加还是减，取决于你的坐标定义和电机旋转方向。
14. 零点偏移不对会怎么样？
如果 offset 不对，现象和角度错类似：
启动抖动
电流大
发热
转矩小
噪声大
速度上不去
正反转不一致
FOC 控制很奇怪
因为 Park 变换的坐标系没对准转子磁场。
你以为：
d轴对准转子磁链
q轴垂直转子磁链
实际：
d/q 轴偏了一截
这样 Id/Iq 就串扰了。
15. 电角度方向也很重要
除了 offset，方向也重要。
如果编码器角度方向和电机电角度方向反了，比如：
电机正转时，真实电角度增加
编码器读数却减少
那 FOC 也会乱。
常见修正方式：
theta_m = -theta_m;
或者：
theta_e = -theta_m * pole_pairs + offset;
如果方向错，常见现象：
一给电就抖
电机吸住不转
反向冲一下
电流暴涨
闭环失败
16. 用平衡车电机举例
假设你的平衡车轮毂电机是：
极对数 = 15
编码器读到机械角度 = 20°
那么电角度就是：
theta_e = 20° × 15 = 300°
如果机械角度继续转到：
30°
电角度就是：
30° × 15 = 450°
取模 360°：
450° - 360° = 90°
所以：
机械角度只变了 10°
电角度已经变了 150°
这就是高极对数电机的特点：
机械动一点，电角度变化很多。
所以高极对数电机对角度采样速度、控制频率、编码器精度要求更高。
17. 电角度在代码里一般怎么写？
假设编码器返回 0~2π 的机械角度：
float theta_m;      // 机械角度，单位 rad
float theta_e;      // 电角度，单位 rad
int pole_pairs = 7; // 极对数
float offset;       // 电角度零点偏移

theta_e = theta_m * pole_pairs + offset;
theta_e = normalize_0_2pi(theta_e);
归一化函数可以这样写：
float normalize_0_2pi(float angle)
{
    while (angle >= 2.0f * PI)
    {
        angle -= 2.0f * PI;
    }

    while (angle < 0.0f)
    {
        angle += 2.0f * PI;
    }

    return angle;
}
实际高性能代码里可能不用 while，而用更快的方法，但初学这样最容易理解。
18. 电角度在 Park 变换中的作用
Park 变换里面用到：
sin(theta_e)
cos(theta_e)
例如：
Id =  Ialpha * cos(theta_e) + Ibeta * sin(theta_e);
Iq = -Ialpha * sin(theta_e) + Ibeta * cos(theta_e);
这里的 theta_e 就是电角度。
它的含义是：
 当前转子磁场坐标系相对于定子 αβ 坐标系转了多少电角度。
所以这个角度准不准，直接决定 Id/Iq 算得准不准。
19. 电角度和机械角度最容易混的地方
你可以这样区分：
机械角度：
电机轴实际转了多少
用于位置控制、机械位置判断

电角度：
磁场周期转了多少
用于 FOC、Park 变换、SVPWM、电流控制
再举个例子：
机械角度 360°：
轴转了一整圈

电角度 360°：
完成了一个 N/S 磁极对的电磁周期
如果极对数是 7：
机械一圈 = 7 个电角度周期
20. 最后总结
你记住这几句话就够了：
机械角度 = 转子物理上转了多少度
电角度 = 转子磁场在电磁周期里转了多少度
电角度 = 机械角度 × 极对数
FOC 里必须用电角度，因为：
FOC 控制的是定子磁场和转子磁场之间的关系
不是单纯控制电机轴的位置
所以 Park 变换需要：
转子电角度 theta_e
不是机械角度。
最终代码一般是：
theta_e = theta_m * pole_pairs + offset;
theta_e = normalize_0_2pi(theta_e);
一句话压缩：
电角度就是“从电磁场角度看，转子磁场转到了哪里”；FOC 要对准转子磁场控制 Id/Iq，所以必须用电角度。
你现在卡住的点，应该不是公式，而是这句话没真正“落地”：
为什么电机轴明明只转了一圈，电角度可能转了好几圈？
我们不用公式，重新从“磁铁经过线圈”来理解。
1. 先忘掉电角度，看一个最简单的磁铁
假设有一个圆盘，上面只有一对磁极：
N
   -------
  /       \
 |         |
  \       /
   -------
      S
这个圆盘转一圈时，固定在外面的一个线圈会经历：
N 极靠近
S 极靠近
N 极又靠近
对于这个线圈来说，磁场变化完成了 1 次完整周期。
所以：
机械转一圈
磁场变化一圈
电角度转一圈
这时：
机械角度 = 电角度
因为只有 1 对极。
2. 现在换成 2 对极电机
转子上不是只有一对 N/S，而是这样：
N
   S         S
        N
更准确一点说，它有：
N S N S
也就是：
2 个 N 极
2 个 S 极
2 对极
现在问题来了：
转子机械转一圈，固定线圈会看到几次 N/S 变化？
它会看到：
第 1 对 N/S 经过
第 2 对 N/S 经过
也就是磁场周期变化了 2 次。
所以：
机械转一圈
磁场变化两圈
电角度转两圈
这就是电角度的来源。
3. 电角度不是“轴转了多少”，而是“磁场周期走到哪了”
你可以把电角度理解成：
磁场周期的进度条。
机械角度看的是：
转子这个铁疙瘩实际转了多少
电角度看的是：
定子线圈眼里，N/S 磁场周期走到哪一步了
所以如果电机有很多对磁极，机械转一圈时，线圈会看到很多次 N/S 变化。
这就像一圈跑道上画了很多组图案。
4. 用跑道图案类比
假设你站在跑道边不动，跑道上有图案。
情况 A：跑道一圈只有 1 组图案
红 → 蓝 → 红
跑道转一圈，你看到图案变化 1 次。
机械一圈 = 图案周期一圈
这相当于：
极对数 = 1
机械角度 = 电角度
情况 B：跑道一圈有 7 组图案
红蓝 红蓝 红蓝 红蓝 红蓝 红蓝 红蓝
跑道机械转一圈，你站在原地会看到：
红蓝周期经过了 7 次
所以：
机械一圈 = 图案周期 7 圈
这就相当于：
极对数 = 7
机械转 360°
电角度转 7 × 360° = 2520°
注意：
电角度不是说轴真的转了 2520°，而是说磁场周期重复了 7 次。
这是关键。
5. 为什么叫“电角度”？
因为三相电流是按照磁场周期变化的。
比如三相正弦电流：
A 相：sin(θ)
B 相：sin(θ - 120°)
C 相：sin(θ + 120°)
这里的 θ 不是机械角度，而是电角度。
为什么？
因为三相电流要配合的是：
N/S 磁极周期
不是配合电机轴上的机械刻度。
6. 举一个 7 对极电机的具体感受
假设一个轮毂电机有：
7 对极
也就是转子一圈有 7 组 N/S。
现在转子机械转了：
1/7 圈
也就是：
机械角度 = 360° / 7 ≈ 51.4°
对于电磁场来说，发生了什么？
因为刚好一组 N/S 磁极经过了定子线圈。
所以磁场周期已经完整走了一圈：
电角度 = 360°
也就是说：
机械只转了 51.4°
电角度已经转了 360°
这句话非常重要。
因为对于定子三相绕组来说：
它看到的磁场关系已经重复了一次
所以电角度已经完成一圈。
7. 再看 7 对极时的几个位置
假设极对数是 7：
机械角度 0°      → 电角度 0°
机械角度 10°     → 电角度 70°
机械角度 20°     → 电角度 140°
机械角度 30°     → 电角度 210°
机械角度 40°     → 电角度 280°
机械角度 51.4°   → 电角度 360°，也就是又回到 0°
机械角度 102.8°  → 电角度 720°，又重复一次
机械角度 360°    → 电角度 2520°，总共重复 7 次
所以电角度真正表达的是：
当前处在第几个磁场周期的哪个位置
而 FOC 通常只关心一个周期内的位置，所以会取模到 0~360°：
0° ~ 360°
8. 你可能疑惑：既然会重复，那怎么知道实际机械位置？
这就是重点：
电角度不能单独代表机械绝对位置。
比如 7 对极电机中：
机械 0°      → 电角 0°
机械 51.4°   → 电角 0°
机械 102.8°  → 电角 0°
机械 154.2°  → 电角 0°
...
你会发现很多机械位置，对应同一个电角度。
所以：
机械角度：适合表示轴的实际位置
电角度：适合表示当前电磁周期位置
FOC 不关心你轮子机械绝对转到了哪一个齿，它更关心：
现在定子磁场应该往哪个方向推转子磁场
所以 FOC 用电角度。
9. 电角度和 FOC 的关系再落地一点
FOC 要做的事情是：
让定子磁场始终在转子磁场前面合适的位置
比如大概理解为：
定子磁场要垂直拉转子磁场
这样力矩最大。
那控制器必须知道：
当前转子磁场方向在哪里？
但转子磁场方向不是按机械 360° 才重复一次，而是按每一对 N/S 磁极重复一次。
所以 FOC 要用：
电角度
因为电角度描述的正是：
转子磁场相对于定子绕组的方向
10. 一个非常简单的判断方法
你可以这样判断：
机械角度回答的问题是：
电机轴转到了哪里？
轮子转了多少？
机械位置是多少？
比如：
轮子转了半圈
机械角度 = 180°
电角度回答的问题是：
当前这一组 N/S 磁极，相对 A 相线圈转到了哪里？
三相电流现在应该输出到正弦波的哪个相位？
Park 变换应该用哪个角度？
比如：
现在三相电流应该走到 sin(θ) 的 θ = 120°
这个 θ 就是电角度。
11. 再用 BLDC 霍尔理解
很多 BLDC 用 3 个霍尔传感器，6 步换相。
你会看到霍尔状态每隔 60° 变化一次。
这个 60° 一般说的是：
电角度 60°
不是机械角度 60°。
如果电机是 7 对极，那么：
电角度 60°
机械角度 = 60° / 7 ≈ 8.57°
也就是说，机械只转了 8.57°，霍尔电角度已经变化 60°。
这就是为什么高极对数电机霍尔变化很频繁。
12. 电角度的本质一句话
你可以把电机想象成：
机械世界：看轴转了多少
电磁世界：看 N/S 磁场周期变化了多少
所以：
机械角度 = 轴的角度
电角度 = 磁场周期的角度
它们的关系是：
电角度 = 机械角度 × 极对数
但这条公式只是结果，不是本质。
真正的本质是：
转子一圈有几对 N/S，机械转一圈时，定子线圈就看到几个磁场周期；电角度数的就是这个磁场周期。
13. 用一句特别土的话说
如果极对数是 7：
转子机械转一圈，里面有 7 组磁铁轮流经过定子。
所以对定子绕组来说：
“磁场剧情”演了 7 遍。
机械角度说的是：
电影胶片转了一圈。
电角度说的是：
剧情播放了几遍、现在播到哪一帧。
FOC 要控制的是磁场剧情，不是胶片机械转盘，所以它用电角度。
14. 最后再压缩成一个图
假设 7 对极：
机械一圈 360°
|------------------------------------------------|

电角度周期：
|------360°------|------360°------|------360°------|------360°------|------360°------|------360°------|------360°------|
第1对极           第2对极           第3对极           第4对极           第5对极           第6对极           第7对极
所以：
机械角度：看整条长线走了多少
电角度：看每一小段磁场周期走了多少
FOC 每一瞬间只需要知道：
当前在这一小段 0~360° 磁场周期里的哪里
这就是电角度。
15. 你就记这个最核心的结论
电角度不是电机轴真实转过的角度，而是转子磁极 N/S 周期相对于定子绕组变化到哪个相位。极对数越多，机械转一点点，磁场周期就变化很多，所以电角度变化更快。
用代码就是：
theta_e = theta_m * pole_pairs + offset;
theta_e = normalize_0_to_2pi(theta_e);
但你心里不要先记公式，先记这个：
机械角度：轴的位置
电角度：磁场周期的位置
FOC 用电角度，因为 FOC 控制的是磁场，不是单纯控制轴
