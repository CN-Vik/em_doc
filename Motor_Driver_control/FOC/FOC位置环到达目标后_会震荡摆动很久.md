# FOC位置环到达目标后"弹簧式震荡"的根治方案
这种**到达目标角度后持续小幅来回摆动**的现象是FOC级联位置环最常见的问题，本质是**控制系统的阻尼不足+超调后的能量无法快速耗散**，完全可以通过系统调试消除。我会按**优先级从高到低**给出可直接落地的解决方法，你可以按顺序排查。

## 一、先明确：你的问题属于典型的"欠阻尼阶跃响应"
你描述的"手动拧到90度→自动回0→来回震荡几次才停下"，对应PID控制理论中的**欠阻尼系统阶跃响应**。震荡的根本原因是：
- 位置环P增益过高，系统"太硬"，纠正偏差的力太大
- 速度环D增益不足，系统"太滑"，没有足够的阻力消耗运动能量
- 积分环节饱和，导致超调后反向纠正过度

⚠️ **重要前提**：FOC是三级级联控制（电流环→速度环→位置环），**必须先确保内环调好再调外环**。如果电流环或速度环本身就震荡，位置环怎么调都没用。

## 二、最高优先级：调整速度环参数（90%的问题出在这里）
绝大多数位置环震荡的根源不是位置环本身，而是**速度环的阻尼不够**。位置环的输出是速度指令，速度环如果响应太"硬"，就会把位置环的微小偏差放大成剧烈的力矩波动。

### 具体调整步骤
1. **先断开位置环，单独调试速度环**
   - 给速度环输入一个固定的低速指令（比如100RPM）
   - 用手轻轻拧电机轴，感受阻力：如果感觉"发飘"，一拧就转很多，说明D增益太低；如果感觉"发涩"，拧的时候有明显的顿挫，说明D增益太高
   - 理想状态：拧动电机轴有明显的阻力，松手后能快速回到设定速度，没有来回摆动

2. **针对性调整速度环PID**
   | 现象 | 调整方向 | 具体操作 |
   |------|----------|----------|
   | 速度环本身就震荡，电机嗡嗡响 | 降低速度环P | 每次降低20%，直到震荡消失 |
   | 拧动轴很轻松，松手后速度恢复慢 | 提高速度环D | 每次提高30%，直到拧动有明显阻尼 |
   | 速度有静差，低速时抖动 | 适当提高速度环I | I增益不要超过P的1/10 |

3. **关键技巧**：对于位置环应用，**速度环宁肯偏软也不要偏硬**。适当降低速度环P，提高速度环D，让速度环成为一个"有阻尼的缓冲器"，能极大吸收位置环的震荡。

## 三、第二优先级：调整位置环参数
速度环调好后，再调整位置环，此时效果会非常明显。

### 标准位置环调试步骤
1. **将位置环I和D都设为0，只保留P**
2. **逐步提高P增益**：每次提高10%，直到电机从90度回到0度时**刚好出现一次超调**（超过0度一点点然后回来）
3. **加入D增益**：逐步提高D，每次提高20%，直到超调完全消失，电机能平稳停在0度
4. **最后加入极少量的I**：I增益不要超过P的1/20，仅用于消除静差（如果没有静差，可以完全不用I）

### 针对你问题的特殊调整
- 如果你发现无论怎么调P，只要P足够大就会震荡，**说明速度环的阻尼还是不够**，回到上一步继续提高速度环D
- 不要试图用位置环D来完全抵消震荡，位置环D的作用是"预判"偏差，而速度环D才是真正提供阻尼的地方

## 四、第三优先级：消除积分饱和（超调后剧烈震荡的元凶）
积分饱和是导致"弹簧式震荡"最容易被忽略的原因。当电机从90度回到0度的过程中，位置偏差很大，积分项会不断累积，输出达到最大值。当电机到达0度时，积分项还没有清零，会继续输出力矩，导致电机冲过0度，然后积分项反向累积，又把电机拉回来，形成持续震荡。

### 解决方法
1. **启用积分限幅**：将位置环和速度环的积分输出限幅设置为**最大输出的10%~20%**
   - 位置环积分限幅：不要超过速度环最大输入速度的20%
   - 速度环积分限幅：不要超过电流环最大输入电流的20%

2. **启用抗积分饱和算法**：最常用的是**遇限削弱积分法**，当PID输出达到限幅值时，停止积分累积。绝大多数FOC库都已经实现了这个功能，只需要打开开关即可。

3. **极端情况：位置环可以完全不用I**：如果你的系统没有静差要求，或者静差很小可以接受，**直接把位置环I设为0**，这是最简单粗暴且有效的消除积分震荡的方法。

## 五、第四优先级：硬件和机械问题排查
如果以上参数调整都无效，就需要检查硬件和机械问题，这些问题导致的震荡是纯软件无法解决的。

### 1. 编码器问题（最常见）
- **AS5600磁编码器安装误差**：磁钢偏心、倾斜或距离芯片太远，会导致角度误差呈现周期性波动，在0度附近形成"死区"或"抖动区"
  - 解决方法：重新校准磁钢，确保磁钢中心与电机轴中心重合，距离芯片0.5~1.5mm
  - 验证方法：缓慢转动电机轴，查看原始角度值是否平滑，没有跳变或卡顿

- **编码器分辨率不足**：如果编码器分辨率太低（比如低于12位），角度采样的量化误差会导致位置环频繁调整，形成震荡
  - 解决方法：启用编码器的硬件滤波，或在软件中对角度值进行一阶低通滤波

### 2. 机械问题
- **负载惯量不匹配**：如果负载惯量远大于电机惯量，电机的力矩不足以快速制动负载，就会导致超调和震荡
  - 解决方法：降低位置环P增益，或增加减速比，提高电机的输出力矩

- **机械间隙**：电机轴与负载之间的齿轮间隙、联轴器间隙，会导致位置反馈滞后，形成震荡
  - 解决方法：消除机械间隙，或在软件中加入间隙补偿

## 六、高级优化技巧
如果以上方法都已经尝试，但还是有轻微震荡，可以使用以下高级技巧进一步优化：

### 1. 位置环输出限幅
将位置环的输出（即速度指令）限制在一个合理的范围内，不要让速度环输入过大。比如你的电机最大速度是1000RPM，位置环输出限幅可以设为500RPM，这样电机不会加速太快，到达目标时更容易停下来。

### 2. 加入速度前馈
速度前馈可以根据位置指令的变化率，提前给速度环一个指令，减少位置环的偏差，从而降低P增益的需求，减少震荡。
```c
// 速度前馈计算示例
float position_error = target_angle - current_angle;
float velocity_feedforward = Kff * (target_angle - last_target_angle) / dt;
float velocity_command = Kp * position_error + velocity_feedforward;
```

### 3. 死区补偿
在目标角度附近设置一个小的死区，当位置偏差小于死区值时，直接输出0力矩，让电机自由停止。
```c
// 死区补偿示例
float deadband = 0.5f; // 0.5度死区
if (fabs(position_error) < deadband) {
    velocity_command = 0.0f;
}
```

## 七、给你的专属调试流程（按顺序执行）
1. 断开位置环，单独调试速度环，直到速度环稳定，拧动电机轴有明显阻尼
2. 位置环I=0，D=0，逐步提高P，直到刚好出现一次超调
3. 逐步提高位置环D，直到超调消失，电机平稳停止
4. 如果有静差，加入极少量的I（I≤P/20），并启用积分限幅
5. 如果还有震荡，检查编码器安装和机械间隙
6. 最后加入位置环输出限幅和速度前馈进一步优化

按照这个流程，99%的位置环震荡问题都能解决。记住一个核心原则：**FOC级联控制中，内环决定系统的稳定性，外环决定系统的响应速度**。不要本末倒置，先把内环调好，外环自然就好调了。

可以**大幅减小到几乎看不出来**，但想“立刻回到 30°，并且完全没有任何过冲、没有任何震荡”，理论上基本不现实。

因为电机转子有惯性，你从 90° 松手后，位置环会给一个较大的 `Uq` 拉回 30°。快到 30° 时，如果没有足够“刹车/阻尼”，转子会因为惯性冲过目标点，然后控制器又反向拉回来，于是就在 30°附近摆几下。

你现在这个现象本质上是：

> **位置环刚度够了，但是阻尼不够，或者回零速度太猛。**

---

## 1. 不能只靠 Kp

如果你的位置环是类似这样：

```c
err = target_angle - now_angle;
Uq = Kp * err;
```

那它本质上像一根弹簧：

```text
偏差越大，拉力越大
偏差越小，拉力越小
```

问题是：
**弹簧只能把你拉回去，不能很好地刹车。**

所以从 90° 回 30° 的时候，误差一开始是 `-60°`，`Uq` 很大，电机加速回去；快到 30° 时，虽然误差变小了，但电机已经有速度了，就会冲过去。

---

## 2. 位置环要加“速度阻尼”

比较标准的位置控制应该像这样：

```c
err_angle = angle_error_deg(target_angle, now_angle);
omega_deg_s = get_motor_omega_deg_s_by_angle(now_angle);

Uq = Kp * err_angle - Kd * omega_deg_s;
```

含义是：

```text
Kp * err_angle       负责拉回目标位置
-Kd * omega_deg_s    负责根据当前速度刹车
```

例如：

```text
当前位置 90°，目标 30°，误差 -60°，Uq 反向拉回
快到 30° 时，虽然误差小了，但速度还很大
Kd 项就会提前反向刹车
这样就不容易冲过头
```

所以你要的“回到 30° 后立刻不动”，核心不是单纯增大 Kp，而是要把 **Kd 阻尼调出来**。

---

## 3. 但是 Kd 不能太大

你之前已经遇到过类似问题：
**Kd 大了会滋滋响、抖动、震荡更明显。**

原因是 AS5600 的角度速度本来就有微小跳动，速度微分项会放大噪声。

所以速度项最好用**滤波后的速度**：

```c
omega_f = low_pass_filter(omega_raw);
Uq = Kp * err_angle - Kd * omega_f;
```

低速位置控制时，速度滤波可以稍微重一点，例如：

```c
omega_f = 0.8f * omega_f + 0.2f * omega_raw;
```

或者更平滑一点：

```c
omega_f = 0.9f * omega_f + 0.1f * omega_raw;
```

---

## 4. 还要限制最大回弹力矩

你从 90° 松手回 30°，误差是 60°，如果 Kp 较大，瞬间 `Uq` 会很大。

比如：

```c
Kp = 0.08
err = -60°
Uq = -4.8V
```

这对 12V 电机来说已经挺猛了，会导致快速拉回，然后过冲。

所以位置环输出必须限幅：

```c
Uq = foc_limit(Uq, -UQ_MAX, UQ_MAX);
```

比如学习阶段可以先试：

```c
UQ_MAX = 2.0f;   // 先温和
```

如果觉得回弹太软，再慢慢加：

```c
UQ_MAX = 2.5f;
UQ_MAX = 3.0f;
UQ_MAX = 3.5f;
```

不要一上来给太大。

---

## 5. 想“不摆动”，要加到位死区

实际系统里，编码器会抖，电机也有齿槽力矩和摩擦。你不能要求它数学意义上刚好停在 `30.000°`。

所以可以设置一个到位死区：

```c
if (fabsf(err_angle) < 0.5f && fabsf(omega_f) < 5.0f)
{
    Uq = 0.0f;
}
```

意思是：

```text
角度误差小于 0.5°
并且速度已经很小
那就认为已经到位
不再继续来回修正
```

否则你的控制器会一直因为 `30.1°、29.9°、30.2°` 这种小误差来回输出 `Uq`，就会轻微抖动。

不过这个有代价：

```text
Uq = 0 之后，抗外力保持能力变弱
```

如果你希望到位后“很难扭动”，那不能直接 Uq=0，而是进入小保持力模式。

---

## 6. 更推荐：到位后切换成“小保持模式”

你可以分两个阶段：

### 阶段 1：远离目标，快速回弹

```c
fabsf(err_angle) > 3°
```

这个阶段允许较大的 `Uq_max`：

```c
UQ_MAX = 2.5f ~ 4.0f
```

让它能明显回弹。

### 阶段 2：接近目标，减小力度

```c
fabsf(err_angle) <= 3°
```

这个阶段降低 `Uq_max`：

```c
UQ_MAX = 0.3f ~ 1.0f
```

让它慢慢贴近，不要冲过头。

### 阶段 3：到位保持

```c
fabsf(err_angle) < 0.5° && fabsf(omega_f) < 某个阈值
```

进入保持：

```c
Uq = Kp_hold * err_angle - Kd_hold * omega_f;
Uq = limit(Uq, -0.3f, 0.3f);
```

这样它不会大幅震荡，但又有一点点保持力。

---

## 7. 比较实用的控制结构

你可以按这个思路做：

```c
err_angle = angle_error_deg(target_angle, now_angle);
omega_f = get_filtered_omega_deg_s(now_angle);

/* 位置 PD */
Uq = Kp * err_angle - Kd * omega_f;

/* 根据误差大小动态限制 Uq */
if (fabsf(err_angle) > 20.0f)
{
    Uq_max = 3.0f;     // 远距离，允许快点回
}
else if (fabsf(err_angle) > 5.0f)
{
    Uq_max = 1.5f;     // 中距离，开始收力
}
else
{
    Uq_max = 0.6f;     // 接近目标，轻轻拉
}

Uq = foc_limit(Uq, -Uq_max, Uq_max);

/* 到位死区 */
if (fabsf(err_angle) < 0.5f && fabsf(omega_f) < 5.0f)
{
    Uq = 0.0f;         // 或者进入小保持模式
}
```

这个比单纯：

```c
Uq = Kp * err_angle;
```

稳定很多。

---

## 8. 调参顺序建议

不要一上来 Kp、Kd、Uq 限幅一起乱调。按这个顺序来：

### 第一步：只用 P

```c
Uq = Kp * err_angle;
```

先把 `Kp` 调到能回弹，但不要太猛。
现象应该是：

```text
能回到目标附近，但会来回摆
```

这是正常的。

---

### 第二步：加 Uq 限幅

比如：

```c
UQ_MAX = 2.0f;
```

如果回得太慢，再加到：

```c
2.5f、3.0f
```

不要先追求很猛的回弹。

---

### 第三步：加 Kd 阻尼

```c
Uq = Kp * err_angle - Kd * omega_f;
```

慢慢加 `Kd`。

判断标准：

```text
摆动次数减少       => Kd 有效
回到目标变肉       => Kd 偏大
滋滋响/抖动明显    => Kd 太大或速度滤波不够
```

---

### 第四步：加到位死区

比如：

```c
角度误差 < 0.5°
速度 < 5 deg/s
```

认为到位，停止大幅调节。

---

## 9. 你真正想要的效果，应该这样定义

不要定义成：

```text
立刻回到 30°，完全不动
```

这个太理想化。

工程上应该定义成：

```text
从 90° 松手后，快速回到 30°
过冲小于 1°
震荡次数小于 1~2 次
0.3 秒内稳定
到位后肉眼看不出摆动
```

这就是比较现实、也比较像产品的目标。

---

## 10. 结论

你这个问题可以明显优化，但不能靠单纯加大 Kp。正确方向是：

```text
位置环 P 负责回弹
速度项 D 负责刹车
Uq 限幅负责防止太猛
速度滤波负责防止 D 抖动
到位死区/保持模式负责防止目标点附近来回修正
```

最推荐你现在先做这个版本：

```c
Uq = Kp * err_angle - Kd * omega_f;
Uq = 根据误差大小动态限幅;
到位后进入死区或小保持模式;
```

这样基本就能把“回到 30°后摆一段时间”的问题压到很小。

| 加 Kd 后滋滋响     | 速度噪声大，D 项放大噪声        |
| 接近目标还一直小抖     | 没有到位死区 / 保持策略        |
| 一松手像弹簧一样弹回    | 位置环刚度高，但阻尼低          |
| 回弹慢但不怎么抖      | Kp 小 / Uq 限幅小 / 阻尼偏大 |

---

所以你这个问题最准确的分类是：

> **FOC 位置闭环的动态响应调参问题，本质是位置伺服系统欠阻尼，表现为目标点附近过冲和振荡。**

不是单纯的“FOC 算法问题”，也不是单纯的“电机问题”。

---

你现在要解决的方向就是：

```text
增加阻尼
降低过冲
限制回弹速度
加入到位死区
优化保持模式
```

对应到代码就是：

```c
Uq = Kp * 位置误差 - Kd * 角速度;
```

再配合：

```text
Uq 限幅
速度滤波
动态限幅
到位死区
保持力矩模式
```

一句话总结：

> 你这个属于**位置环欠阻尼导致的到位震荡问题**，也可以叫**位置闭环过冲振荡问题**。
