你说的 BLDC FOC 开关速度控制，我理解可能有两种意思：
速度控制“打开/关闭”：比如目标速度从 0 突然切到 1000rpm，或者从 1000rpm 突然切到 0。
PWM 开关控制速度：通过三相桥 PWM 开关调节电机电压/电流，从而控制速度。
FOC 里真正控制电机的不是“直接控制速度”，而是：
速度环输出目标力矩电流 Iq → 电流环控制 Iq/Id → SVPWM/PWM 控制三相 MOS 管 → 电机产生转矩 → 速度变化
一、FOC 速度控制时，主要波形长什么样？
1. 目标速度波形
如果你直接开关速度，比如：
target_speed = 0;
突然变成
target_speed = 1000 rpm;
目标速度波形就是一个阶跃波形：
目标速度
1000rpm ┌────────────────────
        │
        │
0rpm ───┘
        ↑
      突然启动
这对电机来说很粗暴。
2. 实际速度波形
实际速度不会瞬间上去，因为电机有惯量、负载、摩擦、电流限制。
实际速度
1000rpm ────────────────
          ／￣￣￣￣￣￣
        ／
      ／
0rpm ─┘
如果控制参数不好，可能会变成这样：
实际速度
1000rpm ──────┐   ┌─────
              │\ /│
              │ X │  ← 超调、振荡
              │/ \│
0rpm ─────────┘   └─────
也就是速度冲过头，再拉回来，甚至来回抖。
3. Iq 力矩电流波形
FOC 中，Iq 基本可以理解为“产生力矩的电流”。
目标速度突然变化时，速度 PI 会认为：
 当前速度离目标速度差很多，需要很大力矩！
于是 Iq 会突然变大：
Iq电流
最大限幅 ┌───────┐
        │       │
        │       │
0 ──────┘       └──────
        ↑
      启动瞬间大电流
如果没有限流、斜坡、软启动，Iq 可能会突然冲到限幅。
4. 三相电流波形
FOC 正常运行时，三相电流大概是接近正弦波的：
Ia:   ／￣＼    ／￣＼
    ／     ＼／     ＼

Ib:      ／￣＼    ／￣＼
      ／     ＼／     ＼

Ic:  ＼     ／＼     ／
      ＼＿／    ＼＿／
三相相差 120°。
如果你开关速度太猛，三相电流会出现突变、畸变、尖峰：
相电流
正常正弦：    ~~~~~~~~
突然加速：    ~~|^^^^|~~~~
突然刹车：    ~~|vvvv|~~~~
实际用示波器看电流，会看到启动瞬间电流明显变大，甚至有毛刺。
5. PWM 波形
FOC 最后会通过 SVPWM 输出三相 PWM。
单相桥臂上的 PWM 大概像这样：
PWM输出
高电平 ┌─┐ ┌──┐ ┌────┐ ┌──────┐
      │ │ │  │ │    │ │      │
低电平┘ └─┘  └─┘    └─┘      └──
        占空比逐渐变化
FOC 调速时，PWM 占空比会随着电角度不断变化。低速时，占空比变化慢；高速时，占空比变化快。
如果速度突然开关，PWM 占空比可能会突然拉大：
小占空比： ┌┐  ┌┐  ┌┐  ┌┐
          └┘  └┘  └┘  └┘

大占空比： ┌────┐ ┌────┐ ┌────┐
          └────┘ └────┘ └────┘
二、速度开关控制的核心风险
风险 1：启动瞬间电流过大
这是最常见的问题。
比如目标速度从 0 突然给到 3000rpm，速度环会疯狂加 Iq，电机电流瞬间增大。
后果可能是：
目标速度突变
    ↓
速度误差很大
    ↓
速度PI输出很大Iq
    ↓
三相电流暴涨
    ↓
MOS管、电机、采样电阻、电源发热
严重时可能烧 MOS、烧驱动、触发过流保护。
风险 2：机械冲击大
对于平衡车、电机轮、风机、云台、机器人关节来说，速度突变会带来很大的机械冲击。
例如：
0rpm → 2000rpm
电机会“猛地一拽”。
后果：
齿轮冲击；
皮带打滑；
轮子空转；
平衡车突然窜出去；
结构件震动；
电机啸叫。
对于你之前说的 双轮平衡车 FOC，这个风险尤其大。平衡车不能简单地“开关速度”，否则车体可能突然前冲或者后仰。
风险 3：速度环 PI 饱和，产生积分 windup
FOC 速度环一般是 PI 控制：
速度误差 = 目标速度 - 实际速度
Iq_ref = Kp * 速度误差 + Ki * 误差积分
如果目标速度突然变很大，但电机由于惯量上不去，误差长时间很大，积分项会越积越多。
结果就是：
积分项越积越大
    ↓
Iq_ref 长时间顶到最大
    ↓
等速度终于上来了
    ↓
积分项还没降下来
    ↓
速度冲过头
表现为：
目标速度： ─────────────
实际速度：   ／￣￣＼＿
            ↑
          超调
这就是 积分饱和 / 积分累积 / anti-windup 问题。
风险 4：低速或启动时转子位置不准
FOC 需要知道电角度。
有感 FOC 用霍尔、编码器、磁编码器，问题小一些。
无感 FOC 低速启动时，反电动势很小，位置估算困难。如果你突然开速度，可能出现：
位置估算不准
    ↓
Park变换角度错
    ↓
Iq/Id控制错
    ↓
电机抖动、反转、堵转、过流
所以无感 FOC 通常要有：
预定位；
开环启动；
速度爬坡；
切闭环；
失败保护。
不能简单一开就给高速。
风险 5：母线电压波动，甚至再生过压
突然加速时，电机会从电源吸收大电流，母线电压可能下跌：
母线电压
24V ─────┐  ┌────
         │  │
         └──┘
       加速瞬间掉压
突然减速时，电机可能进入发电状态，把能量回灌到母线，母线电压可能升高：
母线电压
24V ─────┐  ┌────
         │  │
         └──┘  这是加速掉压

突然刹车时：

24V ─────┐
         └───╮
             ╰── 可能升到 30V、36V
如果没有制动电阻、能量泄放、电压保护，可能损坏驱动板。
三、正确做法：不要直接“开关速度”，要加斜坡
不要这样：
target_speed = 3000;
应该这样：
target_speed_cmd = 3000;       // 用户想要的目标速度
target_speed_ref += ramp_step; // 控制器实际使用的速度慢慢爬上去
波形变成：
错误做法：速度阶跃

3000rpm ┌────────────
        │
0rpm ───┘


正确做法：速度斜坡

3000rpm      ／────────
            ／
          ／
0rpm ────┘
这样速度环不会瞬间输出巨大 Iq。
四、FOC 速度控制推荐结构
比较稳的结构是：
用户目标速度
    ↓
速度斜坡限制
    ↓
速度环 PI
    ↓
Iq_ref 限幅
    ↓
电流环 PI
    ↓
Ud / Uq 限幅
    ↓
SVPWM
    ↓
三相逆变桥
    ↓
BLDC/PMSM 电机
也就是：
Speed_cmd → Ramp → Speed_PI → Iq_ref → Current_PI → SVPWM → Motor
重点保护有这几个：
速度斜坡限制
Iq最大限流
PI积分限幅
母线电压保护
堵转保护
过流保护
过温保护
启动失败保护
五、你用示波器/逻辑分析仪能看到什么？
1. 看三相 PWM
测量 U、V、W 三个桥臂对地 PWM。
你会看到三路占空比不断变化。
U相PWM：占空比按正弦规律变化
V相PWM：比U相滞后120°
W相PWM：比V相滞后120°
注意：不要直接用普通示波器地夹去夹半桥高压节点，容易短路。低压开发板也要注意地线位置。
2. 看相电流
用电流探头、采样电阻差分测量，或者看驱动板的 ADC 采样波形。
正常 FOC 电流应该比较平滑，接近正弦。
异常情况：
电流尖峰大：速度给得太猛 / PI太激进 / 采样有问题
电流毛刺多：PWM死区、MOS开关噪声、采样时刻不对
电流抖动：角度不准 / 电流环参数不好
电流顶死：限流触发 / 负载太大 / 堵转
3. 看母线电压
加速时可能掉压，减速时可能升压。
加速：Vbus 下跌
减速：Vbus 上升
平衡车、轮毂电机、惯量大的负载尤其要注意这个。
六、最危险的场景
最危险的是这几种：
1. 电机静止时，突然给很高速度
2. 高速运行时，突然给反向速度
3. 高速运行时，突然关闭PWM但没有合理制动策略
4. 无感FOC低速时直接闭环高速启动
5. 负载很重时强行加速
6. 母线电压高、限流没做好
7. PI参数太猛，没有积分限幅
尤其是这个：
+3000rpm → -3000rpm
这不是简单调速，这是强制反向制动，电流和母线电压都可能非常吓人。
七、简单结论
BLDC FOC 速度开关控制时，典型波形是：
目标速度：阶跃或斜坡
实际速度：缓慢跟随，可能超调
Iq电流：启动瞬间增大
三相电流：接近正弦，但突变时会有尖峰
PWM占空比：随电角度变化，负载突变时占空比快速变化
母线电压：加速下跌，减速回升
最大的风险是：
速度突变 → 速度误差巨大 → Iq暴涨 → 电流过大 → MOS/电机/电源风险
所以工程上不要直接做硬开关速度，要做：
速度斜坡 + 电流限幅 + PI防积分饱和 + 过流/过压/堵转保护
对平衡车这种应用来说，更不能简单用“速度开关控制”。它应该是：
车身角度环 → 速度环/位置环 → 电流环 → FOC
而不是简单：
开关 → 目标速度 → 电机
不太建议用“开关速度控制”来做 BLDC/FOC 调速，尤其是平衡车、轮毂电机、惯量负载。可以有“启停开关”，但速度目标不要硬切换，应该用斜坡慢慢给速度。
你问的重点是：FOC 三相 PWM 波形是什么样的？
1. 先说结论：FOC 的三相 PWM 不是简单固定占空比
FOC 输出到三相桥的 PWM，大概是这种感觉：
U相 PWM：  占空比从小 → 大 → 小 → 大... 周期性变化
V相 PWM：  同样变化，但相位比 U 相错开 120°
W相 PWM：  同样变化，但相位比 V 相错开 120°
也就是说，每一路本质上还是高频 PWM，例如 20kHz：
单相桥臂 PWM 微观看：

高电平  ┌─┐ ┌──┐ ┌────┐ ┌──────┐ ┌────┐ ┌──┐ ┌─┐
        │ │ │  │ │    │ │      │ │    │ │  │ │ │
低电平──┘ └─┘  └─┘    └─┘      └─┘    └─┘  └─┘ └──
          小     中      大        大      中    小
              占空比在不断变化
宏观看，占空比包络接近三相正弦：
U相占空比包络：      /‾‾‾\      /‾‾‾\
                  /       \    /       \
                 /         \__/         \__

V相占空比包络：  \__      /‾‾‾\      /‾‾‾\
                    \    /       \    /
                     \__/         \__/

W相占空比包络：    /‾‾‾\      /‾‾‾\      
                  /       \    /       \
             ____/         \__/         \__
三相之间相差 120° 电角度。
2. 如果是 SVPWM，三相 PWM 长得更像“马鞍形包络”
FOC 常用 SVPWM，不是最普通的三相正弦 PWM。
所以你如果用示波器看三相桥臂对地电压，看到的不是完美正弦，而是高频 PWM 脉冲。它的占空比包络大概像这样：
U相桥臂对地：  高频PWM，占空比按某种规律变化
V相桥臂对地：  高频PWM，占空比延后120°
W相桥臂对地：  高频PWM，占空比再延后120°
更准确一点说，三相桥臂输出的是：
UH / UL：互补PWM + 死区
VH / VL：互补PWM + 死区
WH / WL：互补PWM + 死区
比如 U 相上桥和下桥：
U上桥 PWM：
高电平  ┌────┐      ┌────┐      ┌────┐
        │    │      │    │      │    │
低电平──┘    └──────┘    └──────┘    └──

U下桥 PWM：
高电平────┐    ┌──────┐    ┌──────┐
          │    │      │    │      │
低电平    └────┘      └────┘      └────

中间要插入死区，防止上下桥直通。
3. 示波器看三相 PWM，会看到什么？
假设你测的是：
CH1：U相桥臂输出对 GND
CH2：V相桥臂输出对 GND
CH3：W相桥臂输出对 GND
你会看到三路都是高速方波：
U相： ┌─┐ ┌──┐ ┌────┐ ┌──────┐ ┌────┐ ┌──┐
     ┘ └─┘  └─┘    └─┘      └─┘    └─┘  └─

V相： ┌──────┐ ┌────┐ ┌──┐ ┌─┐ ┌──┐ ┌────┐
     ┘      └─┘    └─┘  └─┘ └─┘  └─┘    └─

W相： ┌──┐ ┌─┐ ┌──┐ ┌────┐ ┌──────┐ ┌────┐
     ┘  └─┘ └─┘  └─┘    └─┘      └─┘    └─
它们不是同一个占空比，而是一直变化。
4. 相电压、线电压、相电流，波形不一样
这个很关键。
你测 U 相对地
看到的是 PWM 方波：
U-GND：PWM方波
你测 U-V 两相之间
看到的是 线电压 PWM，会有正、负电压变化：
U-V：一堆正负跳变的PWM脉冲
大概类似：
+Vbus  ┌─┐   ┌────┐       ┌──┐
       │ │   │    │       │  │
0V  ───┘ └───┘    └───┬───┘  └──
                      │
-Vbus                 └───────
你测相电流
如果电流环调得好，电流才接近正弦：
Ia：    /‾‾\      /‾‾\
      /     \    /     \
_____/       \__/       \____

Ib：  相差120°

Ic：  再相差120°
所以：
桥臂电压 = PWM方波
线电压 = 正负跳变的PWM
相电流 = 接近正弦波
很多初学者会误以为 FOC 输出的是三相正弦电压，其实 MCU 输出的是 PWM，电机绕组电感把 PWM 电流“滤”成了接近正弦。
5. 低速和高速时，PWM 有啥区别？
低速时
电角度变化慢，所以三相占空比变化慢。
低速：
PWM频率还是 20kHz
但是占空比包络变化慢
高速时
电角度变化快，所以三相占空比包络变化快。
高速：
PWM频率还是 20kHz
但是占空比包络变化快
注意：PWM 频率一般不随速度变化，比如一直是 20kHz。变化的是每个 PWM 周期里的占空比。
6. “开关速度控制”下三相 PWM 会发生什么？
假设目标速度突然从 0 切到 3000rpm。
速度环会突然要求很大的 Iq 电流。于是 FOC 会让三相 PWM 占空比快速变化，输出更大的等效电压。
表现为：
开关前：
三相PWM占空比较小，或者接近中间值

开关后：
三相PWM占空比突然拉大
三相电流突然上升
电机猛地加速
波形感觉是：
开关前：
U相： ┌─┐ ┌─┐ ┌─┐ ┌─┐
     ┘ └─┘ └─┘ └─┘ └─

开关后：
U相： ┌──────┐ ┌────┐ ┌──────┐
     ┘      └─┘    └─┘      └─
但三相不是同时变大，而是按照当前电角度和 SVPWM 算法分配到 U/V/W 三相。
7. 建不建议开关速度控制？
不建议把速度目标硬开关。
不建议这样：
if (start)
{
    target_speed = 3000;
}
else
{
    target_speed = 0;
}
建议这样：
if (start)
{
    speed_cmd = 3000;
}
else
{
    speed_cmd = 0;
}

// 实际送入速度环的 speed_ref 慢慢靠近 speed_cmd
speed_ref = ramp_to(speed_ref, speed_cmd, step);
也就是：
错误：速度阶跃

3000rpm ┌────────────
        │
0rpm ───┘


正确：速度斜坡

3000rpm      /────────
            /
           /
0rpm ─────┘
8. 一个简单判断
如果你用示波器看三相 PWM：
正常 FOC
三相PWM：占空比周期性变化
相电流：接近正弦
电机：平滑转动
声音：比较顺
速度硬开关
三相PWM：占空比突然变化
相电流：突然冲高
母线电压：可能下跌
电机：猛冲、抖动、啸叫
最核心一句话
FOC 的三相 PWM 是三路高频 PWM，占空比按照电角度连续变化，三相相差 120°；真正接近正弦的是电机相电流，不是 MCU 引脚上的 PWM 波形。
速度控制不建议硬开关，建议：
开关命令 → 速度斜坡 → 速度环 → Iq限幅 → 电流环 → SVPWM → 三相PWM
可以开环速度控制，但不建议把它作为正式产品的主控制方式，尤其是平衡车、轮毂电机、负载变化大的设备。
你要先分清楚两个东西：
开环速度控制 ≠ FOC闭环速度控制
1. 什么叫开环速度控制？
开环速度控制大概是：
我想让电机转 1000rpm
    ↓
我直接按 1000rpm 的电角度速度去旋转磁场
    ↓
不管电机真实有没有跟上
也就是控制器自己生成一个旋转角度：
theta += omega_cmd * Ts;
然后根据这个角度输出三相 PWM。
控制器心里想：
“我现在电角度转到这里了，电机应该跟着我走。”
但是问题是：电机真实转子位置不一定在你想的位置。
2. FOC 为什么怕开环速度？
FOC 的核心是：你必须知道转子磁场在哪里。
FOC 要做 Park 变换：
三相电流 Ia/Ib/Ic
    ↓
Clarke变换
    ↓
得到 α/β 电流
    ↓
根据转子电角度做 Park 变换
    ↓
得到 Id/Iq
关键就在这个电角度。
电角度准：
Iq 真的是力矩电流
Id 真的是励磁方向电流

电角度错：
Iq 和 Id 混了
力矩变小
电流变大
电机发热、抖动、失步
可以这样理解：
FOC = 你要一直推着转子的“侧面”走
如果角度准确：
转子磁场 ↑

你施加的定子磁场 →
二者接近 90°
力矩最大
如果角度错了：
转子磁场 ↑

你施加的定子磁场 ↑
二者方向差太小
基本不产生转矩，只会发热
如果角度差太大：
转子磁场 ↑

你施加的定子磁场 ↓
可能反向制动、抖动、失步
3. 开环速度最大的问题：你不知道电机有没有跟上
开环控制是：
给多少速度 → 你就假设电机正在按这个速度转
但真实情况可能是：
负载变重
摩擦变大
电池电压下降
启动时惯量大
地面阻力变化
轮子卡住
这些都会导致真实速度跟不上。
比如你让磁场按 1000rpm 转：
控制器磁场：1000rpm
真实转子：  300rpm
这时电角度误差会越来越大。
结果就是：
角度误差越来越大
    ↓
电流方向越来越不对
    ↓
有效力矩下降
    ↓
电机更跟不上
    ↓
最后失步、抖动、堵转、过流
这个就是开环速度控制最危险的地方。
4. 开环速度控制下，三相 PWM 是什么样？
开环时，三相 PWM 仍然可以长得很“漂亮”。
因为 MCU 是按照自己生成的角度输出波形：
U相PWM：占空比按正弦/SVPWM规律变化
V相PWM：相差120°
W相PWM：相差120°
也就是说，示波器看三相 PWM，可能是正常的：
U相占空比包络：   /‾‾‾\      /‾‾‾\
               /       \    /       \

V相占空比包络：     /‾‾‾\      /‾‾‾\
                 /       \    /

W相占空比包络：       /‾‾‾\      /‾‾‾\
                   /       \    /
但是注意：
PWM 好看，不代表电机真的跟上了。
这是关键。
开环控制下，控制器只是“自嗨式输出三相旋转磁场”。
控制器输出：正常三相PWM
电机实际：可能没跟上、抖动、失步、发热
5. 为什么启动阶段经常可以开环？
因为无感 FOC 启动时，低速反电动势很弱，控制器很难估算转子位置。
所以常见流程是：
预定位
    ↓
开环拖动
    ↓
转速上来
    ↓
反电动势足够
    ↓
切入闭环估算
开环启动不是不能用，而是要小心用。
例如无感 FOC 里常见：
阶段1：给固定电角度，把转子吸到某个位置
阶段2：慢慢旋转电角度，让电机跟着启动
阶段3：达到一定转速后，切到闭环
这个开环速度一般是斜坡，不是猛地给高速。
错误：
0rpm → 3000rpm 硬切

正确：
0rpm → 100rpm → 200rpm → 300rpm → ... → 闭环
6. 开环速度控制适合什么场景？
适合这些：
1. 风扇、泵类负载
2. 负载变化小
3. 对速度精度要求不高
4. 允许丢速
5. 只作为启动阶段
6. 简单成本优先的产品
比如小风扇，转快点慢点没那么严重。即使转速不是特别准，用户可能也不敏感。
7. 不适合什么场景？
不适合这些：
1. 平衡车
2. 机器人关节
3. 轮毂电机
4. 云台
5. 高动态响应负载
6. 负载突然变化的设备
7. 需要准确速度/位置的系统
8. 可能堵转、卡滞的设备
平衡车尤其不适合。
因为平衡车不是单纯要“转起来”，而是要根据车身姿态实时修正力矩。
平衡车真正需要的是：
姿态角度环
    ↓
速度/位置辅助环
    ↓
Iq力矩电流
    ↓
FOC电流环
    ↓
电机输出力矩
它核心控制量应该是力矩/电流，不是开环速度。
8. 开环速度控制的主要风险
风险一：失步
控制器磁场转得太快，转子跟不上。
定子磁场：越转越快
转子：跟不上
结果：抖动、尖叫、停转
风险二：电流大但没力
角度错了以后，电流不一定产生有效转矩。
电流很大
电机不怎么转
MOS发热
电机发热
电池电流暴涨
这就像你用力推门，但是方向推错了，力都浪费了。
风险三：堵转过流
如果轮子被卡住，但你还在开环输出旋转磁场：
控制器以为电机在转
真实电机没转
    ↓
持续加电
    ↓
大电流
    ↓
过热/烧MOS/烧电机
所以开环控制必须加：
母线电流保护
相电流保护
堵转判断
温度保护
超时保护
风险四：速度不准
开环速度的“速度”其实只是：
控制器旋转磁场的速度
不一定等于：
电机真实机械转速
尤其负载变化后，真实速度会掉。
风险五：低速抖动
低速时，摩擦、齿槽转矩、负载扰动影响明显。开环磁场慢慢走，转子可能一卡一卡地跟。
表现是：
低速爬行
抖动
一顿一顿
有啸叫
9. 开环速度控制和闭环速度控制的区别
开环速度控制
目标速度
    ↓
直接生成电角度
    ↓
SVPWM
    ↓
电机

没有速度反馈
没有位置反馈
不知道电机实际情况
闭环速度控制
目标速度
    ↓
和真实速度比较
    ↓
速度PI输出 Iq_ref
    ↓
电流环控制
    ↓
SVPWM
    ↓
电机
    ↑
编码器/霍尔/无感估算反馈
闭环知道：
电机到底转没转
转得快还是慢
有没有跟上目标
所以闭环能修正误差。
10. 一句话总结
不是绝对不能开环速度控制，而是开环速度控制只是在“假设电机跟得上”。
一旦负载变化、启动太猛、轮子卡住、电池电压下降，真实转子跟不上你生成的旋转磁场，就会出现：
失步、抖动、堵转、大电流、发热、烧MOS、速度不准
所以工程上通常是：
开环：用于无感启动、简单风扇、低要求场景
闭环：用于正式调速、平衡车、轮毂电机、机器人、电动车
对你做平衡车来说，建议方向是：
有感FOC/编码器角度反馈
    +
电流闭环
    +
速度/姿态闭环
不要把平衡车做成：
开环给三相PWM，让它自己转
这样车很难稳，而且风险很大。
