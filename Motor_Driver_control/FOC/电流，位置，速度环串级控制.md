对，你说的就是标准的 **FOC 三闭环复合控制**，也叫：

* 位置—速度—电流三环控制
* 串级三闭环
* 级联控制

结构是：

```text
目标位置
   ↓
位置环
   ↓ 输出目标速度
速度环
   ↓ 输出目标转矩电流 Iq*
电流环
   ↓ 输出 Ud、Uq
SVPWM
   ↓
三相逆变器
   ↓
电机
```

## 三个环不是并列相加

不是这样：

```c
Uq = 位置环输出 + 速度环输出 + 电流环输出;
```

而是一级给下一级设定目标：

```text
位置环输出 → 速度环的目标值
速度环输出 → 电流环的目标值
电流环输出 → 电机电压指令
```

所以它叫“串级”。

---

# 每一环具体干什么

## 1. 位置环：决定应该转多快

输入：

```text
目标位置 θ_ref
实际位置 θ
```

位置误差：

$$
e_\theta = \theta_{ref} - \theta
$$

位置环输出目标转速：

$$
\omega_{ref} = K_{p\theta} e_\theta
$$

例如：

```text
距离目标位置很远
→ 目标速度较大

接近目标位置
→ 目标速度逐渐减小
```

位置环通常用：

* P
* PD
* 很少使用很强的积分

因为位置环积分过大，很容易导致过冲和来回震荡。

---

## 2. 速度环：决定需要多大转矩

输入：

```text
目标速度 ω_ref
实际速度 ω
```

速度误差：

$$
e_\omega = \omega_{ref} - \omega
$$

速度 PI 输出目标转矩电流：

$$
I_{q,ref} =
K_{p\omega}e_\omega
+
K_{i\omega}\int e_\omega dt
$$

速度跟不上时：

```text
速度误差大
→ 增大 Iq_ref
→ 增大电磁转矩
```

速度超过目标时：

```text
速度误差变成负数
→ Iq_ref 变成负数
→ 电机产生制动力矩
```

---

## 3. 电流环：真正控制电磁转矩

电流环一般包括两个环：

```text
Id 电流环
Iq 电流环
```

常见表贴式永磁电机一般设置：

$$
I_{d,ref} = 0
$$

$$
I_{q,ref} = \text{速度环输出}
$$

通过电流采样得到三相电流，再经过 Clarke、Park 变换：

```text
Ia、Ib、Ic
    ↓ Clarke
Iα、Iβ
    ↓ Park
Id、Iq
```

然后分别计算：

$$
e_d = I_{d,ref} - I_d
$$

$$
e_q = I_{q,ref} - I_q
$$

电流 PI 输出：

$$
U_d =
K_{pd}e_d
+
K_{id}\int e_d dt
$$

$$
U_q =
K_{pq}e_q
+
K_{iq}\int e_q dt
$$

之后：

```text
Ud、Uq
   ↓ 反Park
Uα、Uβ
   ↓ SVPWM
三相PWM
```

# 为什么需要三环

因为三个环分别解决不同问题：

| 控制环 | 负责的问题    |
| --- | -------- |
| 位置环 | 最终停在哪里   |
| 速度环 | 运动过程转多快  |
| 电流环 | 当前输出多大转矩 |

比如目标从 90° 返回 30°：

```text
位置环：
根据 -60° 位置误差，给出 -200rpm

速度环：
根据当前速度和 -200rpm 的误差，给出 -1.5A 的 Iq_ref

电流环：
控制实际 Iq 跟随 -1.5A，算出 Ud、Uq
```

接近 30° 后：

```text
位置误差变小
→ 目标速度变小
→ 目标 Iq 变小
→ 转矩变小
→ 平稳停下
```

这样就比：

```text
位置误差直接乘 Kp 得到 Uq
```

更加可控。

---

# 电流环带来的关键优势

你现在如果只是：

```text
位置环 → Uq
```

或者：

```text
位置环 → 速度环 → Uq
```

实际上控制的是电压，不是真正控制转矩。

因为同一个 $U_q$，在不同情况下产生的电流可能不同：

* 电机静止时反电动势小，电流可能很大
* 高速时反电动势大，同样的 $U_q$ 电流可能很小
* 电机绕组温度变化后，电阻会变化
* 负载变化后，电流也会变化

加入电流环以后，控制器直接控制：

$$
I_q
$$

而永磁电机转矩近似满足：

$$
T_e \approx K_t I_q
$$

所以：

> 控制 $I_q$，才接近真正控制转矩。

这也是电流环最重要的作用。

---

# 三个环的速度必须不同

串级控制要求：

```text
内环快
外环慢
```

一般：

```text
电流环最快
速度环其次
位置环最慢
```

例如：

```text
PWM频率：20kHz

电流环：20kHz
速度环：1kHz
位置环：100Hz
```

也可以：

```text
电流环：10kHz
速度环：1kHz
位置环：100Hz
```

通常带宽关系大约保持：

```text
电流环带宽 > 速度环带宽 > 位置环带宽
```

每一级大约相差 5～10 倍，会更容易稳定。

你的 20kHz PWM 可以这样安排：

```text
PWM中断每50us：
    执行电流环

每执行20次电流环：
    执行1次速度环
    即1kHz

每执行200次电流环：
    执行1次位置环
    即100Hz
```

# 有没有必要使用三环

## 没有必要的情况

只是学习 FOC、验证电机旋转、小功率低要求实验：

```text
位置环 → Uq
```

也可以运行。

优点是代码简单。

但会存在：

* 电流不可控
* 堵转容易过流
* 启动冲击大
* 高低速性能差异明显
* 负载变化后参数表现不同
* 转矩控制不准确

---

## 比较有必要的情况

存在以下要求时，建议三环：

* 电机可能堵转
* 需要限制最大电流
* 需要精确控制力矩
* 位置回弹要平稳
* 负载变化较大
* 要求低速稳定
* 需要较强的抗扰动能力
* 需要正式做成产品

你之前的位置环存在：

```text
拉开后回弹
到达目标位置后震荡
Uq 大小不容易兼顾响应和稳定
```

加入电流环确实会帮助控制转矩，但要注意：

> 三环本身不会自动消除震荡，参数和带宽关系调错，三环反而可能比单环更容易振荡。

---

# 三环调参顺序非常重要

必须从内到外调：

```text
第一步：只调电流环
第二步：固定电流环，调速度环
第三步：固定电流环和速度环，调位置环
```

不能反过来。

## 第一步：电流环

先禁止位置环和速度环，直接给一个较小的：

$$
I_{q,ref}
$$

观察实际 $I_q$ 是否快速、稳定跟随。

目标是：

* 响应快
* 不振荡
* 不明显过冲
* 电流噪声可接受

## 第二步：速度环

电流环调好后：

```text
目标速度 → 速度PI → Iq_ref
```

先调速度环的 $K_p$，再逐渐增加 $K_i$。

## 第三步：位置环

最后：

```text
目标位置 → 位置P/PD → 目标速度
```

位置环一般先只用 P，并限制最大目标速度。

# 对你当前项目的实际意义

你现在如果升级成带电流环的复合环路，控制变量需要发生变化：

以前可能是：

```text
位置环输出 Uq
速度环输出 Uq
```

改成三环以后应当是：

```text
位置环输出 target_rpm

速度环输出 target_iq

电流环输出 Ud、Uq
```

也就是：

```c

target_rpm = position_controller(target_angle, now_angle);

/* 速度环 */
target_iq = speed_pi_controller(target_rpm, now_rpm);

/* d轴目标通常设置为0 */
target_id = 0.0f;

/* 电流环 */
ud = current_d_pi_controller(target_id, id);
uq = current_q_pi_controller(target_iq, iq);

/* 送入SVPWM */
svpwm_run(ud, uq, electrical_angle);
```

这里最关键的是：

```c
/* 错误思路 */

/* 正确思路 */
position_loop_output = target_rpm;
speed_loop_output    = target_iq;
current_loop_output  = ud、uq;
```

所以，你说的“带电流环、速度环、位置环的复合环路”，就是工业伺服、电机控制里非常标准的三环串级结构。对你当前 FOC 学习项目来说，不是让电机转起来的必要条件，但如果要真正做好位置、速度、转矩和过流保护，它是很值得做的。

需要，但**平衡车用的不是普通“位置环 → 速度环 → 电流环”三环直接照搬**。

平衡车本质是倒立摆，核心目标不是先控制电机位置，而是：

> 通过控制轮子产生前后加速度，让车身倾角保持在直立位置。

因此典型控制结构是：

```text
速度/位置外环
      ↓ 输出目标倾角
车身倾角环
      ↓ 输出目标转矩 Iq_ref
电流环
      ↓ 输出 Ud、Uq
FOC + SVPWM
      ↓
左右电机
```

更准确地说，平衡车通常是：

```text
速度环 → 倾角环 → 电流环
```

而不是普通伺服电机的：

```text
位置环 → 速度环 → 电流环
```

---

## 1. 平衡环是最关键的环

IMU 测量：

* 车身倾角 $\theta$
* 角速度 $\dot{\theta}$

目标倾角一般是：

$$
\theta_{ref}=0^\circ
$$

平衡控制器通常采用 PD：

$$
I_{q,\text{balance}}
= K_{p\theta}(\theta_{ref}-\theta)

K_{d\theta}\dot{\theta}
$$

含义是：

* 车身向前倒，轮子就快速向前跑
* 车身向后倒，轮子就向后跑
* 通过轮子的运动把重心重新接回来

这个倾角环是平衡车的核心。

---

## 2. 为什么还需要速度环

如果只有倾角环，车虽然可能不倒，但容易出现：

* 慢慢往前跑
* 慢慢往后跑
* 无法稳定停在原地
* 推一下之后一直移动
* 速度不可控

所以还需要速度环。

速度环根据目标速度和实际轮速计算一个**目标倾角**：

$$
e_v=v_{ref}-v
$$

$$
\theta_{ref}
============

K_{pv}e_v
+
K_{iv}\int e_vdt
$$

例如目标速度为零，但车正在往前跑：

```text
实际速度向前
    ↓
速度环给出轻微向后倾的目标
    ↓
倾角环让电机产生反向力矩
    ↓
车减速并回到静止
```

因此速度环不是直接输出 $U_q$，而是输出一个小的目标倾角，例如：

```text
-8° ～ +8°
```

然后平衡环负责跟踪这个目标倾角。

---

## 3. 电流环有没有必要

如果使用真正的 FOC，电流环非常有价值。

平衡环最后应输出：

$$
I_{q,ref}
$$

而不是直接输出 $U_q$：

```text
倾角控制器
    ↓
目标转矩电流 Iq_ref
    ↓
Iq 电流PI
    ↓
Uq
```

因为永磁电机的转矩近似为：

$$
T_e \approx K_t I_q
$$

这样车身要向前或向后纠正时，可以快速、准确地产生所需转矩。

电流环还能提供：

* 最大电流限制
* 堵转保护
* 稳定转矩输出
* 电池电压变化补偿
* 低速时更稳定的力矩
* 左右电机输出一致性

所以正式做平衡车，推荐带电流环。

# 平衡车完整控制结构

典型单轴两轮平衡车可以设计成：

```text
                  目标速度
                     ↓
                  速度PI
                     ↓
                  目标倾角
                     ↓
IMU倾角、角速度 → 倾角PD
                     ↓
                 基础 Iq_ref
                     ↓
          ┌──────────┴──────────┐
          ↓                     ↓
      左电机Iq_ref          右电机Iq_ref
          ↓                     ↓
     左电流环FOC            右电流环FOC
          ↓                     ↓
        SVPWM                 SVPWM
```

转向控制再叠加到左右轮：

$$
I_{qL}=I_{q,\text{balance}}-I_{q,\text{turn}}
$$

$$
I_{qR}=I_{q,\text{balance}}+I_{q,\text{turn}}
$$

例如向右转：

* 左轮增加正向转矩
* 右轮减小正向转矩或产生反向转矩

# 位置环放在哪里

平衡车可以有位置环，但不是必须。

如果需要停车后回到原位置，可以加入位置外环：

```text
位置环
   ↓ 目标速度
速度环
   ↓ 目标倾角
倾角环
   ↓ 目标Iq
电流环
   ↓ Ud、Uq
```

完整结构变成：

```text
位置环 → 速度环 → 倾角环 → 电流环
```

不过位置环一定要很慢，否则可能破坏平衡。

普通遥控平衡车通常只需要：

```text
速度环 → 倾角环 → 电流环
```

如果只要求能够站住，也可以先做：

```text
倾角环 → 电流环
```

# 不建议简单把几个输出全部相加

很多入门平衡车代码会这样写：

```c
motor_pwm = balance_output
          + speed_output
          + turn_output;
```

这种写法在传统 PWM 控制中很常见，也可能工作，但从标准串级角度看，更合理的是：

```text
速度环输出目标倾角
倾角环输出目标Iq
转向环产生左右轮Iq差值
电流环控制实际Iq
```

可以写成：

```c
/* 速度环：计算目标倾角 */
target_pitch = speed_pi(target_speed, now_speed);

/* 限制允许倾斜的最大角度 */
target_pitch = limit(target_pitch, -8.0f, 8.0f);

/* 平衡环：计算基础目标转矩电流 */
balance_iq = pitch_pd(target_pitch,
                      now_pitch,
                      pitch_gyro_rate);

/* 转向控制 */
turn_iq = yaw_controller(target_yaw_rate,
                         now_yaw_rate);

/* 左右电机目标电流 */
left_iq_ref  = balance_iq - turn_iq;
right_iq_ref = balance_iq + turn_iq;

/* 两个电机各自执行FOC电流环 */
left_foc_current_loop(left_iq_ref);
right_foc_current_loop(right_iq_ref);
```

# 各环频率建议

平衡车对实时性要求较高，常见安排是：

```text
电流环：10～20kHz
倾角环：500Hz～1kHz
速度环：50～200Hz
位置环：10～50Hz
```

例如你的 PWM 是 20kHz，可以安排：

```text
每50us：
    电流环执行一次，20kHz

每1ms：
    IMU姿态与倾角环执行一次，1kHz

每10ms：
    速度环执行一次，100Hz

每50ms：
    可选位置环执行一次，20Hz
```

需要满足：

```text
电流环最快
倾角环其次
速度环更慢
位置环最慢
```

# 对平衡车最实际的推荐

如果你准备使用 FOC 做两轮平衡车，建议按这个顺序实现：

```text
第一阶段：
电流环FOC，确认Iq能稳定跟随

第二阶段：
倾角PD → Iq_ref
先让车能够被手扶着保持平衡趋势

第三阶段：
增加速度PI → 目标倾角
解决慢慢漂移和速度控制

第四阶段：
增加转向环
控制左右轮差速

第五阶段：
可选位置环
实现原地驻车或位置保持
```

最终建议结构：

```text
速度PI → 目标倾角
             ↓
      倾角PD → 基础Iq
             ↓
     加入转向差分Iq
             ↓
左右电机各自执行Id/Iq电流环
```

所以结论是：

> 平衡车很适合使用复合串级环路，而且电流环对高性能平衡控制非常重要；但最核心的外层不是电机位置环，而是“速度环＋车身倾角环”，需要位置保持时，才在最外层再增加位置环。

# 1. 位置环：角度误差变成目标速度

输入：

```text
目标角度 - 实际角度
```

$$
e_\theta = \theta^*-\theta
$$

最简单的位置 P 环：

$$
\omega^* = K_{p\theta}e_\theta
$$

意思是：

```text
距离目标位置越远
→ 要求电机转得越快

距离目标位置越近
→ 要求电机逐渐减速
```

例如：

```text
目标角度：30°
实际角度：90°
位置误差：-60°
```

假设：

$$
K_{p\theta}=2\ \frac{\text{rpm}}{^\circ}
$$

那么：

$$
\omega^*=2\times(-60)=-120\text{ rpm}
$$

表示位置环要求电机以反方向 120 rpm 返回。

接近目标时，比如误差只有：

$$
e_\theta=-2^\circ
$$

那么：

$$
\omega^*=-4\text{ rpm}
$$

电机自然减速靠近目标。

=

-\omega
$$

所以工程上经常写成：

$$
\omega^*
= K_{p\theta}e_\theta

K_{d\theta}\omega
$$

对应代码：

```c
angle_error = target_angle - now_angle;

target_speed =
      position_kp * angle_error
    - position_kd * now_speed;
```

不过在标准三环中，位置环通常先只用 P：

```c
target_speed = position_kp * angle_error;
```

因为里面已经有速度环，速度环本身就能提供很强的速度阻尼。位置环再加很大的 D，反而可能放大编码器速度噪声。

---

# 2. 速度环：速度误差变成目标电流

速度环输入：

$$
e_\omega = \omega^*-\omega
$$

速度 PI 输出：

$$
I_q^*
=
K_{p\omega}e_\omega
+
K_{i\omega}\int e_\omega dt
$$

这里输出的是目标转矩电流：

$$
I_q^*
$$

例如：

```text
目标速度：120 rpm
实际速度：30 rpm
速度误差：90 rpm
```

速度环发现电机转得不够快，于是要求更大的：

$$
I_q^*
$$

例如输出：

$$
I_q^*=1.5A
$$

这表示：

> 为了让电机达到目标速度，现在需要大约 1.5 A 的 q 轴转矩电流。

如果电机速度超过目标，速度误差变成负数，速度环就可能输出负的：

$$
I_q^*
$$

从而产生制动力矩。

代码大致是：

```c
speed_error = target_speed - now_speed;

speed_integral += speed_error * speed_dt;

target_iq =
      speed_kp * speed_error
    + speed_ki * speed_integral;

target_iq = limit(target_iq,
                  -max_iq,
                   max_iq);
```

速度环通常使用 PI，不太使用 D，因为速度信号本身已经是角度的微分，再对速度误差微分，很容易放大噪声。

---

# 3. 电流环：电流误差变成电压

FOC 电流环实际上包含两个环：

```text
Id 环
Iq 环
```

对于常见表贴式永磁电机，通常设置：

$$
I_d^*=0
$$

速度环输出：

$$
I_q^*
$$

实际三相电流经过 Clarke、Park 变换后，得到：

$$
I_d,\ I_q
$$

然后计算电流误差：

$$
e_d=I_d^*-I_d
$$

$$
e_q=I_q^*-I_q
$$

电流 PI 输出：

$$
U_d
===

K_{pd}e_d
+
K_{id}\int e_d dt
$$

$$
U_q
=

K_{pq}e_q
+
K_{iq}\int e_q dt
$$

也就是：

```text
Id误差 → Id PI → Ud
Iq误差 → Iq PI → Uq
```

代码类似：

```c
id_error = target_id - now_id;
iq_error = target_iq - now_iq;

ud = current_d_kp * id_error
   + current_d_ki * id_integral;

uq = current_q_kp * iq_error
   + current_q_ki * iq_integral;
```

所以严格来说不是：

```text
一个电流PID输出Uq
```

而是：

```text
Id PI输出Ud
Iq PI输出Uq
```

---

# 4. 为什么不直接“位置误差 → Uq”

你现在可能会觉得：

```text
目标是控制位置
直接用角度误差算Uq不就行了吗？
```

确实可以：

```c
uq = position_kp * angle_error;
```

小功率实验里也能跑。

但问题是，位置误差和电机需要的电压之间没有稳定、直接的关系。

同样是 10° 误差：

```text
电机静止时
电机高速旋转时
空载时
重负载时
电池12V时
电池9V时
绕组冷的时候
绕组热的时候
```

需要的 $U_q$ 都不一样。

所以直接：

```text
位置误差 → Uq
```

实际上让一个位置 PID 同时承担了：

* 决定移动速度
* 决定加速度
* 决定转矩
* 克服负载
* 克服反电动势
* 补偿电池电压
* 限制绕组电流
* 处理堵转

一个控制器同时处理这么多动态过程，参数会很难调。

---

# 5. 串级控制是在逐层解决物理问题

三个环分别回答三个问题。

## 位置环回答

> 离目标位置还有多远，现在应该转多快？

输出：

$$
\omega^*
$$

## 速度环回答

> 想达到这个速度，现在需要多大的转矩？

输出：

$$
I_q^*
$$

## 电流环回答

> 想得到这个转矩，需要施加多大的电压？

输出：

$$
U_q
$$

因此整个逻辑是：

```text
位置要求
→ 转换成速度要求
→ 转换成转矩要求
→ 转换成电压要求
```

它和电机的物理关系是一致的。

---

# 6. 为什么速度环输出的是电流

对于表贴式 PMSM 或 BLDC，在：

$$
I_d\approx0
$$

时，电磁转矩可以近似写成：

$$
T_e=K_t I_q
$$

所以：

```text
Iq越大
→ 电机转矩越大

Iq为负
→ 产生反向转矩

Iq接近0
→ 电机输出转矩接近0
```

因此速度环想控制加速和减速，本质上就应该控制转矩，而转矩对应：

$$
I_q
$$

不是直接对应 $U_q$。

因为 $U_q$ 是电压，而同样的电压在不同转速下产生的电流不同。

电机 q 轴电压关系可以粗略理解为：

$$
U_q
\approx
R_s I_q
+
L_q\frac{dI_q}{dt}
+
\omega_e\psi_f
$$

其中最后一项：

$$
\omega_e\psi_f
$$

是反电动势相关项。

高速时反电动势变大，所以同样的 $U_q$，实际 $I_q$ 可能变小。电流环会自动增加 $U_q$，让实际电流仍然跟踪目标电流。

---

# 7. 一个完整运行例子

假设：

```text
目标位置：30°
当前位置：90°
当前速度：0 rpm
当前Iq：0 A
```

## 第一步：位置环

$$
e_\theta=30^\circ-90^\circ=-60^\circ
$$

位置环输出：

$$
\omega^*=-150\text{ rpm}
$$

## 第二步：速度环

当前速度：

$$
\omega=0
$$

速度误差：

$$
e_\omega=-150-0=-150\text{ rpm}
$$

速度 PI 输出：

$$
I_q^*=-2A
$$

表示需要负方向转矩。

## 第三步：电流环

当前实际电流可能只有：

$$
I_q=-0.3A
$$

电流误差：

$$
e_q=-2-(-0.3)=-1.7A
$$

Iq 电流 PI 输出一个负的：

$$
U_q
$$

例如：

$$
U_q=-3.5V
$$

推动电机反向加速。

---

当电机接近 30° 时：

```text
位置误差变小
→ 目标速度变小
→ 速度误差变小
→ 目标Iq变小
→ 电机转矩逐渐减小
```

如果因为惯性即将冲过目标，实际速度仍然很大：

```text
目标速度已经接近0
实际速度仍然向前
→ 速度误差变负
→ Iq目标变成反方向
→ 电机主动刹车
```

这就是三环能更平稳停车的原因。

# 8. 为什么每一环的频率不同

电流变化最快，位置变化最慢，因此：

```text
电流环最快
速度环其次
位置环最慢
```

例如你的 PWM 是 20 kHz，可以设计为：

```text
电流环：20 kHz，每50 us执行一次
速度环：1 kHz，每1 ms执行一次
位置环：100 Hz，每10 ms执行一次
```

典型代码结构：

```c
void foc_control_20khz(void)
{
    static uint32_t speed_div = 0;
    static uint32_t position_div = 0;

    /* 20kHz：采样电流并执行Id/Iq电流环 */
    foc_current_loop();

    speed_div++;
    position_div++;

    /* 1kHz速度环 */
    if (speed_div >= 20)
    {
        speed_div = 0;
        speed_loop();
    }

    /* 100Hz位置环 */
    if (position_div >= 200)
    {
        position_div = 0;
        position_loop();
    }
}
```

内环必须足够快，才能让外环认为它的命令会很快被执行。

# 9. 对你这句话的准确修正

你原来的理解：

```text
位置环：
角度误差 × Kp + Kd × err
输出速度

速度环：
速度误差 × Kp + Ki
输出电流

电流环：
电流误差PID
输出Uq
```

准确写法应该是：

```text
位置环：
Kp × 角度误差
或者
Kp × 角度误差 + Kd × 角度误差变化率
输出目标速度 ω*

速度环：
Kp × 速度误差 + Ki × 速度误差积分
输出目标Iq电流 Iq*

电流环：
Id误差经过PI输出Ud
Iq误差经过PI输出Uq
```

最核心的一句话是：

> 位置环决定“应该转多快”，速度环决定“需要多大转矩”，电流环决定“施加多大电压才能产生这个转矩”。串级三环把位置、速度、转矩三个不同时间尺度的问题分开控制，因此比位置误差直接控制 $U_q$ 更稳定、更安全，也更容易限制速度、电流和转矩。


---------
---------
-------

对，**串级环路不是说位置环、速度环、电流环永远全部一起运行**。

正确理解是：

> 根据当前控制模式，选择从哪一层开始进入串级链路。

三种模式可以这样切换：

```text
位置模式：位置环 → 速度环 → 电流环
速度模式：          速度环 → 电流环
力矩模式：                    电流环
```

也就是说，越靠外的环可以旁路掉，但**电流环通常一直运行**。

# 1. 单独位置控制怎么做

位置控制模式下，三层都运行：

```text
目标角度
   ↓
位置环
   ↓ 目标速度
速度环
   ↓ 目标Iq
电流环
   ↓ Ud、Uq
SVPWM
```

公式：

$$
e_\theta = \theta_{ref}-\theta
$$

$$
\omega_{ref}=K_{p\theta}e_\theta
$$

位置环输出目标速度，然后限速：

$$
-\omega_{max}\leq\omega_{ref}\leq\omega_{max}
$$

速度环：

$$
e_\omega=\omega_{ref}-\omega
$$

$$
I_{q,ref}
=
K_{p\omega}e_\omega
+
K_{i\omega}\int e_\omega dt
$$

再限制最大电流：

$$
-I_{q,max}\leq I_{q,ref}\leq I_{q,max}
$$

最后由电流环产生：

$$
U_d,\ U_q
$$

代码逻辑：

```c
/* 位置模式 */

/* 1. 位置环输出目标速度 */
angle_error = angle_error_deg(target_angle, now_angle);

target_rpm = position_kp * angle_error;

/* 限制位置运动的最大速度 */
target_rpm = foc_limit(target_rpm,
                       -position_max_rpm,
                        position_max_rpm);

/* 2. 速度环输出目标Iq */
speed_error = target_rpm - now_rpm;

speed_integral += speed_error * speed_dt;

target_iq = speed_kp * speed_error
          + speed_ki * speed_integral;

/* 限制最大转矩电流 */
target_iq = foc_limit(target_iq,
                      -max_iq,
                       max_iq);

/* 3. 电流环 */
target_id = 0.0f;

foc_current_loop(target_id, target_iq);
```

这里的位置模式可以同时设置：

* 目标角度
* 最大运动速度
* 最大转矩电流

例如：

```text
目标位置：30°
最大速度：200 rpm
最大Iq：1.5 A
```

这样电机返回 30° 时：

* 不会超过 200 rpm
* 不会超过 1.5 A 的转矩电流

# 2. 单独速度控制怎么做

速度控制模式下，不运行位置环。

直接人为设置目标速度：

```text
目标速度
   ↓
速度环
   ↓ 目标Iq
电流环
   ↓ Ud、Uq
```

也就是：

```c
/* 速度模式 */

/* 目标速度由用户直接设置 */
target_rpm = user_target_rpm;

/* 速度环 */
speed_error = target_rpm - now_rpm;

speed_integral += speed_error * speed_dt;

target_iq = speed_kp * speed_error
          + speed_ki * speed_integral;

/* 限制最大输出转矩 */
target_iq = foc_limit(target_iq,
                      -max_iq,
                       max_iq);

/* 电流环 */
target_id = 0.0f;

foc_current_loop(target_id, target_iq);
```

例如：

```text
目标速度：600 rpm
最大Iq：2 A
```

含义是：

> 电机尽量维持 600 rpm，但为了保护电机，输出电流不能超过 2 A。

负载增加时，速度环自动提高 `Iq_ref`。

负载减小时，速度环自动降低 `Iq_ref`。

# 3. 单独力矩控制怎么做

力矩模式下，位置环和速度环都不运行。

直接给目标：

$$
I_{q,ref}
$$

结构：

```text
目标力矩
   ↓ 换算成目标Iq
电流环
   ↓ Ud、Uq
```

代码：

```c
/* 力矩模式 */

/* 用户直接设置目标Iq */
target_iq = user_target_iq;

/* 限制允许的最大电流 */
target_iq = foc_limit(target_iq,
                      -max_iq,
                       max_iq);

target_id = 0.0f;

/* 只运行电流环 */
foc_current_loop(target_id, target_iq);
```

例如：

```c
target_iq = 1.0f;
```

表示产生正方向转矩。

```c
target_iq = -1.0f;
```

表示产生反方向转矩。

```c
target_iq = 0.0f;
```

表示不主动产生 q 轴转矩。

对于表贴式永磁电机，大致有：

$$
T_e=K_t I_q
$$

因此：

$$
I_{q,ref}=\frac{T_{ref}}{K_t}
$$

假设电机转矩常数：

$$
K_t=0.08\ \text{N·m/A}
$$

想要：

$$
T_{ref}=0.16\ \text{N·m}
$$

则：

$$
I_{q,ref}
=
 \frac{0.16}{0.08}

2A
$$

所以真正的力矩控制是：

```text
目标转矩 → 目标Iq → 电流环
```

不是直接限制 `Uq`。

---

# 4. 三种模式的本质区别

| 模式   | 用户直接设置什么    | 启用哪些环       |
| ---- | ----------- | ----------- |
| 位置模式 | 目标角度        | 位置环、速度环、电流环 |
| 速度模式 | 目标速度        | 速度环、电流环     |
| 力矩模式 | 目标 Iq 或目标转矩 | 电流环         |
| 电压模式 | 目标 Uq       | 不属于真正闭环力矩控制 |

可以记成：

```text
位置模式：
我要停在哪里

速度模式：
我要转多快

力矩模式：
我要用多大力
```

# 5. 程序中怎么切换

可以定义控制模式：

```c
typedef enum
{
    FOC_MODE_TORQUE = 0,   /* 力矩控制 */
    FOC_MODE_SPEED,        /* 速度控制 */
    FOC_MODE_POSITION      /* 位置控制 */
} foc_control_mode_t;
```

控制结构：

```c
typedef struct
{
    foc_control_mode_t mode;

    float target_angle_deg;
    float target_rpm;
    float target_iq;

    float position_max_rpm;
    float max_iq;

    float position_kp;

    float speed_kp;
    float speed_ki;
    float speed_integral;

} foc_controller_t;
```

主控制逻辑：

```c
void foc_outer_loop_run(foc_controller_t *ctrl,
                        float now_angle_deg,
                        float now_rpm)
{
    float angle_error;
    float speed_error;

    switch (ctrl->mode)
    {
        case FOC_MODE_POSITION:
        {
            /*
             * 位置模式：
             * 位置环输出目标速度
             */

            angle_error = angle_error_deg(ctrl->target_angle_deg,
                                          now_angle_deg);

            ctrl->target_rpm =
                ctrl->position_kp * angle_error;

            ctrl->target_rpm =
                foc_limit(ctrl->target_rpm,
                          -ctrl->position_max_rpm,
                           ctrl->position_max_rpm);

            /*
             * 接着执行速度环，
             * 输出目标Iq
             */
            speed_error =
                ctrl->target_rpm - now_rpm;

            ctrl->speed_integral +=
                speed_error * SPEED_LOOP_DT;

            ctrl->target_iq =
                ctrl->speed_kp * speed_error
                + ctrl->speed_ki * ctrl->speed_integral;

            ctrl->target_iq =
                foc_limit(ctrl->target_iq,
                          -ctrl->max_iq,
                           ctrl->max_iq);

            break;
        }

        case FOC_MODE_SPEED:
        {
            /*
             * 速度模式：
             * 跳过位置环，
             * 用户直接设置target_rpm
             */

            speed_error =
                ctrl->target_rpm - now_rpm;

            ctrl->speed_integral +=
                speed_error * SPEED_LOOP_DT;

            ctrl->target_iq =
                ctrl->speed_kp * speed_error
                + ctrl->speed_ki * ctrl->speed_integral;

            ctrl->target_iq =
                foc_limit(ctrl->target_iq,
                          -ctrl->max_iq,
                           ctrl->max_iq);

            break;
        }

        case FOC_MODE_TORQUE:
        {
            /*
             * 力矩模式：
             * 跳过位置环和速度环，
             * 用户直接设置target_iq
             */

            ctrl->target_iq =
                foc_limit(ctrl->target_iq,
                          -ctrl->max_iq,
                           ctrl->max_iq);

            break;
        }

        default:
        {
            ctrl->target_iq = 0.0f;
            break;
        }
    }
}
```

之后，无论是哪种模式，都统一进入电流环：

```c
void foc_current_control_run(foc_controller_t *ctrl,
                             float now_id,
                             float now_iq)
{
    float target_id = 0.0f;

    float id_error = target_id - now_id;
    float iq_error = ctrl->target_iq - now_iq;

    float ud = current_d_pi_run(id_error);
    float uq = current_q_pi_run(iq_error);

    foc_voltage_limit(&ud, &uq);

    svpwm_run(ud, uq, electrical_angle);
}
```

# 6. 为什么电流环通常一直保留

假设你在速度模式下直接让速度环输出 `Uq`：

```text
速度误差 → Uq
```

它也可能运行，但不能保证电流安全。

例如电机堵转时：

* 实际速度为 0
* 速度误差一直很大
* 速度 PI 持续增加 `Uq`
* 电机电流可能迅速升高

有电流环后：

```text
速度环最多只给出 2A 的 Iq_ref
电流环保证实际Iq跟随2A
```

这样容易实现：

* 最大转矩限制
* 堵转限流
* 电机保护
* 电池保护
* MOS 管保护

所以在标准 FOC 中：

> 位置环和速度环可以旁路，电流环通常作为底层一直工作。

# 7. “力矩大小限制”和“力矩模式”不是一回事

这两个概念容易混。

## 力矩模式

用户直接设置：

```c
target_iq = 1.0f;
```

电机持续输出对应方向和大小的转矩。

## 位置模式中的力矩限制

位置环和速度环仍然运行，但限制：

```c
target_iq = foc_limit(target_iq, -1.0f, 1.0f);
```

含义是：

> 电机仍然要去目标位置，但最多只能使用 1A 的转矩电流。

例如：

```text
目标角度：30°
最大速度：100 rpm
最大Iq：0.8 A
```

这就是一个较柔和的位置控制。

如果设置：

```text
最大Iq：3 A
```

回弹力量就会明显增强。

因此位置模式下也能控制“最大力气”。

# 8. 模式切换时必须处理积分项

例如从速度模式切换到力矩模式时，速度 PI 的积分可能还保存着很大的值。

以后重新进入速度模式，电机可能突然冲一下。

所以模式切换时应清零暂时不用的积分器：

```c
void foc_set_control_mode(foc_controller_t *ctrl,
                          foc_control_mode_t new_mode)
{
    if (ctrl->mode == new_mode)
    {
        return;
    }

    /*
     * 模式切换时清除外环积分，
     * 防止旧积分造成突然冲击
     */
    ctrl->speed_integral = 0.0f;

    current_d_pi_reset();
    current_q_pi_reset();

    ctrl->mode = new_mode;
}
```

不过正式产品为了无冲击切换，电流环积分不一定直接清零，通常使用“无扰切换”。学习阶段可以先采用：

```text
目标值设为当前反馈值
清除外环积分
目标电流斜坡到新值
```

例如从位置模式切到速度模式：

```c
ctrl->target_rpm = now_rpm;
ctrl->speed_integral = 0.0f;
ctrl->mode = FOC_MODE_SPEED;
```

这样切换瞬间不会突然出现很大的速度误差。

# 9. 对你当前项目最关键的变化

你之前可能有：

```text
位置控制：位置环直接输出Uq
速度控制：速度环直接输出Uq
```

加入电流环后，应改成：

```text
位置控制：
位置环输出目标rpm
速度环输出目标Iq
电流环输出Ud/Uq

速度控制：
用户直接设置目标rpm
速度环输出目标Iq
电流环输出Ud/Uq

力矩控制：
用户直接设置目标Iq
电流环输出Ud/Uq
```

最直观的总结就是：

```text
位置模式：
target_angle → target_rpm → target_iq → Uq

速度模式：
target_rpm → target_iq → Uq

力矩模式：
target_iq → Uq
```

所以串级并不会让你失去单独的位置、速度、力矩控制。相反，它把三种控制模式统一成了一套底层结构：**需要控制哪一层，就从那一层开始往内执行。**
