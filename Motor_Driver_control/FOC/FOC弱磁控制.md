这个问题终于到 FOC 最核心的一个高级控制了。

而且**结合你现在做的12V、100KV、BLDC、双闭环FOC**，弱磁不是一个理论知识，而是**解决"Uq到顶了，Iq上不去"的唯一办法**（除了提高母线电压）。

---

# 一、为什么需要弱磁？

我们先回到电压方程。

稳态时（忽略电流变化项）：

[
\begin{aligned}
U_d &= R_sI_d-\omega_eL_qI_q \
U_q &= R_sI_q+\omega_eL_dI_d+\omega_e\psi_f
\end{aligned}
]

其中最关键的是：

[
\boxed{\omega_e\psi_f}
]

这一项就是永磁体产生的反电势。

它随着速度线性增加。

例如：

```
100rpm
↓

反电势 1V

----------------

500rpm
↓

反电势 5V

----------------

1000rpm
↓

反电势 10V
```

而你的系统：

```
VBUS =12V

SVPWM

Umax≈6.5V
```

当：

```
反电势≈6V
```

的时候，

已经没有多少电压还能驱动Iq了。

所以：

```
Uq↑

↓

Iq却越来越小
```

这就是你最近一直碰到的问题。

---

# 二、什么叫弱磁（Field Weakening）？

一句话：

> **故意产生一个与永磁体磁场相反的磁场，把总磁链减小。**

为什么？

因为：

反电势：

[
E=\omega_e\psi
]

这里：

不是固定的：

[
\psi_f
]

而是：

整个磁链：

[
\psi=\psi_f+L_dI_d
]

这里重点来了。

---

正常FOC：

```
Id=0
```

所以：

```
总磁链

=

永磁体磁链
```

---

如果：

```
Id<0
```

例如：

```
Id=-2A
```

那么：

定子产生一个：

```
反向磁场
```

去抵消：

```
永磁体磁场
```

于是：

```
总磁链

↓

变小
```

反电势：

```
↓

变小
```

于是：

```
还能继续升速。
```

这就是：

**弱磁。**

# 三、为什么 Id 为负？

dq坐标系：

```
          q轴

           ↑

           |

           |

-----------+----------->

           |

           |

           d轴

```

d轴：

就是：

```
永磁体磁场方向
```

如果：

```
Id>0
```

就是：

```
帮助永磁体

磁链更大
```

反电势：

更大。

所以没人这么干。

---

如果：

```
Id<0
```

就是：

```
反着推

抵消永磁体
```

所以：

```
反电势下降
```

永磁体：

现在：

定子：

# 五、弱磁以后有什么变化？

没有弱磁：

```
反电势：

6V

2A
```

弱磁以后：

```

```

于是：

多出来：

```

```


# 六、什么时候开始弱磁？

通常：

```
Uq

>

0.9Umax
```

或者：

```
速度

>

基速
```

例如：

```c
if(Uq > 0.9f*Umax)
{
    Id_ref -= 0.05f;
}
```

继续：

```
Id_ref

↓

-0.1

↓

-0.2

↓

-0.5A
```

直到：

```
Uq

重新掉下来。
```

# 七、工业怎么做？

不是：

```
速度超过

↓

Id=-1A
```

这样很粗暴。

而是：

看：

```
电压利用率
```

例如：

```
Ud

=

2V

Uq

=

6.2V
```

那么：

```
电压矢量：

sqrt(Ud²+Uq²)

≈6.5V
```

接近极限。

于是：

```
Id_ref

慢慢变负。
```

例如：

```c
float U = sqrt(Ud*Ud+Uq*Uq);

if(U > 6.2f)
{
    Id_ref -= 0.01f;
}
else
{
    Id_ref += 0.01f;
}
```

这样：

一直保持：

```
U≈6V
```

这就是很多工业驱动器的思路。

---

# 八、弱磁有没有代价？

有，而且非常明显。

因为：

电磁转矩：

[
T_e=\frac{3}{2}p\left(\psi_fI_q+(L_d-L_q)I_dI_q\right)
]

对于你这种大多数表贴式永磁电机（SPMSM），通常有：

[
L_d \approx L_q
]

于是转矩近似为：

[
T_e \approx \frac{3}{2}p,\psi_f I_q
]

当你通过负 (I_d) 抵消了一部分磁链后，有效磁链减小，同样的 (I_q) 能产生的转矩也会下降。因此弱磁控制本质上是在做一个权衡：

* **优点**：降低反电势，突破基速，提高最高转速。
* **代价**：高速区单位电流产生的转矩变小，效率也可能下降。

所以工业控制里，弱磁一般只在**电压已经成为瓶颈**时才启用，而不会一开始就施加负 (I_d)。

## 九、结合你的系统

根据我们这几天一直讨论的情况：

* VBUS = 12V
* SVPWM 最大 (U_q \approx 6.5V)
* 100KV 电机
* 你已经观察到高速时 (U_q) 接近限幅，而 (I_q) 上不去

**你的系统已经很接近需要弱磁的典型场景。**

不过，在真正加入弱磁之前，我还是建议先确认一件事：**你的电压确实已经到极限。** 最直接的方法就是记录：

```c
Ud
Uq
sqrt(Ud*Ud + Uq*Uq)
Iq
speed
```

如果发现电压矢量长期贴着上限（例如接近 6.5V），而速度继续升高、(I_q) 下降，那么加入负 (I_d) 的弱磁控制就是下一步合理的方向。如果电压其实还没有到上限，那就应该先排查控制环或模型，而不是急着上弱磁。
