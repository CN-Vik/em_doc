你这个问题其实是**设计一块“通用BLDC/PMSM控制器”的核心问题**。

如果你已经有一块 **STM32G431 + 三相MOS桥 + Gate Driver + 电流采样 + AS5600接口** 的FOC板，那么要扩展成：

* ✅ 有感FOC
* ✅ 无感FOC
* ✅ 有感六步方波
* ✅ 无感六步方波

四种模式共存，

**功率部分基本不用改，主要增加“传感器输入”和“无感检测链路”，以及软件切换能力。**

# 六、电流采样是否四种模式都需要？

## FOC：

必须：

```
Ia/Ib/Ic

```

## 有感六步：

可以不用。

## 无感六步：

可以不用。

但是建议保留。

原因：

保护需要：

```
过流
堵转
限流

```

所以：

```
Shunt + INA240

```

不用删。

# 十一、如果按照你之前的目标（STM32G431 + 1~500W）

我建议硬件定位：

* 母线：12~48V
* MOS：80~100V
* 三相电流采样
* Hall接口
* AS5600接口
* BEMF ADC
* 编码器ABZ接口
* CAN/UART
* SWD
* 硬件过流关断

这样一块板基本就是：

> **国产FOC驱动器、机器人关节驱动、电动车小功率控制器的通用架构。**

核心变化不是功率部分，而是把**“反馈链”从单一AS5600扩展成：Hall + Encoder + BEMF 三套反馈体系。**
