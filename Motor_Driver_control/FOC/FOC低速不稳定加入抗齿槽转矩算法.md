先说核心：

> **齿槽转矩补偿的本质：提前知道电机转到某个角度时会产生多大的周期性负载，然后给一个反向电磁转矩去抵消它。**

它不是PID，也不是滤波。

# 1. 齿槽转矩是什么？

永磁同步电机：

```
       永磁转子

        N
     ┌─────┐
     │     │
S ───┤     ├── N
     │     │
     └─────┘

-----------------

      定子齿
   | | | | | | |

```

永磁体希望：

```
磁极中心
    ↓
定子齿中心
```

但是由于磁阻变化：

转子某些角度：

```
磁阻最低
↓
吸引力最大
↓
出现一个阻力
```

所以产生：

$$
T_c(\theta)
$$

即：

```
角度 → 齿槽转矩
```

它具有周期性：

```
角度

0°     30°    60°    90°

 ↑      ↓      ↑      ↓

阻力周期变化
```

# 2. FOC为什么无法自动消除？

FOC控制的是：

$$
T_e=K_t I_q
$$

也就是：

你给Iq：

```

↓

```

但是实际：

总转矩：

$$

$$

其中：

$$
T_c
$$

就是齿槽。

所以：

```
目标:

恒定转矩


实际:

电磁转矩
  |
  |
  |------------
       \
        \__
           \__
齿槽扰动
```

速度出现：

```
快
慢
快
慢
```

# 3. 补偿的数学原理

假设：

齿槽转矩：

$$
T_c(\theta)
$$

那么需要：

$$
T_{comp}(\theta)=-T_c(\theta)
$$

总：

$$
T=T_e+T_{comp}-T_c
$$

如果：

$$
T_{comp}=T_c
$$

那么：

$$
T≈T_e
$$

速度稳定。
