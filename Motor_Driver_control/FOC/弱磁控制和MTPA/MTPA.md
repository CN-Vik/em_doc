可以。MTPA 是 FOC 里一个非常重要、但也特别容易被讲绕的东西。

你先记住一句最核心的话：

> **MTPA = Maximum Torque Per Ampere，单位电流产生最大电磁转矩。**

也就是：

[
\boxed{\text{同样的电机电流，怎么分配 }I_d\text{ 和 }I_q\text{，才能得到最大的转矩？}}
]

它和你刚刚问的**弱磁**关系非常密切，但目标完全不同：

* **MTPA：省电流、提高转矩**
* **弱磁：省电压、提高最高转速**

---

# 1. 先从你熟悉的 FOC 开始

FOC 中电流被分成：

[
I_d
]

和

[
I_q
]

可以粗略理解：

```text
Id → 控制磁链
Iq → 控制转矩
```

对于普通 SPMSM，大家经常直接：

[
I_d=0
]

然后：

[
I_q\rightarrow控制转矩
]

这没问题。

但是对于 **IPMSM**，事情就不一样了。

---

# 2. PMSM 的完整转矩公式

PMSM 电磁转矩：

[
\boxed{
T_e=
\frac32p
\left[
\psi_fI_q+
(L_d-L_q)I_dI_q
\right]
}
]

拆成两部分：

[
T_e=T_{PM}+T_{rel}
]

其中：

### 永磁转矩

[
T_{PM}
======

\frac32p\psi_fI_q
]

### 磁阻转矩

[
T_{rel}
=======

\frac32p(L_d-L_q)I_dI_q
]

---

# 3. 这就是 MTPA 存在的原因

如果：

[
L_d=L_q
]

那么：

[
L_d-L_q=0
]

于是：

[
T_e=
\frac32p\psi_fI_q
]

此时：

> Id 对产生转矩没有额外帮助。

所以：

[
\boxed{I_d=0}
]

就是最优解。

---

# 4. 但是 IPMSM 不一样

典型 IPMSM：

[
L_q>L_d
]

所以：

[
L_d-L_q<0
]

此时如果：

[
I_d<0
]

那么：

[
(L_d-L_q)I_dI_q>0
]

于是产生额外的：

> **磁阻转矩**

这意味着：

```text
以前：

Id = 0
Iq = 1A
     ↓
全部靠永磁转矩


MTPA：

Id < 0
Iq < 1A
     ↓
永磁转矩
+
磁阻转矩
     ↓
同样总电流下
产生更大转矩
```

这就是 MTPA。

---

# 5. 为什么叫“最大转矩/安培”？

假设最大电流：

[
I_s=1A
]

那么：

[
I_d^2+I_q^2=1
]

你可以有很多种分配：

### 方案 A

[
I_d=0
]

[
I_q=1
]

---

### 方案 B

[
I_d=-0.3
]

[
I_q=\sqrt{1-0.3^2}
]

[
I_q=0.954
]

---

### 方案 C

[
I_d=-0.5
]

[
I_q=0.866
]

---

### 方案 D

[
I_d=-0.7
]

[
I_q=0.714
]

虽然这些方案：

[
I_s=1A
]

都一样。

但是产生的：

[
T_e
]

不同。

MTPA 就是在找：

[
\boxed{
\max T_e
}
]

同时满足：

[
I_d^2+I_q^2=I_s^2
]

---

# 6. 从数学上推导 MTPA

令：

[
\Delta L=L_q-L_d
]

因为通常 IPMSM：

[
L_q>L_d
]

所以：

[
\Delta L>0
]

转矩公式可以写成：

[
T_e=
\frac32p
\left[
\psi_fI_q
---------

\Delta L I_dI_q
\right]
]

因为 MTPA 工作区：

[
I_d<0
]

所以第二项实际上增加转矩。

---

# 7. 电流约束

总电流：

[
I_s^2=I_d^2+I_q^2
]

因此：

[
I_q=
\sqrt{I_s^2-I_d^2}
]

代入转矩公式：

[
T_e=
\frac32p
\left[
\psi_f-\Delta L I_d
\right]
\sqrt{I_s^2-I_d^2}
]

现在问题就变成：

> 找一个最优的 (I_d)。

使：

[
T_e
]

最大。

---

# 8. MTPA 的解析解

对上面的式子求极值，可以得到：

[
\boxed{
I_d^*
=====

\frac{
\psi_f-\sqrt{
\psi_f^2+
8\Delta L^2I_s^2
}
}{
4\Delta L
}
}
]

其中：

[
\Delta L=L_q-L_d
]

这个公式非常重要。

所以如果你已经知道：

[
L_d
]

[
L_q
]

[
\psi_f
]

以及：

[
I_s
]

就可以直接算：

[
I_d^*
]

然后：

[
\boxed{
I_q^*=
\sqrt{I_s^2-I_d^{*2}}
}
]

---

# 9. 举一个具体例子

假设某个 IPMSM：

[
L_d=0.5mH
]

[
L_q=1.0mH
]

所以：

[
\Delta L=0.5mH
]

磁链：

[
\psi_f=0.02Wb
]

最大电流：

[
I_s=5A
]

那么：

[
I_d^*
=====

\frac{
0.02-\sqrt{
0.02^2+
8(0.0005)^2(5)^2
}
}{
4(0.0005)
}
]

算出来大约：

[
I_d^*\approx-0.12A
]

然后：

[
I_q^*
=====

\sqrt{5^2-0.12^2}
]

约：

[
I_q^*\approx4.999A
]

这个例子里：

> MTPA 的收益很小。

为什么？

因为：

[
\Delta L
]

相对磁链：

[
\psi_f
]

太小。

---

# 10. 如果凸极性很强，MTPA 就非常有价值

比如：

[
L_d=0.3mH
]

[
L_q=2.0mH
]

那么：

[
L_q-L_d=1.7mH
]

这时候磁阻转矩很明显。

MTPA 就可能要求：

[
I_d=-1A
]

甚至：

[
I_d=-2A
]

而不是：

[
I_d=0
]

这时候收益就很大。

---

# 11. 所以 SPMSM 和 IPMSM 的区别特别重要

## SPMSM

通常：

[
L_d\approx L_q
]

所以：

[
T_e\approx
\frac32p\psi_fI_q
]

最佳：

[
\boxed{I_d\approx0}
]

---

## IPMSM

通常：

[
L_q>L_d
]

因此：

[
\boxed{I_d<0}
]

能够产生额外磁阻转矩。

所以：

> **MTPA 主要是为 IPMSM 服务的。**

---

# 12. 这和弱磁到底有什么区别？

这个非常重要。

### MTPA

目标：

[
\boxed{\max\frac{T}{I}}
]

也就是：

> **同样的电流，尽可能产生最大的转矩。**

---

### 弱磁

目标：

[
\boxed{\text{降低所需电压}}
]

也就是：

> **同样的转速下，想办法让逆变器电压够用。**

---

所以：

```text
                    FOC
                     │
          ┌──────────┴──────────┐
          │                     │
        低速                    高速
          │                     │
        MTPA                  弱磁
          │                     │
    最优 Id/Iq             负 Id 越来越大
          │                     │
     最大转矩/电流           最大化转速
```

---

# 13. 更准确地说：MTPA 并不是“只有低速”

MTPA 主要受：

> **电流约束**

支配。

弱磁主要受：

> **电压约束**

支配。

所以整个 PMSM 控制其实可以看成：

```text
低速
 │
 │ 电流受限
 │
 │   MTPA
 │
 ├──────── 基速 ─────────
 │
 │ 电压开始受限
 │
 │   MTPA + 弱磁
 │
 ├──────────────────────
 │
 │ 电压严重受限
 │
 │   弱磁 / MTPV
 │
 └──────────────────────→ 转速
```

工业控制器通常不是简单的：

> 低速 MTPA，高速突然切弱磁。

而是平滑过渡。

---

# 14. MTPA 最简单的工程实现

有三种常见方法。

---

## 方法一：解析公式

直接使用刚才的：

[
I_d^*
=====

\frac{
\psi_f-\sqrt{
\psi_f^2+
8(L_q-L_d)^2I_s^2
}
}{
4(L_q-L_d)
}
]

然后：

[
I_q^*=
\sqrt{I_s^2-I_d^{*2}}
]

优点：

> 计算简单。

缺点：

> 参数不准时，最优点会偏。

---

# 15. 方法二：查表 LUT

这是工程里很常见的方法。

提前离线计算：

```text
Iq / Is
     │
     │
     │
     └──────── Id / Is
```

例如：

| (I_s) | (I_d^*) |
| ----: | ------: |
|  0.1A |  -0.01A |
|  0.2A |  -0.02A |
|  0.3A |  -0.04A |
|  0.5A |  -0.08A |
|  0.8A |  -0.15A |
|  1.0A |  -0.22A |
|  1.5A |  -0.35A |

运行时：

[
I_s
]

查表得到：

[
I_d^*
]

再计算：

[
I_q^*
]

---

# 16. LUT 比公式更适合真实电机

因为真实电机：

[
L_d=L_d(I_d,I_q)
]

[
L_q=L_q(I_d,I_q)
]

并不是固定值。

所以可以通过实验：

```text
Id
Iq
Torque
```

得到实际 MTPA 曲线。

甚至建立：

[
I_d^*=f(I_q)
]

查表。

这比单纯使用理论公式更准确。

---

# 17. 方法三：在线搜索最优点

这个方法很有意思。

假设当前：

[
I_s=1A
]

你让：

[
I_d
]

从：

[
0
]

慢慢变成：

[
-0.1A
]

然后：

[
-0.2A
]

[
-0.3A
]

每个点计算或者测量实际转矩。

例如：

|   Id |    Iq | Torque |
| ---: | ----: | -----: |
|    0 |  1.00 |  0.010 |
| -0.1 | 0.995 |  0.011 |
| -0.2 | 0.980 |  0.012 |
| -0.3 | 0.954 | 0.0125 |
| -0.4 | 0.916 | 0.0123 |

那么：

[
I_d=-0.3A
]

就是附近最优点。

这叫：

> **在线 MTPA 搜索/极值寻优。**

---

# 18. 但在线搜索有一个问题

如果直接改变 Id：

```text
Id = -0.1
Id = -0.2
Id = -0.3
```

电机转矩会变化。

所以可能造成：

> 转速波动。

因此实际工程里通常不会这么暴力地扫。

可以通过：

> **高频小扰动 + 转矩/功率反馈 + 极值寻优**

来做。

不过对于你现在的项目：

> **完全没必要一上来做这么复杂。**

---

# 19. 你现在最适合：解析公式 + LUT

你的 ESP32 完全可以：

### 第一阶段

使用：

[
L_d,L_q,\psi_f
]

算理论 MTPA。

### 第二阶段

实际测试：

```text
Id
Iq
RPM
Iq PID输出
```

校正 MTPA 曲线。

### 第三阶段

做成 LUT。

这是最实用的。

   ↓

   ↓

   ↓

   ↓

# 21. 但是实际还要加“电流限制”

假设速度环给：

[
I_q^*=2A
]

最大电流：

[
I_{max}=1A
]

那显然不能直接执行。

应该先：

[
I_s^*=clip(I_q^*,I_{max})
]

然后 MTPA：

[
I_d^*=f(I_s^*)
]

[
I_q^*
=====

\sqrt{I_s^{*2}-I_d^{*2}}
]

---

# 22. 还有一个特别重要的问题：转矩控制时不要直接拿 Iq 当转矩

你之前也问过这个问题。

对于 IPMSM：

[
T=
\frac32p[
\psi_fI_q+
(L_d-L_q)I_dI_q
]
]

所以：

> MTPA 后 (I_d\neq0)，此时“转矩 ≈ Kt×Iq”的简单关系不再完全成立。

应该根据：

[
T^*
]

反算：

[
I_d^*,I_q^*
]

这才是真正的：

> **Torque → MTPA → Id/Iq**

---

# 23. 从目标转矩直接计算 MTPA

目标：

[
T^*
]

MTPA 同时满足：

[
T^*
===

\frac32p[
\psi_fI_q+
(L_d-L_q)I_dI_q
]
]

以及：

[
I_d^2+I_q^2=I_s^2
]

实际工程里通常：

1. 根据 (T^*) 找所需 (I_s)
2. 根据 (I_s) 查 MTPA 曲线
3. 得到 (I_d^*)
4. 得到 (I_q^*)

而不是每次 MCU 里做复杂方程求解。

---

# 24. 为什么 MTPA 对你的 2208 可能几乎没用？

这是你最应该注意的一点。

你之前这个电机：

> 2208-80T，12 槽 14 极

如果它属于典型：

> **SPMSM / 表贴式 BLDC**

那么大概率：

[
L_d\approx L_q
]

于是：

[
L_d-L_q\approx0
]

转矩：

[
T\approx
\frac32p\psi_fI_q
]

此时 MTPA 最优：

[
\boxed{I_d\approx0}
]

也就是说：

> **你给负 Id，并不能凭空获得多少额外磁阻转矩。**

反而：

[
I_d<0
]

会浪费电流容量。

# 25. 举个非常直观的对比

假设：

[
I_{max}=1A
]

### SPMSM

[
Id=0
]

[
Iq=1A
]

转矩：

[
T=K_t
]

---

如果你强行：

[
Id=-0.5A
]

那么：

[
Iq=0.866A
]

由于：

[
L_d\approx L_q
]

磁阻转矩几乎没有。

所以：

[
T\approx0.866K_t
]

反而：

> **转矩下降了约 13.4%。**

# 26. IPMSM 就完全不同

如果：

[
L_d=0.5mH
]

[
L_q=2mH
]

那么：

[
L_d-L_q=-1.5mH
]

此时：

[
Id<0
]

会带来额外：

[
T_{rel}
]

所以：

```text
SPMSM：

负 Id
 ↓
主要是浪费电流
```

而：

```text
IPMSM：

负 Id
 ↓
磁阻转矩增加
 ↓
同样电流得到更大转矩
```

# 27. MTPA 和弱磁可以共存

这点非常重要。

实际完整控制：

```text
                    转速
                      │
          ┌───────────┴───────────┐
          │                       │
       基速以下                 基速以上
          │                       │
        MTPA                  MTPA + 弱磁
          │                       │
      Id = MTPA值            Id = MTPA + FW
          │                       │
          └───────────┬───────────┘
                      ↓
                  Id / Iq
                      ↓
                    FOC
```

也就是说高速的时候：

[
I_d^*
=====

I_{d,MTPA}^*
+
I_{d,FW}^*
]

这是一个非常实用的工程结构。

---

# 28. 但是弱磁和 MTPA 的 Id 不能简单乱加

更准确地说应该满足：

[
I_d^*
=====

\max(
I_{d,MTPA},
I_{d,FW}
)
]

因为两者都是负数。

例如：

[
I_{d,MTPA}=-0.2A
]

弱磁要求：

[
I_{d,FW}=-0.5A
]

最终：

[
I_d^*=-0.5A
]

因为高速时必须满足电压限制。

I_d^*
=====

\frac{
\psi_f-\sqrt{
\psi_f^2+
8(L_q-L_d)^2I_s^2
}
}{
4(L_q-L_d)
}
}
]

---

### 最关键的结论

**MTPA 并不是“负 Id 就叫 MTPA”。**

真正的 MTPA 是：

> **在给定总电流 (I_s) 下，通过合理分配 (I_d/I_q)，让电磁转矩最大。**

而负 Id 之所以出现，是因为对于典型 IPMSM：

[
L_q>L_d
]

负 (I_d) 可以产生磁阻转矩。

对于你这个 **2208-80T**，如果它确实是接近 SPMSM 的结构，那么大概率：

[
L_d\approx L_q
]

因此 **MTPA 基本就是 (I_d=0)**；你真正值得研究的是前面说的**弱磁**。
