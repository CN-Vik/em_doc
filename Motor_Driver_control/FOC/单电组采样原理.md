你现在做 ESP32 FOC，用的是 **双电阻/三电阻思路（INA240采样相电流）**，如果理解单电阻，会对 FOC 底层理解提升很大。

最简单。

```

         |
      U上管
         |
         +------ U相
         |
      U下管
         |
        Rshunt
         |
        GND


      V相

      W相
```

```
       U相
        |
       R
        |

       V相
        |
       R
        |
       ADC


       W相
        |
       R
        |
       ADC
```

```

```

FOC（磁场定向控制）的电流采样确实是一个非常核心且充满技术细节的环节。要搞清楚单电阻采样，我们先得知道一个大前提：**三相电机的电流满足基尔霍夫定律，即 $I_a + I_b + I_c = 0$。** 也就是说，只要我们能测出任意两相的电流，就能算出第三相。

单电阻采样，就是**用一个电阻，通过“时间管理大师”般的操作，在极短的时间内分两次测出两相的电流**。

### 1. 单电阻采样的原理：分时采样

在硬件上，单电阻方案只在**直流母线（DC Bus）的负极回路上**串联一个采样电阻。

**它是怎么用一个电阻测出两相的？核心在于 SVPWM（空间矢量脉宽调制）的状态切换。**
在SVPWM的一个 PWM 周期内，逆变器的6个开关管会组合出不同的状态。单电阻方案正是利用特定的“有效矢量”状态，让母线电流恰好等于某相电流。

举个例子（假设当前 PWM 波形处于第 I 扇区）：

1. **状态一（矢量 100）**：A相上桥臂导通，B、C相下桥臂导通。电流从正极流出，只经过A相进入电机，再从B、C相流出，最后全部流经母线负极的采样电阻。此时，**母线电流 $I_{bus} = I_a$**。我们在这一刻触发 ADC 采样，就抓到了 $I_a$。
2. **状态二（矢量 110）**：A、B相上桥臂导通，C相下桥臂导通。电流从A、B相进入电机，全部从C相流出，最后流经母线负极。此时，**母线电流 $I_{bus} = -I_c$**。我们在这一刻再次触发 ADC 采样，就抓到了 $-I_c$。

有了 $I_a$ 和 $I_c$，利用 $I_a + I_b + I_c = 0$ 这个公式，就能算出 $I_b$。在一个 PWM 周期内通过不同时刻的两次采样，就完成了三相电流的重构。

---

### 2. 单电阻如何实现？（难点解析）

单电阻方案的硬件最简单，但**软件算法极其复杂**。要实现它，必须跨过以下三道坎：

1. **硬件选型:** 天下武功唯快不破.
因为有效矢量的持续时间可能非常短，要求运放（Op-Amp）必须具备高带宽和高压摆率（Slew Rate），能让信号瞬间建立；同时微控制器（MCU）的 ADC 转换速度也必须足够快。


2. **PWM与ADC的精准同步:** 掐表采样.
软件必须精确计算出每个 PWM 周期内两个“有效矢量”的中点时刻，并在此时刻精准触发 ADC。早一点或晚一点，都会采集到开关管切换时产生的巨大电磁干扰毛刺。


3. **攻克“采样盲区”难题:** 最核心的技术壁垒.
当电机在极低速运行，或者矢量正好经过扇区边界时，某些有效矢量的作用时间会**非常非常短**。短到不足以覆盖“硬件死区时间 + 运放稳定时间 + ADC转换时间”。此时 ADC 根本来不及采样，这就是**采样盲区**。

解决办法通常是采用**不对称PWM注入法（相移法）**或**最小脉宽限制法**：强行把短脉冲拉长（凑够采样时间），同时在周期的其他位置把多出来的电压减掉，以此保证电机运行平稳。


---

### 3. 三种采样方式的效果与区别

在实际应用中，单电阻、双电阻和三电阻各有千秋，本质上是**成本与软件复杂度之间的博弈**。

| 对比维度 | 单电阻 (Single-Shunt) | 双电阻 (Dual-Shunt) | 三电阻 (Triple-Shunt) |
| --- | --- | --- | --- |
| **电阻位置** | 1个（位于直流母线负极） | 2个（位于两相的下桥臂） | 3个（位于三相的下桥臂） |
| **硬件成本** | **最低** | 中等 | 最高 |
| **软件复杂度** | **地狱级**（需处理盲区和复杂的移相算法） | 中等 | **最简单**（三相独立，随心所欲） |
| **低速/重载性能** | 较差（受盲区影响大，低频噪音和震动相对明显） | 良好 | **极佳** |
| **高速/高调制比性能** | 良好（高速时有效矢量变宽，反而好采） | 较差（高转速时下桥臂导通时间变短，会出现双电阻特有的盲区） | **极佳** |
| **应用场景** | 成本极度敏感、空间受限的家电（如空调压缩机、水泵、吹风机、吸尘器） | 兼顾成本与性能的主流选择（如电动工具、两轮车、常规工业控制） | 追求极致平顺性和动态响应（如高端伺服系统、汽车主驱） |

**总结一下：**
单电阻采样是在硬件上把成本抠到了极致，逼着软件工程师用极其复杂的算法去弥补。如果你在做对成本极其敏感的消费级产品，单电阻是必杀技；如果是做对控制性能要求较高的项目，双电阻甚至是三电阻会让你少掉很多头发。
