# FOC 三闭环串级PID控制：结构、流程与整定方法
FOC的三闭环串级控制，核心逻辑是**从内到外嵌套：电流环 → 速度环 → 位置环**。外环的输出直接作为内环的目标设定值，内环负责快速跟踪执行、抑制底层扰动，外环负责精准控制宏观状态，层层配合实现高精度、高稳定性的电机控制。

---

## 一、串级控制的整体架构
三个环严格遵循「内快外慢、内环执行、外环决策」的层级关系，结构如下：
```
目标位置 → 【位置PID】 → 目标速度 → 【速度PID】 → 目标电流(Iq) → 【电流PID(Id/Iq)】 → park+clark逆变换 → SVPWM →PWM →电机
    ↑                          ↑                          ↑
    |                          |                          |
编码器位置反馈          编码器速度反馈              三相电流采样反馈(【ia+ib+ic】→ clark变换 → Iα,Iβ → park变换 → iq,id)
```

### 为什么必须用串级结构，而不是单环？
串级控制的核心优势是**内环抗扰，外环精准**：
- 负载突变、母线电压波动、绕组发热等扰动，最先影响电流，最内环的电流环可以在微秒级快速修正，扰动几乎不会传导到速度、位置环。
- 外环只需要关注宏观目标，不需要处理底层细节，系统稳定性和响应速度远优于单环控制。

---

## 二、每个环的作用与PID配置
### 1. 最内环：电流环（双独立PID：Id环 + Iq环）
电流环是整个FOC系统的执行核心，响应速度最快，直接决定转矩控制的精度。
- **输入**
  - 设定值：`Id_ref`（表贴式电机默认固定为0，实现最大转矩/电流比）；`Iq_ref`（来自速度环的输出，对应转矩指令）
  - 反馈值：实际`Id`、`Iq`（三相电流经Clark、Park变换得到）
- **输出**：`Vd`、`Vq`（d/q轴电压指令）
- **控制目标**：让定子电流快速跟随目标值，精准控制输出转矩；同时限制最大电流，保护电机和驱动板。
- **PID形式**：几乎都用**PI控制器**，不使用D项。
  原因：电流采样自带开关噪声，D项会放大噪声导致PWM抖动；且电流响应极快，PI即可实现无静差跟随。
- **执行频率**：与PWM载波完全同步（通常10~20kHz），是系统最高频环节。

### 2. 中间环：速度环
承上启下的环节，负责转速的稳定与跟随。
- **输入**
  - 设定值：`speed_ref`（来自位置环的输出，转速指令）
  - 反馈值：实际转速（由编码器位置差分计算，或状态观测器输出）
- **输出**：`Iq_ref`（转矩电流指令，作为电流环的给定值）
- **控制目标**：稳定电机转速，抵抗负载扰动，实现转速无静差。
- **PID形式**：**PI控制器为主**，对平稳性要求高的场景可加微量D项抑制震荡。
- **执行频率**：通常为电流环的1/5 ~ 1/10（比如1~2kHz），必须远低于电流环带宽。

### 3. 最外环：位置环
最终的控制目标层，负责精准定位。
- **输入**
  - 设定值：`position_ref`（目标位置/角度）
  - 反馈值：实际机械位置（磁编码器/光电编码器的绝对角度）
- **输出**：`speed_ref`（转速指令，作为速度环的给定值）
- **控制目标**：精准控制转子的最终位置，实现定位控制。
- **PID形式**：**PD或P控制器为主**，积分项慎用。
  原因：位置环对超调极其敏感，积分容易导致定位震荡、过冲；只有对静态精度要求极高的场景，才加极微量I项。
- **执行频率**：通常为速度环的1/5 ~ 1/10（比如100~200Hz），是三个环里频率最低的。

## 三、完整的控制执行时序
串级控制必须严格遵循「先内环、后外环」的执行顺序，且频率由内到外逐层降低。以10kHz PWM载波为例，典型工程实现时序：

### 1. 最高优先级：PWM中断（10kHz，每100μs执行）
电流环必须放在中断里，保证实时性：
1. 硬件触发ADC采样三相电流，同步读取编码器当前机械角度
2. 执行Clark变换、Park变换，计算得到当前实际`Id`、`Iq`
3. 读取全局变量中的`Iq_ref`（速度环输出），`Id_ref`固定为0
4. 分别执行`Id_PI`、`Iq_PI`计算，输出`Vd`、`Vq`，并做电压限幅
5. 执行反Park变换、SVPWM计算，更新PWM比较寄存器
6. 计数累加，每执行10次电流环（1ms到），触发速度环执行标志

### 2. 中优先级：速度环（1kHz，每1ms执行）
可放在高优先级任务中，或在PWM中断里分时执行：
1. 根据两次编码器位置差，计算当前实际转速，做一阶低通滤波
2. 读取全局变量中的`speed_ref`（位置环输出）
3. 执行速度PI计算，输出`Iq_ref`，并做电流限幅（不超过电机额定电流）
4. 将`Iq_ref`更新到全局变量，供电流环使用
5. 计数累加，每执行10次速度环（10ms到），触发位置环执行标志

### 3. 低优先级：位置环（100Hz，每10ms执行）
可放在普通任务中执行：
1. 读取编码器当前绝对位置
2. 读取目标位置`position_ref`
3. 执行位置PD计算，输出`speed_ref`，并做转速限幅（不超过电机最大转速）
4. 将`speed_ref`更新到全局变量，供速度环使用

## 四、串级PID参数整定方法（从内到外，逐层整定）
串级PID绝对不能从外环开始调，必须先把内环调稳，再接入外环，否则系统必然震荡。

### 第一步：整定电流环（断开外环，开环给定电流）
1. 断开速度环，手动给`Iq_ref`一个小幅阶跃值（比如额定电流的10%）
2. I项设为0，从小到大增加P值：直到电流反馈出现小幅高频震荡，然后将P值减半
3. 从小到大增加I值：直到电流能快速跟上阶跃指令，无静差、无明显超调
4. 验证标准：阶跃电流上升时间在几百微秒级，超调＜5%
5. 注意：表贴式电机d、q轴参数对称，Id环和Iq环参数可设为一致

### 第二步：整定速度环（接入电流环，断开位置环）
1. 固定电流环参数，断开位置环，手动给`speed_ref`一个阶跃值
2. I项设为0，从小到大增加P值：直到转速出现小幅震荡，P值减半
3. 增加I值：直到转速无静差，负载突变时能快速恢复稳定
4. 可选优化：加微量D项抑制转速波动，但D不能太大，否则会放大噪声
5. 验证标准：阶跃转速超调＜10%，负载扰动后恢复时间短

### 第三步：整定位置环（接入速度环，完整三闭环）
1. 固定速度环参数，给`position_ref`一个阶跃位置指令
2. 先只加P项：增大P直到定位出现震荡，然后P值减到1/2~2/3
3. 若定位有过冲、震荡：增加D项提供阻尼，直到定位平稳
4. 若静态有位置误差：可加极微量I项，或直接用前馈补偿
5. 验证标准：阶跃定位无过冲（或过冲＜5%），定位精准无静差

## 五、串级控制的关键避坑点
### 1. 带宽必须拉开，内环远快于外环
这是串级系统稳定的核心前提：
**电流环带宽 ≥ 5~10倍速度环带宽，速度环带宽 ≥ 5~10倍位置环带宽**。
通俗理解：电流环是“手”，速度环是“胳膊”，位置环是“大脑”，手的动作必须比胳膊快，胳膊比大脑快，才能精准控制。如果外环响应比内环还快，系统会直接震荡失稳。

### 2. 每一环都必须加输出限幅 + 抗积分饱和
- **输出限幅（保护硬件+防止失控）**
  - 位置环输出：限幅为电机最大允许转速
  - 速度环输出：限幅为电机/驱动的最大持续电流
  - 电流环输出：限幅为SVPWM线性调制区最大电压（约 母线电压 / √3）
- **抗积分饱和（防止严重超调）**
  当PID输出达到限幅值时，立即停止积分项的累加，否则积分会持续“饱和”，导致超调严重、恢复缓慢。最简单的实现：判断输出是否达到上下限，若是则不累加本次积分。

### 3. 反馈信号滤波要适度
- 电流采样：加一阶低通滤波，截止频率设为PWM频率的1/5~1/10，滤除开关噪声
- 速度计算：编码器差分天生带噪声，可加滑动平均或一阶低通，但滤波不能太重，否则会增加延迟，降低速度环带宽
- 原则：在可接受的噪声范围内，滤波越轻越好，优先保证响应速度

### 4. 进阶优化：加入前馈控制
如果对跟随精度要求高，可在外环加入前馈，不影响稳定性的同时大幅减小跟随误差：
- 位置环：加入**速度前馈**，将目标速度直接叠加到位置环输出
- 速度环：加入**电流前馈**，将目标转矩电流直接叠加到速度环输出

## 六、平衡车场景的适配
你之前关注的平衡车，本质是三闭环的变体：
- 最外环不是普通位置环，而是**姿态倾角环**（目标是保持车身直立，倾角为0），本质还是角度位置环
- 中间环是车身速度环，最内环仍是电机电流环
- 整定逻辑完全一致：先调电流环，再调速度环，最后调姿态环，带宽逐层拉开
