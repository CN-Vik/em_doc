FOC 无感控制（Sensorless FOC）的核心目标其实只有一个：

> **不用编码器/霍尔，靠电机电压、电流信息估计转子电角度 θe 和速度 ωe，然后完成 Park 变换和速度闭环。**

你现在用 AS5600：

```
AS5600
  |
  v
机械角度 θm
  |
×极对数
  |
电角度 θe
  |
FOC
```

无感 FOC 就是把：

```
AS5600
```

替换成：

```
无感位置观测算法
```

# 二、无感算法主要有哪些？

工业里面主要有：

1. **反电动势观测器（BEMF Observer）**
2. **滑模观测器 SMO（Sliding Mode Observer）**
3. **扩展卡尔曼滤波 EKF**
4. **模型参考自适应 MRAS**
5. **Luenberger Observer（龙伯格观测器）**
6. **高频注入 HFI（High Frequency Injection）**
7. **磁链观测器 Flux Observer**
8. **PLL锁相环估计器**

下面逐个讲。

---

# 1. 反电动势观测器 BEMF Observer

最早也是最直观。

电机模型：

$$
U=Ri+L\frac{di}{dt}+E
$$

所以：

$$
E=U-Ri-L\frac{di}{dt}
$$

得到：

```
电压
 |
减去
 |
电阻压降
 |
电感压降
 |
得到反电动势
```

然后：

```
Eα
Eβ

atan2

θe
```

优点：

* 简单
* 计算量小

缺点：

低速不行：

因为：

$$
E=K_e\omega
$$

速度低：

```
反电动势≈0
```

所以：

一般：

> 中高速使用

---

# 2. SMO 滑模观测器

你刚问的。

结构：

```
电流误差

I-Ihat

    |
    v

sign()

    |
    v

估计反电动势
```

特点：

优点：

✅ 抗参数变化强
✅ 抗扰动强
✅ 工业应用多

缺点：

❌ 抖振
❌ 低速困难

改进：

* Saturation SMO
* Super Twisting SMO

应用：

TI：

* InstaSPIN

ST：

* MCSDK Sensorless

很多工业FOC：

SMO + PLL

# 3. PLL锁相环（重点）

PLL不是观测器。

它负责：

> 把一个抖动的角度变成平滑角度。

比如：

SMO输出：

```
13°

14°
```

PLL：

输出：

```

11°

```

结构：

```
θ误差

 |
 PI

 |
ω

 |
积分

 |
θ
```

数学：

$$
\theta=\int \omega dt
$$

工业组合：

```
SMO

+

PLL
```

非常常见。

# 5. EKF 扩展卡尔曼滤波

这是高级算法。

把电机看成：

状态：

# 8. 磁链观测 Flux Observer

转子磁链。

公式：

$$
\psi=\int(U-RI)dt
$$

然后：

磁链角度：

$$
\theta=atan2(\psi_\beta,\psi_\alpha)

问题：

积分漂移。

需要：

* 低通
* 高频补偿

对，你说得对。**TI 的 FAST 确实是无感 FOC 里面非常有代表性的算法**，而且它和我前面讲的 SMO、EKF 属于同一层级的东西——都是**转子位置/速度估计器（Estimator）**。

刚才没有单独列 FAST，是因为 FAST 是 **TI 自家的商业闭源算法名称**，不是一个公开的通用算法类别。

---

# 1. FAST 是什么？

FAST 全称：

**Flux, Angle, Speed, Torque**

也就是：

* **Flux**：磁链估计
* **Angle**：转子电角度估计
* **Speed**：速度估计
* **Torque**：转矩估计

它是 TI InstaSPIN-FOC 里面的核心。

结构大概：

```
        三相电流
           |
           |
        Clarke
           |
           |
        Iαβ
           |
           |
    +----------------+
    |                |
    |     FAST       |
    |                |
    +----------------+
           |
           |
    ------------------
    |        |       |
    θe       ωe      Flux
    |
    |
   Park
    |
    |
   FOC
```

---

# 2. FAST 和 SMO 的区别

很多人会误认为：

> FAST = SMO？

不是。

它们思想完全不同。

## SMO

滑模观测器：

基于：

$$
U=Ri+L\frac{di}{dt}+E
$$

核心：

估计反电动势。

流程：

```
电压
 |
电流模型
 |
误差
 |
滑模
 |
BEMF
 |
atan2
 |
角度
```

---

## FAST

更接近：

**电机数学模型 + 状态估计**

它估计：

```
定子磁链
转子磁链
转子角度
速度
转矩
```

不是简单估计反电动势。

---

# 3. FAST里面核心思想是什么？

> **SMO 是“通过电流误差估计反电动势”；FAST 是“通过电机模型估计磁链、角度、速度、转矩”。两者目标一样，都是替代编码器，但FAST是TI针对电机控制高度优化的商业级估计器。**
