### 一句话总结 SMO：

> **SMO（滑模观测器）的核心就是：利用电机电压、电流模型，通过“估计电流”和“实际电流”的误差，反推出反电动势，再根据反电动势方向得到转子电角度。**

也就是：

**测电流 → 建电机模型 → 观察误差 → 提取反电势 → atan2得到角度**

---

# 1. SMO整体流程

FOC里：

已知：

* 三相电流采样：

$$
i_a,i_b,i_c
$$

经过Clarke：

$$
i_\alpha,i_\beta
$$

已知：

* SVPWM输出电压：

$$
u_\alpha,u_\beta
$$

输入SMO：

```
        Uα Uβ
         |
         |
         v
     +---------+
     |   SMO   |
     +---------+
         |
         |
      Eα Eβ
         |
         |
      atan2()
         |
         |
     电角度θe
```

# 2. SMO核心数学思想

电机αβ模型：

$$
u=Ri+L\frac{di}{dt}+E
$$

展开：

$$
E=u-Ri-L\frac{di}{dt}
$$

问题：

$$
\frac{di}{dt}
$$

不好直接测。

所以SMO建立一个：

## 电流观测模型

预测：

$$
\hat{i}
$$

实际：

$$
i
$$

比较：

$$
\Delta i=i-\hat{i}
$$

---

如果：

预测电流：

```
100mA
```

实际：

```
150mA
```

说明：

模型少算了一部分电压。

这个误差里面：

包含：

$$
E_\alpha,E_\beta
$$

---

# 3. SMO的灵魂：滑模误差反馈

核心就是：

$$
e=i-\hat{i}
$$

通过：

$$
sign(e)
$$

产生补偿：

$$
z=K_s sign(e)
$$

简单理解：

```
误差大
 |
 |
强力拉回

误差小
 |
 |
轻微修正
```

类似：

汽车自动纠偏：

偏左：

猛打方向

偏小：

微调。

---

# 4. 为什么叫“滑模”？

因为它希望：

误差：

$$
e
$$

快速进入：

$$
e=0
$$

这个面。

例如：

```
误差

  |
5 |
  |
1 |
  |
0 |================  滑模面
  |
-1|
```

一旦进入：

系统就沿着这个面滑动。

所以：

叫：

**Sliding Mode Observer**

---

# 5. SMO怎么得到电角度？

SMO最后得到：

$$
E_\alpha,E_\beta
$$

也就是：

反电势矢量：

```
        Eβ

         |
         |
         |    *
         |  /
         |/
---------+---------- Eα

```

角度：

$$
\boxed{
\theta_e=
atan2(E_\beta,E_\alpha)
}
$$

这就是电角度。

---

# 6. SMO真正的灵魂在哪里？

不是atan2。

也不是公式。

核心只有一句：

> **利用电流误差逼近反电势，把不可测的磁链信息隐藏在电流误差里，通过滑模反馈把它提取出来。**

换句话：

普通方法：

```
电压
 +
电流
 ↓
计算磁链
 ↓
角度
```

SMO：

```
电压
 +
电流
 ↓
预测电流

预测 vs 实际

误差里面包含反电势

 ↓

提取Eα/Eβ

 ↓

角度
```

# 7. SMO参数怎么调？

主要几个参数：

---

## ① 滑模增益 Ks

最重要：

```c
smo.Kslide
```

作用：

误差纠正力度。

---

### Ks太小：

```
误差:

慢慢收敛
```

表现：

* 角度滞后
* 高速跟不上

---

### Ks太大：

```
误差:

\/\/\/\/
```

表现：

* 抖振
* 电流噪声大
* 角度跳动

---

调节：

从小开始增加：

例如：

```
Ks:

0.05

0.1

0.2

0.5
```

找到：

既能跟踪，又不震荡。

---

# 8. ② 边界层参数

实际不用：

$$
sign(x)
$$

因为：

会产生抖振。

改：

$$
sat(x)
$$

例如：

```c
if(x>h)
 return 1;

else if(x<-h)
 return -1;

else
 return x/h;
```

参数：

$$
h
$$

---

h太小：

接近sign：

```
噪声大
```

h太大：

```
响应慢
```

---

一般：

$$
0.01~0.1
$$

---

# 9. ③ 电机参数

SMO依赖：

# 11. SMO和PLL分工

这个非常重要：

```
SMO:

负责发现方向

"反电势在哪里？"


PLL:

负责稳定跟踪

"角度应该怎么平滑走？"
```

所以：

SMO：

像眼睛。

PLL：

像大脑。

---

结合你的ESP32 + 2208：

推荐结构：

```
ADC采样
 |
Clarke
 |
SMO
 |
Eα Eβ
 |
低通滤波
 |
PLL
 |
θe
 |
Park变换
 |
FOC
```

最终记住：

**SMO灵魂：用电流误差逼出反电势。**

**PLL灵魂：让角度追踪反电势相位。**

两者组合才是工业无感FOC最经典方案。**你之前SMO单独跑电机“嗡嗡响”，本质原因就是：SMO给出了一个抖动角度，但没有PLL把它变成稳定连续的电角度。**
