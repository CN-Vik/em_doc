滑模控制（Sliding Mode Control，SMC）在 FOC 里面非常常见，尤其是：

* **无感 FOC 转子位置估计**
* **滑模观测器（SMO，Sliding Mode Observer）**
* **滑模速度控制**
* **抗负载扰动控制**

你现在做 ESP32 + AS5600 + FOC，其实最容易接触的是 **滑模观测器 SMO 做无感位置估计**。我从 FOC 新手角度讲。

---

# 1. 先理解：为什么需要滑模？

FOC 最核心的问题：

> 我知道三相电流，但是不知道转子在哪里。

比如：

```
U相电流
V相电流  ---> Clarke ---> αβ电流
W相电流

                |
                v

             Park变换

                |
                v

            Id/Iq
```

但是 Park 变换需要：

```
θe 电角度
```

没有角度：

```
abc电流
    |
    |
 Clarke
    |
 αβ电流
    |
 Park
    |
 错误
```

所以无感 FOC 需要估计：

```
转子角度 θe
转速 ωe
```

滑模观测器就是干这个的。

---

# 2. 普通观测器有什么问题？

电机数学模型：

永磁同步电机 PMSM：

$$
U_\alpha = R_s i_\alpha + L_s\frac{di_\alpha}{dt}+e_\alpha
$$

其中：

* Uα：α轴电压
* iα：α轴电流
* Rs：电阻
* Ls：电感
* eα：反电动势

整理：

$$
e_\alpha=U_\alpha-R_si_\alpha-L_s\frac{di_\alpha}{dt}
$$

理论上：

测电流

↓

算：

$$
\frac{di}{dt}
$$

↓

得到反电动势

然后：

$$
e_\alpha,e_\beta
$$

求角度：

$$
\theta_e=atan2(e_\beta,e_\alpha)
$$

问题来了：

实际：

ADC有噪声：

```
真实电流:

        /\/\/\/


ADC:

      ~~~~~~~~~~
```

微分：

$$
\frac{di}{dt}
$$

会无限放大噪声。

所以普通观测器不好用。

# 3. 滑模的核心思想

一句话：

> 不精确知道系统，但是强行把误差压到一个滑动面上。

比如：

目标：

```
估计电流 i_hat

        |
        |
        v

真实电流 i
```

误差：

$$
e=i-\hat{i}
$$

希望：

$$
e=0
$$

定义滑模面：

$$
S=e
$$

然后设计控制：

让：

$$
S\rightarrow0
$$

# 6. FOC里面滑模观测器怎么用？

PMSM：

建立：

αβ数学模型：

$$
\dot i_\alpha=
-\frac{R}{L}i_\alpha+
\frac1L(U_\alpha-e_\alpha)
$$

建立估计：

$$
\dot{\hat i}*\alpha=
-\frac RL\hat i*\alpha+
\frac1L(U_\alpha-\hat e_\alpha)
$$

两个相减：

得到误差：

$$
\tilde i=i-\hat i
$$

然后：

设计：

$$
\hat e=K \cdot sign(i-\hat i)
$$

也就是：

```
真实电流

      |
      |
      v

   差值


      |
      |
  sign函数


      |
      |
估计反电动势
```

你这个问题问到了**无感FOC最关键的地方**。很多刚接触 SMO 的人都会卡在这里。

先给结论：

1. **SMO 输出的角度不一定是 -0.5π ~ +0.5π，通常是 `-π~π` 或 `0~2π` 的电角度。**
2. **FOC 内部用的是电角度，不一定要求 0~2π，-π~π完全可以。**
3. **电角度不能直接得到机械角度，需要知道极对数。**
4. **速度环需要机械速度，所以需要对机械角度求导，或者直接从电角速度换算。**

下面详细讲。

---

# 1. SMO输出到底是什么角度？

滑模观测器得到：

$$
e_\alpha
$$

$$
e_\beta
$$

反电动势空间矢量：

```
          β

          |
          |
          |
----------+---------- α


          θe
```

角度：

$$
\theta_e=atan2(e_\beta,e_\alpha)
$$

注意：

C语言：

```c
atan2f(y,x)
```

返回：

$$
-\pi \sim +\pi
$$

也就是：

```
-180° ~ +180°
```

不是：

```
-90°~+90°
```

你可能把：

atan：

$$
-\frac{\pi}{2}\sim\frac{\pi}{2}
$$

和：

atan2：

搞混了。

FOC不关心：

```

```

sin/cos周期一样。

```
350°
```

等价：

```
-10°
```

因为：

$$
sin(350°)=sin(-10°)
$$

所以：

下面都可以：

方式1：

```c

```

方式2：

```c

```

工程里面很多这样处理：

```c

{
    theta += 2*PI;
}
```

变成：

```

```

重点来了。

# 7. 机械速度怎么算？

速度：

本质：

角度变化率。

$$
\omega_m=
\frac{\Delta\theta_m}{\Delta t}
$$

代码：

```c
omega_m =
(theta_m_now - theta_m_last)
/
dt;
```

单位：

rad/s

---

换 RPM：

$$
RPM=
\omega_m
\times
\frac{60}{2\pi}
$$

代码：

```c
rpm =
omega_m * 9.5493f;
```

# 三、滑模观测器核心

PMSM αβ模型：

$$
\dot{i}
=
-\frac{R}{L}i
+
\frac{1}{L}(u-e)
$$

离散化：

$$
i(k+1)
=
i(k)+Ts\dot{i}
$$

代码：

```c
void SMO_Update(
        SMO_Handle *smo,
        float Ts)
{


    float error_alpha;
    float error_beta;


    // 1. 电流误差


    error_alpha =
        smo->Ialpha -
        smo->Ialpha_hat;


    error_beta =
        smo->Ibeta -
        smo->Ibeta_hat;


    // 2. 滑模校正项



    float Zalpha =
        smo->Kslide *
        SMO_Sign(error_alpha);


    float Zbeta =
        smo->Kslide *
        SMO_Sign(error_beta);




    // 3. 反电动势估计


    smo->Ealpha_hat = Zalpha;

    smo->Ebeta_hat = Zbeta;




    // 4. 更新电流估计


    float di_alpha;


    di_alpha =
    (-smo->Rs/smo->Ls)
        *
    smo->Ialpha_hat

    +
    (1.0f/smo->Ls)
    *
    (
       smo->Valpha
       -
       smo->Ealpha_hat
    );



    smo->Ialpha_hat +=
        di_alpha * Ts;




    float di_beta;


    di_beta =
    (-smo->Rs/smo->Ls)
        *
    smo->Ibeta_hat

    +
    (1.0f/smo->Ls)
    *
    (
       smo->Vbeta
       -
       smo->Ebeta_hat
    );


    smo->Ibeta_hat +=
        di_beta * Ts;

}

```

```c

    float delta;


    delta =
    smo->theta_m
    -
    theta_m_last;



    theta_m_last =
    smo->theta_m;
```

不过提醒你一个关键点：

$$

------------------
------------------
------------

这个问题非常关键，因为**无感 FOC 最容易出错的地方就是“SMO角度”和“FOC需要的角度”之间的关系**。

先给结论：

> **SMO 输出的是“估计的转子电角度”，理论上可以直接用于 FOC 的 Park 变换。但是实际工程需要做：方向校正、零点偏移校正、角度归一化。**
>
> **机械角度 = 电角度 / 极对数（但是必须基于展开后的连续电角度计算）。**

下面一步一步讲。

---

# 1. SMO到底输出什么角度？

SMO估计：

$$
E_\alpha,E_\beta
$$

反电动势空间矢量：

```
              β

              |
              |
              |
--------------+------------ α


              θe
```

计算：

```c
theta_smo = atan2f(Ebeta,Ealpha);
```

得到：

$$
\theta_{smo}
$$

它是：

**电角度**

不是机械角度。

范围：

```text
-π ~ +π
```

或者：

```text
0 ~ 2π
```

---

# 2. FOC需要什么角度？

FOC里面：

Park变换：

$$
\begin{bmatrix}
d\q
\end{bmatrix}
=

\begin{bmatrix}
cos\theta_e & sin\theta_e\
-sin\theta_e&cos\theta_e
\end{bmatrix}
\begin{bmatrix}
\alpha\
\beta
\end{bmatrix}
$$

这里的：

$$
\theta_e
$$

就是：

**转子磁场电角度**。

所以：

理论：

```
SMO输出 θ
       |
       |
       v

FOC Park直接使用
```

但是！！！

实际不能直接用。

---

# 3. 为什么SMO角度不能直接给FOC？

因为存在三个偏差。

---

## ① 反电动势角和磁链角有90°差

PMSM：

反电动势：

$$
E=\frac{d\psi}{dt}
$$

也就是说：

电压方向：

比磁链超前：

90°

所以：

SMO得到：

```
BEMF角
```

而FOC需要：

```
磁链角
```

存在：

$$
\theta_{FOC}
=

## \theta_{SMO}

90^\circ
$$

或者：

$$
+
90^\circ
$$

具体取决于：

* 电机相序
* Clarke方向
* Park定义

所以需要校准。

---

## ② 零点偏移

即：

$$
\theta_{offset}
$$

最终：

$$
\theta_{FOC}
=

\theta_{SMO}
+
\theta_{offset}
$$

例如：

```c
theta_foc =
theta_smo
+
offset;
```

offset可能：

30°

---

## ③ 方向问题

比如：

实际转：

顺时针

但是：

SMO认为：

逆时针

表现：

```text
电机抖动
反转
无法启动
```

需要：

```c
theta_foc = -theta_smo;
```

---

# 4. 最终FOC角度公式

工程里面：

$$
\boxed{
\theta_{FOC}
=

dir
\times
\theta_{SMO}
+
offset
}
$$

代码：

```c
theta_foc =
direction *
theta_smo
+
offset;
```

然后：

归一化：

```c
while(theta_foc>2*PI)
    theta_foc-=2*PI;


while(theta_foc<0)
    theta_foc+=2*PI;
```

这个：

就是给：

Park变换使用。

---

# 5. 电角度如何变机械角度？

电机关系：

$$
\theta_e=p\theta_m
$$

所以：

$$
\boxed{
\theta_m=\frac{\theta_e}{p}
}
$$

例如：

你的电机：

12槽14极

极对数：

$$
p=7
$$

如果：

SMO：

电角度：

```

```

机械：

$$
360/7=51.43°
$$

# 9. 机械速度怎么算？

机械角：

$$

$$

速度：

$$
\omega_m=
\frac{\Delta\theta_m}{T_s}
$$

代码：

```c

(theta_m -
 theta_m_last)

Ts;
```

单位：
