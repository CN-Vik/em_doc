FOC 电流环的核心其实就是：

> **根据电机数学模型，计算“需要多少电压”让电流按照目标变化。**
>
> PI负责纠正误差，前馈负责提前补偿电机自身产生的电压需求。

很多人只理解 PI：

$$
U_q=K_p(I_{qref}-I_q)+K_i\int(I_{qref}-I_q)
$$

但是高速以后这个是不够的，因为电机本身需要电压：

* 电阻压降
* 电感变化电压
* dq轴耦合电压
* 永磁反电动势

这些都会吃掉你的母线电压。

---

## 1. PMSM在dq坐标系电压方程

PMSM dq模型：

$$
U_d=R_s I_d+L_d\frac{dI_d}{dt}-\omega_e L_q I_q
$$

$$
U_q=R_s I_q+L_q\frac{dI_q}{dt}
+\omega_e L_d I_d
+\omega_e\psi_f
$$

($$Microchip Technology$$$$1$$)

每一项都有物理意义。

# 6. 实际代码结构

推荐：

```c
// 电流误差

err_d = Id_ref - Id;
err_q = Iq_ref - Iq;


// PI

Ud_pi = PID_d(err_d);
Uq_pi = PID_q(err_q);


// 前馈

Ud_ff = -omega_e * Lq * Iq;

Uq_ff = omega_e * Ld * Id
       + omega_e * psi_f;


// 总电压

Ud = Ud_pi + Ud_ff;

Uq = Uq_pi + Uq_ff;
```

这就是工业FOC结构。($$MathWorks$$$$3$$)
