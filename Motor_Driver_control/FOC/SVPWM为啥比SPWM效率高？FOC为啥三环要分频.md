这两个问题其实都是 FOC 里面非常核心的思想：

1. **SVPWM 为什么比 SPWM 母线利用率高？**
2. **为什么 FOC 三环（电流环、速度环、位置环）要分频运行？**

我结合你现在做的 **ESP32 + 2208 7极对 FOC** 来解释。

---

# 一、SVPWM 为什么比 SPWM 电压利用率高？

先说结论：

> SPWM 是把三相正弦波直接映射到 PWM，占用母线空间有限；
> SVPWM 是把三相电压看成一个旋转空间矢量，充分利用六个开关状态形成的六边形空间，所以最大输出电压提高约 **15.5%**。

---

## 1. SPWM 的限制

三相逆变桥：

```
        DC+
         |
     U桥 V桥 W桥
         |
        DC-
```

母线电压：

$$
V_{dc}
$$

每个桥臂只能输出：

```
+Vdc/2
-Vdc/2
```

SPWM：

给三个桥臂：

$$
U_a = U_m sin(\theta)
$$

$$
U_b = U_m sin(\theta-120^\circ)
$$

$$
U_c = U_m sin(\theta+120^\circ)
$$

要求：

最大调制度：

$$
m \leq 1
$$

否则 PWM 饱和。

所以 SPWM 最大基波线电压：

$$
V_{phase,max}
=

\frac{V_{dc}}{2}
$$

换算到 αβ 空间：

$$
V_{max}
=
\frac{V_{dc}}{2}
$$

---

举例：

12V 电池：

SPWM：

$$
V_{max}=6V
$$

也就是说你的 dq 轴：

最多：

$$
U_q≈6V
$$

---

# 2. SVPWM 的思想

SVPWM 不直接生成三条正弦。

它认为：

三相电压：

$$
(U_a,U_b,U_c)
$$

可以合成为一个空间矢量：

```

        β

        ↑
        |
    V2  |  V3
       \|
        \
 V1 -----> α
        \
       /
    V6

```

逆变器实际上只有8个状态：

```
000
001
010
011
100
101
110
111
```

其中：

6个有效矢量：

```
V1
V2
V3
V4
V5
V6
```

形成：

```
        V2

   V3        V1


V4            V6


   V5

```

一个正六边形。

---

关键来了：

SPWM只能使用：

```
圆形内接六边形
```

但是SVPWM：

直接利用六边形边界。

所以：

```
SPWM:

       六边形


        ○
     ○     ○


SVPWM:

       ⬡

```

空间增加：

$$
\frac{2}{\sqrt3}=1.1547
$$

也就是：

**15.47%提升**

---

## 3. 对你12V电机的实际意义

你的参数：

VBUS=12V

SPWM：

$$
U_{max}=6V
$$

SVPWM：

$$
U_{max}
=
\frac{12}{\sqrt3}
$$

≈

$$
6.93V
$$

你之前计算：

> 6.93V × 0.071A = 0.49A

这个就是SVPWM带来的。

所以：

同样12V：

SPWM：

```
最大Iq ≈0.42A
```

SVPWM：

```
最大Iq ≈0.49A
```

差：

约17%。

# 二、为什么FOC三环要分频？

FOC经典结构：

```
          位置环
            |
          速度环
            |
          电流环
            |
          SVPWM
            |
          电机

```

三个环动态速度完全不同。

---

# 1. 电流环最快

电流：

本质控制：

$$
L\frac{di}{dt}=U-RI
$$

响应非常快。

例如：

20kHz PWM：

周期：

$$
50us
$$

所以：

电流环：

```
10kHz~20kHz
```

运行。

你的：

ESP32：

20kHz FOC

就是合理的。

---

# 2. 速度环慢很多

速度变化靠：

```
电磁转矩
      ↓
机械惯量
      ↓
转速变化

```

机械系统：

毫秒级。

比如：

2208：

惯量比较小：

速度响应：

几十 ms。

所以速度环：

```
500Hz~2kHz
```

足够。

如果你20kHz跑速度PID：

会发生什么？

速度测量：

AS5600：

1kHz更新

但是PID：

20kHz执行：

等于：

```
同一个速度数据

重复计算20次

```

结果：

噪声放大。

---

# 3. 位置环最慢

位置：

比如机器人：

```
目标角度
↓
速度
↓
电流
```

位置变化：

几十毫秒甚至秒级。

所以：

位置环：

```
50Hz~200Hz
```

即可。

---

# 三、实际代码一般这样

假设：

PWM：

20kHz

中断：

每次：

```
FOC ISR

↓

电流采样

↓

Clarke

↓

Park

↓

Id/Iq PI

↓

SVPWM

```

每次执行。

然后：

计数：

```c
static uint8_t cnt_speed;

cnt_speed++;

if(cnt_speed>=20)
{
    speed_loop();
    cnt_speed=0;
}
```

那么：

20kHz / 20

=

1000Hz

速度环1kHz。

位置：

```c
if(cnt_position>=10)
{
    position_loop();
}
```

100Hz。

形成：

```
20kHz 电流环

 ↓20倍

1kHz速度环

 ↓10倍

100Hz位置环

```

# 四、为什么不能三个环都20kHz？

很多初学者会想：

> 频率越高越好？

不是。

原因：

## 1. 速度反馈没那么快

你的AS5600：

1kHz

20kHz速度环：

实际上：

```
19次使用旧数据
```

---

## 2. 放大噪声

速度：

$$
speed=
\frac{\Delta angle}{dt}
$$

本身就是微分。

高速采样：

噪声巨大。

---

## 3. 环路带宽冲突

控制理论：

外环带宽必须低于内环。

经验：

```
电流环带宽

>>>

速度环带宽

>>>

位置环带宽

```

一般：

比例：

```
10:1:0.1
```

例如：

电流环：

1kHz

速度环：

100Hz

位置：

10Hz

---

# 五、结合你的2208 FOC

你现在：

```
PWM 20kHz

电流环20kHz

速度环20kHz

AS5600 1kHz
```

这个结构实际上不合理。

建议：

```
PWM ISR

20kHz
 |
 |
电流环

20kHz

================

速度环

500Hz~1kHz


================

位置环

50~100Hz

```

尤其你的：

* 2208小惯量
* AS5600慢
* 低速100RPM抖动

速度环高频运行会严重放大：

* 编码器量化误差
* 齿槽转矩扰动
* 速度计算噪声

---

所以总结一句：

**SVPWM提高利用率，是因为它利用了逆变器六个电压矢量形成的六边形空间，比SPWM只利用内接圆多出15.5%的电压空间。**

**FOC三环分频，是因为三个控制对象时间尺度不同：电流是电磁毫秒级，速度是机械十毫秒级，位置更慢。如果全部20kHz跑，不但没优势，反而容易震荡。**你现在2208低速不稳定，速度环频率和AS5600速度估算就是重点怀疑对象。
