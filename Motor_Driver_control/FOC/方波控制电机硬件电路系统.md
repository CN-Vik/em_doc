明白了，你想看的不是FOC算法对应的硬件，而是**一块支持三种控制模式：**

1. **有感六步方波控制（Hall/磁编码器）**
2. **无感六步方波控制（反电动势BEMF）**
3. **FOC矢量控制（电流+角度反馈）**

的**完整电机驱动板硬件系统结构**。

这种板子的硬件设计思路和纯FOC板不一样，它更接近一个通用BLDC/PMSM驱动器。

下面按照实际原理图模块来画。

所以一块真正的**通用BLDC/PMSM驱动板**：

硬件上必须同时具备：

| 功能    | 硬件           |
| ----- | ------------ |
| 有感六步  | Hall输入       |
| 无感六步  | BEMF分压检测     |
| FOC   | 电流采样+角度传感    |
| 功率输出  | 6 MOS三相桥     |
| MOS控制 | Gate Driver  |
| 保护    | OCP/OVP/OTP  |
| 控制核心  | STM32G431    |
| 调试通信  | UART/CAN/SWD |

这就是类似 **TI C2000 LaunchPad电机控制板、ST MCSDK参考板、国产FOC驱动器** 的典型硬件架构。你后面如果画PCB，基本就是围绕这个结构展开。
