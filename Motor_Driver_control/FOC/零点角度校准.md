比如：

真实位置：

```
       |
       |
       O
```

正向定位：

齿槽拉偏：

       |
      /
     O

测：

$$
\theta_f
$$

反向定位：

```
       |
        \
         O
```

测：

$$
\theta_r
$$

平均：

$$
(\theta_f+\theta_r)/2
$$

齿槽误差抵消。

这个思想非常正确。

## 3. 圆平均函数（推荐）

```c
float encoder_angle_average(void)
{
    float sin_sum = 0;
    float cos_sum = 0;


    for(int i=0;i<SAMPLE_NUM;i++)
    {
        float angle = AS5600_GetAngle_Rad();


        sin_sum += sinf(angle);
        cos_sum += cosf(angle);


        vTaskDelay(pdMS_TO_TICKS(SAMPLE_DELAY_MS));
    }


    float angle_avg = atan2f(sin_sum, cos_sum);


    if(angle_avg < 0)
        angle_avg += 2.0f*M_PI;


    return angle_avg;
}
```

这个解决360°跳变。

# 4. 双向零点校准函数

```c
float foc_zero_offset_calibrate(void)
{

    float theta_forward;
    float theta_reverse;



    printf("FOC align forward...\n");


    /*
     * 电角度0°
     *
     * Valpha = Vd
     * Vbeta  = 0
     */

    SVPWM_SetVoltage(
            ALIGN_VOLTAGE,
            0
    );


    vTaskDelay(pdMS_TO_TICKS(ALIGN_TIME_MS));



    theta_forward = encoder_angle_average();



    printf("forward mech angle=%f\n",
            theta_forward);



    /*
     * 电角度180°
     *
     * Valpha=-Vd
     */

    printf("FOC align reverse...\n");


    SVPWM_SetVoltage(
            -ALIGN_VOLTAGE,
            0
    );


    vTaskDelay(pdMS_TO_TICKS(ALIGN_TIME_MS));



    theta_reverse = encoder_angle_average();



    printf("reverse mech angle=%f\n",
            theta_reverse);



    //关闭PWM

    SVPWM_SetVoltage(0,0);



    /*
     * offset计算
     */

    float offset_forward;

    float offset_reverse;



    offset_forward =
        -(float)POLE_PAIRS * theta_forward;



    offset_reverse =
        M_PI -
        (float)POLE_PAIRS * theta_reverse;



    float offset =
        (offset_forward + offset_reverse)/2.0f;



    /*
     * 限制到0~2PI
     */

    offset =
        fmodf(offset,2*M_PI);


    if(offset < 0)
        offset += 2*M_PI;



    printf(
        "zero offset=%f rad\n",
        offset
    );


    return offset;
}
```

---

### 一、 为什么这个“思路”是好的？（优点）

1. **解决齿槽转矩误差**：
常规的强制定位法是给d轴施加正向电压（通常电角度设为0），让转子被吸过去。但由于电机有“齿槽”（转子磁铁喜欢卡在定子铁芯的某些特定位置），转子最终停下的位置往往是“电磁力 + 齿槽转矩 + 摩擦力”的平衡点，而不是真正的电磁零点。
通过在0°和180°（$\pi$）两个相反的电角度分别定位，齿槽转矩产生的偏差方向通常是相反的（或者至少受力情况不同），**取平均可以抵消很大一部分机械阻力带来的误差**。
2. **验证方法非常标准**：
作者提到的验证方法（设 $V_d=0, V_q>0$，观察 $I_d$ 是否为0）是FOC领域**最经典、最有效的验证手段**。对于表贴式电机（SPM），如果零点完全准确，所有的电流都会用来产生转矩（$I_q$），而励磁电流（$I_d$）应该自然趋近于0。

---

### 二、 为什么“代码”不能直接用？（致命缺陷）

代码中这一句存在**严重的“相位环绕（Phase Wrapping）”问题**：

```c
float offset = (offset_fwd + offset_rev) / 2.0f; 

```

**角度是循环的，不能直接做算术平均！**
**举个极端的例子**：
假设真正的 offset 是 $0^\circ$。

* 正向对齐时，由于少许误差，算出的 `offset_fwd` 是 $358^\circ$（在代码里相当于接近 $2\pi$）。
* 反向对齐时，算出的 `offset_rev` 是 $2^\circ$。
* 如果直接相加除以 2：$(358 + 2) / 2 = 180^\circ$！
明明两个值都在 $0^\circ$ 附近，取平均后居然变成了 $180^\circ$，这就导致零点完全找反，电机一启动就会失控或锁死。

---

### 三、 如果你要参考，应该怎么改？（实战建议）

你可以完全采用他的思路，但代码需要进行以下**三点核心改良**：

#### 1. 修复角度平均算法（必须改）

计算两个角度的平均值，必须计算它们的“最短角距”。修正后的代码应该类似这样：

```c
// 确保 offset_fwd 和 offset_rev 都在 0 ~ 2PI 之间
offset_fwd = fmodf(offset_fwd, 2.0f * M_PI);
if(offset_fwd < 0) offset_fwd += 2.0f * M_PI;

offset_rev = fmodf(offset_rev, 2.0f * M_PI);
if(offset_rev < 0) offset_rev += 2.0f * M_PI;

// 计算两者的最短角度差
float diff = offset_rev - offset_fwd;
while(diff > M_PI)  diff -= 2.0f * M_PI;
while(diff < -M_PI) diff += 2.0f * M_PI;

// 正确的平均值
float offset = offset_fwd + (diff / 2.0f);

// 最终结果再次归一化到 0 ~ 2PI
offset = fmodf(offset, 2.0f * M_PI);
if(offset < 0) offset += 2.0f * M_PI;

```

#### 2. 电压应“平滑过渡”而非瞬间突变（建议改）

代码中直接使用 `SVPWM_SetVoltage(ALIGN_VOLTAGE, 0);` 瞬间加上去，这会导致：

* 转子受到剧烈冲击，发生剧烈的来回震荡（Oscillation）。
* 如果 `ALIGN_TIME_MS` 等待时间不够长，你读取编码器角度时，转子还在晃动，读到的值就是错的。
**更好的做法**：将电压从 0 线性 Ramp-up（斜坡上升）到 `ALIGN_VOLTAGE`，然后保持一段时间再读角度。

#### 3. 进阶玩法：多点平均（更精确）

如果你的系统对启动零点要求极高（比如直驱机械臂），仅仅正反转两点依然不够。业界通常会做 **6步定位法**。
分别强行对齐电角度的 $0^\circ, 60^\circ, 120^\circ, 180^\circ, 240^\circ, 300^\circ$，算出 6 个 offset，然后利用向量求和（或转换为正余弦求均值）来算出一个极致精确的零点。

### 四、 总结：你该不该用？

* **可以参考采用！** 相比于只定位一次的“傻瓜式”做法，这种正反两次定位确实精度更高。
* **前提是：** 必须把我上面提到的**角度求平均（Phase Wrapping）Bug 修复**。
* **调试提醒：** 在做这段校准时，`ALIGN_VOLTAGE` 给多大很有讲究。太小了克服不了静摩擦力（转子动不到位），太大了电机发热严重且震荡剧烈。通常建议给到电机额定电压的 10%~20% 左右，以电机能明显有力地锁止但不过流为准。

这份代码不仅修复了原有的角度平均Bug，还引入了“电压平滑斜坡上升（Ramp-up）”，防止电机瞬间通电时发生剧烈抖动导致定位不准。

### 一、 完整重构代码

你可以直接在你的 FOC 工程中新建一个 `.c` 文件，参考以下逻辑：

```c
#include <math.h>
#include <stdint.h>

// --- 依据你的实际工程修改以下宏定义 ---
#ifndef M_PI
#define M_PI 3.14159265358979323846f
#endif

#define POLE_PAIRS       7        // 电机极对数（根据你的电机修改）
#define ALIGN_VOLTAGE    1.5f     // 对齐电压，通常是电机额定电压的 10%~20%
#define RAMP_TIME_MS     500      // 电压斜坡上升时间 (毫秒)
#define HOLD_TIME_MS     600      // 电压保持时间，等待转子完全静止 (毫秒)
#define STEP_TIME_MS     5        // 每次斜坡递增的步长 (毫秒)

// --- 外部接口声明 (请替换为你自己的硬件底层函数) ---
extern void SVPWM_SetVoltage(float V_alpha, float V_beta);
extern float Encoder_GetAngle_Rad(void);  // 获取机械角度 (返回 0 ~ 2π)
extern void HAL_Delay(uint32_t ms);       // 毫秒级延时

/**
 * @brief 角度归一化辅助函数 (确保角度在 0 ~ 2π 之间)
 */
float normalize_angle(float angle) 
{
    float a = fmodf(angle, 2.0f * M_PI);
    if (a < 0.0f) {
        a += 2.0f * M_PI;
    }
    return a;
}

/**
 * @brief 辅助函数：平滑施加电压并读取角度
 * @param target_elec_angle 目标电角度 (0 或 π)
 * @return 稳定后的机械角度 (弧度)
 */
float align_and_read_angle(float target_elec_angle) 
{
    // 目标电压的 Alpha 和 Beta 分量
    float V_alpha_target = ALIGN_VOLTAGE * cosf(target_elec_angle);
    float V_beta_target  = ALIGN_VOLTAGE * sinf(target_elec_angle);
    
    // 1. 斜坡上升 (平滑增加电压，防止转子剧烈震荡)
    int steps = RAMP_TIME_MS / STEP_TIME_MS;
    for (int i = 1; i <= steps; i++) 
    {
        float ratio = (float)i / (float)steps;
        SVPWM_SetVoltage(V_alpha_target * ratio, V_beta_target * ratio);
        HAL_Delay(STEP_TIME_MS);
    }
    
    // 2. 保持电压，等待转子彻底停稳
    HAL_Delay(HOLD_TIME_MS);
    
    // 3. 读取并返回此刻的机械角度
    return Encoder_GetAngle_Rad();
}

/**
 * @brief 核心函数：正反转平均法校准零点 (已修复环绕Bug)
 */
float calibrate_zero_offset_bidirectional_improved(void) 
{
    // --- 第一步：正向对齐 (目标电角度 0) ---
    float theta_m_fwd = align_and_read_angle(0.0f);
    
    // 先把电压降回0，稍微休息一下，防止直接反转导致电流冲击
    SVPWM_SetVoltage(0.0f, 0.0f);
    HAL_Delay(200);
    
    // --- 第二步：反向对齐 (目标电角度 π) ---
    float theta_m_rev = align_and_read_angle(M_PI);
    
    // 测量完毕，关闭输出
    SVPWM_SetVoltage(0.0f, 0.0f);
    
    // --- 第三步：计算两次独立算出的 offset ---
    // offset = target_elec_angle - POLE_PAIRS * theta_m
    float offset_fwd = normalize_angle(0.0f - (float)POLE_PAIRS * theta_m_fwd);
    float offset_rev = normalize_angle(M_PI - (float)POLE_PAIRS * theta_m_rev);
    
    // --- 第四步：安全求平均 (解决 0度和360度相加除以2变成180度的Bug) ---
    // 1. 计算两者的最短角度差
    float diff = offset_rev - offset_fwd;
    while (diff > M_PI)  diff -= 2.0f * M_PI;
    while (diff < -M_PI) diff += 2.0f * M_PI;
    
    // 2. 在正向offset的基础上，加上一半的差值，即为真正的中心零点
    float final_offset = normalize_angle(offset_fwd + (diff / 2.0f));
    
    return final_offset;
}

```

### 二、 具体该咋做？（实操步骤）

#### 第 1 步：调整关键参数

* **`ALIGN_VOLTAGE`**：这是最关键的参数。从较小的值（比如 `1.0f`）开始测试。
* **太小**：转子可能会“卡在”某个齿槽里，动不到位。
* **太大**：电机会急剧发热（因为这时候完全是堵转状态，能量全变热能了）。
* **标准**：通电后，用手去拨动一下电机，感觉有明显的“磁力阻力”拉着它回正，这就是合适的电压。


* **`HOLD_TIME_MS`**：看你的负载大小。如果是空载电机，500ms足够它停稳了；如果带了很重的惯性负载，可能需要设到 1000ms 甚至 2000ms。

#### 第 2 步：跑代码并打印数据看现象

在调用 `calibrate_zero_offset_bidirectional_improved()` 的时候，通过串口把 `offset_fwd` 和 `offset_rev` 打印出来观察：

* 正常情况下，这两个值应该非常接近。例如一个是 `1.25` 弧度，另一个是 `1.31` 弧度。
* 如果这两个值相差特别大（比如差了 $\pi/2$ 以上），说明你的 **极对数（POLE_PAIRS）设错了**，或者编码器读取方向和极对数方向反了。

#### 第 3 步：验证校准结果（非常重要！）

零点校准完，必须验证。具体做法如下，这也是最正宗的 FOC 验证流程：

1. **设定目标电流或电压**：
在 FOC 闭环里，强制设定 $V_d = 0$（或者 $I_d = 0$ 闭环），然后给一个较小的正向 $V_q$（或者 $I_q$），比如 $V_q = 1.0V$。
2. **观察电机表现**：
* **完美现象**：电机应该非常顺滑地、平稳地朝着一个方向匀速转动。且你用手去捏住转子，会感受到持续且平稳的扭矩。
* **失败现象 1（零点差了 90度）**：电机完全不转，但是疯狂发热，因为所有电流都变成发热的励磁电流了。
* **失败现象 2（零点差了 180度）**：电机反向疯狂加速失控，或者疯狂抖动。


3. **观察上位机 / 示波器**：
如果你有电流采样（ADC），在电机转动时观察 $I_d$ 的波形，$I_d$ 应该始终是在 $0$ 附近波动的一条直线。如果 $I_d$ 明显不为 0（而是有一个很大的直流偏置），说明算出来的零点依然有偏差，可能需要调整极对数、检查编码器延迟，或者增大校准电压。

# 6. 我建议你最终代码结构这样

```c
float circular_mean(float *angle,int num)
{
    float sx=0;
    float sy=0;


    for(int i=0;i<num;i++)
    {
        sx += cosf(angle$$i$$);
        sy += sinf(angle$$i$$);
    }


    float result =
        atan2f(sy,sx);


    if(result<0)
        result+=2*M_PI;


    return result;
}
```
