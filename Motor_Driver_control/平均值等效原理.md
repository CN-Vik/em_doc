**平均值等效原理**就是：

> 虽然逆变器/MOS 在某一瞬间只能输出“高电平”或者“低电平”，但如果开关频率足够高，电机绕组看到的效果可以近似等效为这段时间内的平均电压。

这就是 PWM、SPWM、SVPWM 能工作的核心原理。

---

## 1. 先用普通 PWM 理解

假设母线电压是：

```text
Vbus = 12V
```

一个 PWM 周期内，MOS 输出：

```text
高电平 12V 持续 25% 时间
低电平 0V  持续 75% 时间
```

那么平均电压就是：

```text
Uavg = 12V × 25% + 0V × 75%
     = 3V
```

也就是说，虽然 MOS 实际输出是这种：

```text
12V  ┌──┐      ┌──┐
     │  │      │  │
0V ──┘  └──────┘  └────
```

但负载从平均效果上看，近似像是你给了它：

```text
3V  ─────────────────
```

这就是平均值等效。

---

## 2. 为啥电机可以这样等效？

因为电机绕组不是纯电阻，它有 **电感**。

电感有一个特点：

> 电流不能突变。

所以虽然电压在高速跳变：

```text
0V / 12V / 0V / 12V / 0V ...
```

但电机电流不会跟着瞬间跳变，而是比较平滑地变化。

可以理解成：

```text
MOS 输出电压：很方，很跳
电机绕组电流：被电感滤波后，比较平滑
```

所以电机主要感受到的是一个 PWM 周期内的平均电压，而不是每一瞬间的高低电平。

---

## 3. 占空比越大，平均电压越高

PWM 的平均值公式很简单：

```text
Uavg = D × Vbus
```

其中：

```text
D = 占空比
```

比如 Vbus = 12V：

| 占空比 D | 平均电压 |
| ----- | ---- |
| 0%    | 0V   |
| 25%   | 3V   |
| 50%   | 6V   |
| 75%   | 9V   |
| 100%  | 12V  |

所以 MCU 不需要真的输出模拟电压，只需要改变 PWM 占空比，就可以等效改变输出电压。

这就是 PWM 控制电机速度、LED 亮度、电源电压的基础。

---

## 4. 放到 SVPWM 里面是什么意思？

SVPWM 里面，逆变器一个瞬间只能输出 8 种状态：

```text
000
001
010
011
100
101
110
111
```

但是我们希望输出的是一个任意方向的目标电压矢量：

```text
Vref
```

怎么办？

SVPWM 的办法就是：

> 在一个很短的 PWM 周期 Ts 内，分别输出几个基础矢量，让它们的时间平均效果等于目标矢量 Vref。

比如第 I 扇区：

```text
000 → 100 → 110 → 111 → 110 → 100 → 000
```

其中：

```text
100 作用 T1 时间
110 作用 T2 时间
000/111 作用 T0 时间
```

只要满足：

```text
T1 + T2 + T0 = Ts
```

那么这个 PWM 周期内的平均电压矢量可以等效为：

```text
Vref ≈ V100 × T1/Ts + V110 × T2/Ts + Vzero × T0/Ts
```

因为零矢量 `000/111` 不产生有效电压，所以主要是：

```text
Vref ≈ V100 × T1/Ts + V110 × T2/Ts
```

这就是 SVPWM 的平均值等效原理。

---

## 5. 举个 SVPWM 的直观例子

假设目标矢量在 `100` 和 `110` 中间偏向 `100`。

那一个 PWM 周期里就可以这样安排：

```text
100 输出久一点
110 输出短一点
零矢量填充剩余时间
```

如果目标矢量更靠近 `110`，那就：

```text
110 输出久一点
100 输出短一点
零矢量填充剩余时间
```

虽然逆变器每一瞬间只能输出固定方向的矢量，但是从一个 PWM 周期的平均效果看，就能合成任意方向的矢量。

这就是：

```text
离散开关状态 → 平均后等效成连续电压矢量
```

---

## 6. 这个原理成立的前提

平均值等效不是任何情况下都完美成立，它有前提：

### 第一，PWM 频率要足够高

比如电机电流变化比较慢，而 PWM 是 20kHz。

那么一个 PWM 周期只有：

```text
1 / 20000 = 50us
```

电机电感在 50us 内电流变化不会太大，所以可以用平均值近似。

---

### 第二，负载要有滤波能力

电机绕组有电感，所以可以滤掉很多高频 PWM 分量。

如果是纯电阻负载，电压跳变会更直接地反映出来，平均值意义还是有，但电流纹波会更大。

---

### 第三，不是完全没有波动

平均值等效只是近似。

真实电流还是会有纹波：

```text
平均电流附近上下小幅波动
```

PWM 频率越高，电感越大，纹波通常越小。

PWM 频率越低，电感越小，纹波越大。

---

## 7. 和你前面问的 SVPWM 关系

你前面问：

```text
000 → 100 → 110 → 111 → 110 → 100 → 000
```

这串开关状态不是让电机“瞬间一会儿往这里，一会儿往那里乱受力”。

因为这个切换过程非常快。

电机真正感受到的是：

```text
这一整个 PWM 周期内的平均电压矢量
```

所以 SVPWM 才能用几个基础矢量合成一个目标矢量。

---

## 8. 一句话总结

**平均值等效原理就是：MOS 虽然只能高速开关输出 0/Vbus 这种离散电压，但在一个很短的 PWM 周期内，电机绕组主要感受到的是这些电压按时间加权后的平均值。SVPWM 正是利用这个原理，用几个基础电压矢量按不同作用时间合成目标电压矢量。**
