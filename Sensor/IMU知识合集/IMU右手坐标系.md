IMU 的**右手坐标系**，本质就是：用右手的三个手指表示 IMU 自己身上的三个轴。

最经典的记法：

```text
右手三指坐标系：

食指  →  +X轴
中指  →  +Y轴
大拇指 ↑  +Z轴
```

而且必须满足：

```text
X × Y = Z
```

也就是：**X 轴叉乘 Y 轴，得到 Z 轴方向**。这就是右手坐标系的核心。

---

## 1. 按你说的手势理解

你可以这样摆右手：

```text
大拇指：向上       = +Z
食指：向前         = +X
中指：和食指垂直   = +Y
```

如果你规定：

```text
+X = 向前
+Z = 向上
```

那么为了满足右手坐标系：

```text
+Y 必须指向左边
```

也就是：

```text
          +Z 大拇指向上
           ↑
           |
           |
+Y ←-------●-------- +X 向前
中指向左             食指向前
```

注意：
**中指不是小拇指方向。中指要和食指成 90°，而且也要和大拇指成 90°。**

---

## 2. IMU 坐标系是“跟着芯片走”的

IMU 的坐标系不是固定在地球上的，而是固定在 IMU 芯片/模块上的。

比如你把 IMU 模块这样放：

```text
X 轴朝前
Y 轴朝左
Z 轴朝上
```

那么它就是：

```text
        +Z
         ↑
         |
         |
+Y ←-----●----→ +X
```

但是你把板子旋转 90°，IMU 的 X/Y/Z 也会跟着板子一起转。

所以在代码里经常要做一件事：

```c
// 把 IMU 原始坐标系转换成车体坐标系/设备坐标系
body_x = imu_x;
body_y = imu_y;
body_z = imu_z;
```

或者如果安装方向不一样，可能要这样：

```c
body_x =  imu_y;
body_y = -imu_x;
body_z =  imu_z;
```

这个叫**安装方向映射**，做平衡车、无人机、头部追踪时非常重要。

## 3. 加速度计的 XYZ 是什么意思？

IMU 里的加速度计输出：

```text
ax, ay, az
```

分别表示沿着 IMU 自己 X/Y/Z 轴方向的加速度/受力。

例如模块平放，假设：

```text
+Z 朝上
```

静止不动时，很多 IMU 会输出：

```text
ax ≈ 0
ay ≈ 0
az ≈ +1g
```

注意这里容易混淆：
加速度计测到的不是单纯的“重力加速度方向”，而是**支撑力/比力**。所以静止放桌面上时，Z 轴经常显示 +1g。

不过不同厂家、不同驱动可能符号处理不一样，最终还是要看数据手册和实际测试。

---

## 4. 陀螺仪的 XYZ 是什么意思？

陀螺仪输出：

```text
gx, gy, gz
```

表示绕 X/Y/Z 轴旋转的角速度。

正方向也用右手定则判断：

```text
大拇指指向 +轴方向
四指弯曲方向 = 正旋转方向
```

例如：

### 绕 Z 轴旋转

```text
大拇指指向 +Z，也就是向上
四指弯曲的方向，就是 gz 为正的旋转方向
```

如果：

```text
+X 向前
+Y 向左
+Z 向上
```

那么：

```text
绕 +Z 正转 = 从 +X 转向 +Y
```

也就是从上往下看，设备向左转，通常可以理解成：

```text
gz > 0 ：左转/逆时针转
gz < 0 ：右转/顺时针转
```

## 5. 平衡车里常见的轴定义

做两轮平衡车时，通常可以这样定义车体坐标系：

```text
+X：车头前进方向
+Y：车体左侧
+Z：车体上方
```

也就是：

```text
             +Z 上
              ↑
              |
              |
+Y 左  ←------●------→ +X 前
```

对应姿态通常是：

```text
绕 X 轴转：Roll  横滚
绕 Y 轴转：Pitch 俯仰
绕 Z 轴转：Yaw   偏航
```

对于两轮平衡车，最重要的一般是：

```text
Pitch 俯仰角
```

也就是车子前后倒的角度。这个角度通常和**绕 Y 轴的旋转**关系最大。

## 6. 一个非常重要的判断方法

你以后拿到一个 IMU，不要只相信图纸，最好实际测一下。

### 测加速度方向

把 IMU 静止放好，分别让某个轴朝上：

```text
+X 朝上，看 ax 是 +1g 还是 -1g
+Y 朝上，看 ay 是 +1g 还是 -1g
+Z 朝上，看 az 是 +1g 还是 -1g
```

这样可以验证加速度计轴向。

### 测陀螺仪方向

比如测试 Z 轴：

```text
让 +Z 朝上
手动逆时针旋转模块
看 gz 是正还是负
```

如果和你定义的不一致，就在代码里取反：

```c
gz = -gz;
```

---

## 7. 最核心的一句话

IMU 右手坐标系就是：

```text
食指指 +X
中指指 +Y
大拇指指 +Z

并且满足：

X × Y = Z
```

如果你规定：

```text
+X 向前
+Z 向上
```

那么：

```text
+Y 就必须向左
```

这就是很多人最容易搞错的地方：
**不是随便把 Y 轴画到右边就行，必须满足右手定则。**
