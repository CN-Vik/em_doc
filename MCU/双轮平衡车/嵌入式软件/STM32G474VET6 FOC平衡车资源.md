结论先说：**STM32G474VET6 很适合做 FOC 平衡车，尤其适合“双电机 FOC + 姿态控制 + 电流采样 + 过流保护”这种方案。**
它不是普通 MCU，而是 ST 专门偏向 **电机控制、数字电源、模拟采样** 场景设计的一颗 G4 系列 MCU。

---

## 1. 型号先拆一下：STM32G474VET6 是什么？

`STM32G474VET6` 大概可以这样理解：

| 字段    | 含义                               |
| ----- | -------------------------------- |
| STM32 | ST 的 32 位 MCU                    |
| G     | 通用型 / 混合信号增强系列                   |
| 474   | STM32G474 子系列                    |
| V     | 100 引脚                           |
| E     | 512 KB Flash                     |
| T     | LQFP 封装                          |
| 6     | 工业温度，-40 ~ 85°C 环境温度，最高 105°C 结温 |

这些编码在 ST 数据手册的订购信息里有说明：V 表示 100 pins，E 表示 512 KB Flash，T 表示 LQFP，6 表示 -40 到 85°C 工业温度范围。([STMicroelectronics][1])

---

## 2. 核心资源：170 MHz Cortex-M4F，带 FPU

STM32G474 是 **Arm Cortex-M4 内核，最高 170 MHz**，并且带 **单精度 FPU** 和 DSP 指令。ST 官方资料也标明 G4 系列最高 170 MHz，并带 FPU。([STMicroelectronics][2])

对你做平衡车很重要：

1. **FOC 计算需要 sin、cos、Park、Clarke、PI 控制**
2. **平衡车姿态控制需要 IMU 滤波、角速度积分、角度估算**
3. **速度环、电流环、姿态环都要实时跑**

Cortex-M4F 的 FPU 对这些浮点运算很有帮助。比如你写：

```c
float angle;
float sin_theta = arm_sin_f32(angle);
float cos_theta = arm_cos_f32(angle);
```

它比没有 FPU 的 M0/M3 舒服很多。

如果你用定点算法当然也可以，但对初期开发来说，**G474 允许你先用 float 把算法跑通**，后面再优化。

---

## 3. Flash / RAM：512 KB Flash + 128 KB SRAM

STM32G474xE 最大是 **512 KB Flash**，SRAM 是 **128 KB**，数据手册里也标明该系列最高 512 KB Flash、128 KB SRAM。([STMicroelectronics][1])

对平衡车来说，这个容量比较宽裕：

| 用途                  | 够不够 |
| ------------------- | --- |
| 双电机 FOC             | 够   |
| 姿态控制算法              | 够   |
| IMU 驱动              | 够   |
| CAN / UART / 蓝牙模块通信 | 够   |
| 参数保存、PID 参数、校准参数    | 够   |
| 简单日志缓存              | 够   |
| RTOS                | 也够  |

但它不适合干这些：

| 不适合的事         | 原因            |
| ------------- | ------------- |
| 跑 Linux / ROS | MCU 不是 MPU    |
| 图像处理          | 算力和 RAM 不够    |
| 大屏 GUI        | RAM 不适合       |
| 大量音频/图片资源     | Flash/RAM 不适合 |

所以它非常适合当 **运动控制主控 MCU**，不适合当上位机 SOC。

---

## 4. 最关键：它有 3 个电机控制高级定时器

这是它非常适合双电机 FOC 的关键原因之一。

STM32G474 有：

| 定时器类型         | 数量  |
| ------------- | --- |
| 16 位高级电机控制定时器 | 3 个 |
| 32 位通用定时器     | 2 个 |
| 16 位通用定时器     | 7 个 |
| 低功耗定时器        | 1 个 |
| HRTIM 高分辨率定时器 | 1 个 |

ST 数据手册中标明它有 **3 个 16-bit advanced motor control timers**，还有一个 **184 ps 分辨率的高分辨率定时器 HRTIM**。([STMicroelectronics][1])

对双电机平衡车来说，通常可以这样分：

| 功能           | 建议资源            |
| ------------ | --------------- |
| 左轮三相 PWM     | TIM1            |
| 右轮三相 PWM     | TIM8 或 TIM20    |
| 编码器 / 霍尔测速   | 其他通用定时器         |
| 姿态控制周期       | 基本定时器 / SysTick |
| 蜂鸣器 / 辅助 PWM | 普通定时器           |
| 高精度特殊 PWM    | HRTIM，可选        |

FOC 控制最需要的是这种能力：

```text
三相互补 PWM
上桥臂 PWM：UH VH WH
下桥臂 PWM：UL VL WL
死区时间
刹车输入 BKIN
中心对齐 PWM
PWM 中点触发 ADC 采样
```

普通定时器也能出 PWM，但做三相逆变器，最好用高级定时器。因为它有：

1. 互补输出
2. 死区插入
3. 刹车保护
4. 中心对齐 PWM
5. ADC 触发同步能力

这对 FOC 很关键。

---

## 5. ADC 资源非常强：5 个 12 位 ADC，最高 4 MSPS

STM32G474 有 **5 个快速 12 位 ADC**，最高 **4 MSPS**，并支持硬件过采样。ST 官方资料明确写到 G474 有 5 个 12-bit ADC，采样率可到 4 MSPS。([STMicroelectronics][1])

对 FOC 来说，ADC 主要采这些：

| 信号      | 用途            |
| ------- | ------------- |
| A 相电流   | 电流环           |
| B 相电流   | 电流环           |
| C 相电流   | 可选，三电阻采样      |
| 母线电压    | 电压保护、SVPWM 限幅 |
| 母线电流    | 保护 / 功率估算     |
| MOS 温度  | 热保护           |
| 电机温度    | 热保护           |
| 电池电压    | 欠压保护          |
| 油门/控制输入 | 可选            |

双电机如果用 **双电阻采样**：

```text
左电机：Ia、Ib
右电机：Ia、Ib
总共 4 路相电流 ADC
```

这个 G474 完全够。

如果用 **三电阻采样**：

```text
左电机：Ia、Ib、Ic
右电机：Ia、Ib、Ic
总共 6 路相电流 ADC
```

G474 也可以做，但要仔细规划 ADC 通道、OPAMP 输入脚、PWM 定时器触发点。

FOC 里面 ADC 不是随便采的，最好是：

```text
PWM 周期开始
    ↓
上桥/下桥开关稳定
    ↓
PWM 中间点
    ↓
触发 ADC 采样相电流
    ↓
ADC 转换完成中断
    ↓
执行 Clarke/Park/PI/SVPWM
    ↓
更新下一周期 PWM 占空比
```

也就是说，**ADC 必须和 PWM 定时器同步**，这就是为什么 G474 比普通 STM32 更适合电机控制。

---

## 6. 内置 6 个运放 OPAMP，非常适合电流采样

STM32G474 有 **6 个内部运放**，ST 数据手册中也列出该系列有 6 个 operational amplifiers。([STMicroelectronics][1])

这个对 FOC 很香。

电机相电流一般通过采样电阻测量：

```text
电机电流 → 采样电阻 → 几十 mV 小电压 → 运放放大 → ADC
```

比如你用 5 mΩ 采样电阻，电流 10A 时：

```text
V = I × R = 10A × 0.005Ω = 0.05V = 50mV
```

50 mV 太小，ADC 直接采会精度不够，所以需要运放放大。

G474 内部有 OPAMP/PGA，就可以减少外部电流采样放大器数量。ST G4 介绍资料也说明其 OPAMP 支持 PGA 增益，比如 2、4、8、16 等多种增益。([STMicroelectronics][2])

对双电机：

| 采样方式         | 需要运放数量 | G474 是否够 |
| ------------ | -----: | -------- |
| 双电阻采样 × 2 电机 |    4 个 | 够        |
| 三电阻采样 × 2 电机 |    6 个 | 刚好够      |

不过注意：
**内部 OPAMP 够不代表 PCB 一定好画。**
因为 OPAMP 输入脚、ADC 通道、定时器 PWM 脚都有复用关系，必须提前用 STM32CubeMX 把引脚锁好。

---

## 7. 内置 7 个比较器 COMP，适合硬件过流保护

STM32G474 有 **7 个比较器**。ST 数据手册也写了该系列有 7 个 comparators。([STMicroelectronics][1])

比较器可以做快速保护，比如：

```text
相电流过大
    ↓
采样电阻电压超过阈值
    ↓
比较器翻转
    ↓
直接触发高级定时器 BKIN
    ↓
PWM 立即关闭
```

这个比软件 ADC 判断快很多。

软件判断是：

```text
ADC采样 → 中断 → CPU判断 → 关闭PWM
```

硬件比较器保护是：

```text
电流过大 → COMP → TIM刹车 → PWM关闭
```

这条路径可以不经过 CPU。

做平衡车的时候，电机堵转、轮子卡住、MOS 短路、相线短路都可能产生大电流。**硬件过流保护必须做，不要只靠软件。**

---

## 8. CORDIC 和 FMAC：这是 G474 做 FOC 的特色资源

STM32G474 内部有：

| 加速器    | 作用                     |
| ------ | ---------------------- |
| CORDIC | 三角函数、坐标旋转、atan2、sqrt 等 |
| FMAC   | FIR/IIR 滤波、数字控制计算      |

ST 数据手册明确写到 G474 带 **CORDIC** 和 **FMAC** 数学/算术加速器。([STMicroelectronics][1])

这对 FOC 很有用。

FOC 里面最核心的东西就是坐标变换：

```text
三相电流 Ia/Ib/Ic
    ↓ Clarke
两相静止坐标 Iα/Iβ
    ↓ Park，使用 sinθ/cosθ
旋转坐标 Id/Iq
```

Park 变换需要电角度 θ 的 sin/cos：

```c
Id =  Ialpha * cos_theta + Ibeta * sin_theta;
Iq = -Ialpha * sin_theta + Ibeta * cos_theta;
```

CORDIC 就是专门适合干这种事的。

ST 官方 G4 介绍里也直接提到 CORDIC 对 FOC 很有帮助。([STMicroelectronics][2])

FMAC 可以用来做滤波，比如：

```text
电流采样滤波
母线电压滤波
速度滤波
IMU 加速度滤波
角速度滤波
```

不过初期你可以先不用 CORDIC/FMAC，直接用 CMSIS-DSP 或普通 float 算法。等系统跑通后，再用 CORDIC/FMAC 优化实时性。

这些数量在 ST 数据手册里有列出。([STMicroelectronics][1])

## 10. GPIO：100 引脚封装，实际 GPIO 资源比较充足

STM32G474V 是 100 引脚型号，数据手册里表格显示对应 GPIO 数量为 **86 个**。([STMicroelectronics][1])

双电机 FOC 会吃很多脚：

| 功能            | 大概占用 |
| ------------- | ---: |
| 左电机 3 相互补 PWM |    6 |
| 右电机 3 相互补 PWM |    6 |
| 左电机电流采样       |  2~3 |
| 右电机电流采样       |  2~3 |
| 母线电压/电流/温度    |  3~6 |
| IMU SPI       |  4~5 |
| 编码器/霍尔        |  4~6 |
| UART 调试       |    2 |
| CAN           |    2 |
| 按键/LED/蜂鸣器    |   若干 |

所以 100 引脚是比较合理的。
如果你选 64 引脚，双电机 FOC 会比较紧张。**VET6 这个 100 引脚版本更适合你做平衡车。**

## 11. 它不是电机驱动芯片，外部功率部分还得自己做

这个一定要分清楚：

```text
STM32G474：负责算法、PWM、采样、保护逻辑
MOSFET驱动器：负责驱动MOS管栅极
MOSFET功率桥：真正给电机供电
采样电阻：测电流
电源系统：给MCU、驱动器、传感器供电
```

STM32G474 不能直接驱动无刷电机。你还需要：

| 模块              | 作用            |
| --------------- | ------------- |
| 三相栅极驱动器 × 2     | 驱动左右两个电机的 MOS |
| MOSFET 三相桥 × 2  | 真正输出大电流       |
| 电流采样电阻          | 测相电流          |
| 母线电压采样          | 电池电压检测        |
| 过流保护电路          | 硬件保护          |
| IMU             | 姿态检测          |
| 编码器 / 霍尔 / 无感算法 | 电角度 / 速度获取    |
| DC-DC / LDO     | 电源转换          |

## 12. 做 FOC 平衡车的推荐资源分配

我建议你可以按这个思路设计：

```text
STM32G474VET6
├── TIM1：左轮三相互补PWM
├── TIM8 / TIM20：右轮三相互补PWM
├── ADC1/ADC2：左轮相电流采样
├── ADC3/ADC4：右轮相电流采样
├── ADC5：母线电压、电池电压、温度等慢速采样
├── OPAMP1~OPAMP6：相电流采样放大
├── COMP：过流保护，接入高级定时器刹车
├── SPI：IMU
├── UART：调试日志 / 蓝牙模块
├── CAN：BMS 或上位控制器
├── CORDIC：FOC sin/cos、atan2
└── FMAC：滤波、控制器优化
```

控制周期可以这样定：

| 控制环       |            频率建议 |
| --------- | --------------: |
| PWM / 电流环 | 16 kHz ~ 40 kHz |
| 速度环       |  500 Hz ~ 2 kHz |
| 姿态平衡环     |  500 Hz ~ 1 kHz |
| IMU 采样    |  500 Hz ~ 2 kHz |
| 电池/温度检测   |  10 Hz ~ 100 Hz |
| 通信/日志     |  10 Hz ~ 100 Hz |

初期建议：

```text
PWM：20 kHz
电流环：20 kHz
速度环：1 kHz
姿态环：1 kHz
IMU：1 kHz
```

## 13. 我对这个芯片做平衡车的评价

### 优点

1. **非常适合 FOC**
2. **高级定时器多，双电机够用**
3. **ADC 多，采样能力强**
4. **内部 OPAMP 多，可以省外部电流采样放大器**
5. **内部 COMP 多，方便硬件过流保护**
6. **有 CORDIC，适合 FOC 三角函数计算**
7. **有 FPU，姿态算法更容易写**
8. **100 引脚版本 IO 够用**
9. **512 KB Flash / 128 KB RAM 对运动控制够宽裕**

### 缺点 / 注意点

1. **引脚复用复杂，必须先用 CubeMX 规划**
2. **内部 OPAMP 虽好，但模拟布局难度不低**
3. **双电机三电阻采样会把 OPAMP 用满**
4. **FOC 实时性要求高，软件架构不能乱**
5. **功率板设计比 MCU 选型更难**
6. **平衡车安全保护必须做好，不能只靠软件**

## 最终建议

**STM32G474VET6 可以作为你的平衡车电机控制主控，而且是比较合适的选择。**

我建议你的系统架构是：

```text
STM32G474VET6 专门负责：
1. 双电机FOC
2. 姿态平衡控制
3. IMU采样与滤波
4. 电池电压检测
5. 电流/温度保护
6. CAN/UART通信
```

如果后面你还想加摄像头、Wi-Fi 图传、语音、ROS，那就再加一个 Linux SoC 或 ESP32-S3 作为上位机。
**G474 负责实时运动控制，上位机负责高级功能。** 这才是比较稳的架构。

**STM32G474VET6 是专为高性能电机控制（如FOC平衡车）优化的 Cortex‑M4F 主控，核心优势：170MHz 带 FPU/DSP、硬件数学加速器（CORDIC/FMAC）、3路高级电机定时器、5路高速ADC、丰富模拟前端，完全满足双电机FOC+姿态融合+平衡控制的实时性需求。**


### 一、核心基本参数（LQFP‑100）
- **内核**：ARM Cortex‑M4F（带单精度 FPU）
- **主频**：**170 MHz**（213 DMIPS）
- **Flash**：**512 KB**（带 ECC，双 bank）
- **SRAM**：**128 KB**（含 16 KB 指令缓存）
- **供电**：1.71–3.6 V（模拟区可独立供电）
- **温度**：-40 ℃ ~ +85 ℃
- **封装**：LQFP‑100（14×14 mm）
- **GPIO**：86 个（5V 容忍，大部分可复用）

### 二、FOC 平衡车关键资源（重点）
#### 1. 数学硬件加速器（FOC 必备）
- **CORDIC**：硬件加速 **Clarke / Park / 反Park**、sin/cos/atan2
- **FMAC**：硬件加速 **滤波、PID、矢量点积**
- 效果：FOC 运算时间减少 **50%+**，电流环可跑到 **10–20 kHz** 仍留大量余量给姿态与平衡环

#### 2. 定时器（双电机FOC核心）
- **高级控制定时器（3个）**：**TIM1 / TIM8 / TIM20**
  - 16 位，**带死区插入、互补输出、刹车、BDTR**
  - 每路可独立驱动 **1 套三相无刷（3对互补PWM）**
  - 支持 **中心对齐/边沿对齐**、**ADC触发同步**
  - → **刚好满足双轮平衡车：2路独立FOC电机控制**
- **高分辨率定时器 HRTIM1**：184 ps 精度
  - 适合高精度电源/相移PWM，平衡车FOC一般不用
- **通用/基本定时器**：7个通用 + 2个基本
  - 用于 **编码器输入、系统时基、串口波特率、额外PWM**

#### 3. ADC（电流采样+电压+温度）
- **5 × 12 位 ADC**（ADC1~5）
  - 最高 **4 Msps**，支持 **硬件过采样（提高有效精度到13–14位）**
  - **ADC1/2/4/5 支持差分输入**（适合低侧/高侧电流采样）
  - 多ADC **同步采样、交叉触发、注入组**
- 平衡车典型用法：
  - 电机A：**2相电流采样**（差分）+ 母线电压
  - 电机B：**2相电流采样**（差分）+ 母线电压
  - 额外：**温度、电池分压、IMU模拟（如需）**
  - → **5路ADC完全够用，无需外部扩ADC**

#### 4. 模拟前端（减少外围，降低成本）
- **7 个轨到轨模拟比较器**
  - 用于 **过流保护、母线过压、刹车快速关断**
- **6 个轨到轨可编程运放（OPA）**
  - 带宽 15 MHz，支持 **PGA 增益 1/2/4/8/16/32/64**
