## 一、最精准的PID原理（平衡车专用版）
### 1. 核心定义（必须背下来）
PID = **根据误差，自动计算输出，让系统回到目标**
平衡车里只有一个目标：**车身垂直=0度**

标准**位置式PID公式**（平衡车直立/速度/转向全用这个）：
```
Output = Kp*Err + Ki*Sum_Err + Kd*(Err - Last_Err)
```
变量解释（平衡车场景）：
- `Err`：**当前误差** = 目标值 - 当前测量值
- `Sum_Err`：**误差累计和** = 所有历史误差相加
- `Last_Err`：**上一次误差**
- `Kp/Ki/Kd`：三个需要你调试的系数
- `Output`：最终输出给**电机PWM**

---

### 2. 三个参数在平衡车里的**唯一作用**（绝对精准）
| 系数 | 名字 | 平衡车里的作用 | 调大后果 | 调小后果 |
|------|------|----------------|----------|----------|
| **Kp** | 比例 | 快速扶正，反应速度 | 剧烈抖动、狂甩 | 站不起来、一推就倒 |
| **Ki** | 积分 | 消除静差，让车彻底站直不漂移 | 滞后、冲过头、振荡 | 车永远歪一点、站不直 |
| **Kd** | 微分 | 阻尼、刹车、抑制抖动 | 高频抽搐、电机啸叫 | 来回晃、停不下来 |

**一句话记住**：
P让车站起来，D让车不抖，I让车站直不溜。

## 二、平衡车的3个PID环（硬件+数据流向+代码）
平衡车 = **直立环(P-D) + 速度环(P-I) + 转向环(P)**
**执行顺序绝对不能变**：
1. 读取MPU6050 → 计算倾角
2. 速度PID → 输出**目标角度**
3. 直立PID → 输出**电机基础PWM**
4. 转向PID → 输出**左右电机差量**
5. 最终PWM输出到电机

### 第一环：直立环（Balance PID）【最重要】
**作用**：让车保持垂直，不倒
**输入**：车身倾角（目标=0°）
**输出**：电机PWM
**参数**：**只用 Kp、Kd，绝对不用 Ki！**

#### 1. 直立环公式
```
Balance_Out = Kp_Bal * (Angle - Target_Angle) + Kd_Bal * (Gyro - Target_Gyro)
```
- `Angle`：滤波后的倾角
- `Target_Angle`：速度环给的修正角度
- `Gyro`：陀螺仪角速度（D项直接用这个，更稳定）

#### 2. 标准代码（C语言，STM32/ESP32通用）
```c
// 直立环参数（初始先设0）
float Kp_Bal = 15;   // 核心
float Kd_Bal = 0.8;  // 阻尼

float Balance_PID(float Angle, float Gyro)
{
    float Bias;	     // 角度误差
    float Balance;   // 直立环输出

    Bias = Angle - 0;  // 目标：0度垂直
    // PD计算
    Balance = Kp_Bal * Bias + Kd_Bal * Gyro;

    return Balance;
}
```

#### 3. 直立环**黄金调试步骤（必须照做）**
1. **关闭速度环、转向环**，全部参数=0
2. 先设 `Kd_Bal = 0`
3. **慢慢加大 Kp_Bal**
   - 从 0 → 5 → 10 → 15 → 20
   - 现象：电机开始反抗你的转动
4. 加到**车开始轻微低频晃动**
5. **开始加 Kd_Bal**
   - 0 → 0.2 → 0.5 → 0.8 → 1.0
   - 现象：晃动立刻消失
6. 最终目标：
   - 手一松，车能**独立站立1~3秒**
   - 无抖动、不抽搐、不猛冲

**直立环常用参数区间**
- Kp_Bal：**10 ~ 30**
- Kd_Bal：**0.5 ~ 2.0**

---

### 第二环：速度环（Velocity PID）【让车站稳不跑】
**作用**：让车静止不动，推它能回来
**输入**：左右电机转速
**输出**：给直立环的**目标角度**
**参数**：**只用 Kp、Ki，不用 Kd！**

#### 1. 速度环公式
```
Velocity_Out = Kp_Vel * Err + Ki_Vel * Sum_Err
```

#### 2. 标准代码
```c
// 速度环参数
float Kp_Vel = 0.5;
float Ki_Vel = 0.02;

float Velocity_PID(int Motor1, int Motor2)
{
    static float Bias, Sum_Err;
    static float Velocity;
    int Encoder;

    Encoder = (Motor1 + Motor2) / 2;  // 平均速度
    Bias = Encoder - 0;              // 目标速度=0

    // PI计算
    Sum_Err += Bias;
    // 积分限幅（必须加！防止溢出失控）
    if(Sum_Err > 200) Sum_Err = 200;
    if(Sum_Err < -200) Sum_Err = -200;

    Velocity = Kp_Vel * Bias + Ki_Vel * Sum_Err;

    return Velocity;
}
```

#### 3. 速度环调试步骤
1. 确保**直立环已经调好**
2. 先设 `Ki_Vel = 0`
3. 加大 `Kp_Vel`
   - 0 → 0.2 → 0.5 → 0.8
   - 现象：推车，车会往回走
4. 再加 `Ki_Vel`
   - 0 → 0.01 → 0.02 → 0.05
   - 现象：车彻底站稳，**不会慢慢漂移**
5. 最终目标：
   - 放地上能**长期静止**
   - 推一下 → 回来 → 停稳

**速度环常用参数**
- Kp_Vel：**0.3 ~ 1.0**
- Ki_Vel：**0.01 ~ 0.08**

---

### 第三环：转向环（Turn PID）【让车转弯/走直线】
**作用**：差速控制转向
**输入**：陀螺仪Z轴/遥控量
**输出**：左右电机PWM差值
**参数**：**只用 Kp**

#### 代码
```c
float Kp_Turn = 0.3;

float Turn_PID(float Target)
{
    return Kp_Turn * Target;
}
```

#### 调试
- Kp_Turn 太小：转不动
- Kp_Turn 太大：抖动、甩尾
- 常用：**0.2 ~ 0.8**

## 四、总输出代码（三环合一，直接用）
```c
void Control(float Angle, float Gyro, int Motor1, int Motor2, float Turn_Target)
{
    float Velocity_Out, Balance_Out, Turn_Out;
    int PWM1, PWM2;

    // 1. 速度环（输出给直立环当目标角度）
    Velocity_Out = Velocity_PID(Motor1, Motor2);

    // 2. 直立环（输出电机基础PWM）
    Balance_Out = Balance_PID(Angle + Velocity_Out, Gyro);

    // 3. 转向环（输出左右差量）
    Turn_Out = Turn_PID(Turn_Target);

    // 最终电机PWM
    PWM1 = Balance_Out + Turn_Out;
    PWM2 = Balance_Out - Turn_Out;

    // PWM限幅（必须！）
    if(PWM1 > 250) PWM1 = 250;
    if(PWM1 < -250) PWM1 = -250;
    if(PWM2 > 250) PWM2 = 250;
    if(PWM2 < -250) PWM2 = -250;

    // 输出到电机
    Motor_SetPWM(PWM1, PWM2);
}
```

## 六、10种故障+直接解决方案（调试查表）
1. **一上电猛冲、疯跑**
   - 电机线反了 / 角度方向反了
   - 解决：反转电机或取反角度

2. **能站但剧烈抖动**
   - Kp_Bal 太大
   - 减小 Kp_Bal

3. **电机高频啸叫、抽搐**
   - Kd_Bal 太大
   - 减小 Kd_Bal

4. **站着慢慢溜走**
   - Ki_Vel 太小
   - 加大 Ki_Vel

5. **推车不回来**
   - Kp_Vel 太小
   - 加大 Kp_Vel

6. **回来又冲过去**
   - Kp_Vel 太大
   - 减小 Kp_Vel

7. **一推就倒**
   - Kp_Bal 太小
   - 加大 Kp_Bal

8. **左右摇摆**
   - 转向Kp太大
   - 减小 Kp_Turn

9. **站起来又突然倒**
   - 积分饱和 / PWM限幅不够
   - 加积分限幅、PWM限幅

10. **滤波差、数据乱跳**
    - 必须用互补滤波/卡尔曼滤波

# 平衡车PID从入门到精通：零基础也能调通的完整指南

作为嵌入式初学者，你完全不用害怕PID。它不是什么高深的数学理论，而是一个**"自动纠偏"的简单算法**，就像你骑自行车时大脑自动调整身体平衡一样。我会用最通俗的语言，结合平衡车的实际场景，从原理到调试步骤，一步步带你搞懂。

## 一、PID到底是什么？（大白话版）

PID是**比例(Proportional)、积分(Integral)、微分(Derivative)**三个英文单词的缩写。它的核心思想非常简单：**根据"当前的误差"、"过去的总误差"和"未来的误差趋势"，来决定现在应该输出多大的控制量**。

### 最形象的类比：你用手端着一杯水走路

想象一下，你端着一杯满满的水走路，目标是不让水洒出来：
- **P(比例)作用**：看到杯子歪了多少，就用多大的力气往回扳。歪得越厉害，扳得越用力。
- **I(积分)作用**：如果杯子一直往左边歪一点，你会慢慢加大往左扳的力气，直到把它彻底扳正。
- **D(微分)作用**：看到杯子正在快速往左边倒，你会提前用更大的力气往右扳，防止它倒得太猛。

这三个作用加起来，就是一个完整的PID控制器。你的大脑天生就会用PID，现在我们只是把这个过程写成代码，让单片机来执行。

## 二、P、I、D三个参数分别起什么作用？

| 参数 | 作用 | 调大后的现象 | 调小后的现象 | 平衡车中的直观感受 |
|------|------|--------------|--------------|--------------------|
| **P(比例)** | 快速响应当前误差 | 反应变快，但容易震荡；太大时会剧烈抖动 | 反应迟钝，误差大 | P太大：车会像弹簧一样来回晃；P太小：车一推就倒，扶不起来 |
| **I(积分)** | 消除静态误差 | 消除误差更快，但太大时会出现"积分饱和"，导致超调 | 无法彻底消除误差 | I太大：车会慢慢往一个方向倒，然后突然猛的往回冲；I太小：车总是歪一点站不直 |
| **D(微分)** | 预测误差趋势，抑制震荡 | 系统更稳定，震荡减少；太大时会对噪声敏感，出现高频抖动 | 无法抑制震荡，超调大 | D太大：车会出现"抽搐"式的高频抖动；D太小：车会来回晃，停不下来 |

**核心公式**（不用背，理解就行）：
```
输出 = Kp*当前误差 + Ki*误差的总和 + Kd*(当前误差-上次误差)
```

## 三、平衡车为什么需要PID？

平衡车的本质是一个**倒立摆系统**，就像你把一根筷子竖在手指上一样。它本身是不稳定的，只要稍微偏离垂直位置，就会加速倒下。

单片机需要以**非常高的频率**（通常是100Hz~1000Hz）不断读取陀螺仪和加速度计的数据，计算出车身当前的倾斜角度，然后通过PID算法计算出电机应该输出多大的扭矩，让车轮向倾斜的方向转动，从而把车身"拉"回来。

## 四、平衡车的三个PID环详解

一个完整的平衡车需要**三个独立又相互配合的PID控制器**，它们的优先级从高到低依次是：直立环 > 速度环 > 转向环。

### 1. 直立环（核心中的核心）
- **输入**：车身的倾斜角度（由MPU6050等六轴传感器测量）
- **输出**：电机的基础PWM值
- **目标**：让车身始终保持垂直
- **使用的参数**：主要是**Kp和Kd**，**一般不需要Ki**（直立环要求快速响应，积分会引入滞后）

### 2. 速度环
- **输入**：两个电机的平均速度
- **输出**：直立环的目标角度偏移量
- **目标**：让车保持静止或匀速运动
- **使用的参数**：主要是**Kp和Ki**，**一般不需要Kd**（速度变化比较慢，微分作用不明显）

### 3. 转向环
- **输入**：两个电机的速度差或陀螺仪的Z轴角速度
- **输出**：左右电机的PWM差值
- **目标**：让车保持直线行驶或按指令转向
- **使用的参数**：通常只有**Kp**，简单的平衡车甚至可以不用PID，直接用比例控制

### 三个环的配合关系
```
速度环输出 → 修正直立环的目标角度 → 直立环输出基础PWM → 转向环输出左右PWM差值 → 最终输出到电机
```

## 五、平衡车PID调试的黄金步骤（必看！）

这是无数前辈踩坑总结出来的**唯一正确的调试顺序**，**绝对不能颠倒**！先调直立环，再调速度环，最后调转向环。

### 第一步：准备工作
1. 确保硬件没问题：电机能正常转动，MPU6050数据准确，没有明显的漂移
2. 烧录一个最简单的测试程序，确认串口能正常输出角度、速度等数据
3. 把所有PID参数都先设为0
4. 准备好串口调试助手，最好能显示波形（如SerialPlot）

### 第二步：调试直立环（最关键的一步）
**目标**：用手扶住车，松开后车能自己站立1~2秒不倒下

1. **先调Kp**：
   - 慢慢增大Kp，直到用手转动车身时，电机有明显的反向力矩
   - 继续增大Kp，直到车出现轻微的低频震荡（大约每秒2~3次）
   - 然后把Kp减小到震荡刚好消失的那个值

2. **再调Kd**：
   - 慢慢增大Kd，你会发现车的稳定性明显提高
   - 继续增大Kd，直到车出现高频的"吱吱"声或抖动
   - 然后把Kd减小到抖动刚好消失的那个值

3. **验证**：
   - 用手扶住车，让它垂直，然后突然松开
   - 如果车能自己站立1~2秒，然后慢慢倒下，说明直立环基本调好了
   - 如果车一松开就往一个方向猛冲，说明Kp太大；如果一松开就直接倒下，说明Kp太小

**重要提示**：直立环**绝对不要加Ki**！加了Ki会导致车出现"漂移"现象，根本站不稳。

### 第三步：调试速度环
**目标**：让车能稳定站立，并且被推动后能自动回到原位

1. **先调Kp**：
   - 慢慢增大速度环的Kp，直到车被推动后能往回走
   - 继续增大Kp，直到车出现来回震荡的现象
   - 然后把Kp减小到震荡刚好消失的那个值

2. **再调Ki**：
   - 慢慢增大Ki，直到车能稳定地停在原地，不会慢慢溜走
   - 继续增大Ki，直到车出现缓慢的来回移动
   - 然后把Ki减小到移动刚好消失的那个值

3. **验证**：
   - 把车放在地上，它应该能稳定站立
   - 用手轻轻推一下车，它应该能往回走，然后停在原来的位置附近
   - 如果车被推后回不来，说明Kp太小；如果回来后又冲过去，说明Kp太大

### 第四步：调试转向环
**目标**：让车能直线行驶，并且能按指令转向

1. **调Kp**：
   - 慢慢增大转向环的Kp，直到车能保持直线行驶
   - 继续增大Kp，直到车出现左右摇摆的现象
   - 然后把Kp减小到摇摆刚好消失的那个值

2. **验证**：
   - 把车放在地上，它应该能直线前进或后退
   - 给一个转向指令，车应该能平稳地转向，不会出现抖动

| 车转向时抖动 | 转向环Kp太大 | 减小转向环Kp |

## 七、调试技巧与注意事项

1. **调试频率要足够高**：PID计算的频率至少要100Hz，最好是200Hz以上。频率太低，车根本站不稳。

2. **传感器数据要滤波**：MPU6050的原始数据有噪声，一定要用互补滤波或卡尔曼滤波处理后再给PID使用。

3. **参数要一点点调**：每次只调一个参数，每次调整的幅度不要太大（比如每次增加0.1或0.5）。

4. **用串口波形辅助调试**：把角度、速度、PID输出等数据通过串口发送出来，用波形显示工具观察，比肉眼观察准确得多。

5. **先空载调试，再装电池**：刚开始调试时，不要装电池，用手扶住车，观察电机的反应。确认没问题后再装电池。

6. **做好安全防护**：调试时车可能会突然冲出去，一定要在空旷的地方调试，并且远离人和贵重物品。

7. **参考别人的参数**：可以先找一个和你硬件配置相似的平衡车的参数作为起点，然后再慢慢微调。比如：
   - 直立环Kp：10~30
   - 直立环Kd：0.5~2
   - 速度环Kp：0.5~2
   - 速度环Ki：0.01~0.1
   - 转向环Kp：0.1~1

## 八、给初学者的最后建议

PID调试是一个**需要耐心和细心**的过程，不要指望一次就能调完美。很多人调了几十次甚至上百次才调通，这是非常正常的。

记住一个原则：**先让车能站起来，再让它站得稳，最后让它跑得快**。不要一开始就追求完美，先实现最基本的功能，然后再逐步优化。

作为嵌入式初学者，想要制作一台能自己站稳的平衡车，PID 控制算法是你必须跨过的第一道坎。很多新手一听到 "比例、积分、微分" 就头大，其实 PID 的原理非常朴素，甚至和我们人日常的行为逻辑一模一样。
这篇指南会用最通俗的语言，带你从 PID 的基础原理，一步步搞懂它在平衡车中是怎么工作的，以及最关键的 —— 怎么一步步把参数调对，让你的小车稳稳站起来。

一、先搞懂：PID 到底是什么？
PID 是 P (比例 Proportion)、I (积分 Integral)、D (微分 Derivative) 三个单词的缩写。它的核心思想用一句话就能概括：
根据 "现在的误差"、"过去的累积" 和 "未来的趋势"，来决定现在该出多大的力。
我们可以用一个生活中的例子来理解它 —— 就像你开车去接朋友：
1. 比例控制 P：现在差多少，就补多少
这是最直观的部分。当你发现离朋友还有 100 米的时候，你会踩油门加速；当你离他只有 10 米的时候，你会松油门减速。误差越大，你纠正的力度就越大。
在 PID 里，P 就是干这个的：
P输出 = Kp * 当前误差
- Kp 就是比例系数，它决定了你对当前误差的敏感程度。
- Kp 太小：反应迟钝，车倒了半天才反应过来，结果还是倒了。
- Kp 太大：反应过激，车歪了一点你就猛打方向，结果来回晃个不停。
2. 积分控制 I：过去欠了多少，慢慢补上
有时候，光靠 P 是不够的。比如你开车，风一直从侧面吹你，你为了保持直线，方向盘必须一直稍微歪一点来对抗这个风。如果只靠 P，当车刚好在直线上时，误差为 0，P 的输出就为 0 了，风一吹你又歪了。
这时候就需要 I：它会把过去一段时间的小误差累积起来。只要误差不为 0，它就会一直累加，直到把这个顽固的 "静差" 彻底消除。
I输出 = Ki * 误差的积分（过去所有误差的总和）
- Ki 是积分系数。
- Ki 太小：消除静差太慢，车一直慢慢往一边跑。
- Ki 太大：积分过头了，导致车来回晃，甚至 "积分饱和" 失控。
3. 微分控制 D：预判未来，提前刹车
当你开车快到朋友身边时，你看到车速很快，虽然现在距离还挺大，但你知道再不刹车就要撞上去了。所以你会提前减速。这就是 D 的作用：看误差变化的快慢，提前预判，给系统一个 "刹车" 的阻尼力。
在 PID 里，D 看的是误差的变化率：
D输出 = Kd * 误差的变化率
- Kd 是微分系数。
- Kd 太小：刹不住车，车一歪就冲过了头，导致来回振荡。
- Kd 太大：刹车太猛，系统变得很 "呆滞"，反应很慢，而且对噪声很敏感，一点点抖动都会被放大。

二、平衡车里的 PID：为什么要用 "串级"？
两轮平衡车本质上就是一个倒立摆。你用手指顶一根铅笔，铅笔随时会倒，你必须不停移动手指来跟上它。平衡车的电机就是你的手指，PID 就是你的大脑。
但平衡车的控制不是一个简单的单环 PID，而是用了串级 PID（双闭环 / 三闭环）。为什么？因为单环 PID 响应太慢了，跟不上倒立摆这么快的变化速度。
1. 三个环，各司其职
我们把控制分成了三层，从内到外，从快到慢：
[图片]
图：平衡车串级 PID 控制原理。速度环在外，直立环在内，层层嵌套。
① 最核心：直立环（内环，PD 控制）
这是让车能站起来的根本。它的任务非常简单：保持车身垂直，别倒下。
- 输入：车身的倾斜角度（来自 MPU6050）
- 输出：为了纠正这个倾斜，车轮需要以多快的速度转动。
- 为什么用 PD？
  - P 项：车歪了多少，我就用多大的力去拉回来。歪 5 度比歪 2 度力要大。
  - D 项：车倒的速度越快，我就越要提前用力刹车。防止车倒的太快拉不回来。
  - 为什么不用 I？ 因为直立环反应要极快，积分项会带来滞后和振荡，反而容易让车不稳。
② 防乱跑：速度环（外环，PI 控制）
如果你只开直立环，车虽然能站起来，但它会慢慢的、不受控制的往一个方向越跑越快，最后跑远了倒下。这是因为没有东西管它的位置。
速度环就是干这个的：让车待在原地别动，或者按你想要的速度走。
- 输入：车轮的实际速度（来自编码器）
- 输出：对直立环的目标角度做一个微小的修正。
- 为什么用 PI？
  - 比如车在慢慢往前跑，速度环检测到了，它就会告诉直立环："你稍微往后仰一点点"，这样车就会为了保持平衡而后退，慢慢把速度降回 0。
  - I 项用来消除速度的静差，保证车真的能停在原地，而不是慢慢漂移。
③ 管方向：转向环（辅助环）
这个环负责左右转向。它通过控制两个轮子的差速来实现转向，同时防止车自己慢慢跑偏。

三、手把手教你：PID 参数怎么调？
调参是平衡车制作中最有成就感也最磨人的一步。别怕，只要按顺序来，新手也能很快调好。
🔴 第一步：标定机械零点（最重要的前提！）
在调任何参数之前，你必须先找到你的车的 "平衡位置"。这个位置不是理论上的 0 度，而是由你的硬件决定的（电池重心、电机安装偏差都会影响）。
操作步骤：
1. 在代码里让 OLED 或者串口实时显示当前的融合角度。
2. 断电，用手慢慢把车向前倾斜，直到它马上要倒下的瞬间，记下这个角度 θ_max。
3. 同理，向后倾斜，记下倒下瞬间的角度 θ_min。
4. 机械零点 mech_zero = (θ_max + θ_min) / 2。
举个例子：你测出来向前倒的临界角是 8.3 度，向后倒是 - 6.9 度，那么零点就是 (8.3 + (-6.9))/2 = 0.7 度。以后你的目标角度就不是 0，而是这个 0.7 度！
⚠️ 注意： 每次开机最好都重新校准一下，因为 MPU6050 每次上电的零偏都不一样。
🟠 第二步：调直立环（先让车能站住）
直立环是基础，必须先调它。参数范围参考：Kp_angle: 50~500, Kd_angle: 1.0~5.0
1. 先调 Kp（比例）
- 先把 Kd_angle 设为 0。
- 从一个比较小的值开始（比如 100），慢慢增大 Kp。
- 现象观察：
  - Kp 太小：你一松手，车慢悠悠的就倒了，电机没反应。
  - Kp 慢慢增大：你会发现，松手后车倒的越来越慢，甚至能短暂的站住一下，然后开始前后晃。
  - 当 Kp 大到一定程度，车会在原地高频小幅度的振荡（这就是临界振荡）。
- 停下来！ 记下这个临界的 Kp 值，然后把它乘以 0.6，就是你最终的 Kp。
比如临界 Kp 是 220，那最终 Kp 就是 220 * 0.6 = 132。这是为了留够稳定裕度。
2. 再调 Kd（微分）
- Kp 定了之后，现在开始加 Kd，从 1.0 开始慢慢加。
- 现象观察：
  - Kd=0 的时候，车还是会晃。
  - 随着 Kd 增大，你会发现车的振荡越来越小，越来越稳。
  - 直到你用手推它一下，它能 "Duang" 一下就弹回来，不晃，也不超调。这就对了！
  - Kd 太大了：车会变得很僵硬，推它半天不动，反应很迟钝。
调完这步，你的车已经能在原地站住了！虽然可能还会慢慢漂移，但至少不会倒了。
🟡 第三步：调速度环（让车别乱跑）
直立环调好后，就该处理漂移问题了。速度环的参数都很小，别调太大！参数范围参考：Kp_speed: 0.05~0.3, Ki_speed: Kp_speed / 200
1. 先确定极性
- 先给个初始值，比如 Kp_speed=0.1, Ki_speed=0.0005。
- 上电，如果车立马往前冲，说明极性反了，加个负号就行。
2. 微调参数
- 慢慢增大 Kp，你会发现车漂移的速度越来越慢。
- Ki 按照 Ki = Kp / 200 这个经验公式来设就行。比如 Kp 是 0.2，Ki 就是 0.001。
- 直到你发现，车站稳了之后，几乎不动了，就停在原地。这就成了！
🟢 第四步：调转向环（让车不跑偏）
最后调转向，这个比较简单。
- Kd_steer 从 0.5 开始加，直到车能走直线不跑偏。
- Kp_steer 用来控制遥控转向的灵敏度，一般设个 10 左右就行。

五、参考代码：PID 的 C 语言实现
这里给你一份最基础的 PID 代码模板，你可以直接用在 STM32 上：
// PID结构体
typedef struct {
    float kp;
    float ki;
    float kd;
    float integral;
    float prev_error;
    float integral_max;
    float output_max;
} PID_Controller;

// 初始化PID
void PID_Init(PID_Controller* pid, float kp, float ki, float kd, 
              float integral_max, float output_max) {
    pid->kp = kp;
    pid->ki = ki;
    pid->kd = kd;
    pid->integral = 0.0f;
    pid->prev_error = 0.0f;
    pid->integral_max = integral_max;
    pid->output_max = output_max;
}

// PID计算函数
float PID_Calculate(PID_Controller* pid, float target, float current, float dt) {
    if (dt <= 0) return 0;
    
    float error = target - current;
    
    // 比例项
    float p = pid->kp * error;
    
    // 积分项（带限幅，防止积分饱和）
    pid->integral += error * dt;
    if (pid->integral > pid->integral_max) pid->integral = pid->integral_max;
    if (pid->integral < -pid->integral_max) pid->integral = -pid->integral_max;
    float i = pid->ki * pid->integral;
    
    // 微分项
    float d = pid->kd * (error - pid->prev_error) / dt;
    pid->prev_error = error;
    
    // 总输出（带限幅）
    float output = p + i + d;
    if (output > pid->output_max) output = pid->output_max;
    if (output < -pid->output_max) output = -pid->output_max;
    
    return output;
}

// 全局变量
PID_Controller angle_pid;   // 直立环
PID_Controller speed_pid;  // 速度环
float mech_zero = 0.7f;    // 你的机械零点

// 主控制循环
void Balance_Ctrl_Loop() {
    // 1. 读取传感器数据
    float current_angle = Get_Angle() - mech_zero; // 减去零点
    float current_gyro = Get_Gyro();
    float current_speed = Get_Encoder_Speed();
    
    // 2. 串级PID计算
    // 外环：速度环，输出修正后的目标角度
    float target_angle = PID_Calculate(&speed_pid, 0, current_speed, dt);
    
    // 内环：直立环，输出电机PWM
    // 注意：直立环的D项我们直接用陀螺仪数据，更准确
    float pwm = angle_pid.kp * target_angle - angle_pid.kd * current_gyro;
    
    // 3. 输出到电机
    Motor_Set_PWM(pwm, pwm);
}

PID 本质上就一句话：

**我想要的状态 − 现在的状态 = 误差，PID 根据这个误差算出“该输出多大的控制量”。**

比如平衡车：

**目标角度是 0° 直立，现在车身向前倒了 5°，误差就是 -5°，控制器就让轮子往前跑，把车身接回来。**

## 1. PID 是什么？

PID 有三个部分：

u(t)=K_p e(t)+K_i\int_0^t e(\tau)d\tau+K_d\frac{de(t)}{dt}

这里：

`e(t)` 是误差。

`u(t)` 是控制输出，比如 PWM、目标电流、目标速度。

`Kp`、`Ki`、`Kd` 是三个参数，也就是你要调的 PID 参数。

---

## 2. 用通俗的话理解 P、I、D

### P：比例控制，看到偏差马上修正

假设平衡车往前倒：

```c
error = target_angle - current_angle;
output = Kp * error;
```

偏得越多，输出越大。

例如：

```c
目标角度 = 0°
当前角度 = 5°
误差 = 0 - 5 = -5°
```

如果 `Kp = 20`：

```c
output = -100
```

这个输出可以理解为：让电机往某个方向转，去把车拉回来。

P 的特点：

**反应快，但是容易抖。**

Kp 太小：车软趴趴，扶不住。
Kp 太大：车来回震荡，甚至疯狂抽搐。

---

### I：积分控制，用来消除长期小误差

比如平衡车本来应该停住，但是因为电池、地面、机械重心不完全对称，它可能一直慢慢往前溜。

这时候单纯 P 控制可能解决不了，因为误差很小，P 输出也很小。

I 的作用就是：

**误差虽然小，但是只要一直存在，我就慢慢累加，直到把它消掉。**

```c
integral += error * dt;
output_i = Ki * integral;
```

I 的特点：

**能消除静态误差，但是容易过冲、发疯、积分饱和。**

平衡车里 I 不能乱加。尤其是角度环里面，初学阶段建议先不用 I。

---

### D：微分控制，预测趋势，提前刹车

D 看的是误差变化速度。

比如车已经往前倒了，而且倒得越来越快，D 就会提前加大控制。

在平衡车里，D 项经常直接用陀螺仪角速度。

因为陀螺仪本来测的就是：

```c
车身正在以多快的速度倾倒
```

所以平衡车角度环常见写法不是完整 PID，而是 **PD 控制**：

```c
angle_error = target_angle - pitch_angle;

output = Kp * angle_error + Kd * gyro_y;
```

注意：`gyro_y` 前面是加还是减，要看你的 IMU 坐标方向和电机方向，实际调试时要确认符号。

D 的特点：

**抑制震荡，让车更稳，但是对噪声敏感。**

Kd 太小：车容易来回晃。
Kd 太大：电机发麻、抖动、噪声大、发热。

# 3. 平衡车为什么需要 PID？

平衡车本质上是一个 **倒立摆系统**。

普通小车是稳定的，停着不会倒。

但是两轮平衡车像一个倒着放的棍子：

```text
    |
    |
   车身
    |
   轮子
```

它天然是不稳定的。

只要稍微往前倒，重力就会让它倒得更快。

所以平衡车必须一直做这件事：

```text
检测车身角度
↓
判断往前倒还是往后倒
↓
控制两个轮子往对应方向跑
↓
把车身重新拉回直立
```

这个过程要非常快，一般控制周期在：

```text
1ms ~ 5ms
```

也就是 200Hz 到 1000Hz 左右。

初学可以先用：

```text
5ms 一次控制，也就是 200Hz
```

---

# 4. 平衡车里面一般不是一个 PID，而是多个环

初学者容易误解：以为平衡车就是一个 PID。

实际更常见的是：

```text
角度环：负责不倒
速度环：负责不乱跑
转向环：负责左右转
```

可以理解成：

```text
速度环给角度环一个目标角度
角度环输出电机控制量
转向环给左右轮加差速
```

整体结构大概是：

```text
IMU 角度/角速度
    ↓
角度环 PD
    ↓
基础电机输出
    ↓
左右轮 PWM
```

如果加上速度控制：

```text
编码器速度
    ↓
速度环 PI
    ↓
目标倾角 angle_target
    ↓
角度环 PD
    ↓
电机 PWM
```

---

## 5. 最基础的平衡车控制结构

### 只做站立，不考虑前进后退

最简单：

```c
target_angle = 0.0f;          // 目标直立角度
angle_error = target_angle - pitch_angle;

motor_output = Kp * angle_error + Kd * gyro_y;
```

然后两个电机同向输出：

```c
left_motor_pwm  = motor_output;
right_motor_pwm = motor_output;
```

这个只能让车站住，不适合长期稳定停在原地，因为它可能慢慢往前或往后跑。

---

## 6. 加入速度环之后

速度环的作用是：

**让车不要一直往前溜或者往后溜。**

它一般不直接输出 PWM，而是输出一个小的目标倾角。

比如车往前溜了，速度环就让车身稍微往后仰一点，让它减速回来。

```c
speed_error = target_speed - current_speed;

speed_integral += speed_error * dt;

angle_target = Kp_speed * speed_error + Ki_speed * speed_integral;
```

然后把这个 `angle_target` 交给角度环：

```c
angle_error = angle_target - pitch_angle;

balance_output = Kp_angle * angle_error + Kd_angle * gyro_y;
```

最后输出给电机。

---

## 7. 转向怎么做？

转向一般靠左右轮差速。

```c
turn_output = Kp_turn * turn_error;
```

最后：

```c
left_motor_pwm  = balance_output - turn_output;
right_motor_pwm = balance_output + turn_output;
```

比如：

```text
左轮慢一点，右轮快一点，车就会往左转
左轮快一点，右轮慢一点，车就会往右转
```

# 8. 一个典型的平衡车控制框架

```c
void balance_control_loop(void)
{
    // 1. 读取 IMU
    float pitch_angle = imu_get_pitch_angle();   // 车身俯仰角，单位：度
    float gyro_y      = imu_get_gyro_y();        // 绕 Y 轴角速度，单位：度/s

    // 2. 读取编码器速度
    float left_speed  = encoder_get_left_speed();
    float right_speed = encoder_get_right_speed();

    // 3. 计算整车平均速度
    float current_speed = (left_speed + right_speed) * 0.5f;

    // 4. 速度环：输出目标倾角
    float speed_error = target_speed - current_speed;

    speed_integral += speed_error * CONTROL_DT;

    // 积分限幅，防止积分爆炸
    if (speed_integral > 1000.0f)  speed_integral = 1000.0f;
    if (speed_integral < -1000.0f) speed_integral = -1000.0f;

    float angle_target = KP_SPEED * speed_error + KI_SPEED * speed_integral;

    // 目标倾角限幅，防止速度环要求车身倾斜太大
    if (angle_target > 8.0f)  angle_target = 8.0f;
    if (angle_target < -8.0f) angle_target = -8.0f;

    // 5. 角度环：输出基础电机控制量
    float angle_error = angle_target - pitch_angle;

    float balance_output = KP_ANGLE * angle_error + KD_ANGLE * gyro_y;

    // 6. 转向控制
    float turn_output = KP_TURN * target_turn;

    // 7. 合成左右电机输出
    float left_pwm  = balance_output - turn_output;
    float right_pwm = balance_output + turn_output;

    // 8. PWM 限幅
    left_pwm  = limit(left_pwm,  -PWM_MAX, PWM_MAX);
    right_pwm = limit(right_pwm, -PWM_MAX, PWM_MAX);

    // 9. 防止车已经倒了还疯狂输出
    if (pitch_angle > 35.0f || pitch_angle < -35.0f)
    {
        motor_stop();
        speed_integral = 0;
        return;
    }

    // 10. 输出到电机
    motor_set_pwm(left_pwm, right_pwm);
}
```

# 9. 平衡车 PID 调试顺序

## 第一步：先别急着调 PID，先确认方向

这是最重要的。

你要先确认：

```text
车身往前倒，pitch_angle 是变大还是变小？
车身往前倒，gyro_y 是正还是负？
电机正转时，车是往前走还是往后走？
```

如果方向错了，PID 参数再怎么调都没用。

正确现象应该是：

```text
车身往前倒
↓
轮子应该往前跑
↓
轮子追上车身，把车拉回来
```

如果车身往前倒，轮子反而往后跑，那它会直接加速倒地。

这种情况不是参数问题，是符号方向错了。

---

## 第二步：只调角度环，先不用速度环

先让车只做一件事：

```text
不倒
```

暂时关掉速度环和转向环：

```c
target_speed = 0;
KP_SPEED = 0;
KI_SPEED = 0;
KP_TURN = 0;
```

角度环先用 PD：

```c
balance_output = KP_ANGLE * angle_error + KD_ANGLE * gyro_y;
```

先设置：

```text
KI_ANGLE = 0
KD_ANGLE = 0
KP_ANGLE 从小往大加
```

---

## 第三步：调 Kp

Kp 从小慢慢加。

### Kp 太小的现象

```text
车站不住
反应很软
你手扶着它，它也慢慢倒
```

说明：

```text
扶正力度不够
```

解决：

```text
增大 Kp
```

---

### Kp 合适时

```text
车有明显回正力量
你轻轻推它，它会尝试回来
```

但是这时候可能会前后晃。

---

### Kp 太大

```text
车剧烈前后抖动
电机一抽一抽
轮子疯狂来回转
```

说明：

```text
比例太猛
```

解决：

```text
减小 Kp
```

---

## 第四步：加 Kd 抑制震荡

当 Kp 已经能让车有回正能力之后，再加 Kd。

Kd 的作用像阻尼。

类似弹簧和避震：

```text
Kp 像弹簧
Kd 像避震器
```

只有弹簧没有避震，车会来回弹。

加上 Kd 之后，它会更稳。

### Kd 太小

```text
来回晃
收不住
像弹簧一样弹来弹去
```

### Kd 合适

```text
推一下能回来
震荡少
车身比较稳
```

### Kd 太大

```text
电机高频抖动
声音尖
发热
对 IMU 噪声很敏感
```

---

# 10. 角度环调试口诀

你可以记这个：

```text
先 P 后 D
先站住，再站稳
P 管力度
D 管刹车
I 先不要乱加
```

# 11. 速度环怎么调？

等角度环已经能让车基本站住之后，再加速度环。

速度环通常是 PI：

```c
speed_error = target_speed - current_speed;
speed_integral += speed_error * dt;

angle_target = KP_SPEED * speed_error + KI_SPEED * speed_integral;
```

注意，速度环输出的不是 PWM，而是：

```text
目标倾角
```

比如：

```text
想往前走 → 目标角度稍微往前倾
想停下来 → 目标角度往反方向补偿
```

速度环调试建议：

先只加 `KP_SPEED`，不加 `KI_SPEED`。

```text
KP_SPEED 从很小开始加
```

如果车会慢慢溜，说明速度环不够。

然后再加一点点 `KI_SPEED`，用来消除长期速度误差。

### 速度环调太强的现象

```text
车一会儿往前冲
一会儿往后冲
像喝醉一样来回跑
```

解决：

```text
减小 KP_SPEED
减小 KI_SPEED
限制 angle_target
```

建议：

```c
angle_target = limit(angle_target, -5.0f, 5.0f);
```

初期目标倾角不要太大，`±3° ~ ±8°` 就够了。

# 12. 一个推荐的调试顺序

可以按这个来：

```text
1. 确认 IMU 角度方向
2. 确认陀螺仪方向
3. 确认电机方向
4. 关闭速度环、转向环
5. 只调角度环 Kp
6. 加角度环 Kd
7. 能站住后，加速度环 Kp
8. 再加速度环 Ki
9. 最后加转向控制
10. 做保护逻辑和滤波优化
```

# 13. 调参现象对照表

| 现象        | 可能原因         | 处理方法             |
| --------- | ------------ | ---------------- |
| 一上电直接倒得更快 | 电机方向或角度符号反了  | 反转电机方向或 PID 输出符号 |
| 车软软的，扶不住  | Kp 太小        | 增大角度环 Kp         |
| 车剧烈前后抖    | Kp 太大或 Kd 太小 | 减小 Kp 或增大 Kd     |
| 电机高频发麻    | Kd 太大或陀螺仪噪声大 | 减小 Kd，加滤波        |
| 能站住但慢慢溜走  | 没有速度环或速度环太弱  | 加速度环 PI          |
| 一会前冲一会后冲  | 速度环太强        | 减小速度环 Kp/Ki      |
| 车刚扶正就突然暴冲 | 积分饱和或输出没限幅   | 加积分限幅和 PWM 限幅    |
| 倒地后电机还疯狂转 | 没有倒地保护       | 角度超过阈值立即停机       |

# 14. 平衡车里最关键的不是 PID，而是这几个细节

## 1. 控制周期必须固定

PID 里面的积分和微分都和时间有关。

所以控制周期不能乱跳。

建议用定时器或者高优先级任务固定调用：

```text
1ms、2ms、5ms 都可以
```

初学建议：

```text
5ms 控制一次
```

也就是：

```c
#define CONTROL_DT 0.005f
```

不要在控制循环里 `printf` 大量打印。

打印会拖慢控制周期，导致车抖、倒、响应不稳定。

---

## 2. IMU 角度要滤波

平衡车一般用：

```text
加速度计：长期稳定，但动态时容易受干扰
陀螺仪：短期灵敏，但长期会漂移
```

所以要做融合。

初学可以用互补滤波：

```c
gyro_angle += gyro_y * dt;

pitch_angle = 0.98f * gyro_angle + 0.02f * accel_angle;
```

更高级可以用 Kalman、Mahony、Madgwick。

但是做平衡车入门，互补滤波已经够你起步。

---

## 3. 输出一定要限幅

```c
motor_pwm = limit(motor_pwm, -PWM_MAX, PWM_MAX);
```

否则 PID 算出来的值可能特别大，电机直接暴冲。

---

## 4. 积分一定要限幅

如果用了 I 项，一定加：

```c
integral = limit(integral, -INTEGRAL_MAX, INTEGRAL_MAX);
```

否则车倒了之后，误差一直存在，积分越积越大。

等你扶起来，它可能突然暴冲。

这个叫：

```text
积分饱和
```

英文叫：

```text
Integral Windup
```

---

## 5. 倒地保护必须做

比如：

```c
if (pitch_angle > 35.0f || pitch_angle < -35.0f)
{
    motor_stop();
    speed_integral = 0;
}
```

不然车倒地之后，轮子还会疯狂转，非常危险。

---

目标：

```text
手扶着能明显感觉它会自己回正
```

## 第二阶段：加速度 PI


目标：

```text
能站住，不明显往前后溜
```

## 第三阶段：加转向

目标：

# 16. 你可以先记住这个核心公式

平衡车最核心的控制大概是：

```c
angle_error = angle_target - pitch_angle;

balance_output = KP_ANGLE * angle_error + KD_ANGLE * gyro_y;

left_pwm  = balance_output - turn_output;
right_pwm = balance_output + turn_output;
```

初学阶段，重点不是把公式背熟，而是理解：

```text
车往前倒 → 轮子往前追
车往后倒 → 轮子往后追
倒得越厉害 → 追得越猛
倒得越快 → 提前刹住趋势
```

这就是 PID 在平衡车里的本质。

倒立摆的 PID，本质上和平衡车是同一个思想：

**杆子往哪边倒，底座/轮子就往哪边跑，把支点追到杆子下面。**

平衡车其实可以看成：

```text
倒立摆 + 两个轮子 + 电机
```

# 1. 什么是倒立摆？

普通摆是这样的：

```text
支点
 |
 |
 小球
```

它天然稳定，偏一下会自己回来。

倒立摆是这样的：

```text
 小球/车身重心
 |
 |
支点/轮子
```

它天然不稳定。

只要偏一点点，重力就会让它越倒越快。

所以倒立摆控制要做的事情就是：

```text
检测杆子角度
↓
判断往左倒还是往右倒
↓
控制底座往同方向移动
↓
让支点重新跑到重心下面
```

平衡车就是：

```text
检测车身角度
↓
车身往前倒
↓
轮子往前跑
↓
轮子追上车身
↓
车重新立住
```

---

# 2. 倒立摆 PID 控制到底控制什么？

倒立摆一般有几个状态量：

```c
theta      // 杆子的角度
theta_dot  // 杆子的角速度
x          // 小车/底座位置
x_dot      // 小车/底座速度
```

对应平衡车就是：

```c
pitch_angle    // 车身俯仰角
gyro_y         // 车身倾倒角速度
wheel_position // 轮子位置，编码器积分得到
wheel_speed    // 轮子速度，编码器计算得到
```

最核心的是角度：

```text
目标角度：0°
当前角度：theta
角度误差：target_theta - theta
```

如果只考虑让它不倒，最简单的控制就是角度 PID。

---

# 3. 最基础的倒立摆角度 PID

假设：

```c
target_theta = 0.0f;   // 目标直立角度
theta        = 当前角度;
```

那么误差是：

```c
error = target_theta - theta;
```

PID 输出：

```c
output = Kp * error + Ki * integral + Kd * derivative;
```

这个 `output` 可以理解成：

```text
让小车往左/往右移动的力
或者让轮子往前/往后转的 PWM
```

在倒立摆里，最常用的其实不是完整 PID，而是 **PD 控制**：

```c
output = Kp * angle_error + Kd * angle_speed;
```

原因是：

```text
P：根据当前倒了多少来修正
D：根据现在倒得多快来提前刹车
I：在角度环里容易导致过冲和发疯，初期通常不用
```

---

# 4. 为什么倒立摆常用 PD，而不是一上来就 PID？

倒立摆很敏感。

如果你在角度环里加 I：

```c
integral += angle_error;
```

车一旦倒下，角度误差一直很大，积分会越积越多。

然后你把车扶起来，它可能突然暴冲。

这就是积分饱和。

所以倒立摆/平衡车一般这样做：

```text
角度环：PD
速度环：PI
位置环：PD 或 PID
```

也就是：

```text
最里面的快速稳定环，不乱用 I
外面的慢速修正环，可以适当用 I
```

---

# 5. 倒立摆控制的核心直觉

假设倒立摆往右倒：

```text
     /
    /
   /
小车
```

这时候小车应该怎么办？

答案是：

```text
小车也往右跑
```

因为要让支点重新跑到杆子的重心下面。

如果小车反而往左跑，会变成：

```text
杆子往右倒
小车往左跑
重心和支点越来越远
直接倒得更快
```

所以调试倒立摆第一件事不是调 PID，而是确认方向。

你要确认：

```text
杆子往右倒，角度是正还是负？
杆子往右倒，角速度是正还是负？
控制输出为正，小车往右还是往左？
```

如果方向错了，PID 参数再怎么调都没用。

# 6. 单环 PID 控制倒立摆

最简单结构：

```text
目标角度 0°
    ↓
角度误差
    ↓
角度 PID/PD
    ↓
电机 PWM / 小车力
    ↓
倒立摆运动
    ↓
IMU 反馈角度
```

代码大概是：

```c
void inverted_pendulum_angle_control(void)
{
    float target_theta = 0.0f;       // 目标角度，直立为 0 度
    float theta = get_angle();       // 当前角度
    float gyro = get_gyro();         // 当前角速度

    float error = target_theta - theta;

    // 角度环一般先用 PD
    float output = KP_ANGLE * error - KD_ANGLE * gyro;

    output = limit(output, -PWM_MAX, PWM_MAX);

    motor_set_pwm(output);
}
```

注意这个地方：

```c
float output = KP_ANGLE * error - KD_ANGLE * gyro;
```

这里的 `+` 或 `-` 不绝对，要看你的角度方向、陀螺仪方向、电机方向。

有些工程里会写成：

```c
output = KP_ANGLE * error + KD_ANGLE * gyro;
```

所以你不能死背符号，要看实际现象：

```text
杆子往前倒，轮子应该往前追
杆子往后倒，轮子应该往后追
```

只要这个现象对，方向就对。

---

# 7. 单环控制的问题

只用角度环，可以让倒立摆不倒，但是会有一个问题：

```text
小车可能一直跑
```

比如平衡车：

```text
它能站住，但是会慢慢往前溜
```

为什么？

因为角度环只关心：

```text
车身是不是直立
```

它不关心：

```text
轮子是不是一直在跑
位置是不是越来越偏
```

所以实际倒立摆一般要加外环。

---

# 8. 串级 PID：倒立摆真正常用结构

更合理的倒立摆控制是：

```text
位置环/速度环 → 给出目标角度
角度环 → 给出电机输出
```

比如平衡车：

```text
速度环：你现在是不是在乱跑？
    ↓
输出一个目标倾角
    ↓
角度环：根据目标倾角控制车身
    ↓
输出 PWM
```

整体是：

```text
目标速度
   ↓
速度 PI
   ↓
目标角度
   ↓
角度 PD
   ↓
电机 PWM
```

---

# 9. 为什么速度环输出的是目标角度？

这个非常关键。

平衡车想往前走，并不是直接让电机往前转就完了。

而是应该让车身稍微往前倾：

```text
目标角度 = +3°
```

车身一往前倾，角度环为了不让它倒，就会让轮子往前追。

于是车就往前走了。

所以：

```text
速度环控制“想倾斜多少”
角度环控制“如何保证不倒”
```

这就是串级控制的思想。

---

# 10. 倒立摆串级 PID 代码框架

假设有编码器，可以得到速度：

```c
void inverted_pendulum_control(void)
{
    // ==============================
    // 1. 获取传感器数据
    // ==============================
    float theta = imu_get_pitch_angle();    // 当前角度
    float gyro  = imu_get_gyro_y();         // 当前角速度

    float speed = encoder_get_speed();      // 当前轮子速度

    // ==============================
    // 2. 速度环 PI
    // 速度环输出目标角度
    // ==============================
    float speed_error = target_speed - speed;

    speed_integral += speed_error * CONTROL_DT;

    // 积分限幅
    speed_integral = limit(speed_integral, -SPEED_I_MAX, SPEED_I_MAX);

    float target_theta = KP_SPEED * speed_error
                       + KI_SPEED * speed_integral;

    // 目标倾角限幅
    target_theta = limit(target_theta, -8.0f, 8.0f);

    // ==============================
    // 3. 角度环 PD
    // 角度环输出电机 PWM
    // ==============================
    float angle_error = target_theta - theta;

    float motor_output = KP_ANGLE * angle_error
                       - KD_ANGLE * gyro;

    motor_output = limit(motor_output, -PWM_MAX, PWM_MAX);

    // ==============================
    // 4. 倒地保护
    // ==============================
    if (theta > 35.0f || theta < -35.0f)
    {
        motor_stop();
        speed_integral = 0;
        return;
    }

    // ==============================
    // 5. 输出
    // ==============================
    motor_set_pwm(motor_output);
}
```

---

# 11. 对应到平衡车就是这样

平衡车两个轮子，一般这样输出：

```c
left_pwm  = balance_output - turn_output;
right_pwm = balance_output + turn_output;
```

其中：

```c
balance_output
```

来自角度环。

```c
turn_output
```

来自转向控制。

完整结构：

```text
速度环 PI
    ↓
目标倾角 target_angle
    ↓
角度环 PD
    ↓
balance_output
    ↓
左右轮差速
```

# 12. 倒立摆 PID 参数怎么调？

## 第一步：先只调角度环

先不要管速度环、位置环。

也就是：

```c
target_theta = 0;
KP_SPEED = 0;
KI_SPEED = 0;
```

只保留：

```c
motor_output = KP_ANGLE * angle_error - KD_ANGLE * gyro;
```

---

## 第二步：确认控制方向

手扶着车/倒立摆，让它轻轻往前倒。

正确现象：

```text
往前倒 → 轮子/小车往前跑
往后倒 → 轮子/小车往后跑
```

错误现象：

```text
往前倒 → 轮子/小车往后跑
```

这种会直接炸，不要继续调参数。

应该改：

```c
motor_output = -motor_output;
```

或者调整电机方向、角度方向。

---

## 第三步：调 Kp

先设置：

```c
KI_ANGLE = 0;
KD_ANGLE = 0;
```

然后慢慢增大 `KP_ANGLE`。

### Kp 太小

现象：

```text
扶不住
软绵绵
倒了也没什么反应
```

处理：

```text
增大 Kp
```

### Kp 逐渐合适

现象：

```text
有明显回正力量
手推它，它会顶回来
```

### Kp 太大

现象：

```text
剧烈来回抖
电机抽搐
轮子疯狂正反转
```

处理：

```text
减小 Kp
```

---

## 第四步：调 Kd

Kp 有回正能力后，再加 Kd。

Kd 就像阻尼。

你可以这样理解：

```text
Kp = 弹簧
Kd = 避震器
```

只有 Kp，没有 Kd，倒立摆容易像弹簧一样来回弹。

加 Kd 后，能压住震荡。

### Kd 太小

```text
来回晃
收不住
```

### Kd 合适

```text
推一下能回来
震荡少
```

### Kd 太大

```text
电机高频抖动
声音发尖
发热
对 IMU 噪声很敏感
```

---

# 13. 角度环调好后，再调速度环

当角度环已经能让车基本站住，再加速度环。

速度环先只加 P：

```c
target_theta = KP_SPEED * speed_error;
```

如果车会慢慢溜，说明需要速度环。

然后一点点加 `KI_SPEED`：

```c
speed_integral += speed_error * dt;
target_theta = KP_SPEED * speed_error + KI_SPEED * speed_integral;
```

速度环的作用是：

```text
让车不要越跑越远
让它自己慢慢回到静止
```

---

# 14. 速度环调坏的表现

速度环太弱：

```text
车能站住，但是慢慢往前/往后溜
```

速度环太强：

```text
车一会往前冲
一会往后冲
像喝醉一样
```

速度积分太大：

```text
扶起来突然暴冲
停不住
越修越猛
```

解决方法：

```c
target_theta = limit(target_theta, -5.0f, 5.0f);
speed_integral = limit(speed_integral, -I_MAX, I_MAX);
```

# 15. 倒立摆 PID 和普通电机 PID 有什么区别？

普通电机速度 PID：

```text
速度慢了 → 加大 PWM
速度快了 → 减小 PWM
```

它是稳定系统。

倒立摆 PID：

```text
角度偏了 → 必须马上控制底座追过去
```

它是不稳定系统。

区别很大：

| 项目   | 普通电机 PID | 倒立摆 PID   |
| ---- | -------- | --------- |
| 对象   | 稳定       | 天然不稳定     |
| 调参难度 | 相对简单     | 难很多       |
| 控制周期 | 可以慢一点    | 必须快       |
| 传感器  | 编码器即可    | IMU + 编码器 |
| I 项  | 常用       | 角度环慎用     |
| 保护   | 可选       | 必须有倒地保护   |

# 16. 倒立摆控制频率建议

平衡车/倒立摆建议：

```text
角度环：200Hz ~ 1000Hz
速度环：50Hz ~ 200Hz
```

初学可以这样：

```c
角度环：5ms 一次，也就是 200Hz
速度环：10ms 一次，也就是 100Hz
```

不要在控制环里疯狂 `printf`。

因为打印会让周期变长，控制就乱了。

# 17. 倒立摆 PID 最关键的几个点

## 1. 角度必须准

IMU 角度不能乱跳。

常见做法：

```text
加速度计 + 陀螺仪互补滤波
```

比如：

```c
gyro_angle += gyro_y * dt;
pitch_angle = 0.98f * gyro_angle + 0.02f * accel_angle;
```

---

## 2. 角速度很重要

很多初学者只用角度，不用角速度。

这样很容易震荡。

因为你只知道：

```text
现在倒了多少
```

但不知道：

```text
它正在以多快速度倒下去
```

角速度就是 D 项的核心。

---

## 3. 输出一定要限幅

```c
motor_output = limit(motor_output, -PWM_MAX, PWM_MAX);
```

---

## 4. 积分一定要限幅

```c
speed_integral = limit(speed_integral, -I_MAX, I_MAX);
```

---

## 5. 倒地要停机

```c
if (theta > 35.0f || theta < -35.0f)
{
    motor_stop();
    speed_integral = 0;
}
```

不然倒地后轮子疯狂转，非常危险。

---

# 18. 一个简单调试流程

你可以按这个顺序来：

```text
1. 只读 IMU，看角度是否稳定
2. 手动前后倾斜，看角度方向
3. 手动控制电机，看正反方向
4. 确认“往前倒，轮子往前追”
5. 关闭速度环，只开角度 PD
6. Kp 从小加到有回正力
7. 加 Kd 压震荡
8. 加速度环 P，抑制溜车
9. 加速度环 I，消除长期漂移
10. 加倒地保护、输出限幅、积分限幅
```

---

# 19. 一句话总结倒立摆 PID

倒立摆 PID 可以这么理解：

```text
P：倒了多少，我就追多少
D：倒得多快，我就提前刹多少
I：长期偏差，我慢慢补多少
```

在实际平衡车里，更推荐这样：

```text
角度环用 PD，负责不倒
速度环用 PI，负责不乱跑
转向环做差速，负责左右转
```

核心控制逻辑就是：

```c
// 速度环输出目标倾角
target_angle = speed_PI(target_speed, current_speed);

// 角度环输出平衡 PWM
balance_pwm = angle_PD(target_angle, pitch_angle, gyro_y);

// 左右轮输出
left_pwm  = balance_pwm - turn_pwm;
right_pwm = balance_pwm + turn_pwm;
```

你先不要一开始追求完整复杂算法，先把这个最小闭环跑通：

```text
IMU 角度稳定
电机方向正确
角度 PD 能扶住
速度 PI 能防止溜车
```

这就已经是平衡车倒立摆控制的核心了。
