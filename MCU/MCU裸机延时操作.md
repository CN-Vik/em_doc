# 代码完整解读（嵌入式定时上报逻辑）
这是一段**单片机非阻塞延时执行代码**（涂鸦智能MCU开发场景），核心功能：**上电初始化后，延迟1500ms（1.5秒）执行一次数据上报，之后每间隔1500ms循环执行**。

## 完整代码
```c
// 定义静态32位无符号变量，初始值为0
static u32 t0 = 0;
static u32 t1 = 0;

// 三元运算符：初始化时间基准,第一次运行时候让两个值相等操作，后续只需要让另一个值变化就可以了
(t0 == t1) ? (t1 = t0) : (t0 = mode.sys_time_ms);

// 判断：当前时间 - 基准时间 > 1500ms
if (t0 > t1 + 1500)
{
    t1 = t0;  // 更新基准时间，重新计时
    // 上报字符串数据点到云端/APP
    mcu_dp_string_update(DPID_TOILET_LIST, string_data, strlen((char *)string_data));
    mcu_dp_string_update(DPID_CLEAN_COMPLETED, string_clean, strlen((char *)string_clean));
}
```

---

## 逐行详细解析

### 1. 静态变量定义
```c
static u32 t0 = 0;
static u32 t1 = 0;
```
- `static`：**静态局部变量**，函数多次调用时**不会重置**，永久保存上一次的值；
- `u32`：无符号32位整数（嵌入式专用类型，用于存储时间戳）；
- `t0`：**当前系统时间**；
- `t1`：**上一次执行操作的基准时间**；
- 初始值：上电后两个变量都默认为 `0`。

---

### 2. 三元运算符逻辑（核心初始化）
```c
(t0 == t1) ? (t1 = t0) : (t0 = mode.sys_time_ms);
```
**等价于 if-else 语句**：
```c
if (t0 == t1) {
    t1 = t0;  // 时间相等时，同步基准时间
} else {
    t0 = mode.sys_time_ms;  // 时间不等时，刷新当前时间
}
```

#### 执行流程：
1. **第一次运行（上电初始）**：
   `t0=0`，`t1=0` → 条件成立 → 执行 `t1 = t0`（无实际变化，仅同步基准）；
2. **第二次及以后运行**：
   `t0≠t1` → 条件不成立 → 执行 `t0 = mode.sys_time_ms`，**持续获取最新系统毫秒时间**。

---

### 3. 延时判断逻辑
```c
if (t0 > t1 + 1500)
```
- 判断条件：**当前时间 t0 ＞ 基准时间 t1 + 1500毫秒**；
- 含义：距离上一次执行操作，已经过去了**1.5秒**，满足延时要求。

---

### 4. 执行任务 + 重置基准时间
```c
{
    t1 = t0;  // 把当前时间赋值给基准时间，重新开始计时
    // 上报两个字符串类型的数据点到云端
    mcu_dp_string_update(DPID_TOILET_LIST, string_data, strlen((char *)string_data));
    mcu_dp_string_update(DPID_CLEAN_COMPLETED, string_clean, strlen((char *)string_clean));
}
```
- `t1 = t0`：关键操作，更新基准时间，保证**每1500ms执行一次**，不重复触发；
- `mcu_dp_string_update`：涂鸦智能SDK函数，**上报字符串数据**；
- 功能：上报`马桶列表`和`清洁完成状态`到手机APP/云端。

---

## 整体运行流程（最易懂版）
1. 上电：`t0=0`，`t1=0`；
2. 第一次循环：同步时间，不执行上报；
3. 后续循环：持续刷新当前时间`t0`；
4. 当`t0`比`t1`大1500ms时：
   - 执行数据上报；
   - 重置`t1 = t0`；
5. 循环往复：**每隔1.5秒自动上报一次数据**。

---

## 关键特性
1. **非阻塞延时**：不使用`delay`死等，不影响主程序其他任务；
2. **静态变量保值**：`t0/t1`不会被重置，持续计时；
3. **定时循环执行**：1500ms为周期，稳定上报数据；
4. **适配嵌入式/单片机**：适用于涂鸦智能物联网设备开发。

### 总结
1. 代码功能：**上电延迟1.5s后，每间隔1.5s循环上报数据**；
2. 核心原理：**时间戳差值判断** + 静态变量保值；
3. 应用场景：智能马桶/家电联网数据定时上报。
