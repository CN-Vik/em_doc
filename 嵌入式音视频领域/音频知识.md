不一定。“音频信号是不是单相信号线”，要看你说的是**哪种音频接口/传输方式**。

## 1. 模拟音频：可以是单端，也可以是差分

### 单端音频信号

常见于耳机口、AUX、LINE OUT、麦克风输入等。

一根信号线配一根地线：

```text
Audio_L  ---- 音频信号
GND      ---- 参考地
```

如果是左右声道，就是：

```text
L        ---- 左声道信号
R        ---- 右声道信号
GND      ---- 公共地
```

例如 3.5mm 耳机口：

```text
Tip   = L
Ring  = R
Sleeve = GND
```

这种可以理解成“单端信号”，但严格说不是“单相”。“单相”更多用于交流电供电，比如单相 220V。

---

## 2. 差分音频信号

有些音频接口不是一根信号线对地，而是一对信号线互为反相：

```text
Audio_P  ---- 正相信号
Audio_N  ---- 反相信号
```

接收端看的是：

```text
Audio_P - Audio_N
```

这种叫**差分音频**，抗干扰能力更强。

常见于：

```text
平衡音频 XLR
部分功放输出
差分麦克风输入
I2S 音频 codec 的模拟差分输入/输出
一些 Class-D 功放输入/输出
```

比如功放喇叭输出经常是 BTL 桥接输出：

```text
SPK_P  ---- 喇叭一端
SPK_N  ---- 喇叭另一端
```

这时候**喇叭两端都不是地**，不能随便把 SPK_N 接地，否则可能烧功放。

---

## 3. 数字音频：不是普通“音频波形线”

比如 I2S、PCM、PDM 这些是数字音频接口。

### I2S 常见信号线

```text
BCLK   ---- 位时钟
LRCLK  ---- 左右声道选择/帧同步
DATA   ---- 音频数据
MCLK   ---- 主时钟，可选
GND    ---- 地
```

I2S 不是“一根音频线”，它传的是数字采样数据。

---

## 4. 总结一句话

音频信号线不能简单说成“单相信号线”。

更准确地说：

```text
模拟音频可能是单端信号：Signal + GND
模拟音频也可能是差分信号：P + N
数字音频一般是多根数字线：BCLK/LRCLK/DATA/MCLK
喇叭功放输出常见是差分/BTL：SPK_P + SPK_N
```

你在嵌入式硬件里最需要注意的是：**看到 Audio_N、SPK_N、MIC_N 这种名字，不要默认它是 GND。**它很可能是差分负端。

是的，**很多音频数据接口都是串行传输的**，尤其是嵌入式里常见的 **I2S / PCM / PDM / S/PDIF**。

但要区分：**模拟音频信号**和**数字音频数据**。

## 1. 模拟音频不是“串行数据”

比如耳机口、AUX、喇叭模拟信号：

```text
Audio_L  ---- 连续变化的模拟电压
GND      ---- 参考地
```

它不是一位一位传输的数字数据，而是连续电压波形。

比如一个正弦波音频：

```text
电压
 ^
 |      / \      / \
 |     /   \    /   \
 |____/     \__/     \____> 时间
```

这个不能说是串行数据。

---

## 2. 数字音频通常是串行的

比如 **I2S**，音频采样数据是一 bit 一 bit 送出去的。

典型 I2S 有这些线：

```text
BCLK   ---- 位时钟
LRCLK  ---- 左右声道选择，也叫 WS
DATA   ---- 串行音频数据
MCLK   ---- 主时钟，有些场景需要
GND    ---- 地
```

其中真正传音频数据的是 `DATA`，它是串行的。

例如 16bit 立体声音频：

```text
左声道样本：  1010 1100 0011 0101
右声道样本：  0110 1001 1110 0001
```

在 I2S 的 DATA 线上，会变成一位一位传：

```text
DATA: 1 0 1 0 1 1 0 0 0 0 1 1 0 1 0 1 ...
BCLK: ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑
```

每来一个 `BCLK`，传输一位数据。

---

## 3. 为什么音频数据喜欢用串行？

因为省引脚。

假如 16bit 音频用并行传输，那至少要 16 根数据线：

```text
D0 D1 D2 D3 ... D15
```

这样太浪费 IO。

串行只需要一根或少数几根数据线：

```text
DATA + BCLK + LRCLK
```

所以嵌入式里音频 codec、功放、麦克风常用串行音频接口。

---

## 4. I2S 里面左右声道怎么分？

靠 `LRCLK` 区分。

```text
LRCLK = 0  一般表示左声道
LRCLK = 1  一般表示右声道
```

示意：

```text
LRCLK: ____--------____--------
DATA : LLLLLLLLLLLLRRRRRRRRRRRR
BCLK : |||||||||||||||||||||||||
```

也就是说，`DATA` 线上不是同时传左声道和右声道，而是：

```text
先传左声道的一帧数据
再传右声道的一帧数据
然后循环
```

---

## 5. PDM 麦克风也是串行

PDM 数字麦克风通常只有：

```text
CLK   ---- 时钟
DATA  ---- 串行数据
GND
VDD
```

PDM 的 DATA 也是一位一位输出，只是它不是普通 PCM 采样值，而是高频 1bit 数据流，后面需要滤波/抽取得到 PCM 音频数据。

---

## 6. 总结

可以这样理解：

```text
模拟音频：连续电压波形，不是串行数据
I2S 音频：串行数字音频数据
PCM 音频接口：多数也是串行
PDM 麦克风：1bit 串行数据流
S/PDIF：串行数字音频
```

所以你问“音频数据是不是串行的”，答案是：

**数字音频数据大多数是串行的；模拟音频信号不是串行数据。**
