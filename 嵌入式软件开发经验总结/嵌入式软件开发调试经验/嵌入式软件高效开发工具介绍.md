# 二、实时波形 / 数据观测工具

这一类对于你的FOC最重要。

| 工具          | 类似什么      | 数据来源        | 是否影响实时性 | 适合场景        |

# 三、MCUViewer和J-Link关系

MCUViewer比较特殊。

它支持：

* ST-Link
* J-Link
* CMSIS-DAP

取决于芯片和接口。

但是体验：

J-Link最好。

原因：

采样速度。

例如：

读取：

```
1000个变量
```

ST-Link：

可能几十Hz。

J-Link：

几百Hz甚至更高。
