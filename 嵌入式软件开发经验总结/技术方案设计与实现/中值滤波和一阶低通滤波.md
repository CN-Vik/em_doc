针对你的 **CS1237猫砂盆称重**，可以写一个组合滤波：

流程：

```
CS1237 ADC原始值
        |
        ↓
  5点中值滤波
        |
        ↓
 一阶IIR低通滤波
        |
        ↓
  输出稳定重量
```

代码如下：

### weight_filter.h

```c
#ifndef __WEIGHT_FILTER_H__
#define __WEIGHT_FILTER_H__

#include <stdint.h>


typedef struct
{
    int32_t median_buf[5];
    uint8_t index;

    float lpf_value;     //低通输出值
    float alpha;         //低通系数

    uint8_t init_flag;

}weight_filter_t;



void weight_filter_init(weight_filter_t *filter, float alpha);

int32_t weight_filter_update(weight_filter_t *filter, int32_t adc_value);


#endif
```

---

### weight_filter.c

```c
#include "weight_filter.h"
#include <string.h>


/*
 * 5点中值滤波
 */
static int32_t median_filter5(int32_t *buf)
{
    int32_t temp[5];

    memcpy(temp, buf, sizeof(temp));


    //冒泡排序
    for(int i=0;i<5;i++)
    {
        for(int j=i+1;j<5;j++)
        {
            if(temp[i] > temp[j])
            {
                int32_t t=temp[i];
                temp[i]=temp[j];
                temp[j]=t;
            }
        }
    }


    return temp[2];
}



/*
 * 初始化
 */
void weight_filter_init(weight_filter_t *filter, float alpha)
{
    memset(filter,0,sizeof(weight_filter_t));

    filter->alpha = alpha;

}



/*
 * 更新一次重量数据
 */
int32_t weight_filter_update(weight_filter_t *filter, int32_t adc_value)
{

    /*
     * 第一次进入
     * 防止启动慢慢爬升
     */
    if(filter->init_flag == 0)
    {
        for(int i=0;i<5;i++)
        {
            filter->median_buf[i]=adc_value;
        }

        filter->lpf_value = adc_value;

        filter->init_flag=1;
    }


    /*
     * ===========
     * 1. 中值滤波
     * ===========
     */

    filter->median_buf[filter->index]=adc_value;


    filter->index++;

    if(filter->index>=5)
    {
        filter->index=0;
    }


    int32_t median_value;


    median_value = median_filter5(filter->median_buf);



    /*
     * ===========
     * 2. 一阶低通
     * ===========
     *
     * y(k)=y(k-1)+a(x-y(k-1))
     *
     */


    filter->lpf_value += 
        filter->alpha *
        ((float)median_value - filter->lpf_value);



    return (int32_t)filter->lpf_value;

}
```

---

## 使用方法

比如你的CS1237：

```c
weight_filter_t weight_filter;
```

初始化：

```c
weight_filter_init(
        &weight_filter,
        0.2f
);
```

ADC读取：

```c
int32_t adc;


adc = cs1237_get_data();


int32_t weight_adc;


weight_adc = weight_filter_update(
                &weight_filter,
                adc
             );
```

## 参数建议（你的猫砂盆）

你之前：

```c
alpha = 0.92
```

太快。

建议：

### 猫进入检测

```c
alpha = 0.25
```

响应快：

约200~400ms

### 精确显示重量

```c
alpha = 0.1
```

更加稳定：

约1秒左右

### 防电机震动

```c
alpha = 0.05
```

非常稳。

## 进一步建议

你的猫砂盆还有一个特殊情况：

清理电机运行时，会产生机械震动。

所以最好再加一个：

```c
if(abs(new-old)>阈值)
{
    丢弃
}
```

也就是：

```
中值滤波
 ↓
突变检测
 ↓
IIR
 ↓
重量状态机
```

这个结构基本就是商业宠物秤/智能猫砂盆常用方案。你现在的 CS1237 + 状态机方向是对的。
