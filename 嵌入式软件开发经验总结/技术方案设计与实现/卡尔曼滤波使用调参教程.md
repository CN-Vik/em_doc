很多人一听到“卡尔曼滤波（Kalman Filter）”就觉得是高深莫测的数学魔法（满屏幕的矩阵运算）。但如果只是处理**单一传感器的数据**（比如 ADC 读电压、温度传感器、单轴距离等），我们完全可以剥离复杂的矩阵，使用**一维卡尔曼滤波**。

一维卡尔曼滤波非常轻量级，普通单片机也能轻松跑起来。它的核心逻辑就是：**“我预测的值”和“传感器测量的值”，我该相信谁多一点？**

## 1. 核心思想：动态的信任分配

卡尔曼滤波在循环做两件事：

1. **预测（Predict）：** 根据上一时刻的状态，预测当前应该是什么值。同时估算这个预测的“误差（不确定性）”。
2. **更新（Update）：** 读取传感器的真实测量值。计算出一个**卡尔曼增益（$K$）**。
* 如果传感器的噪声大，$K$ 就小，系统就更相信“预测值”。
* 如果系统自身的模型很不准（比如突然受到外力），$K$ 就大，系统就更相信“传感器的测量值”。



相比于一阶低通滤波死板的系数 $\alpha$，卡尔曼增益 $K$ 是**每次计算时动态自适应调节的**，这就是它强大的原因。

## 2. 一维卡尔曼滤波 C语言实现

在处理单一标量（如电位器电压、温度）时，我们不需要矩阵。你只需要定义几个变量，并套用下面的代码。

```c
// 定义卡尔曼滤波器的结构体
typedef struct {
    float x;  // 系统的状态量 (最优估计值，也就是最终的滤波输出)
    float p;  // 估计误差协方差 (系统对当前预测的“信心”大小)
    float q;  // 过程噪声 (系统真实状态发生改变的波动程度)
    float r;  // 测量噪声 (传感器自身的硬件底噪)
} KalmanFilter1D;

// 初始化函数
// 初始值 init_x 可以设为第一次读到的传感器值
// q 和 r 是需要你根据实际情况调整的参数
void Kalman1D_Init(KalmanFilter1D *kf, float init_x, float q, float r) {
    kf->x = init_x;
    kf->p = 1.0f;   // 初始误差可以随便设一个非零值，算法跑几次后会自动收敛
    kf->q = q;      // 例如: 0.01
    kf->r = r;      // 例如: 0.1
}

// 核心计算函数 (每次采集到新数据时调用)
float Kalman1D_Update(KalmanFilter1D *kf, float measurement) {
    // 1. 预测阶段
    // 对于温度、ADC等简单信号，我们假设它静止不变，所以预测值就是上一次的值 x。
    // 但我们的不确定性 p 增加了，因为时间推移，现实可能发生了变化 (加上过程噪声 q)
    kf->p = kf->p + kf->q;

    // 2. 计算卡尔曼增益 K (核心！)
    // 如果测量噪声 r 很大，K 就会变小；如果预测误差 p 很大，K 就会变大趋近于 1
    float k = kf->p / (kf->p + kf->r);
    
    // 3. 更新阶段：融合预测值与测量值
    // 新的最优估计 = 旧预测值 + 增益 * (测量值 - 旧预测值)
    kf->x = kf->x + k * (measurement - kf->x);
    
    // 4. 更新误差协方差，供下一次循环使用
    kf->p = (1.0f - k) * kf->p;
    
    return kf->x;
}

```

### 如何在主程序中使用？

```c
KalmanFilter1D my_filter;

void setup() {
    // 假设第一次读取到的传感器值为 50.0
    // Q = 0.01 (认为真实温度变化很慢)
    // R = 0.5 (认为传感器读数容易上下跳动 0.5 的幅度)
    Kalman1D_Init(&my_filter, 50.0f, 0.01f, 0.5f); 
}

void loop() {
    float raw_data = Read_Sensor(); // 读取传感器原始毛刺数据
    
    // 送入卡尔曼滤波，得到平滑结果
    float filtered_data = Kalman1D_Update(&my_filter, raw_data); 
    
    // 使用 filtered_data 进行后续控制...
}

```

## 3. 怎么调参（如何定 $Q$ 和 $R$）？

用好一维卡尔曼滤波，**90% 的工作在于调 $Q$ 和 $R$ 这两个参数的比例关系。**

* **$R$（测量噪声）：看传感器手册或实际测试。**
如果你把传感器静止放在那里，读数在 $10.0$ 到 $11.0$ 之间乱跳，说明底噪大概是 $1.0$左右。你可以把 $R$ 设为 $1.0$ 或者 $0.5$。**$R$ 越大，滤波越平滑，但响应越慢。**
* **$Q$（过程噪声）：看你要测量的东西变化有多快。**
如果你测的是室温，一分钟也变不了一度，那真实世界的波动极小，$Q$ 就可以设得非常小（比如 $0.001$）。如果你测的是摇杆，人手随时会快速拨动，$Q$ 就要设大一点（比如 $0.1$）。**$Q$ 越大，系统越倾向于相信新测到的数据，响应越快，但波形容易有毛刺。**

**调参口诀：** 先固定 $R$（根据传感器底噪估算一个值，比如 $0.1$），然后慢慢调 $Q$。想要平滑就减小 $Q$，想要跟手（响应快）就增大 $Q$。

想要加强卡尔曼滤波的平滑效果（把毛刺彻底抹平），核心逻辑就是：**让算法更“不信任”传感器当前的读数，而更“偏执地相信”之前的平稳状态。**

在代码中，这完全由 $Q$（过程噪声）和 $R$（测量噪声）的**比例**来决定。

## 调参的两把板斧

为了达到更强的滤波效果，你可以做以下两件事（任选其一或同时使用）：

1. **调大 $R$（测量噪声）：**
这相当于告诉系统：“我的传感器非常不稳定，总是乱跳。” $R$ 越大，系统计算出的卡尔曼增益就会越小，新读取的数据权重就越低。
2. **调小 $Q$（过程噪声）：**
这相当于告诉系统：“我正在测量的这个东西（比如温度、水箱液位）在物理现实中变化得极其缓慢，绝对不可能发生瞬间突变。” $Q$ 越小，系统就越倾向于维持上一次的预测值。

## 实用调参公式（固定一个，调另一个）

新手调参最忌讳两个参数一起瞎改。建议**固定 $R$，只调 $Q$**，因为它们本质上是比例关系。

假设你将 $R$ 固定为 `1.0`，你可以像拧收音机旋钮一样，慢慢把 $Q$ 往下调：

* **轻度滤波：** $Q = 0.1$ （跟手，反应快，但还有点微弱毛刺）
* **中度滤波：** $Q = 0.01$ （平滑度明显提升，有轻微滞后感）
* **重度滤波（你要的加强版）：** $Q = 0.001$ （极其平滑，波形像直线一样顺滑，但会有明显的“慢半拍”现象）
* **极端滤波：** $Q = 0.0001$ （彻底变“迟钝”，只适合测量一天才变几度的环境温度）

你可以直接在代码的初始化里修改这两个值试试看：

```c
// 原来的可能比较灵敏：
Kalman1D_Init(&my_filter, init_val, 0.01f, 0.5f); 

// 加强滤波后的版本 (把 Q 缩小了 10 倍，或者把 R 放大了)：
Kalman1D_Init(&my_filter, init_val, 0.001f, 0.5f); 

```

## ⚠️ 无法违背的物理定律：延迟代价

当你把 $Q$ 调得很小、加强了滤波效果后，你一定会发现一个现象：**系统变“肉”了（相位延迟）**。

如果你猛地拨动一下传感器，由于算法极度不信任新数据，它需要经过几十次循环才会慢慢爬升到真实值。

**专家建议：**
如果加强滤波后，延迟大到你无法接受，这就说明单靠纯数学滤波已经到了瓶颈。你需要像之前提到的那样，结合“限幅滤波（剔除突变大毛刺） + 适当参数的卡尔曼滤波”，才能兼顾“极其平滑”与“不那么迟钝”。
